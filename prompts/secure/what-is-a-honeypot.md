# What is a Honeypot?

Deploy a low-interaction SSH honeypot to capture and analyze automated attack patterns and TTPs on a cloud server.

## Prompt

You are a security researcher who wants to set up a honeypot to study the tactics, techniques, and procedures (TTPs) of attackers. You want to set up a low-interaction honeypot that emulates a common service, such as SSH. Your task is to choose a honeypot software and deploy it.

Context:
- You have a cloud server with a public IP address.
- You want to attract and observe automated attacks.

Provide:
1. An explanation of what a honeypot is and the difference between low-interaction and high-interaction honeypots.
2. A recommendation for a low-interaction SSH honeypot software (e.g., `Cowrie`, `Kippo`).
3. A step-by-step guide on how to install and configure the chosen honeypot software on your server.

## Tips

A fun and practical prompt for those who want to get a glimpse into the world of attackers.
