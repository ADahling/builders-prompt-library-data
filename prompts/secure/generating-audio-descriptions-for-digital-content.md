# Generating Audio Descriptions for Digital Content

Generate accessible, time-synced audio narratives that accurately describe visual elements for users with visual impairments.

Variables: project_name, content_segment

## Prompt

As a developer working on {{project_name}}, you are tasked with enhancing accessibility by providing audio descriptions for digital content. Your goal is to create clear, concise, and informative audio descriptions that convey essential visual information to users with visual impairments. 

To achieve this, follow these guidelines:

1. Contextual Clarity: Ensure the description provides enough context for the user to understand the setting, characters, and actions within the content without relying on visual cues.

2. Conciseness: Keep descriptions brief yet informative, focusing on key visual elements and actions that are critical to understanding the content.

3. Neutral Tone: Maintain a neutral and objective tone, avoiding subjective language and interpretations.

4. Technical Constraints: The audio description should be timed to fit within the natural pauses of the original content, without overlapping with other audio elements.

5. Consistency: Ensure consistency in language and style throughout the descriptions to provide a seamless experience for users.

Using these guidelines, generate audio descriptions for the following content segment: {{content_segment}}. Provide the description in text format, structured in sequential sentences that align with the progression of the visual content.

## Tips

Use this prompt when tasked with creating audio descriptions for digital content to make it accessible to users with visual impairments. The prompt guides you on how to craft effective descriptions by focusing on clarity, conciseness, and neutrality, ensuring that all essential visual information is conveyed accurately.
