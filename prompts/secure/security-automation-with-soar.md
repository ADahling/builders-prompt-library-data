# Security Automation with SOAR

Design a SOAR-based phishing response workflow to automate incident analysis, reputation checks, and containment via security integrations.

## Prompt

You are a senior security analyst in a SOC that is looking to improve its efficiency by automating incident response playbooks. You have been tasked with evaluating and implementing a Security Orchestration, Automation, and Response (SOAR) platform. Your first use case is to automate the response to a phishing email report.

Context:
- The SOC receives phishing reports from users via a dedicated email address.
- The current process is manual and slow.

Provide:
1. An explanation of what a SOAR platform is and how it can help automate incident response.
2. A high-level workflow for a SOAR playbook that automates the analysis of a reported phishing email. The playbook should include steps like extracting observables (e.g., URLs, attachments), checking their reputation, and taking an action (e.g., blocking the URL, deleting the email from other inboxes).
3. A list of the key integrations that the SOAR platform would need to have to implement this playbook (e.g., with the email provider, threat intelligence feeds, EDR solution).
