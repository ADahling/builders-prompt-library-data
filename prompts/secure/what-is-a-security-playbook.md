# What is a Security Playbook?

Generate a comprehensive malware incident response playbook with step-by-step EDR procedures to standardize SOC detection and recovery.

## Prompt

You are a security analyst in a SOC who has been tasked with creating a new security playbook for a common incident type: a malware infection on an employee's laptop. Your task is to write this playbook.

Context:
- The SOC uses an EDR solution to detect and respond to malware.
- The playbook should be a step-by-step guide for a junior analyst to follow.

Provide:
1. An explanation of what a security playbook (or runbook) is and why it is important for a SOC.
2. A security playbook for a malware incident, with clear sections for each phase of the incident response process: preparation, identification, containment, eradication, recovery, and lessons learned.
3. For each step in the playbook, specify the action to be taken and the tool to be used.

## Tips

A practical prompt for security operations teams on how to standardize and improve their incident response process.
