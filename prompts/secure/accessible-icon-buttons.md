# Accessible Icon Buttons

Write icon button markup with clear, concise aria-label descriptions for application buttons that use icons instead of visible text.

Variables: description

## Prompt

Ensure that icon buttons in your application have accessible labels. Use the format '<button aria-label='{{description}}'> <i class='{iconClass}'></i></button>' and make sure the description is clear and concise.

## Tips

Proper labeling of icon buttons improves accessibility.
