# Check for Cross-Site Scripting (XSS) Vulnerabilities

Review a frontend component for potential XSS vulnerabilities, with a list of input injection areas and sanitization and validation measures.

Variables: frontend_component

## Prompt

Analyze the {{frontend_component}} of your web application for potential Cross-Site Scripting (XSS) vulnerabilities. Provide a list of areas where user input can be injected and detail measures to sanitize and validate input.

## Tips

XSS is a common vulnerability; ensuring input sanitization is crucial.
