# Ensuring Accessibility in Web Forms

Implement WCAG 2.1 AA standards in web forms by optimizing labels, keyboard navigation, error handling, and color contrast.

Variables: project_name, tech_stack

## Prompt

As a web developer, your task is to enhance the accessibility of a web form for the project {{project_name}}. This form is built using {{tech_stack}} and is intended for a diverse audience, including users with disabilities. The form should comply with the WCAG 2.1 AA standards. The key areas to address include: 

1. **Labeling**: Ensure all form fields have appropriate labels using the <label> HTML tag and the 'for' attribute. Provide examples of both visible and aria-labels for screen readers.

2. **Keyboard Navigation**: Confirm that the form can be navigated using only a keyboard. This includes ensuring logical tab order and focus states.

3. **Error Handling**: Implement error messages that are both visible and announced by screen readers. Describe how to use aria-live regions to achieve this.

4. **Color Contrast**: Validate that the color contrast between text and background meets WCAG 2.1 AA guidelines.

Please provide a step-by-step guide, including code snippets and best practices, to achieve these accessibility improvements. Ensure that your recommendations consider both technical implementation and user experience aspects.

## Tips

Use this prompt when you need to improve the accessibility of web forms, ensuring they are usable by individuals with disabilities. This prompt guides developers through critical accessibility features, adhering to WCAG standards, and provides a comprehensive approach to making web forms inclusive.
