# Beginner's Guide to Optimizing Websites for Screen Readers

Review website screen reader accessibility with HTML and ARIA guidance, alt text examples, navigation advice, and testing tools for your stack.

Variables: tech_stack

## Prompt

You are tasked with ensuring that a website is accessible and optimized for screen readers. This is critical for improving accessibility for users with visual impairments. The website is built using {{tech_stack}}, and your goal is to identify and implement improvements. Please follow these steps: 

1. Identify and list common accessibility issues that affect screen reader compatibility. 
2. Review the website's existing HTML structure, focusing on semantic elements and ARIA (Accessible Rich Internet Applications) roles. Suggest improvements.
3. Explain how to use alt attributes effectively for images and provide examples based on fictional image descriptions.
4. Discuss best practices for organizing content and navigation to enhance screen reader usability.
5. Offer guidance on testing the site with popular screen readers, such as JAWS or NVDA, and recommend freely available tools or browser plugins.

Constraints: Ensure your recommendations are applicable to {{tech_stack}}. Provide code snippets or examples where applicable to illustrate your suggestions.

Output Format: 
- "Accessibility Issues": List of issues.
- "HTML and ARIA Improvements": Detailed description with code examples.
- "Image Descriptions": Examples of effective alt text.
- "Content Organization": Best practices.
- "Testing Guidance": Recommended tools and methods.

## Tips

Use this prompt when you need to make a website more accessible for users who rely on screen readers. It guides the developer through identifying common issues, improving HTML and ARIA usage, and testing with screen readers. Suitable for projects built on various tech stacks.
