# What is a Security Culture?

Develop a strategic plan to transform organizational security culture from compliance-based to proactive through creative initiatives.

## Prompt

You are a CISO who wants to improve the security culture in your organization. You believe that security is everyone's responsibility, not just the security team's. Your task is to create a plan to foster a strong security culture.

Context:
- The organization has a traditional, compliance-focused approach to security.
- Employees often see security as a blocker.

Provide:
1. An explanation of what a strong security culture is and why it is important for an organization.
2. A plan with at least three initiatives to improve the security culture. The initiatives should be creative and engaging, and they should target different levels of the organization. Examples could include a security champions program, a security awareness fair, or a 'security hero' award.
3. A list of metrics to measure the effectiveness of your security culture program.

## Tips

A strategic prompt for security leaders on how to build a more security-conscious organization.
