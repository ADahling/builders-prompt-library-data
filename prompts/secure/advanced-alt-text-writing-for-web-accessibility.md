# Advanced Alt Text Writing for Web Accessibility

Generate context-aware, accessible alt text for web images to improve screen reader compatibility and SEO while maintaining concise clarity.

Variables: website_name, image_description

## Prompt

You are tasked with writing advanced alt text descriptions for images used in the {{website_name}} project. The goal is to ensure full web accessibility compliance, particularly for users who rely on screen readers. Please consider the following requirements and constraints:

1. **Contextual Relevance**: Ensure that each alt text provides context relevant to the image's placement on the page. Describe the image in a way that complements the surrounding content. 

2. **Conciseness and Clarity**: While the description should be detailed, avoid unnecessary verbosity. Use clear and succinct language to convey the necessary details.

3. **Functional Information**: If the image serves a functional purpose (e.g., a button or a link), ensure the alt text describes its functionality (e.g., 'submit form button' or 'link to homepage').

4. **Avoid Redundancy**: Do not repeat information that is already conveyed in the text adjacent to the image. The alt text should add value rather than duplicate existing content.

5. **Semantic Meaning**: Consider the semantic meaning of the image and its role in the content to craft a meaningful description.

6. **Cultural Sensitivity**: Be mindful of cultural context and sensitivity when describing images that may have cultural significance.

Provide alt text for the following image: {{image_description}}. Ensure it meets all the guidelines listed above.

Output format:
- **Image Description**: [Detailed alt text here]

## Tips

Use this prompt when developing web content that requires accessibility compliance. It is particularly useful for web developers, content creators, and UX designers who need to ensure their images are accessible to all users, including those using assistive technologies. This prompt helps generate alt text that is not only compliant but also contextually relevant and functional.
