# Cognitive Accessibility Improvements

Get a structured plan for making complex web content more cognitively accessible through simpler language, headings, and visual aids.

## Prompt

Devise a plan to improve cognitive accessibility on a web page containing complex content like {contentType}. Include techniques such as simplifying language, using headings effectively, and adding visual aids. Document the changes in a structured format, for example: '1. Use simpler language; 2. Break content into smaller, manageable sections; 3. Add images or icons to support understanding.'

## Tips

This helps to make complex information easier to understand for users with cognitive disabilities.
