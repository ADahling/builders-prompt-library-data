# Create ARIA-Labeled Widgets

Design ARIA-labeled interactive widgets such as sliders and date pickers, with role attributes and appropriate label examples.

Variables: value, label

## Prompt

Design ARIA-labeled widgets for interactive elements such as sliders or date pickers. Use the format '<div role='slider' aria-valuenow='{{value}}' aria-label='{{label}}'>' to make them accessible. Provide examples of labels that would be appropriate for each widget.

## Tips

Labels enhance the usability of interactive components.
