# Security Information and Event Management (SIEM)

Develop and document custom SIEM correlation rules to detect anomalous geographic authentication patterns and establish incident response plans.

Variables: siem_product

## Prompt

You are a security analyst in a Security Operations Center (SOC). Your main tool is a Security Information and Event Management (SIEM) system. You have been tasked with creating a new correlation rule to detect a specific type of attack: a user logging in from multiple countries in a short period of time.

Context:
- The SIEM you are using is `{{siem_product}}` (e.g., Splunk, QRadar, Elastic SIEM).
- The log sources include firewall logs, VPN logs, and application logs.

Provide:
1. The pseudo-code or the specific query for the correlation rule that will detect this suspicious activity.
2. An explanation of the logic behind the rule.
3. A plan for how to respond to an alert generated by this rule, including the steps to investigate the incident and determine if it is a true positive.
