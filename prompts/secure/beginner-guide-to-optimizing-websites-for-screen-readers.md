# Beginner Guide to Optimizing Websites for Screen Readers

Develop a structured action plan to improve website accessibility for screen reader users through semantic HTML, ARIA, and keyboard testing.

## Prompt

You are tasked with optimizing a website to ensure it is accessible to users who rely on screen readers. This involves improving the user experience for those who may have visual impairments. Use the following guidelines and constraints to create an action plan:

1. **Semantic HTML**: Ensure all HTML elements are used appropriately. Replace generic `<div>` and `<span>` tags with more descriptive elements like `<header>`, `<nav>`, `<main>`, `<section>`, and `<article>` where applicable.

2. **ARIA Roles and Attributes**: Implement ARIA (Accessible Rich Internet Applications) roles and attributes to provide additional context to screen readers. Use ARIA roles only when standard HTML elements cannot convey the necessary information.

3. **Alt Text for Images**: Make sure all images have descriptive `alt` attributes that convey the purpose or content of the image. If an image is purely decorative, use an empty `alt` attribute.

4. **Keyboard Navigation**: Ensure that all interactive elements are accessible via keyboard alone. Check that users can navigate through the site using the `Tab` key and activate elements using the `Enter` key.

5. **Form Labels and Instructions**: Ensure all form fields have associated `<label>` elements. Provide clear instructions and error messages that can be read by screen readers.

6. **Headings and Landmarks**: Use headings (`<h1>` to `<h6>`) to create a logical structure. Ensure headings are hierarchical and not used for styling purposes only.

7. **Testing**: Use screen reader software such as NVDA (Windows) or VoiceOver (Mac) to test the website’s accessibility. Identify and address any issues that arise during these tests.

Please format your action plan as a numbered list, detailing specific steps and tools you would use for each task. Include any additional considerations you believe are relevant to this optimization task.

## Tips

Use this prompt when you're beginning to learn about web accessibility and want to ensure a website is optimized for screen reader users. It provides a structured approach to implementing basic accessibility features and offers guidance on testing and refining your work using screen reader software.
