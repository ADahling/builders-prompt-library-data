# Create Accessible Image Galleries

Get a code snippet for an accessible image gallery with descriptive alt text and arrow-key navigation for keyboard users.

## Prompt

Develop an image gallery with accessibility in mind. Each image should have associated alt text that describes the image. Implement keyboard navigation to allow users to navigate through the gallery using arrow keys. Provide a code snippet that outlines your implementation.

## Tips

Accessible galleries allow all users to enjoy visual content.
