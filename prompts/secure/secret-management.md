# Manage secrets safely

Design a secrets management plan covering storage, access, rotation, revocation, CI, incident response, and migration from hardcoded secrets.

## Prompt

Design a secrets-management plan for {{system}}. Inventory secret classes, storage locations, runtime access, least privilege, rotation, revocation, logging exclusions, local development, CI, and incident response. Include a migration plan for any hardcoded secrets.
