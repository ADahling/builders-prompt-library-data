# Password Hashing vs. Encryption

Learn to secure user authentication systems by implementing robust one-way hashing algorithms over reversible encryption.

## Prompt

You are a junior developer who is confused about the difference between hashing and encrypting passwords. You need to understand why passwords should be hashed, not encrypted. Your task is to research and explain the difference.

Context:
- You are building a user authentication system.
- You need to decide how to store user passwords in the database.

Provide:
1. A clear explanation of the difference between hashing and encryption.
2. An explanation of why hashing is the appropriate method for storing passwords.
3. A recommendation for a strong password hashing algorithm (e.g., bcrypt, Argon2).

## Tips

A fundamental concept for any developer building systems with user accounts.
