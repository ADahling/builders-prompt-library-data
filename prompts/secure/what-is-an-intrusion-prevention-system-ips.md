# What is an Intrusion Prevention System (IPS)?

Design a strategic deployment plan for upgrading network security from passive detection to active automated threat prevention.

## Prompt

You are a network security engineer who is responsible for protecting your company's network from attacks. You have an Intrusion Detection System (IDS) in place, but you want to be able to automatically block malicious traffic. You have decided to upgrade to an Intrusion Prevention System (IPS). Your task is to explain the difference between an IDS and an IPS and to plan the deployment of an IPS.

Context:
- Your company has a high-speed internet connection and cannot tolerate any significant latency.
- You are concerned about the risk of the IPS blocking legitimate traffic (false positives).

Provide:
1. A clear explanation of the difference between an IDS and an IPS, including the pros and cons of each.
2. A plan for deploying the IPS. This should include whether to deploy it in-line or out-of-band, and how to initially run it in a non-blocking mode to monitor for false positives.
3. A list of the key metrics you will use to evaluate the performance and effectiveness of the IPS.
