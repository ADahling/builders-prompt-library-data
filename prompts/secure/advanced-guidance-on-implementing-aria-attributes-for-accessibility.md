# Advanced Guidance on Implementing ARIA Attributes for Accessibility

Generate a structured implementation plan for ARIA attributes to enhance web accessibility while maintaining semantic HTML and UX standards.

Variables: project_name, tech_stack

## Prompt

You are working on enhancing the accessibility of a web application, {{project_name}}, which utilizes a complex user interface built with {{tech_stack}}. The goal is to ensure that all interactive elements are accessible to screen readers and other assistive technologies by implementing appropriate ARIA (Accessible Rich Internet Applications) attributes. 

Please provide a detailed plan for the integration of ARIA attributes across the interface. Include explanations of why specific attributes are necessary, how they improve accessibility, and any potential pitfalls or common mistakes to avoid. Consider the following aspects in your guidance:

1. Identification of interactive elements and their roles (e.g., buttons, menus, dialogs).
2. Recommendations for using ARIA roles, states, and properties to enhance accessibility.
3. How to maintain semantic HTML while using ARIA attributes.
4. Strategies for testing the accessibility improvements with screen readers.
5. Best practices for maintaining ARIA attributes during future updates.

Output your response as a structured plan in JSON format with sections for 'Overview', 'Element Analysis', 'ARIA Implementation', 'Testing Strategies', and 'Maintenance Recommendations'.

## Tips

Use this prompt when you need to integrate or audit ARIA attributes in a web application to ensure it meets accessibility standards. This is ideal for developers looking to deepen their understanding and application of ARIA in complex interfaces, ensuring inclusive user experiences.
