# Designing Keyboard Navigation for Web Applications

Establish an accessible, WCAG-compliant keyboard navigation scheme with defined shortcuts, focus states, and a usability testing plan.

Variables: app_name, tech_stack, feature_1, feature_2, feature_3

## Prompt

You are tasked with designing an intuitive keyboard navigation scheme for a web application named {{app_name}}. The application is developed using {{tech_stack}} and includes features such as {{feature_1}}, {{feature_2}}, and {{feature_3}}. The goal is to enhance accessibility and improve user experience for keyboard-only users. 

Please follow these guidelines:

1. **Identify Key Functions**: List all critical functions and features in the application that users need to navigate using a keyboard.

2. **Define Navigation Shortcuts**: Propose keyboard shortcuts for each identified function. Ensure that shortcuts are intuitive and do not conflict with common browser shortcuts.

3. **Accessibility Compliance**: Ensure that the navigation scheme complies with WCAG 2.1 guidelines for accessibility. Include tab order, focus indicators, and ARIA roles where necessary.

4. **Usability Testing**: Outline a plan for testing the keyboard navigation with real users, focusing on ease of use and efficiency.

5. **Documentation**: Provide detailed documentation for developers and users explaining how the keyboard navigation works, including a list of all shortcuts.

Output your response in the following format:

- **Key Functions**: A list of functions with brief descriptions.
- **Keyboard Shortcuts**: A table of functions with corresponding shortcuts.
- **Accessibility Features**: A summary of how WCAG 2.1 is addressed.
- **Testing Plan**: A step-by-step plan for usability testing.
- **Documentation Summary**: Key points that should be included in user and developer guides.

## Tips

Use this prompt when you need to establish or refine keyboard navigation for a web application to improve accessibility and user experience for keyboard-only users. It helps ensure compliance with accessibility standards and provides a structured approach to designing, implementing, and documenting keyboard navigation features.
