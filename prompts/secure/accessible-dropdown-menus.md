# Accessible Dropdown Menus

Get a dropdown menu code example with ARIA roles and keyboard controls that open the menu on Enter and close it on Escape.

## Prompt

Create an accessible dropdown menu that can be navigated using the keyboard. Ensure that the dropdown opens on 'Enter' and closes on 'Escape'. Use ARIA roles for the menu and menu items. Provide a code example to illustrate your implementation.

## Tips

Dropdown menus need to be navigable for users with disabilities.
