# Enhancing Keyboard Navigation for Web Applications

Implement WCAG-compliant keyboard navigation and focus management for complex web components using tactical accessibility strategies.

Variables: tech_stack

## Prompt

You are tasked with improving the keyboard navigation experience for a web application, ensuring it is fully accessible and user-friendly. Please consider the following requirements and constraints as you design the navigation system:

1. **Project Context**: The application is built using {{tech_stack}}, and it includes complex components such as modals, dropdowns, and dynamic lists. 

2. **Accessibility Standards**: Ensure compliance with WCAG 2.1 guidelines, focusing on keyboard accessibility for users with disabilities.

3. **Navigation Flow**: Define a logical tab order that follows the visual layout of the application. Ensure that all interactive elements are reachable via keyboard.

4. **Focus Management**: Implement focus states that are visually distinct to help users track their position on the page.

5. **Special Features**: Provide shortcuts for frequently used actions and ensure that custom components (e.g., custom dropdowns) are accessible via keyboard.

6. **Browser Compatibility**: The solution must work across all modern browsers.

7. **Testing**: Outline a testing strategy to ensure all components are accessible and function as expected.

Provide a detailed plan that includes code snippets, libraries, or tools you will use to implement these features.

## Tips

Use this prompt when tasked with enhancing or creating keyboard navigation systems for web applications. It guides developers through accessibility standards and practical implementation steps, ensuring a comprehensive approach to improving user experience for keyboard-only users.
