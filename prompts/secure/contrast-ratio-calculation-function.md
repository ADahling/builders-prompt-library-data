# Contrast Ratio Calculation Function

Write a JavaScript color contrast function using the specified formula and typed signature, returning a ratio and reporting WCAG compliance.

## Prompt

Create a JavaScript function to calculate the contrast ratio between two colors using the formula: 'L1 = (0.2126 * R1 + 0.7152 * G1 + 0.0722 * B1) / 255' and return the ratio. Use the format 'function calculateContrast(color1: string, color2: string): number { ... }'. Ensure the function reports if the colors meet WCAG standards.

## Tips

Calculating contrast ratios is crucial for ensuring text is readable.
