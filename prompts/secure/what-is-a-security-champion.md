# What is a Security Champion?

Generate a compelling business case and roadmap to launch a Security Champions program that scales security expertise across engineering teams.

Variables: number_of_developers, number_of_security_engineers

## Prompt

You are a security manager who wants to scale your security team's efforts by creating a security champions program. You need to create a presentation to convince your engineering leadership to support this program. Your task is to create the content for this presentation.

Context:
- The engineering organization has `{{number_of_developers}}` developers, and the security team has only `{{number_of_security_engineers}}` engineers.
- The goal of the program is to embed security expertise within the development teams.

Provide:
1. A clear definition of a security champion and their role in a development team.
2. A list of the key benefits of a security champions program for the organization (e.g., improved security posture, faster development, better security culture).
3. A plan for how to select, train, and motivate the security champions.

## Tips

A strategic prompt for security leaders on how to scale their security efforts and build a better security culture.
