# What is a Zero-Trust Architecture?

Design a high-level zero-trust security framework for hybrid environments to ensure secure, identity-based access across all devices.

## Prompt

You are a network security architect who is designing a new security architecture for your company. You have decided to adopt a zero-trust model. Your task is to create a high-level design for a zero-trust architecture.

Context:
- The company has a mix of on-premise and cloud-based applications.
- Employees need to be able to access applications from anywhere, on any device.

Provide:
1. An explanation of the core principles of a zero-trust architecture (e.g., 'never trust, always verify', least privilege access, micro-segmentation).
2. A high-level architecture diagram that shows the key components of a zero-trust architecture, such as an identity provider, a device management solution, an access proxy, and a policy engine.
3. A description of how a user would access an application in this zero-trust architecture, highlighting the key security checks that would be performed.

## Tips

A strategic and forward-looking prompt that deals with a modern approach to network security.
