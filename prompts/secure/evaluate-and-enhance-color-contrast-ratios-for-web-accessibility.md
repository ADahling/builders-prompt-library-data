# Evaluate and Enhance Color Contrast Ratios for Web Accessibility

Audit web color palettes for WCAG 2.1 accessibility compliance and generate compliant hexadecimal alternatives for failing contrast ratios.

Variables: project_name

## Prompt

You are working on a web development project called {{project_name}}. Your task is to ensure that the color contrast ratios for the text and background combinations used in your project comply with the Web Content Accessibility Guidelines (WCAG) 2.1 standards. Specifically, you need to achieve a minimum contrast ratio of 4.5:1 for normal text and 3:1 for large text. The color values are provided in hexadecimal format. Your task is to:

1. Identify and list all the text and background color combinations used in the project.
2. Calculate the contrast ratio for each combination.
3. Suggest alternative color combinations for any that do not meet the required contrast ratio.
4. Present your findings in a table format with the following columns: Text Color, Background Color, Current Contrast Ratio, Meets WCAG Standards (Yes/No), Suggested Text Color, Suggested Background Color.

Ensure your response includes all combinations and suggestions for compliance with accessibility standards.

## Tips

Use this prompt during the web development process to ensure your project's color schemes are accessible to users with visual impairments. This prompt will help identify any non-compliant color contrast ratios and provide suggestions for improvement, ensuring compliance with WCAG 2.1 standards.
