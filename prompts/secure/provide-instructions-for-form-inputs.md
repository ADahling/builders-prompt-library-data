# Provide Instructions for Form Inputs

Write concise, visible HTML label instructions with examples for complex form inputs that need clearer entry guidance.

Variables: example

## Prompt

Add concise instructions for complex form inputs, such as {inputType}. Use the format '<label for='inputId'>Enter {inputType} (e.g., {{example}}):</label>' to provide clarity. Ensure the instructions are visible and understandable.

## Tips

Helpful instructions can enhance comprehension for all users.
