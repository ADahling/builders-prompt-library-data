# What is a Security Mindset?

Mentor a junior developer on adopting a security mindset by explaining core concepts, providing a login-threat exercise, and listing code audits.

## Prompt

You are a senior developer who is mentoring a junior developer. You want to help them develop a 'security mindset'. Your task is to explain what a security mindset is and to give them a simple exercise to practice it.

Context:
- The junior developer is working on a new feature for a web application.
- You want to encourage them to think about security from the beginning of the development process.

Provide:
1. A simple and relatable explanation of what a security mindset is (e.g., thinking like an attacker, questioning assumptions, considering how things can be abused).
2. A simple exercise for the junior developer. For example, ask them to look at a simple login form and list all the ways an attacker might try to break it or bypass it.
3. A list of a few key questions that a developer with a security mindset should ask themselves when they are writing code.

## Tips

A great prompt for cultivating a security culture and encouraging developers to take ownership of security.
