# Secure SDLC: Integrating Security into the Development Lifecycle

Embed security controls into agile workflows to build resilient software faster without compromising development velocity or release cycles.

Variables: agile_framework

## Prompt

You are a security manager who wants to implement a Secure Software Development Lifecycle (SDLC) in your organization. The current development process is agile, but security is often an afterthought. Your task is to create a plan to integrate security activities into each phase of the SDLC.

Context:
- The organization uses the `{{agile_framework}}` (e.g., Scrum, Kanban).
- The development teams are primarily focused on shipping features quickly.

Provide:
1. A mapping of security activities to each phase of the agile SDLC (e.g., threat modeling in the design phase, static analysis in the development phase, penetration testing in the testing phase).
2. A proposal for how to introduce these activities without significantly slowing down the development process.
3. A list of metrics to measure the effectiveness of the Secure SDLC program.
