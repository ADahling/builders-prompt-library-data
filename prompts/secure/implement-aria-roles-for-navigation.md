# Implement ARIA Roles for Navigation

Get a React navigation menu refactor with ARIA roles and properties, while maintaining keyboard navigation for your menu links.

## Prompt

Refactor a navigation menu in your React application to include appropriate ARIA roles and properties. For a menu with links to {menuItems}, add roles such as 'navigation', 'menu', and 'menuitem'. Ensure proper keyboard navigation is also maintained. Use the React component structure while implementing ARIA attributes: '<nav role='navigation'> <ul role='menu'>...</ul></nav>'.

## Tips

This is important for making navigation accessible to assistive technologies.
