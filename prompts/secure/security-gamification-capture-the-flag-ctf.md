# Security Gamification: Capture the Flag (CTF)

Generate a web security CTF challenge featuring a vulnerable SQL injection scenario, code snippet, and participant hints to train developers.

## Prompt

You are a security trainer who wants to organize a Capture the Flag (CTF) competition for your company's developers to make security training more engaging. You need to create a simple web security challenge for the CTF. The challenge will be a simple SQL injection vulnerability.

Context:
- The CTF will be hosted on a dedicated platform.
- The participants are developers with basic knowledge of web security.

Provide:
1. A description of the CTF challenge, including the scenario and the goal (i.e., what the flag is and how to find it).
2. A code snippet of the vulnerable PHP or Python web page that contains the SQL injection vulnerability.
3. A hint that you can provide to the participants if they get stuck.

## Tips

A fun and creative prompt for those interested in security education and gamification.
