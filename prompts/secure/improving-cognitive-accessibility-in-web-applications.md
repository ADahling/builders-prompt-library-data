# Improving Cognitive Accessibility in Web Applications

Generate a tailored accessibility report with actionable UI/UX improvements to reduce cognitive load for users with diverse learning needs.

Variables: application_name, brief_description_of_app_functionality, tech_stack

## Prompt

You are tasked with enhancing the cognitive accessibility of a web application, specifically aimed at users with cognitive disabilities. Your objective is to identify potential barriers and propose solutions that make the application more accessible. Consider elements such as navigation, content clarity, and user interface design. 

1. **Project Details**: The application is called {{application_name}} and involves {{brief_description_of_app_functionality}}. It is built using {{tech_stack}}.

2. **User Demographics**: Target users include individuals with cognitive disabilities, such as dyslexia, ADHD, or memory impairments.

3. **Current Challenges**: Briefly describe the known issues or areas in the application where users might face cognitive barriers.

4. **Output Requirements**:
   - Provide a list of at least five specific changes or improvements that can be implemented to enhance cognitive accessibility.
   - For each suggested change, include a brief explanation of how it addresses a specific cognitive barrier.
   - If applicable, reference any accessibility standards or guidelines, such as WCAG, that support your recommendations.

Ensure that your suggestions are practical and can be readily integrated into the current application setup. Consider aspects like visual design, interaction complexity, and content layout.

## Tips

Use this prompt when tasked with improving cognitive accessibility in web applications, especially for users with cognitive impairments. This prompt guides you in identifying barriers and creating actionable changes to enhance user experience.
