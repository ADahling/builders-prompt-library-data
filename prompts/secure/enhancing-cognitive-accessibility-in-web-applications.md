# Enhancing Cognitive Accessibility in Web Applications

Generate a comprehensive report with actionable strategies to simplify content, navigation, and design for improved cognitive accessibility.

Variables: app_description, main_features

## Prompt

You are a developer focused on improving the cognitive accessibility of a web application. Your task is to ensure that users with cognitive disabilities can interact with the application effectively. Given a brief overview of the application, {{app_description}}, and the main features it offers, {{main_features}}, follow these steps to enhance its cognitive accessibility:

1. **Content Simplification**: Analyze the existing content structure and suggest ways to simplify the language and layout. Focus on reducing cognitive load by using clear, concise language, and logical content organization.

2. **Navigation Improvements**: Evaluate the current navigation system. Propose enhancements that make navigation intuitive, such as using consistent labels, providing clear feedback, and allowing easy orientation within the site.

3. **Design Considerations**: Recommend design changes that support cognitive accessibility, such as using high-contrast colors, ample white space, and consistent iconography.

4. **Feedback Mechanisms**: Outline strategies to offer clear feedback to user actions, ensuring they understand the results of their interactions with the application.

5. **Testing and Validation**: Describe methods for testing cognitive accessibility, including involving users with cognitive disabilities in the testing process and using tools or guidelines like WCAG to validate changes.

Provide a structured report with your recommendations, including examples and references to current best practices in cognitive accessibility.

## Tips

Use this prompt when tasked with improving the cognitive accessibility of a web application. It guides the developer through a comprehensive process of evaluation and enhancement, focusing on content, navigation, design, and feedback mechanisms. Ideal for projects aiming to make digital experiences more inclusive and user-friendly for individuals with cognitive disabilities.
