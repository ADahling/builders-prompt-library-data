# Secure Software Development Lifecycle (SDLC) Policy

Generate a comprehensive Markdown-based Secure SDLC policy to integrate mandatory security controls across every stage of the development lifecycle.

Variables: company_name

## Prompt

You are a security architect responsible for defining and implementing a Secure Software Development Lifecycle (SDLC) policy for your organization, {{company_name}}. The goal is to integrate security into every phase of the development process, from design to deployment.

Create a comprehensive Secure SDLC policy document in Markdown. The policy should be applicable to all development teams in the organization.

The policy must include the following sections:

1.  **Introduction:** The purpose and scope of the policy.
2.  **Roles and Responsibilities:** The security responsibilities of developers, security engineers, and product managers.
3.  **Security Activities by Phase:**
    *   **Requirements:** How to define security requirements for new features and products.
    *   **Design:** The requirement to conduct threat modeling and security architecture reviews.
    *   **Implementation:** Secure coding standards, peer code reviews, and the use of SAST tools.
    *   **Testing:** The requirement for penetration testing and DAST.
    *   **Deployment:** Secure configuration and change management processes.
    *   **Maintenance:** Ongoing vulnerability management and incident response.
4.  **Training and Awareness:** The requirement for all developers to complete security training.
5.  **Compliance and Enforcement:** How compliance with the policy will be measured and enforced.

Your policy document should be a clear and actionable guide that will help your organization build more secure software.
