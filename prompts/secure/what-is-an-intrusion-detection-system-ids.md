# What is an Intrusion Detection System (IDS)?

Select and deploy an open-source network intrusion detection system to monitor suspicious traffic and improve network security.

## Prompt

You are a network administrator who wants to monitor your network for suspicious activity. You have decided to deploy an Intrusion Detection System (IDS). Your task is to choose an IDS and to deploy it in your network.

Context:
- Your network has a single connection to the internet.
- You are looking for a free and open-source network-based IDS (NIDS).

Provide:
1. An explanation of what an IDS is and the difference between a network-based IDS (NIDS) and a host-based IDS (HIDS).
2. A recommendation for a free and open-source NIDS (e.g., `Snort`, `Suricata`).
3. A high-level guide on how to deploy the chosen NIDS in your network. This should include where to place the sensor and how to configure it to monitor the traffic.
