# What is a Security Token?

Compare session cookies, JWTs, and API keys to select the most secure and efficient authentication method for a web application.

## Prompt

You are a developer who is learning about authentication and authorization. You are confused about the different types of security tokens, such as session cookies, JWTs, and API keys. Your task is to research and to explain the differences between these tokens.

Context:
- You are building a web application with a frontend and a backend.
- You need to decide which type of token to use for managing user sessions.

Provide:
1. A clear explanation of what a security token is and its purpose.
2. A comparison of session cookies, JWTs, and API keys. The comparison should cover how they work, where they are stored, and their pros and cons.
3. A recommendation on which type of token to use for your web application and why.

## Tips

A foundational concept for web developers, presented as a clear and structured comparison.
