# Color Contrast Checker

Build a utility function that checks contrast between two hex colors and returns a message about meeting WCAG AA or AAA standards.

## Prompt

Create a utility function that checks the color contrast ratio between two colors provided in hex format. The function should return a message indicating whether the contrast ratio meets WCAG AA or AAA standards. Use the format 'function checkContrast(color1: string, color2: string): string { ... }'.

## Tips

This is essential for ensuring text is readable against background colors.
