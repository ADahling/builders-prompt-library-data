# Enhancing Cognitive Accessibility for Web Applications

Optimize web application accessibility for users with cognitive disabilities through UI simplification, plain language, and WCAG alignment.

Variables: application_name

## Prompt

You are tasked with improving the cognitive accessibility of a web application, {{application_name}}, to ensure it is usable by individuals with cognitive disabilities. Your goal is to identify and implement strategies that enhance the user experience by making the application more understandable, navigable, and manageable. Consider the following steps to guide your process:

1. **User Interface Simplification**: Evaluate the current design of {{application_name}} and suggest modifications that simplify navigation and reduce cognitive load. Consider factors like layout, color contrast, and text size.

2. **Content Clarity**: Review the language used throughout the application. Provide recommendations for simplifying complex language, using plain language, and adding supportive visuals where necessary.

3. **Consistent Navigation**: Identify inconsistencies in navigation patterns and propose changes to create a uniform experience across the application.

4. **Feedback Mechanisms**: Suggest ways to implement clear and immediate feedback for user actions, helping users understand the results of their interactions.

5. **Error Prevention and Recovery**: Propose strategies for minimizing user errors and providing easy-to-follow recovery pathways when mistakes occur.

6. **Customizability**: Recommend features that allow users to customize their interaction with the application to better suit their cognitive needs.

Provide a detailed plan highlighting proposed changes, expected impact on user experience, and any potential challenges in implementation. Ensure your suggestions adhere to recognized web accessibility standards, such as WCAG, and aim to enhance the inclusivity of {{application_name}}.

## Tips

Use this prompt when you need to enhance the cognitive accessibility of a web application, ensuring compliance with accessibility standards and improving the overall user experience for individuals with cognitive disabilities. It is suitable for developers and UX designers looking to create more inclusive digital products.
