# WCAG 2.2 Compliance Evaluation and Improvement

Conduct a comprehensive WCAG 2.2 accessibility audit to identify non-compliance issues and develop a prioritized technical remediation plan.

Variables: website_name

## Prompt

You are tasked with ensuring that the website {{website_name}} is compliant with WCAG 2.2 standards. Your goal is to evaluate the current accessibility of the website and provide a comprehensive report on areas needing improvement. Follow these steps:

1. **Identify Key Areas**: Analyze the website's structure, content, and interactive elements to identify key areas for compliance, such as text alternatives, keyboard accessibility, and adaptable content.

2. **Evaluate Against WCAG 2.2 Guidelines**: Use the Web Content Accessibility Guidelines (WCAG) 2.2 as a benchmark to assess the website. Focus on principles such as Perceivable, Operable, Understandable, and Robust (POUR).

3. **Report Format**: Provide a structured report detailing:
   - Summary of current compliance status.
   - Specific non-compliant elements and corresponding WCAG 2.2 criteria.
   - Recommendations for compliance improvements, including technical implementations and design changes.
   - Prioritization of issues based on severity and user impact.

4. **Implementation Plan**: Suggest an action plan for implementing the recommended changes, including estimated timelines and resource requirements.

Constraints:
- Ensure that your evaluation covers all major pages and functionalities of the website.
- Use clear, professional language suitable for communication with both technical and non-technical stakeholders.

Output your findings in a detailed report format, ready for presentation to the development team and stakeholders.

## Tips

Use this prompt when you need to assess and improve the accessibility of a website to comply with WCAG 2.2 standards. This is ideal for accessibility experts, web developers, and UX designers involved in ensuring web accessibility and inclusivity.
