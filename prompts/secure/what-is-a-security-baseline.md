# What is a Security Baseline?

Define, list, and implement a foundational security hardening strategy to ensure consistent server configurations and continuous monitoring.

Variables: operating_system

## Prompt

You are a system administrator who is responsible for deploying a new fleet of servers. You want to ensure that all the servers are configured securely and consistently. You have decided to create a security baseline for the servers. Your task is to create a simple security baseline.

Context:
- The servers are all running `{{operating_system}}`.
- The servers will be used to host a web application.

Provide:
1. An explanation of what a security baseline (or hardening guide) is and why it is important.
2. A list of at least ten security settings that you would include in your security baseline for the operating system (e.g., disable unnecessary services, enforce strong password policies, configure a host-based firewall).
3. A plan for how to apply the security baseline to the new servers and how to monitor for any deviations from the baseline over time.

## Tips

A foundational security practice, presented as a practical task for system administrators.
