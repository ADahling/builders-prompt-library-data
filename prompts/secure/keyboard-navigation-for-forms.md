# Keyboard Navigation for Forms

Get a form keyboard navigation implementation using Tab and Shift + Tab, with visual focus indicators and the specified JavaScript structure.

## Prompt

Implement a keyboard navigation strategy for a form with the following fields: {fieldNames}. Ensure users can navigate through the form using the Tab key, and use Shift + Tab to navigate backwards. Additionally, provide visual focus indicators for each field. Use the structure 'document.querySelectorAll('input, select, textarea').forEach((element) => { ... });'.

## Tips

This helps make forms more accessible for keyboard users.
