# Screen Reader Optimization for Images

Build a TypeScript function that takes image elements and assigns context-based alt attributes for screen reader accessibility.

## Prompt

Create a function to improve screen reader accessibility for images in your web application. The function should take an array of image elements and ensure that each image has an appropriate alt attribute based on its context. For example, provide default alt text for decorative images or use a descriptive text for informative images. Use the format 'function optimizeImageAccessibility(images: HTMLImageElement[]): void { ... }'.

## Tips

This prompt helps ensure all images are accessible to screen reader users.
