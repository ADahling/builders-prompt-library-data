# What is a Security Control?

Define and categorize security controls with specific examples and integrated scenarios to master fundamental cybersecurity protection layers.

## Prompt

You are a security student who is learning about the different types of security controls. Your task is to research and to provide examples of the three main types of security controls: preventative, detective, and corrective.

Context:
- You are preparing for a security certification exam.
- You need to be able to differentiate between the different types of controls.

Provide:
1. A clear definition of each of the three types of security controls.
2. At least two examples of each type of control. For each example, you should explain how it works and why it belongs to that category.
3. A scenario that illustrates how the three types of controls can work together to protect an asset.
