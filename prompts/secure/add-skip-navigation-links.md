# Add Skip Navigation Links

Get skip navigation link markup and a matching main content ID so keyboard users can jump directly to a webpage's main content.

## Prompt

Implement skip navigation links at the top of your webpage to improve keyboard navigation. The links should allow users to skip directly to the main content. Use the format: '<a href='#main-content' class='skip-link'>Skip to main content</a>' and ensure the main content has an id of 'main-content'.

## Tips

This enhances the experience for users who rely on keyboard navigation.
