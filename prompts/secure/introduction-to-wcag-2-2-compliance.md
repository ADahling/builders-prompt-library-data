# Introduction to WCAG 2.2 Compliance

Implement WCAG 2.2 accessibility standards into a web project using a structured strategy, update summary, and testing tool recommendations.

Variables: project_name

## Prompt

You are tasked with ensuring that your web application, {{project_name}}, is compliant with WCAG 2.2 guidelines. WCAG (Web Content Accessibility Guidelines) is essential for making web content more accessible to people with disabilities. The goal is to adhere to the latest standards to provide an inclusive user experience. Please follow these steps:

1. **Understand the Basics**: Briefly summarize the key principles of WCAG 2.2, which include Perceivable, Operable, Understandable, and Robust (POUR).

2. **Identify Key Changes**: List and explain any significant updates introduced in version 2.2 compared to 2.1.

3. **Implementation Strategy**: Propose a strategy for integrating these guidelines into your existing project, {{project_name}}. Include a checklist of critical checkpoints to verify compliance.

4. **Testing Tools**: Recommend at least three tools or techniques to test the web application’s compliance with WCAG 2.2.

5. **Output Format**: Provide your response in a structured format, including sections for Introduction, Key Changes, Strategy, and Tools.

Ensure your response is clear and concise, suitable for a developer new to accessibility standards.

## Tips

This prompt is intended for developers new to web accessibility who need to ensure their project complies with the latest WCAG 2.2 standards. It focuses on understanding fundamental principles, identifying changes, and implementing practical strategies for compliance.
