# Guide to Implementing Basic Keyboard Navigation

Implement accessible keyboard navigation, focus management, and event handling within a specific tech stack through code and testing guides.

Variables: project_name, tech_stack

## Prompt

You are tasked with adding basic keyboard navigation to the user interface of your project, {{project_name}}. This involves enabling users to navigate through interactive elements using the keyboard, enhancing accessibility and efficiency. Please provide comprehensive guidance on how to achieve this using {{tech_stack}}. Include the following details: 

1. **Focus Management**: Explain how to manage focus between different elements (e.g., buttons, links, forms) and the importance of logical tab order.

2. **Event Handling**: Detail how to handle keyboard events such as 'Tab', 'Enter', and 'Arrow keys' to enhance navigation.

3. **Accessibility Considerations**: Describe best practices for ensuring your keyboard navigation is accessible to all users, including those who rely on assistive technologies.

4. **Example Code**: Provide example code snippets that illustrate how to implement keyboard navigation in a simple form or menu using {{tech_stack}}.

5. **Testing**: Offer guidance on how to test keyboard navigation functionality to ensure it works across different browsers and screen readers.

Please ensure that your instructions are clear and suitable for a developer who is new to implementing keyboard navigation. Assume basic knowledge of HTML, CSS, and JavaScript.

## Tips

Use this prompt when you need to implement or improve keyboard navigation in a web project, especially if you are a beginner or unfamiliar with accessibility standards. This will guide you through the process with practical examples and best practices.
