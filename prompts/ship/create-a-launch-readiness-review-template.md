# Create a Launch Readiness Review Template

Generate a comprehensive program management template to coordinate cross-functional status, mitigate risks, and confirm final launch approval.

## Prompt

You are a program manager. Create a template for a launch readiness review meeting. This is a meeting where all the teams involved in a launch present their status.

Instructions:
1. The template should have sections for each team (engineering, QA, product, etc.).
2. Each section should list the key deliverables and their status.
3. It should have a section for risks and mitigation plans.
4. It should have a clear agenda and a list of required attendees.

## Tips

A way to formalize and standardize the launch readiness process.
