# Create an Alerting Rule for High Error Rate

Get an error-rate alert rule for your app with a threshold, time window, tool setup instructions, and notification channels.

Variables: threshold, duration

## Prompt

Generate a detailed alerting rule for our application {appName} that triggers when the error rate exceeds {{threshold}} over a {{duration}}. Include setup instructions for integration with our alerting tool {alertTool} and specify notification channels like {channel1} and {channel2}.

## Tips

Ensure the alerts are actionable and minimize false positives.
