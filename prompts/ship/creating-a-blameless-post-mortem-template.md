# Creating a Blameless Post-Mortem Template

Generate a structured Markdown template for blameless post-mortems to identify root causes and preventive actions without assigning fault.

## Prompt

You are tasked with creating a blameless post-mortem template for your team to use after an incident has been resolved. The focus should be on identifying the root causes and learning from the incident without attributing blame to individuals. Include sections for Incident Summary, Timeline of Events, Root Cause Analysis, Impact Assessment, What Went Well, What Could Be Improved, and Action Items. Ensure each section includes guiding questions or prompts to help team members provide detailed and constructive input. Format your template in a structured markdown format, ready to be used in your team's documentation system.

## Tips

Use this prompt to develop a reusable template for incident analysis.
