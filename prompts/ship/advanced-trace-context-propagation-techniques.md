# Advanced Trace Context Propagation Techniques

Implement seamless multi-language tracing using OpenTelemetry across microservices, asynchronous queues, and complex distributed systems.

Variables: language1, language2, language3

## Prompt

You are tasked with ensuring reliable trace context propagation across multiple microservices written in different languages, including {{language1}}, {{language2}}, and {{language3}}. Describe the challenges associated with cross-language trace context propagation and outline advanced techniques to ensure seamless propagation. Include specific libraries or tools you would use for each language and any potential pitfalls to watch out for. Explain how you would test the trace context propagation to ensure there are no breaks or losses. Provide examples where possible of complex scenarios such as asynchronous processing or message queues.

## Tips

This prompt is for developers dealing with complex environments involving multiple programming languages.
