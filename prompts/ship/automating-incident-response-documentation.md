# Automating Incident Response Documentation

Get a script template that gathers logs, alerts, and metrics into incident reports, with manual input fields, integration guidance, and prerequisites.

Variables: monitoring_tool, logging_system

## Prompt

Design an automation script template that helps streamline the documentation process during an incident response. The script should automatically gather relevant logs, alerts, and metrics from your monitoring tools and format them into a standard incident report. Include placeholders for manual inputs such as incident summary and resolution steps. Provide a detailed explanation of how the script integrates with your existing tools (e.g., {{monitoring_tool}}, {{logging_system}}) and any prerequisites needed for implementation.
