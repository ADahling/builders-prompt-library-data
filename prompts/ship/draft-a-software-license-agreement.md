# Draft a Software License Agreement

Generate a professional software license agreement template and comparative guide to protect intellectual property and define usage terms.

## Prompt

You are a software developer who has created a new software program. Your task is to draft a software license agreement.

Context:
- The software license agreement is a legal document that gives users the right to use your software.
- It should cover the scope of the license, the license fee, and other important matters.

Provide:
1. A template for a software license agreement.
2. An explanation of the different types of software licenses (e.g., perpetual, subscription).

## Tips

A legal document that is used to license software.
