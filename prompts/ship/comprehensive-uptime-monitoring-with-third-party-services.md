# Comprehensive Uptime Monitoring with Third-Party Services

Plan third-party uptime monitoring for an application, including service selection, integration, alerts, dashboards, and incident processes.

Variables: project_name

## Prompt

Develop a comprehensive uptime monitoring solution using third-party services like Pingdom or UptimeRobot for a {{project_name}} application. Outline the following:

1. Criteria for choosing an appropriate third-party service.
2. Step-by-step integration instructions for the chosen service.
3. Configuration options for monitoring intervals, regions, and alerting mechanisms.
4. How to interpret and use the monitoring data to improve application reliability.
5. Integration with existing incident management processes.
6. Setting up dashboards for real-time monitoring and historical analysis.

The output should be a detailed implementation plan, complete with configuration screenshots and best practices for using third-party services effectively.

Useful for developers looking to leverage external tools for comprehensive uptime monitoring.
