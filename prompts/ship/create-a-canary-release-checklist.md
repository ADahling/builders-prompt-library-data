# Create a Canary Release Checklist

Generate a comprehensive canary release guide covering pre-deployment metrics, real-time monitoring criteria, and post-launch cleanup protocols.

## Prompt

You are a junior release engineer. Create a checklist of things to consider before, during, and after a canary release.

Instructions:
1. Pre-release: What metrics to monitor? What's the rollback plan?
2. During release: How to monitor the canary? What's the decision criteria for promotion?
3. Post-release: How to clean up the old version? How to communicate the results?
4. This checklist will serve as a guide for future canary releases.

## Tips

A good exercise for formalizing the process of canary releasing.
