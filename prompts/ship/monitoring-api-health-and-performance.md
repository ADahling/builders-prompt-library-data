# Monitoring API Health and Performance

Get an API monitoring guide for your app with metrics, tool setup, configuration examples, dashboards, alerts, and troubleshooting advice.

Variables: project_name, tech_stack

## Prompt

Develop a solution for monitoring the health and performance of APIs used in the {{project_name}} application. Your solution should include:

1. Metrics to track such as response time, error rate, and availability.
2. Tools or libraries suitable for API monitoring within the {{tech_stack}}.
3. Instructions for setting up and configuring these tools.
4. Methods to visualize API performance data with dashboards.
5. Strategies for setting performance thresholds and alerts.
6. Tips for diagnosing and resolving common API performance issues.

The output should be a comprehensive guide structured for developers to quickly implement effective API monitoring, complete with configuration examples and troubleshooting advice.

## Tips

Appropriate for developers needing to ensure API reliability and performance in their applications.
