# Create Alerts for Latency Issues

Plan latency alerts for your service with metrics to monitor and alert thresholds configured for your monitoring tool.

## Prompt

Develop a set of alerts for latency issues in our service {serviceName}. Specify the metrics to monitor, such as {latencyMetric} and set thresholds for alerts using {monitoringTool}.

## Tips

Latency can significantly affect user experience, so alerts should be timely.
