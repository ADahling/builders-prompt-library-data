# Create Actionable Alerting Playbooks

Generate standardized, step-by-step incident response guides to streamline troubleshooting and reduce mean time to resolution for on-call teams.

## Prompt

You are an SRE. For every alert your system can fire, you need to create a playbook that tells the on-call engineer what to do.

Instructions:
1. For a given alert (e.g., 'High CPU usage'), write a playbook.
2. The playbook should explain what the alert means.
3. It should provide a step-by-step guide for diagnosing the problem.
4. It should list common causes and their solutions.
5. It should link to relevant dashboards and logs.

## Tips

Playbooks reduce stress and mean time to resolution for on-call engineers.
