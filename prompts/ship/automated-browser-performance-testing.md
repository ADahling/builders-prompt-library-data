# Automated Browser Performance Testing

Set up browser performance tests for every deployment, with network conditions, KPI measurement, CI/CD integration, reporting, and troubleshooting.

Variables: website_url, testing_framework

## Prompt

Set up an automated browser performance testing framework for {{website_url}} using {{testing_framework}}. Your goal is to integrate continuous performance testing into the CI/CD pipeline. Define tests that measure key performance indicators (KPIs) such as load time, responsiveness, and resource usage under different network conditions. Ensure the tests are run on every deployment and that results are automatically logged and reported. Document the process of integrating these tests with the CI/CD pipeline, including any tools or plugins used. Provide troubleshooting tips for common issues encountered.

## Tips

This prompt is for developers with knowledge of CI/CD pipelines and automated testing frameworks.
