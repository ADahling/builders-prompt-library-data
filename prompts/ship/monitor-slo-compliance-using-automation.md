## Prompt

You need to set up an automated system for monitoring SLO compliance for an e-commerce website, {{website_name}}. Describe the process of integrating monitoring tools like Prometheus or DataDog to collect metrics relevant to your SLOs. Provide a step-by-step guide on setting up automation scripts and the necessary infrastructure to ensure continuous monitoring and alerting. Address potential challenges in maintaining the system and strategies for overcoming them.
