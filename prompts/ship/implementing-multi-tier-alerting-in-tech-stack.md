# Implementing Multi-Tier Alerting

Design critical, warning, and informational alerts for an app, with triggers, actions, team ownership, delivery, integrations, and review guidelines.

Variables: tech_stack

## Prompt

Design a multi-tier alerting system for an application built on {{tech_stack}}. Your task is to define three tiers of alerts: critical, warning, and informational. For each tier, specify the criteria that would trigger an alert, the appropriate response actions, and the responsible team. Consider how these alerts will be delivered (e.g., email, SMS, dashboard) and how they will integrate with existing incident management tools. Additionally, provide guidelines on how to regularly review and update alert criteria. Format your response as: 1) Critical Alerts, 2) Warning Alerts, 3) Informational Alerts, 4) Delivery and Integration, 5) Review and Update Processes.

## Tips

This prompt is useful for developers setting up a structured alert response system.
