# Draft an SLA for a Cloud Service

Draft a cloud service SLA covering availability, support, performance, issue reporting, compensation, legal considerations, and responsibilities.

Variables: service_provider_name

## Prompt

Draft a Service Level Agreement (SLA) for a cloud service provided by {{service_provider_name}}. The SLA should define the service availability, support response times, and performance metrics that customers can expect. Include the process for reporting and addressing service issues, and the compensation model in case of SLA violations. Ensure that the SLA is clear and understandable for non-technical stakeholders, while also being detailed enough to set precise expectations. Discuss the legal and compliance considerations that need to be taken into account when drafting this SLA. Provide a summary section that outlines the key commitments and responsibilities of both the service provider and the customer.
