# Visualizing Traces with Jaeger

Get local Jaeger setup and troubleshooting steps to connect an instrumented app, view traces, and identify bottlenecks or errors.

## Prompt

You have completed the instrumentation of a {{tech_stack}} application with distributed tracing data and need to visualize this data using Jaeger. Describe the steps required to set up Jaeger in a local development environment. Include instructions on configuring the connection between your application and Jaeger, and how to use Jaeger's UI to visualize traces. Explain how to interpret the visualized traces to identify performance bottlenecks or errors within the application. Provide troubleshooting tips for common issues that might arise when integrating Jaeger with your application.
