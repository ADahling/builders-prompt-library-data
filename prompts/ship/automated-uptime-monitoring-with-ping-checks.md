# Automated Uptime Monitoring with Ping Checks

Get an uptime monitoring guide with code, configuration, and deployment steps for periodic URL checks, structured logs, alerts, and summary reports.

## Prompt

Create a script or tool that automates uptime monitoring for a list of URLs using ping checks. The solution should:

1. Accept a list of URLs as input.
2. Periodically ping each URL to check for uptime.
3. Log response times and statuses in a structured format.
4. Generate alerts for any non-responsive URLs.
5. Include configuration options for alert thresholds and notification methods.
6. Provide a summary report of uptime statistics over a configurable time period.

Output the solution as a detailed guide with code samples, configuration files, and instructions for deploying and running the script or tool. Ensure the guide is accessible to developers with moderate scripting experience.

## Tips

This prompt guides developers in setting up basic uptime monitoring with customizable alerting.
