# Create a Data Processing Agreement (DPA) Template

Generate a GDPR-compliant Data Processing Agreement template featuring customizable placeholders for scope, security measures, and international transfers.

## Prompt

You are a legal consultant. Your task is to create a template for a Data Processing Agreement (DPA) that can be used with multiple clients.

Context:
- The DPA should be customizable for different data processing activities.
- It needs to be compliant with GDPR.

Provide:
1. A template with placeholders for the names of the data controller and data processor.
2. Sections for describing the scope of data processing, security measures, and sub-processors.
3. Standard contractual clauses for international data transfers.

## Tips

A reusable DPA template for B2B service providers.
