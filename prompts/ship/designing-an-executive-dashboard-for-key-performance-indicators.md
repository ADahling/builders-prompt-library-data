# Designing an Executive Dashboard for Key Performance Indicators

Get an executive KPI dashboard design document with wireframes, metric calculations, and data sources for non-technical stakeholders.

Variables: revenue_data, customer_satisfaction_data, efficiency_data

## Prompt

Create an executive-level dashboard that highlights key performance indicators (KPIs) for your organization. Focus on high-level metrics such as revenue, customer satisfaction scores, and operational efficiency. Use clear and concise visualizations such as bar charts, pie charts, and single-value panels. The dashboard should be designed with non-technical stakeholders in mind, ensuring that it provides insights at a glance. Include the following sections: Revenue Trends, Customer Satisfaction, and Efficiency Metrics. Use the variables: {{revenue_data}}, {{customer_satisfaction_data}}, {{efficiency_data}}. Specify how each KPI is calculated and the data source used. The output should be a detailed design document with wireframes and an explanation of each section.

## Tips

Ideal for developers creating dashboards for non-technical users.
