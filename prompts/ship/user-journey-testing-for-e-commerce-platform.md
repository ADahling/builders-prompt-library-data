# User Journey Testing for E-commerce Platform

Plan e-commerce journey tests across devices and browsers, with expected outcomes, failure alerts, and a results report template.

Variables: ecommerce_url, testing_tool

## Prompt

Design a comprehensive user journey testing plan for the e-commerce platform at {{ecommerce_url}} using {{testing_tool}}. Focus on critical user paths such as product search, adding items to the cart, and checkout process. Ensure that the tests cover various devices and browsers to simulate real-world user scenarios. Document the test cases, expected outcomes, and any assumptions made. Additionally, configure automated alerts for failed test scenarios and provide a detailed report template that includes test results and recommendations for improvements.

## Tips

This prompt targets developers who are familiar with user journey testing and e-commerce workflows.
