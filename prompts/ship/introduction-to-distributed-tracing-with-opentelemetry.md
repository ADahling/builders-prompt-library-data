# Introduction to Distributed Tracing with OpenTelemetry

Implement distributed tracing in microservices by configuring the OpenTelemetry SDK, managing spans, and visualizing end-to-end traces.

Variables: tech_stack

## Prompt

You are a software developer new to distributed tracing and want to implement basic tracing in a microservices application using OpenTelemetry. Describe the steps you would take to integrate OpenTelemetry into a {{tech_stack}} application. Include how to set up the OpenTelemetry SDK, create spans, and propagate trace context across services. Explain in detail how you would verify that the tracing is correctly implemented by analyzing trace data collected during a sample transaction. Your response should include any necessary code snippets or configuration files and describe any tools you would use to visualize the trace data.
