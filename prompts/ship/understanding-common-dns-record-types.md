# Understanding Common DNS Record Types

Explain common DNS record types with examples and analogies to master fundamental networking concepts.

## Prompt

You are a student learning about networking. Explain the purpose of the following common DNS record types: `A`, `AAAA`, `CNAME`, `MX`, and `TXT`.

Instructions:
1. For each record type, explain what it's used for.
2. Provide an example of each.
3. Use an analogy to explain the role of DNS in the internet.

## Tips

A foundational prompt for anyone new to web technologies.
