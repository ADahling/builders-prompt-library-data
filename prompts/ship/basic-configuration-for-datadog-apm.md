# Basic Configuration for Datadog APM

Configure Datadog APM for any tech stack and hosting platform with step-by-step setup, environment configuration, and trace verification.

Variables: tech_stack, hosting_platform

## Prompt

You are tasked with setting up Datadog APM for a new application. The application is built using {{tech_stack}} and hosted on {{hosting_platform}}. Provide a step-by-step guide on how to configure Datadog APM, including agent installation, environment variables, and initial service settings. Make sure to explain how to set up the Datadog agent on both the server and local development environments. Also, include instructions on verifying the installation and ensuring that traces are being sent to Datadog. The output should be a list of steps with brief explanations for each.

## Tips

This prompt is suitable for developers who are new to APM tools and need a straightforward setup guide.
