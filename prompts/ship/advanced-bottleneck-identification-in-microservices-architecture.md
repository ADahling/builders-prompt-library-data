# Advanced Bottleneck Identification in Microservices Architecture

Diagnose and resolve microservices latency by implementing distributed tracing and service mesh observability for system-wide optimization.

Variables: cloud_provider

## Prompt

You are managing a microservices architecture deployed on {{cloud_provider}}. To ensure optimal performance, you need to identify and resolve bottlenecks within the system. Discuss advanced techniques for bottleneck identification, such as distributed tracing with tools like Jaeger or Zipkin, and service mesh observability with Istio. Detail how to install and configure these tools, analyze the collected data to pinpoint bottlenecks, and propose strategies for resolving them. Include considerations for scalability and potential impact on different microservices. Output should be a comprehensive report format including example queries and scenarios.
