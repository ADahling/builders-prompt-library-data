# Configure a CI/CD Pipeline with Jenkins

Get a Jenkinsfile with build, test, and deployment stages for your application, plus version control integration to trigger builds automatically.

Variables: project_name, environment, version_control_system

## Prompt

Create a Jenkins pipeline configuration file (Jenkinsfile) for your {{project_name}} application. Define stages for building, testing, and deploying to {{environment}}. Include integration with {{version_control_system}} to trigger builds automatically.

## Tips

Jenkins is a powerful CI/CD tool widely used in the industry.
