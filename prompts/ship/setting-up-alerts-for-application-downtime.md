# Setting Up Alerts for Application Downtime

Get a downtime alert setup checklist for your cloud application, covering metrics, service integrations, triggers, testing, and response actions.

Variables: tech_stack, cloud_provider

## Prompt

Create a comprehensive plan to set up alerts for detecting application downtime in a {{tech_stack}} application deployed on {{cloud_provider}}. Cover the essential metrics to monitor, such as server uptime, HTTP response status codes, and network latency. Include steps for integrating with alerting services like PagerDuty or OpsGenie, and define the criteria for triggering an alert. Describe how to test the alert system to ensure reliability and what actions to take when an alert is triggered. Provide a checklist format for easy implementation and validation.

## Tips

Useful for setting up a reliable alerting system for downtime detection.
