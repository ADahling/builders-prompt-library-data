# Develop a System for Monitoring API Performance

Plan an API performance monitoring system for your service with metric selection, response time and error rate tracking, visualizations, and alerts.

## Prompt

Outline how to develop a system for monitoring API performance for our service {apiName}. Discuss which metrics to track, such as {responseTime} and {errorRate}, and how to visualize and alert on these metrics.

## Tips

API performance monitoring is crucial for identifying issues impacting users.
