# Server Health Dashboard Creation

Build a server health dashboard with real-time metrics, trends, and alerts, plus setup instructions and a guide to interpreting the data.

Variables: project_name, dashboard_tool

## Prompt

Create a comprehensive dashboard to monitor server health metrics for the {{project_name}} infrastructure. The dashboard should display real-time data on CPU load, memory usage, disk space, and network traffic for each server. Use {{dashboard_tool}} for this task, ensuring the dashboard is intuitive and user-friendly. Document the steps for setting up the data sources, creating the visualizations, and configuring alerts for critical thresholds. The final dashboard should include:

- Visual representation of real-time metrics
- Historical data trends
- Alerts and notifications

Provide a brief guide on how to interpret the dashboard and respond to alerts effectively.

## Tips

Beginner-friendly task to introduce developers to monitoring dashboards.
