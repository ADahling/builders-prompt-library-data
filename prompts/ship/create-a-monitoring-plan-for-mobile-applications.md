# Create a Monitoring Plan for Mobile Applications

Get a mobile app monitoring plan covering metrics such as crash rate and how to gather and analyze data with your monitoring tool.

## Prompt

Help me create a monitoring plan for our mobile application {mobileAppName}. Discuss which metrics to monitor, such as {crashRate}, and how to gather and analyze this data using {monitoringTool}.

## Tips

Mobile app monitoring is essential for delivering a high-quality user experience.
