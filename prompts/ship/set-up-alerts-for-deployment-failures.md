# Set Up Alerts for Deployment Failures

Design deployment failure alerts for your app using your monitoring tool, with trigger criteria and channels for notifying the team.

Variables: application_name, monitoring_tool

## Prompt

Design an alerting system for deployment failures in your {{application_name}} using {{monitoring_tool}}. Specify criteria for triggering alerts and the communication channels to notify the team.

## Tips

Alerts can help catch issues in real-time.
