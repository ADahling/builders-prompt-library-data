# Implement Blue-Green Deployment Strategy

Get a blue-green deployment plan for your cloud application, covering identical environments, active traffic routing, and version switches.

Variables: application_name, cloud_provider

## Prompt

Outline the steps necessary to implement a blue-green deployment strategy for your {{application_name}} application on {{cloud_provider}}. Describe how to set up two identical environments (Blue and Green), how to route traffic to the active environment, and the steps to switch traffic when deploying a new version.

## Tips

Use this prompt to ensure zero downtime during your application deployments.
