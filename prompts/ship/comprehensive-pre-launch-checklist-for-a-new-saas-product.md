# Comprehensive Pre-Launch Checklist for a New SaaS Product

Get a categorized checklist covering technical, product, marketing, sales, and support readiness before launching a new B2B SaaS product.

Variables: product_name, target_audience, core_features, tech_stack

## Prompt

My team is about to launch a new B2B SaaS product. I need a comprehensive pre-launch checklist to ensure we have covered all the critical aspects before making the product publicly available.

**Product Details:**
- **Product Name:** `{{product_name}}`
- **Target Audience:** `{{target_audience}}`
- **Core Features:** `{{core_features}}`
- **Tech Stack:** `{{tech_stack}}`

**Requirements for the Checklist:**
Generate a detailed, multi-category checklist that we can use to track our launch readiness. The checklist should be organized into the following sections:

1.  **Technical Readiness:**
    - Infrastructure and hosting setup (servers, databases, CDN).
    - Final security review (penetration testing, vulnerability scanning).
    - Performance and load testing.
    - Backup and disaster recovery plan.
    - Monitoring and alerting setup.

2.  **Product Readiness:**
    - Final round of QA and bug fixing.
    - Usability testing with a small group of beta users.
    - All features are complete and meet the acceptance criteria.
    - Onboarding flow for new users is polished.

3.  **Marketing & Sales Readiness:**
    - Website and landing page are live.
    - Pricing page is finalized.
    - Marketing materials (blog posts, social media announcements) are ready.
    - Sales team is trained on the new product.

4.  **Support & Operations Readiness:**
    - Help documentation and knowledge base are complete.
    - Customer support channels (email, chat) are set up.
    - Billing and payment processing is tested and working.
    - A process for handling customer feedback and bug reports is in place.

For each item in the checklist, provide a brief description of what needs to be done and why it is important. The output should be in a clear, easy-to-read format (e.g., Markdown with checkboxes).

## Tips

This is a beginner-friendly prompt that is useful for any team launching a new product. It provides a good starting point for creating a comprehensive launch plan.
