# Cross-Browser Performance Analysis

Get a website performance report comparing major browsers, with load and rendering metrics, discrepancy analysis, and browser-specific optimizations.

Variables: website_url, analysis_tool

## Prompt

Conduct a cross-browser performance analysis for {{website_url}} using {{analysis_tool}}. Your task is to compare the site's performance across major browsers such as Chrome, Firefox, Safari, and Edge. Focus on metrics like page load time, time to first byte, and rendering speed. Identify any discrepancies between browsers and possible reasons for such differences. Provide a report detailing the findings and suggest browser-specific optimizations to enhance performance. Include a section on potential challenges and how they were addressed during the analysis.

## Tips

This prompt is intended for developers interested in understanding and optimizing browser-specific performance issues.
