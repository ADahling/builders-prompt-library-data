# Setting Up Alert Escalation Procedures

Get an alert escalation procedure for your project, with escalation criteria, notifications, documentation, communication, and a decision flowchart.

Variables: project_name

## Prompt

Outline a procedure for alert escalation in the context of {{project_name}}. Define the criteria for escalating alerts and the process for notifying the appropriate personnel at each escalation level. Describe the documentation required for each stage of escalation and how communication is maintained throughout the process. Include a flowchart illustrating the escalation path and decision points. Your response should cover: 1) Escalation Criteria, 2) Notification Process, 3) Documentation and Communication, 4) Escalation Path Flowchart.

## Tips

Helpful for developers responsible for creating alert escalation protocols.
