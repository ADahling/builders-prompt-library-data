# Evaluate SLO Performance for a Legacy System

Create a comprehensive assessment and modernization plan to analyze SLO performance and improve reliability for aging legacy infrastructure.

Variables: system_name

## Prompt

You are responsible for evaluating the SLO performance of a legacy system named {{system_name}}. This system has been in operation for over a decade and has historically struggled with performance issues. Outline a plan to assess the current SLO performance, including gathering historical data, identifying key performance indicators, and benchmarking against industry standards. Discuss the challenges associated with monitoring legacy systems and propose solutions to improve SLO compliance. Include recommendations for modernizing the monitoring infrastructure and integrating with newer technologies if necessary. Provide a report format for communicating findings to stakeholders, emphasizing transparency and accountability.

## Tips

Focuses on legacy systems, offering strategies for performance evaluation and improvement.
