# Set Up Alerts for Resource Utilization

Get an alert configuration for your app's CPU and memory thresholds, including integration with your chosen monitoring tool.

## Prompt

Generate a configuration for setting up alerts on resource utilization for our application {appName}. The alerts should trigger when CPU usage exceeds {cpuThreshold} or memory usage exceeds {memoryThreshold}. Include integration with {monitoringTool}.

## Tips

Focus on optimizing alert thresholds to reduce alert fatigue.
