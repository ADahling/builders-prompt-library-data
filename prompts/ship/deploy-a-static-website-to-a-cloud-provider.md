# Deploy a Static Website to a Cloud Provider

Configure object storage and hosting settings to deploy a production-ready static website on a specified cloud provider.

Variables: cloud_provider

## Prompt

You are a frontend developer. Your task is to deploy a static website to {{cloud_provider}}'s object storage service. The website is built with HTML, CSS, and JavaScript.

Instructions:
1. Create a new storage bucket/container in {{cloud_provider}}.
2. Upload the website files to the created bucket.
3. Configure the bucket for static website hosting.
4. Provide the public URL to access the deployed website.

## Tips

This prompt helps beginners understand the basics of deploying simple websites to the cloud.
