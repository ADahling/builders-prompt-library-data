# Developing an On-Call Handoff Guide

Get a Markdown on-call handoff guide with system status, incidents, maintenance, and a checklist for outgoing and incoming engineers.

## Prompt

Develop a detailed guide for on-call handoffs to ensure seamless transitions between team members. The guide should include an overview of the current system status, outstanding issues, ongoing incidents, and any scheduled maintenance. Provide a checklist of information that the outgoing on-call engineer should communicate to the incoming engineer, including recent alerts, response actions taken, and escalation contacts. Format the output as a markdown document that can be stored in your team's knowledge base for easy reference.

## Tips

Ensures effective communication during on-call transitions.
