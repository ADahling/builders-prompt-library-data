# Create API Terms of Use

Generate a comprehensive API Terms of Use agreement that balances service protection with developer accessibility and legal compliance.

## Prompt

You are a product manager for a company that offers a public API. Your task is to create the Terms of Use for the API.

Context:
- The API provides access to your company's data and services.
- The terms need to protect your company's interests while encouraging developers to use the API.

Provide:
1. A clear description of the API and its intended use.
2. Restrictions on API usage, including rate limits and prohibited activities.
3. Clauses on data ownership, intellectual property, and liability.
4. The process for revoking API access.

## Tips

Essential for any company that offers a public API.
