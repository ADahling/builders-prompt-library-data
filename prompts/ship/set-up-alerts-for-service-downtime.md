# Set Up Alerts for Service Downtime

Get a detailed service downtime alerting rule with a duration threshold and notification integration for your chosen alerting tool.

## Prompt

Create a detailed alerting rule for detecting service downtime for {serviceName}. The alert should trigger if the service is unavailable for more than {downtimeThreshold} minutes. Integrate with {alertTool} for notifications.

## Tips

Make sure the downtime threshold is realistic based on normal fluctuations.
