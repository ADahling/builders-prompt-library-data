# Establish Incident Response Protocols

Draft a team incident response protocol for triggered alerts, with diagnosis steps, communication plans, and post-mortem documentation guidelines.

## Prompt

Draft a basic incident response protocol for our team when an alert is triggered by the {alertSystem}. Include steps for diagnosing the issue, communication plans, and post-mortem documentation guidelines.

## Tips

Ensure the protocol is clear and easy to follow under pressure.
