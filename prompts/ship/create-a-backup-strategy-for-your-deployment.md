# Create a Backup Strategy for Your Deployment

Design a deployment backup plan for databases and file storage, including backup frequency, storage locations, and tool-based automation.

Variables: database_name, file_storage, backup_tool

## Prompt

Design a backup strategy for your {{database_name}} and {{file_storage}} as part of your deployment process. Include frequency of backups, storage location, and how to automate the backup process using {{backup_tool}}.

## Tips

Having a backup strategy is critical to prevent data loss.
