# Draft a GDPR-compliant Cookie Consent Banner Text

Generate clear, transparent, and GDPR-compliant cookie consent banner copy that offers users explicit control over their data preferences.

## Prompt

You are a UX writer. Your task is to write the text for a GDPR-compliant cookie consent banner.

Context:
- The website uses both essential and non-essential (e.g., analytics, advertising) cookies.
- The banner needs to be clear, concise, and easy for users to understand.

Provide:
1. A brief explanation that the website uses cookies.
2. Clear options for the user to accept all cookies, reject all non-essential cookies, or customize their cookie settings.
3. A link to the full cookie policy.
