# Designing SEV-1 Incident Response Procedures

Get a Markdown SEV-1 response procedure with roles, escalation steps, communication protocols, and a checklist for critical incidents.

## Prompt

Design a comprehensive incident response procedure specifically for SEV-1 (Severity Level 1) incidents, which are critical issues that require immediate attention. The procedure should include steps for initial detection, immediate response actions, communication protocols, escalation processes, and resolution verification. Specify roles and responsibilities for each step and include a checklist to ensure all necessary actions are completed. The output should be a detailed document in markdown format that can be easily integrated into your team's operational handbook.

## Tips

This prompt helps create a structured response plan for critical incidents.
