# Create SLIs for a Microservices Architecture

Define, collect, and visualize microservice SLIs to ensure high performance and reliability using industry-standard monitoring tools.

Variables: company_name

## Prompt

You are developing a set of Service Level Indicators (SLIs) for a microservices architecture used by {{company_name}}. Identify key SLIs that are crucial for monitoring the performance and reliability of this architecture. Consider factors such as request latency, error rates, throughput, and resource utilization across different services. Explain the methods for collecting and aggregating these metrics, and how they can be visualized in a dashboard for real-time monitoring. Discuss the importance of each SLI in the context of the overall service performance and user satisfaction. Provide examples of tools and technologies that can be used to implement and maintain these SLIs.

## Tips

Focuses on the technical challenges and solutions for monitoring microservices.
