# Write a Legal Disclaimer for an Open-Source AI Project

Draft a plain-language Markdown README disclaimer for an open-source AI project covering warranties, liability, and AI output risks.

Variables: project_name

## Prompt

My open-source AI project, `{{project_name}}`, generates output (e.g., text, images, code) and I need to add a clear legal disclaimer to the README to protect the project and its contributors from liability.

Generate a standard legal disclaimer in Markdown format. The disclaimer should be written in plain, easy-to-understand language, while still covering the necessary legal points. It should not be a substitute for actual legal advice, but a good-faith effort to inform users.

The disclaimer should include the following points:

1.  **No Warranty**: A clear statement that the software is provided "AS IS", without any warranties of any kind, express or implied. This should include, but not be limited to, warranties of merchantability, fitness for a particular purpose, and non-infringement.

2.  **Limitation of Liability**: A statement that in no event shall the authors or copyright holders be liable for any claim, damages, or other liability, whether in an action of contract, tort, or otherwise, arising from, out of, or in connection with the software or the use or other dealings in the software. This is standard language found in most open-source licenses like MIT and Apache.

3.  **AI-Specific Disclaimers**:
    *   **Output Quality**: A statement that the output generated by the AI model may be unpredictable, inaccurate, or offensive.
    *   **No Responsibility for Output**: A clause stating that the user is solely responsible for the use of any output generated by the model and for verifying its accuracy and appropriateness.
    *   **Potential for Bias**: An acknowledgement that the model was trained on large datasets and may reflect biases present in that data.

4.  **Not Legal/Financial/Medical Advice**: A clear statement that the output of the model should not be considered a substitute for professional advice (e.g., legal, financial, or medical advice).

5.  **Recommendation to Consult a Professional**: A final sentence advising users to consult with a qualified professional for any serious matters.

Your output should be a single block of Markdown text, starting with a heading like `## Disclaimer`, that can be easily copied and pasted into the project's `README.md`.
