# Creating a Post-Incident Review Workshop Plan

Plan a post-incident review workshop in Markdown with a timed agenda, discussion questions, and methods to record insights and action items.

## Prompt

Create a detailed plan for conducting a post-incident review workshop. The workshop should be designed to facilitate open discussion among team members about a recent incident, focusing on understanding the root cause, learning opportunities, and process improvements. Include an agenda with time allocations for each section, key questions to guide the discussion, and methods for documenting insights and action items. The output should be a structured plan in markdown format that can be used to run future workshops effectively.

## Tips

Useful for team leads planning collaborative review sessions.
