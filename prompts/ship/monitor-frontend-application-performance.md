# Monitor Frontend Application Performance

Implement Real User Monitoring to track core web vitals and JavaScript errors through a comprehensive performance dashboard.

Variables: rum_tool

## Prompt

You are a frontend developer. Your task is to set up monitoring for your single-page application (SPA) to track its performance from the user's perspective.

Instructions:
1. Use a Real User Monitoring (RUM) tool like `{{rum_tool}}`.
2. Track key metrics like First Contentful Paint (FCP), Largest Contentful Paint (LCP), and Cumulative Layout Shift (CLS).
3. Track JavaScript errors and their impact on users.
4. Create a dashboard to visualize these frontend performance metrics.

## Tips

Focuses on the often-neglected area of frontend monitoring.
