# Implement a Visual Regression Testing Workflow for a Design System

Establish an automated visual regression pipeline to detect UI inconsistencies and manage component baseline changes across a design system.

Variables: visual_regression_tool

## Prompt

You are a design systems engineer. Your task is to implement a visual regression testing workflow for a design system to ensure that all the components are visually consistent and that changes are intentional. You will use a tool like {{visual_regression_tool}}.

Context:
- The design system is used by multiple teams and applications.
- You need to create a robust workflow for managing visual changes and preventing regressions.

Provide:
1. A configuration for the visual regression testing tool to capture screenshots of all the components in the design system.
2. A process for creating and updating the baseline screenshots.
3. A notification system to alert the team of any visual differences found.

## Tips

A prompt for engineers who are responsible for maintaining the quality and consistency of a design system.
