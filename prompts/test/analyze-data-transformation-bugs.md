# Analyze Data Transformation Bugs

Get a systematic approach to diagnosing and resolving incorrect data conversion output for your source format, target format, and affected data.

Variables: source_format, target_format, specific_data

## Prompt

There seems to be a data transformation bug in my application. When I transform data from {{source_format}} to {{target_format}}, the output is incorrect, especially for {{specific_data}}. Could you provide a systematic approach to diagnose and resolve this issue?
