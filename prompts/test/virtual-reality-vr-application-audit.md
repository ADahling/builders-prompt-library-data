# Virtual Reality (VR) Application Audit

Generate a comprehensive UX audit report for VR applications to identify usability issues and prioritize technical improvements for immersive comfort.

Variables: application_name, application_description

## Prompt

As a UX designer specializing in VR, I need to conduct a UX audit for our VR application, `{{application_name}}`. The application is a {{application_description}}, and we want to improve the user experience and make the application more intuitive and user-friendly.

Your audit should cover the following aspects of the VR application:

1.  **Onboarding and First-Time User Experience:**
    *   Evaluate the onboarding process for new users.
    *   Ensure that users can easily understand how to use the application.

2.  **Locomotion and Navigation:**
    *   Assess the locomotion and navigation mechanics of the application.
    *   Ensure that users can easily move around in the virtual world.

3.  **Interaction Design:**
    *   Review the interaction design of the application.
    *   Ensure that users can easily interact with virtual objects.

4.  **Performance and Comfort:**
    *   Assess the performance of the application and its impact on user comfort.

**Output Format:**

Please provide a UX audit report in a Markdown file with the following structure:

*   **UX Score:** A summary of the application's overall UX quality, with scores for each of the audited areas.
*   **Audit Findings:** A detailed list of all identified issues, categorized by the areas mentioned above. For each issue, provide:
    *   **Issue ID:** A unique identifier.
    *   **Severity:** (High, Medium, Low)
    *   **Description:** A clear explanation of the issue.
    *   **Recommendation:** Specific and actionable steps to fix the issue.
*   **UX Improvement Plan:** A prioritized list of recommendations for improving the application's UX.
