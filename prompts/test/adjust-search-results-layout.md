# Adjust Search Results Layout

Get a review of crowded or unclear search results, with design suggestions and CSS modifications for layout, spacing, and usability.

Variables: page_name, search_result_items

## Prompt

Inspect the layout of search results on the {{page_name}}. Identify areas where items may be overcrowded or unclear. Suggest design changes to {{search_result_items}} to improve layout, spacing, and usability, including CSS modifications.

## Tips

An improved search results layout enhances user satisfaction and engagement.
