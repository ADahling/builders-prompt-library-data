# Design Responsive Tables

Review table readability across screen sizes and get a responsive design strategy with CSS grid or flexbox implementations.

Variables: page_name, table_elements

## Prompt

Evaluate the table layout on the {{page_name}}. Identify any issues related to responsiveness or readability on various screen sizes. Propose a responsive design strategy for {{table_elements}}, including CSS grid or flexbox implementations for better usability.

## Tips

Responsive tables ensure data accessibility across devices.
