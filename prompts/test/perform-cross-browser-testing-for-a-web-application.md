# Perform Cross-Browser Testing for a Web Application

Identify, document, and resolve visual or functional inconsistencies across multiple browsers to ensure a seamless cross-platform experience.

Variables: application_type, browser_1, browser_2, browser_3

## Prompt

You are a frontend developer. Your task is to perform cross-browser testing for a web application to ensure that it looks and works correctly on different web browsers. The application is a {{application_type}}.

Context:
- You need to test the application on the latest versions of the major browsers, such as {{browser_1}}, {{browser_2}}, and {{browser_3}}.
- You will manually test the application on each browser and look for any visual or functional issues.

Provide:
1. A checklist of the features to be tested on each browser.
2. A report with all the cross-browser issues found, with screenshots and steps to reproduce.
3. Recommendations for fixing the issues and improving the cross-browser compatibility of the application.

## Tips

A prompt for frontend developers to practice manual cross-browser testing, which is an important step in delivering a high-quality web application.
