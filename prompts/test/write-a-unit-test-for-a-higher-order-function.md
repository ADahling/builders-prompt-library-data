# Write a Unit Test for a Higher-Order Function

Generate comprehensive unit tests in your chosen language to validate the logic and edge cases of functional higher-order functions.

Variables: function_name, function_purpose, programming_language

## Prompt

You are a functional programming enthusiast. Your task is to write a unit test for a higher-order function that takes a function as an argument or returns a function. The higher-order function is called {{function_name}} and it {{function_purpose}}.

Context:
- The function is written in a functional programming style in {{programming_language}}.
- You need to test that the higher-order function behaves correctly with different input functions.

Provide:
1. A unit test that calls the higher-order function with a simple function as an argument.
2. A test case that uses a more complex function to test the behavior of the higher-order function.
3. Assertions to verify that the returned function or the result of the function is correct.

## Tips

A prompt for developers who want to practice testing higher-order functions, which are a key concept in functional programming.
