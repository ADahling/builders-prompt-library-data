# Responsive Images Implementation

Review a page for nonresponsive images and get srcset and CSS code examples to make images scale across screen sizes.

Variables: page_name, srcset

## Prompt

Review the image usage on the {{page_name}}. Identify any images that are not responsive. Suggest using the <img> tag's {{srcset}} attribute or CSS properties to ensure images scale properly across different screen sizes. Provide code examples for both methods.

## Tips

Responsive images improve performance and user experience on all devices.
