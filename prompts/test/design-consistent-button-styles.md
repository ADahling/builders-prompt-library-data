# Design Consistent Button Styles

Get a review of button inconsistencies on a page, plus a unified style guide and example CSS for colors, borders, and hover states.

Variables: page_name, button_types

## Prompt

Review the button styles used across the {{page_name}}. Identify inconsistencies in styles, colors, or sizes. Propose a unified style guide for {{button_types}}, including specifications for colors, borders, and hover states. Provide example CSS to illustrate your design.

## Tips

Consistent button styles improve user familiarity and confidence.
