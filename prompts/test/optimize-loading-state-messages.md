# Optimize Loading State Messages

Get a review of loading messages with tone and wording adjustments for pages where users need clearer information while waiting.

Variables: page_name, loading_messages

## Prompt

Evaluate the loading messages displayed on the {{page_name}}. Identify if they are clear and informative. Propose changes to the {{loading_messages}} to enhance clarity and user engagement during loading periods, including tone and wording adjustments.

## Tips

Clear loading messages improve user patience and satisfaction.
