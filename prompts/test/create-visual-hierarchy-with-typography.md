# Create Visual Hierarchy with Typography

Review a page's typography hierarchy and get a CSS adjustment plan for heading and body text sizes, weights, and colors.

Variables: page_name, headings, body_text

## Prompt

Review the typography hierarchy on the {{page_name}}. Identify areas where the hierarchy is weak and suggest improvements to font sizes, weights, and colors for {{headings}} and {{body_text}}. Provide a clear plan for CSS adjustments to enhance readability and visual interest.

## Tips

A strong typography hierarchy helps guide users through content effectively.
