# Tackle Responsive Layout Bugs

Fix a page's responsive layout bug with CSS adjustments for element alignment, sizing, and positioning on the specified device and screen size.

Variables: device_type, page_name, specific_element, screen_size

## Prompt

Identify the responsive layout bug on the {{device_type}} for the {{page_name}}. Make sure to check the alignment of the elements and use media queries to adjust the styles. Ensure that the {{specific_element}} is properly sized and positioned for {{screen_size}}. Consider using flexbox or grid systems for better responsiveness. Provide the necessary CSS adjustments.

## Tips

Use this prompt when you need to fix a layout that behaves incorrectly on different screen sizes.
