# Develop a Test Coverage Strategy for a New Project

Create a resource-optimized test coverage strategy, risk-based prioritization, and monitoring plan to ensure quality under tight deadlines.

Variables: project_type

## Prompt

You are a test manager. Your task is to develop a comprehensive test coverage strategy for a new project. The project is a {{project_type}} with a tight deadline and limited resources.

Context:
- The strategy should define the different levels of testing to be performed (e.g., unit, integration, E2E).
- It should also specify the tools and techniques to be used for each level of testing.

Provide:
1. A document outlining the test coverage strategy.
2. A risk analysis to prioritize the testing efforts.
3. A plan for monitoring and reporting the test coverage throughout the project.

## Tips

This prompt is for test managers and leads who need to create a strategic plan for testing a new project.
