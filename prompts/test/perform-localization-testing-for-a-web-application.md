# Perform Localization Testing for a Web Application

Generate a localization testing checklist, defect report, and optimization recommendations to ensure UI and functional compliance for specific locales.

Variables: locale

## Prompt

You are a QA engineer. Your task is to perform localization testing for a web application to ensure that it is correctly translated and adapted for a specific locale. The application is being localized for {{locale}}.

Context:
- You need to check that all the text in the application is translated correctly and that the UI is adapted to the conventions of the target locale (e.g., date formats, number formats, currency symbols).
- You will manually test the application in the target locale and look for any localization issues.

Provide:
1. A checklist of the items to be checked during the localization testing.
2. A report with all the localization issues found, with screenshots and steps to reproduce.
3. Recommendations for improving the localization of the application.

## Tips

A prompt for QA engineers to practice localization testing, which is an important step in making a web application accessible to a global audience.
