# Eliminate Animation Jank

Review component animations for scroll or hover stuttering and get specific optimization suggestions with example code snippets.

Variables: component_name, page_name, animation_type

## Prompt

Review the animations applied to the {{component_name}} on {{page_name}}. Identify any instances of jank or stuttering during scroll or hover events. Suggest specific optimizations, such as using {{animation_type}} or reducing the number of elements being animated simultaneously. Provide example code snippets demonstrating your improvements.

## Tips

High-performance animations enhance user experience significantly.
