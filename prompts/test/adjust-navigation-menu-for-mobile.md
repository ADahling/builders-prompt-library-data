# Adjust Navigation Menu for Mobile

Get a mobile navigation review, a proposed menu layout, and CSS changes addressing small touch targets, tight spacing, and accessibility.

Variables: page_name, menu_type

## Prompt

Evaluate the navigation menu on the {{page_name}} for mobile usability. Identify any elements that are too small or closely spaced, which may hinder user interaction. Propose a new layout that utilizes a {{menu_type}} and provides CSS changes for better accessibility and touch target sizing.

## Tips

A mobile-friendly navigation menu is crucial for a good user experience.
