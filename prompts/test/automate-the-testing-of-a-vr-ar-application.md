# Automate the Testing of a VR/AR Application

Generate automated functional tests and regression cases for VR/AR applications using platform-specific engines and testing frameworks.

Variables: platform, engine, testing_framework

## Prompt

You are a QA automation engineer specializing in immersive technologies. Your task is to automate the testing of a VR/AR application to ensure its quality and prevent regressions. The application is for {{platform}} and it is built with {{engine}}.

Context:
- You need to test the functionality of the VR/AR application in a real or simulated VR/AR environment.
- You will use a testing framework that supports testing VR/AR applications, such as {{testing_framework}}.

Provide:
1. A test that launches the VR/AR application and interacts with its virtual objects and UI.
2. Assertions to verify that the VR/AR application behaves as expected and that the virtual world is correct.
3. A test case to handle the scenario where the VR/AR application is updated.
