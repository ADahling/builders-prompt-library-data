# Optimize a Website for Mobile Performance

Get a mobile performance checklist for a slow website, covering loading, JavaScript, rendering, touch interactions, and monitoring tools.

Variables: WebsiteURL

## Prompt

Our website, `{{WebsiteURL}}`, has poor performance on mobile devices, with slow load times and a sluggish user interface. I need a comprehensive checklist of optimizations to improve the mobile performance of our site.

Act as a mobile performance expert and provide a detailed checklist of actions we can take to make our website faster and more responsive on mobile devices.

Your response should be a checklist covering the following areas:
1. **Network and Loading:** Optimizations to reduce the amount of data transferred and speed up the initial load time, such as image optimization, text compression, and using a CDN.
2. **JavaScript Performance:** Techniques to reduce the impact of JavaScript on mobile devices, such as code splitting, tree shaking, and deferring non-critical scripts.
3. **Rendering Performance:** Optimizations to ensure smooth scrolling and animations, such as using CSS animations instead of JavaScript, promoting layers with `will-change`, and avoiding layout thrashing.
4. **User Experience:** Recommendations to improve the user experience on mobile devices, such as implementing a responsive design, ensuring tap targets are large enough, and providing a good touch experience.
5. **Testing and Monitoring:** How to test and monitor the mobile performance of our website using tools like WebPageTest, Lighthouse, and real user monitoring (RUM).
