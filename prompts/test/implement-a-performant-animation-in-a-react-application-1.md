# Implement a Performant Animation in a React Application

Get a React animation guide for complex effects, comparing CSS, JavaScript, and libraries, with acceleration tips, example code, and profiling.

## Prompt

I need to implement a complex animation in our React application, and I want to ensure that it is performant and doesn't cause jank. I am looking for a guide on how to create high-performance animations in React.

Your task is to provide a comprehensive guide to creating performant animations in React. The guide should cover different animation techniques and libraries.

Your response should include:
1. **CSS Animations vs. JavaScript Animations:** A comparison of CSS animations and JavaScript-based animations, with a discussion of when to use each.
2. **Hardware Acceleration:** An explanation of how to trigger hardware acceleration for your animations using CSS properties like `transform` and `opacity`.
3. **React Animation Libraries:** A comparison of popular React animation libraries, such as `Framer Motion` and `React Spring`. Include the pros and cons of each and provide a recommendation for our use case.
4. **Implementation Guide:** A step-by-step tutorial on how to use your recommended animation library to create a performant animation. Provide a complete code example.
5. **Performance Profiling:** How to use browser developer tools to profile your animations and identify performance bottlenecks.
