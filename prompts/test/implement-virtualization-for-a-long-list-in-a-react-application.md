# Implement Virtualization for a Long List in a React Application

Get a React list virtualization guide with library comparisons, fixed and variable-size examples, and advanced features for long lists.

## Prompt

I have a React application that needs to render a very long list of items (thousands of items). The current implementation renders all the items at once, which is causing severe performance issues and a high memory footprint. I need to implement list virtualization (also known as windowing) to solve this problem.

Your task is to provide a guide on how to implement list virtualization in a React application. The guide should compare different libraries and provide a complete code example.

Your response should include:
1.  **Virtualization Explained:** A clear explanation of what list virtualization is and how it can improve the performance of long lists.
2.  **Library Comparison:** A comparison of popular React libraries for list virtualization, such as `react-window` and `react-virtualized`. Include the pros and cons of each and provide a recommendation.
3.  **Implementation Guide:** A step-by-step tutorial on how to use your recommended library to implement a virtualized list. The tutorial should cover both fixed-size and variable-size lists.
4.  **Code Example:** A complete, working React component that demonstrates the implementation of a virtualized list.
5.  **Advanced Features:** A discussion of more advanced features, such as infinite loading and scroll-to-index, and how to implement them with the chosen library.
