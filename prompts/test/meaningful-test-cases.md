# Write meaningful test cases

Write a feature test suite covering normal use, edge cases, failures, accessibility, and mobile, with setup, actions, outcomes, and priority.

## Prompt

Create a test suite for {{feature}}. Cover happy path, boundaries, invalid input, permissions, concurrency, network failure, loading, empty state, accessibility, mobile behavior, and regression risks. Provide setup, action, expected result, and priority.
