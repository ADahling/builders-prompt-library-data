# Find a logical error in a code snippet

Identify and fix logical bugs in a code snippet while providing a corrected version and an explanation of the underlying issue.

Variables: language, code_snippet

## Prompt

You are an AI coding assistant. Find the logical error in the following code snippet and explain what is wrong.

Code:
```{{language}}
{{code_snippet}}
```

Provide the corrected code.
