# Investigate State Synchronization Across Tabs

Get debugging guidance for a web app where a state update in one browser tab does not appear in another tab.

Variables: state_key

## Prompt

I have a web application where state changes in one tab do not reflect in another tab. When I update {{state_key}} in tab A, it stays the same in tab B. What can I do to debug this state synchronization issue?
