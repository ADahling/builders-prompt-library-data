# Redesign Error Message Placement

Review form error visibility and get placement and styling recommendations with markup and CSS updates for clearer feedback.

Variables: form_name, page_name, error_messages

## Prompt

Inspect the placement of error messages on the {{form_name}} on {{page_name}}. Assess whether the errors are easily noticeable by users. Suggest improved placement and styling for {{error_messages}} to ensure they are clear and actionable. Include necessary markup and CSS updates.

## Tips

Well-placed error messages can help users correct issues quickly.
