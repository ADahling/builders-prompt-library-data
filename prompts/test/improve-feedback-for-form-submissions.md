# Improve Feedback for Form Submissions

Review form submission feedback for clarity and actionable next steps, with suggestions for visual cues, animations, and messages.

Variables: form_name, page_name, submission_feedback

## Prompt

Evaluate the feedback provided to users after submitting the {{form_name}} on {{page_name}}. Identify if the feedback is clear and actionable. Suggest improvements for the {{submission_feedback}} including visual cues, animations, or messages.

## Tips

Clear feedback for submissions increases user confidence.
