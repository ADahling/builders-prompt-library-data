# Enhance Loading Progress Feedback

Review a page's loading feedback and get suggestions for visual indicators and status text that explain loading progress to users.

Variables: page_name, loading_feedback_elements

## Prompt

Analyze the loading progress feedback on the {{page_name}}. Identify if users are adequately informed of the loading status. Propose enhancements to {{loading_feedback_elements}}, including visual indicators and textual feedback to improve user engagement during loading.

## Tips

Effective loading progress feedback keeps users informed and patient.
