# Respond to a Critical Security Breach (SQL Injection)

Remediate an SQL injection incident by securing the database, patching legacy PHP code with prepared statements, and managing stakeholder communication.

## Prompt

You are a security engineer. A web application has been compromised via an SQL injection vulnerability, and sensitive user data has been exfiltrated. Your task is to manage the security incident.

Context:
- The application is a PHP-based e-commerce site with a MySQL backend.
- The attackers have gained access to the customer database.
- The vulnerability was in a legacy part of the codebase.

Provide:
1. A checklist of immediate actions to take, including isolating the system and assessing the damage.
2. A technical guide on how to patch the SQL injection vulnerability using prepared statements.
3. A communication plan for notifying affected users and stakeholders.

## Tips

A practical scenario for assessing incident response and secure coding practices.
