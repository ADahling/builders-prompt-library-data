# Enhance Progress Indicators

Review progress indicators for long tasks and get design suggestions with CSS changes to make task progress visible and understandable.

Variables: page_name, progress_indicator_type

## Prompt

Assess the progress indicators displayed on the {{page_name}} during long tasks. Determine if they effectively communicate progress to users. Suggest design improvements, such as using {{progress_indicator_type}} and ensuring the indicators are visible and easily understood. Include relevant CSS changes.

## Tips

Clear progress indicators keep users informed during lengthy operations.
