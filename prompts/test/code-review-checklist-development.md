# Code Review Checklist Development

Get a stack-specific review checklist for readability, functionality, performance, security, and compatibility, with explanations and 1 to 5 ratings.

Variables: tech_stack, project_name

## Prompt

Develop a code review checklist for {{tech_stack}} in a software development project called {{project_name}}. The checklist should contain pertinent items related to code readability, functionality, performance, security, and compatibility. Each item must include a brief explanation and a confidence level rating scale from 1 (low) to 5 (high).
