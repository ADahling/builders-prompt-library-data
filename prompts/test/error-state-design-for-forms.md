# Error State Design for Forms

Design form error states with colors, icons, and actionable messages, plus proposed markup and CSS changes to clarify feedback.

Variables: form_name, page_name

## Prompt

Outline the error state design for the {{form_name}} on {{page_name}}. Specify how errors should be visually indicated, including the colors, icons, and messages. Propose adjustments to both the markup and the CSS to ensure that error states are clear and provide actionable feedback for users.

## Tips

Clear error states help users correct mistakes effectively.
