# Perform a Security Test for a Web Application

Conduct a comprehensive security assessment to identify vulnerabilities, execute proofs-of-concept, and receive targeted mitigation strategies.

Variables: application_type, sensitive_data, vulnerability_1, vulnerability_2, vulnerability_3

## Prompt

You are a security analyst. Your task is to perform a security test for a web application to identify and exploit vulnerabilities. The application is a {{application_type}} that handles sensitive user data, such as {{sensitive_data}}.

Context:
- The security test should cover common vulnerabilities like {{vulnerability_1}}, {{vulnerability_2}}, and {{vulnerability_3}}.
- The goal is to assess the application's security posture and provide recommendations for improvement.

Provide:
1. A report with all the vulnerabilities found, including their severity and impact.
2. A proof-of-concept exploit for each vulnerability.
3. A list of recommendations for mitigating the identified risks.

## Tips

An advanced prompt for security professionals to test the security of web applications and protect them from attacks.
