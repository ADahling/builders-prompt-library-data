# Optimize Table Layout for Mobile

Get a mobile table usability review, a responsive layout strategy, and CSS changes for tables that are hard to read or use on small screens.

Variables: page_name, table_type

## Prompt

Examine the table layout on the {{page_name}}. Identify issues related to readability and interaction on mobile devices. Propose a responsive design strategy, such as using {{table_type}} or card views, and provide CSS changes necessary to achieve this layout.

## Tips

Optimizing tables for mobile is essential for ensuring data is accessible.
