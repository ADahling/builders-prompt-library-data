# Generate a performance review check-list

Get a prioritized Markdown checklist for reviewing application performance across queries, algorithms, containers, client-side work, and caching.

Variables: tech_stack

## Prompt

We need focused check-lists to determine the performance of our {{tech_stack}} application. Identify the critical performance areas to consider, such as database queries, inefficient algorithms, oversized containers, heavy client-side computation, and caching strategies. Prioritize and list these out in a markdown checklist.
