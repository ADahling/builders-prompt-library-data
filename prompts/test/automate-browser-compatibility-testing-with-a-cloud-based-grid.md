# Automate Browser Compatibility Testing with a Cloud-Based Grid

Automate parallel cross-browser E2E testing using cloud-based grids to ensure web application compatibility across multiple platforms.

Variables: grid_provider, browser_1, browser_2, browser_3

## Prompt

You are a frontend developer. Your task is to automate browser compatibility testing for a web application to ensure that it works correctly on different browsers and operating systems. You will use a cloud-based grid like {{grid_provider}}.

Context:
- The web application needs to support a wide range of browsers, including {{browser_1}}, {{browser_2}}, and {{browser_3}}.
- You want to run your existing E2E tests on the cloud-based grid.

Provide:
1. A configuration for your E2E testing framework to run the tests on the cloud-based grid.
2. A script to run the tests in parallel on multiple browsers.
3. A dashboard to view the test results and the screenshots from the different browsers.

## Tips

A prompt for frontend developers who want to automate browser compatibility testing and ensure a consistent user experience across all browsers.
