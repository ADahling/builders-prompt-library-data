# Perform a Manual Accessibility Test with a Screen Reader

Identify and document barrier-free navigation issues and remediation steps for a website using a manual screen reader evaluation.

Variables: website_url, screen_reader_name

## Prompt

You are a QA tester. Your task is to perform a manual accessibility test of a website using a screen reader to ensure that it is usable by visually impaired users. The website is {{website_url}}.

Context:
- You need to use a screen reader like {{screen_reader_name}} to navigate the website and interact with its elements.
- You should check for common accessibility issues, such as missing alt text for images, improper heading structure, and inaccessible forms.

Provide:
1. A list of all the accessibility issues you found during the manual test.
2. A description of the steps to reproduce each issue.
3. Recommendations for fixing the issues to improve the accessibility of the website.
