# Optimize the Performance of a Single-Page Application (SPA) for Search Engines

Get SPA SEO guidance with a rendering strategy comparison and recommendation, plus routing, meta tags, structured data, and crawlability advice.

Variables: Framework

## Prompt

We have a Single-Page Application (SPA) built with `{{Framework}}` (e.g., React, Vue, Angular), and we are concerned about its SEO performance. I need a set of best practices for optimizing our SPA for search engines.

Act as an SEO expert and provide a comprehensive guide to SPA SEO.

Your response should cover the following:
1. **Rendering:** A comparison of different rendering strategies for SPAs, such as server-side rendering (SSR), static site generation (SSG), and dynamic rendering. Provide a recommendation for which strategy to use for our application.
2. **Routing:** Best practices for implementing routing in a SPA to ensure that search engines can crawl and index all of the pages.
3. **Meta Tags:** A guide to managing meta tags (e.g., `title`, `meta description`) in a SPA to provide unique and relevant information for each page.
4. **Structured Data:** How to use structured data (e.g., Schema.org) to provide search engines with more information about the content of your SPA.
5. **JavaScript:** How to ensure that your SPA is crawlable and indexable by search engines, even if it relies heavily on JavaScript.
