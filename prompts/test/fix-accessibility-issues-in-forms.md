# Fix Accessibility Issues in Forms

Audit a form's labels, error messages, and ARIA roles to get a list of accessibility changes for usability with assistive technologies.

Variables: form_name, page_name

## Prompt

Audit the accessibility features of the {{form_name}} on {{page_name}}. Identify shortcomings such as lack of labels, error messages, or ARIA roles. Provide a comprehensive list of necessary changes to improve accessibility compliance and enhance usability for all users, including those using assistive technologies.

## Tips

Accessibility improvements benefit all users and enhance overall usability.
