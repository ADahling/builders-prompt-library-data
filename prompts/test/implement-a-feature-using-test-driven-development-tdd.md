# Implement a Feature using Test-Driven Development (TDD)

Execute a full TDD cycle by generating failing tests, functional code, and refactored logic for a specific application feature.

Variables: feature_name, user_action, application_type, programming_language

## Prompt

You are a senior software developer and a TDD practitioner. Your task is to implement a new feature, {{feature_name}}, in an existing application using the Test-Driven Development (TDD) approach. The feature should allow users to {{user_action}}.

Context:
- The application is a {{application_type}} written in {{programming_language}}.
- The existing codebase has a good test coverage.

Provide:
1. A series of failing tests that define the new feature.
2. The implementation of the feature that makes the tests pass.
3. A final refactoring of the code to improve its quality.

## Tips

This advanced prompt is for experienced developers who want to practice and demonstrate their TDD skills.
