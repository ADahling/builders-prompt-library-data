# Write an E2E Test with Playwright for a User Authentication Flow

Generate a Playwright test script with assertions to automate and validate full user sign-up, login, and logout authentication flows.

Variables: application_type, frontend_framework, database_name

## Prompt

You are a test automation engineer. Your task is to write an end-to-end (E2E) test for a user authentication flow using Playwright. The flow includes signing up, logging in, and logging out.

Context:
- The application is a {{application_type}} built with {{frontend_framework}}.
- The user data is stored in {{database_name}}.

Provide:
1. A Playwright script that automates the entire authentication flow.
2. Assertions to verify that each step of the flow is completed successfully.
3. A video recording of the test execution.

## Tips

A good prompt for those who want to practice E2E testing with Playwright for a common web application feature.
