# Write a Unit Test for a Function with a Fluent Interface

Generate comprehensive unit tests to validate method chaining logic and property assignment for complex objects using fluent interfaces.

Variables: function_type, function_purpose

## Prompt

You are a junior developer. Your task is to write a unit test for a function that has a fluent interface. The function allows you to chain multiple method calls together to build a complex object or perform a series of actions.

Context:
- The function is a {{function_type}} that is used to {{function_purpose}}.
- You need to test that the fluent interface works as expected and that the final result is correct.

Provide:
1. A unit test that chains multiple method calls together and creates a complex object.
2. Assertions to verify that the properties of the object are set correctly.
3. A test case to handle invalid method calls or arguments.

## Tips

A beginner-friendly prompt for learning how to test functions with fluent interfaces, which are common in many libraries and frameworks.
