# Write an E2E Test with Cypress for a Real-Time Chat Application

Automate multi-user WebSocket testing in Cypress to verify real-time message exchange and presence updates across concurrent chat sessions.

## Prompt

You are an experienced QA automation engineer. Your task is to write an E2E test with Cypress for a real-time chat application. The application allows multiple users to chat with each other in real-time.

Context:
- The application uses WebSockets for real-time communication.
- You need to test that messages are sent and received correctly by all users in the chat room.

Provide:
1. A Cypress script that opens two browser windows and simulates a chat conversation between two users.
2. Assertions to verify that the messages are displayed correctly in both browser windows.
3. A test case to handle the scenario where a user joins or leaves the chat room.
