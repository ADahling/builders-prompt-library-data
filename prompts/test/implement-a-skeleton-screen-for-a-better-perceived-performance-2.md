# Implement a Skeleton Screen for a Better Perceived Performance

Get a skeleton screen guide with CSS animation, a reusable React component, and accessibility advice for web pages waiting on data.

## Prompt

I want to improve the perceived performance of our web application by implementing a skeleton screen while the data is loading. I need a guide on how to create a skeleton screen that looks good and accurately represents the layout of the page.

Your task is to provide a comprehensive guide to creating a skeleton screen for a web application.

Your response should include:
1. **Skeleton Screen Benefits:** A brief explanation of what a skeleton screen is and how it can improve the user's perception of performance.
2. **Design:** Best practices for designing a skeleton screen that is effective and not distracting.
3. **Implementation with CSS:** A tutorial on how to create a skeleton screen using only CSS, with techniques like gradients and animations to create a pulsing effect.
4. **Implementation with React:** A guide to creating a reusable skeleton screen component in React that can be easily integrated into our application.
5. **Accessibility:** How to ensure that your skeleton screen is accessible to users with disabilities.
