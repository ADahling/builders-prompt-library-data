# Optimize Modal Accessibility

Get a modal accessibility review covering keyboard use, focus, and screen readers, with proposed ARIA, tabindex, and JavaScript changes.

Variables: page_name

## Prompt

Evaluate the modal dialog implemented on the {{page_name}}. Check for accessibility issues such as keyboard navigation, focus traps, and screen reader support. Propose a list of improvements, including ARIA attributes, tabindex adjustments, and any necessary JavaScript modifications to ensure a smooth user experience.

## Tips

Accessible modals improve user experience for all users, including those with disabilities.
