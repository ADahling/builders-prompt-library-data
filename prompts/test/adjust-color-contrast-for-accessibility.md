# Adjust Color Contrast for Accessibility

Get a review of page elements with low color contrast, plus specific replacement color values and CSS adjustments for accessibility.

Variables: page_name, color_elements

## Prompt

Review the color scheme used on the {{page_name}}. Identify any elements that do not meet the recommended contrast ratios for accessibility. Propose changes to {{color_elements}} to ensure they are compliant with accessibility standards, providing specific color values and CSS adjustments.

## Tips

Adequate color contrast is vital for users with visual impairments.
