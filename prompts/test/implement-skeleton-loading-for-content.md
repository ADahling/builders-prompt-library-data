# Implement Skeleton Loading for Content

Design a content-shaped skeleton loading UI for your page, with example HTML and CSS that preview the structure of incoming content.

Variables: content_type, page_name

## Prompt

Design a skeleton loading UI for the {{content_type}} on {{page_name}}. Ensure that the skeleton reflects the structure of the content being loaded to provide users with a visual cue of what to expect. Include CSS styles and example HTML for the skeleton elements.

## Tips

Skeleton screens can improve perceived performance and user satisfaction.
