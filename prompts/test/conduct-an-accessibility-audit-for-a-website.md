# Conduct an Accessibility Audit for a Website

Audit a website for WCAG 2.1 compliance to identify accessibility barriers and receive actionable remediation strategies with code fixes.

Variables: website_url, target_audience

## Prompt

You are a web accessibility consultant. Your task is to conduct an accessibility audit for a website to ensure it complies with the Web Content Accessibility Guidelines (WCAG) 2.1. The website is {{website_url}} and its target audience is {{target_audience}}.

Context:
- The audit should cover all aspects of accessibility, including keyboard navigation, screen reader compatibility, and color contrast.
- The findings should be documented in a detailed report.

Provide:
1. A list of all accessibility issues found on the website, with severity levels.
2. Recommendations for fixing each issue, with code examples where applicable.
3. A summary of the website's overall accessibility compliance.

## Tips

This prompt is for developers and QA professionals who want to ensure their websites are accessible to everyone.
