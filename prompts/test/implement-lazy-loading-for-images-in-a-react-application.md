# Implement Lazy Loading for Images in a React Application

Get React image lazy loading examples using native attributes and Intersection Observer, plus library comparisons for a media-heavy app.

## Prompt

I'm building a media-heavy React application, and I need to improve the initial page load time by implementing lazy loading for images. I want a solution that is both efficient and provides a good user experience.

Your task is to provide a guide on how to implement image lazy loading in a React application. The guide should cover multiple techniques and provide code examples for each.

Your response should include:
1.  **Native Lazy Loading:** An explanation of how to use the `loading="lazy"` attribute on `<img>` tags and its browser support.
2.  **Intersection Observer API:** A detailed tutorial on how to use the Intersection Observer API to build a custom lazy loading solution. Provide a reusable React component for this purpose.
3.  **Third-Party Libraries:** A comparison of popular React libraries for lazy loading images, such as `react-lazyload` or `react-intersection-observer`. Include the pros and cons of each.
4.  **Best Practices:** Recommendations for providing placeholders, handling errors, and ensuring accessibility for lazy-loaded images.
