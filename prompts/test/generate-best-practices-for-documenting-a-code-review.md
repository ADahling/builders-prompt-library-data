# Generate best practices for documenting a code review

Get a Markdown guide for documenting your project's code reviews, including capturing comments, following up on actions, and logging issues and solutions.

Variables: project_name

## Prompt

Generate an easy-to-follow guide on how to document a code review process for the {{project_name}}. This should include how to capture comments, how to follow-up on action items, and how to maintain a log of issues and solutions discussed during the process. The output should be a markdown document.
