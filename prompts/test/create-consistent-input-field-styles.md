# Create Consistent Input Field Styles

Review inconsistent input fields on a page and get a unified style guide with CSS for borders, padding, and hover states.

Variables: page_name, input_fields

## Prompt

Inspect the input fields across the {{page_name}}. Identify inconsistencies in styles, sizes, or spacing. Propose a unified style guide for {{input_fields}}, including CSS styles for borders, padding, and hover states.

## Tips

Consistent input field styles enhance usability and appearance.
