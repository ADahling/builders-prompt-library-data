# Achieve a Perfect Lighthouse Score for a Static Website

Get a static website optimization checklist by Lighthouse category, with practical guidance, code examples, and tooling recommendations.

Variables: WebsiteURL

## Prompt

I have a static website, `{{WebsiteURL}}`, and my goal is to achieve a perfect 100 score across all categories in Google Lighthouse (Performance, Accessibility, Best Practices, and SEO). I need a detailed checklist and guide to help me achieve this.

Your task is to provide a comprehensive action plan that I can follow to optimize my website and get a perfect Lighthouse score. The guide should be practical and provide code examples where applicable.

Your response should be a checklist organized by Lighthouse category:
1.  **Performance:** A list of all the performance optimizations needed to get a 100 score, including asset optimization, caching, and rendering optimizations.
2.  **Accessibility:** A checklist of accessibility improvements to ensure the site is usable by everyone, including proper semantic HTML, ARIA attributes, and color contrast.
3.  **Best Practices:** A list of best practices to follow, such as using HTTPS, avoiding deprecated APIs, and ensuring a safe user experience.
4.  **SEO:** A guide to optimizing the site for search engines, including meta tags, structured data, and a mobile-friendly design.
5.  **Tooling:** Recommendations for tools that can help automate the optimization process and check for compliance with the Lighthouse audit criteria.
