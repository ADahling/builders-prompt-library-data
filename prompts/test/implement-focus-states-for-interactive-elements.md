# Implement Focus States for Interactive Elements

Audit a page for interactive elements missing visible focus feedback and get suggested changes with hover and focus CSS.

Variables: page_name, interactive_elements

## Prompt

Conduct an audit of the {{page_name}} to identify interactive elements that lack visible focus states. Suggest changes to {{interactive_elements}} to ensure they provide clear feedback when focused, including CSS styles for hover and focus states.

## Tips

Clear focus states are essential for keyboard accessibility.
