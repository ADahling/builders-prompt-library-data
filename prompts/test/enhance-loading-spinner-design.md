# Enhance Loading Spinner Design

Design a loading spinner that matches a component's UI, with suggested animations, visual styles, and CSS implementation snippets.

Variables: component_name, page_name

## Prompt

Design a loading spinner for the {{component_name}} on {{page_name}}. Ensure that the spinner is visually appealing and matches the overall UI style. Propose animations and styles for the spinner, including CSS code snippets for implementation.

## Tips

Loading spinners should be visually appealing yet functional.
