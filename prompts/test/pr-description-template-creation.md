# PR Description Template Creation

Get a standardized project PR description template with Summary, Changes, Testing, and Related Tickets sections, plus tips for filling them out.

Variables: project_name

## Prompt

Create a standardized Pull Request (PR) description template for the {{project_name}}. The template should include sections such as `Summary`, `Changes`, `Testing`, and `Related Tickets`. Additionally, insert tips on how to fill out each section effectively.
