# Write an E2E Test with Cypress for a WYSIWYG Editor

Generate comprehensive Cypress E2E tests to validate rich text formatting, image insertion, and external clipboard pasting in a WYSIWYG.

## Prompt

You are a skilled QA automation engineer. Your task is to write an E2E test with Cypress for a WYSIWYG editor. The editor allows users to format text, insert images, and create tables.

Context:
- The WYSIWYG editor is a complex component with a lot of functionality.
- You need to test that the editor works as expected and that the generated HTML is correct.

Provide:
1. A Cypress script that simulates user interactions with the WYSIWYG editor, such as typing text, applying formatting, and inserting an image.
2. Assertions to verify that the content of the editor is correct and that the generated HTML is well-formed.
3. A test case to handle the scenario where the user pastes content from an external source.

## Tips

An advanced prompt for QA engineers who want to test complex and interactive components like WYSIWYG editors.
