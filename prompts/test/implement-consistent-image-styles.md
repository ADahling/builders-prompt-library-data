# Implement Consistent Image Styles

Audit image borders, shadows, and spacing on a page, and get a unified style guide with example CSS aligned to your site's design.

Variables: page_name, image_elements

## Prompt

Inspect the image styles across the {{page_name}}. Identify inconsistencies in borders, shadows, or spacing. Propose a unified style guide for {{image_elements}} ensuring they align with the overall design aesthetic, providing example CSS for implementation.

## Tips

Consistent image styles enhance visual cohesion.
