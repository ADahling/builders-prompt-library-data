# Choose and Implement a Static Site Generator (SSG) for a React Project

Compare React static site generators for a content-heavy site, with a recommendation, setup and deployment steps, and guidance on SSG versus SSR.

Variables: ProjectName

## Prompt

I’m starting a new content-heavy React project, `{{ProjectName}}`, and I want to use a Static Site Generator (SSG) to achieve the best possible performance and SEO. I need a guide on how to choose the right SSG for my project and how to get started with it.

Your task is to provide a comprehensive guide to choosing and implementing an SSG for a React project. The guide should compare the most popular options and provide a getting-started tutorial for one of them.

Your response should include:
1. **SSG Comparison:** A detailed comparison of popular React SSGs, such as Next.js, Gatsby, and Astro. The comparison should cover their features, performance, learning curve, and community support.
2. **Recommendation:** A recommendation for which SSG to use for my project, based on the fact that it is a content-heavy site.
3. **Getting Started Guide:** A step-by-step tutorial on how to create a new project with your recommended SSG. The tutorial should cover the basic setup, creating pages, and fetching data.
4. **Deployment:** A guide on how to build and deploy the static site to a hosting provider like Netlify or Vercel.
5. **When to use SSG vs. SSR:** A clear explanation of the differences between Static Site Generation (SSG) and Server-Side Rendering (SSR) and when to choose one over the other.
