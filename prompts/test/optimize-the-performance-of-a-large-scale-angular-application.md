# Optimize the Performance of a Large-Scale Angular Application

Get an Angular optimization guide covering change detection, AOT, lazy loading, tree shaking, and profiling for slow apps with large bundles.

## Prompt

Our large-scale Angular application is experiencing performance issues with slow change detection and a large bundle size. I need a set of best practices and optimization techniques for our Angular application.

Act as an Angular performance expert and provide a comprehensive guide to optimizing a large-scale Angular application.

Your response should cover the following:
1.  **Change Detection:** A guide to optimizing change detection in Angular, such as using the `OnPush` change detection strategy and detaching the change detector.
2.  **AOT Compilation:** An explanation of Ahead-of-Time (AOT) compilation and how it can be used to improve the performance and reduce the bundle size of an Angular application.
3.  **Lazy Loading:** How to use lazy loading to split the application into smaller modules and load them on demand.
4.  **Tree Shaking:** A guide to ensuring that tree shaking is working correctly in an Angular application to remove unused code from the bundle.
5.  **Performance Profiling:** How to use the Angular devtools and other tools to profile the performance of an Angular application and identify bottlenecks.
