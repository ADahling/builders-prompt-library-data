# Fix Dropdown Menu Usability

Get a dropdown usability review with CSS changes for hard-to-click items, unclear labels, sizing, and hover states on your page.

Variables: page_name, dropdown_elements

## Prompt

Inspect the dropdown menus on the {{page_name}}. Identify any usability issues such as items that are hard to click or unclear labeling. Propose improvements for {{dropdown_elements}}, including size adjustments, clearer labels, and hover states. Provide relevant CSS changes.

## Tips

User-friendly dropdowns enhance navigation and overall user experience.
