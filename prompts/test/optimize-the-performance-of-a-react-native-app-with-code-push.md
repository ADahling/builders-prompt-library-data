# Optimize the Performance of a React Native App with Code Push

Get a CodePush guide for React Native updates, covering Android and iOS setup, deployment, rollbacks, testing, and breaking changes.

## Prompt

I want to use CodePush to instantly update our React Native application without having to go through the app store review process. I need a guide on how to set up CodePush and how to use it to deploy updates to our users.

Your task is to provide a comprehensive guide to using CodePush with a React Native application.

Your response should include:
1. **What is CodePush?:** A clear explanation of what CodePush is and how it can be used to instantly update a React Native application.
2. **Setup:** A step-by-step guide to setting up CodePush for both Android and iOS.
3. **Deploying Updates:** A guide to deploying updates to your users with CodePush.
4. **Rollbacks:** How to roll back an update if you discover a bug.
5. **Best Practices:** A discussion of best practices for using CodePush, such as how to handle breaking changes and how to test your updates before deploying them to your users.
