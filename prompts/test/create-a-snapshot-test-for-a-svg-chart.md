# Create a Snapshot Test for a SVG Chart

Generate and automate snapshot tests for SVG-based charts to detect unintended visual regressions and ensure rendering consistency.

Variables: chart_data

## Prompt

You are a data visualization developer. Your task is to create a snapshot test for a SVG chart that is generated by a charting library. The chart displays {{chart_data}}.

Context:
- You want to ensure that the visual representation of the chart does not change unexpectedly.
- You are using a testing framework that supports snapshot testing for SVG elements.

Provide:
1. A test that renders the chart with some sample data and creates a snapshot of the SVG output.
2. A script to update the snapshot when the chart is intentionally changed.

## Tips

A prompt for developers who work with data visualizations to learn how to use snapshot testing to maintain the consistency of their charts.
