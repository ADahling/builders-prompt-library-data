# Use TDD to Implement a Finite State Machine

Implement a finite state machine for a specific system using test-driven development to ensure reliable state transitions and logic.

Variables: system_name

## Prompt

You are a software developer. Your task is to use Test-Driven Development (TDD) to implement a finite state machine (FSM). The FSM will be used to model the behavior of a {{system_name}}.

Context:
- The FSM has a set of states, a set of events, and a set of transitions between the states.
- You will write a set of tests that define the behavior of the FSM for each state and event.

Provide:
1. A set of failing tests that define the transitions of the FSM.
2. The implementation of the FSM that makes the tests pass.
3. A diagram that visualizes the states and transitions of the FSM.

## Tips

A prompt for developers who want to practice TDD to implement a common design pattern like a finite state machine.
