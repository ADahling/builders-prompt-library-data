# Enhance Tooltip Usability

Review tooltip positioning and readability on desktop and mobile, with suggested CSS, visibility timing, and JavaScript adjustments.

Variables: page_name, element

## Prompt

Analyze the tooltip implementation on the {{page_name}}. Determine if the tooltip appears at an optimal position relative to the {{element}} and if it is easily readable on both desktop and mobile. Suggest improvements to the CSS positioning and visibility timing, as well as any necessary JavaScript adjustments.

## Tips

Tooltips should not obstruct the main content while providing useful information.
