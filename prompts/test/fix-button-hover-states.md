# Fix Button Hover States

Review a page's buttons for unclear hover feedback and get proposed CSS changes, such as distinct colors or animations for hover states.

Variables: page_name, button_elements

## Prompt

Inspect the button hover states on the {{page_name}}. Identify any buttons that do not provide clear feedback to the user when hovered. Propose CSS changes to ensure that {{button_elements}} have distinct hover states, such as color changes or animations.

## Tips

Effective hover states enhance interactivity and engagement.
