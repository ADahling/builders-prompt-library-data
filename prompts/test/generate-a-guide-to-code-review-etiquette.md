# Generate a guide to code review etiquette

Get Markdown tips for team code reviews covering constructive criticism, different personalities, compromise, and focusing on the code.

Variables: project_name

## Prompt

Generate a guide to code review etiquette applicable to our team working on the {{project_name}}. This should include best practices for constructive criticism, how to approach different personalities, knowing when to hold and when to fold, and how to maintain a focus on the code rather than on the coder. The output should be a set of markdown-formatted steps or tips.
