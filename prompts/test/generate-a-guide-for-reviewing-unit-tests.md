# Generate a guide for reviewing unit tests

Get a Markdown unit test review guide for your stack, with good and bad patterns for speed, independence, repeatability, and thoroughness.

Variables: tech_stack

## Prompt

Generate a guide to review unit tests in our {{tech_stack}} projects. This should focus on good unit test characteristics: they should be fast, independent, repeatable, self-validating, and thorough. Each point should provide elaboration of good patterns to look for and bad patterns to avoid. The output needs to be a markdown formatted guide.
