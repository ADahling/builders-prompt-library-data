# Optimize CSS Custom Properties Performance

Get guidance on scope, inheritance, animation, JavaScript updates, and profiling when CSS custom properties raise performance concerns.

## Prompt

We are using CSS Custom Properties (Variables) in our web application to make our CSS more maintainable, but we are concerned about the performance implications. I need a set of best practices for optimizing the performance of CSS Custom Properties.

Act as a CSS performance expert and provide a comprehensive guide to writing performant CSS Custom Properties code.

Your response should cover the following:
1. **Scope:** A guide to scoping your custom properties to the smallest possible subtree of the DOM to reduce the cost of invalidation.
2. **Inheritance:** A discussion of the performance implications of using inherited custom properties and when it is appropriate to use them.
3. **Animating Custom Properties:** Best practices for animating custom properties to avoid performance bottlenecks.
4. **JavaScript and Custom Properties:** A guide to using JavaScript to update custom properties and the performance implications of doing so.
5. **Profiling:** How to use browser developer tools to profile the performance of CSS Custom Properties and identify bottlenecks.
