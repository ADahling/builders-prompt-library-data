# Code Scope and Complexity Review Strategy

Plan a code scope and complexity review for your project's tech stack, outlining how to check adherence to DRY, KISS, and YAGNI.

Variables: project_name, tech_stack

## Prompt

Construct a strategy for conducting a review focusing on code scope and complexity for {{project_name}}, particularly in the context of {{tech_stack}}. It should outline how to ensure the code follows principles like DRY (Don't Repeat Yourself), KISS (Keep It Simple, Stupid), and YAGNI (You Aren't Gonna Need It).
