# Create Contextual Help for Forms

Design tooltips or help icons for difficult form fields, with HTML and CSS adjustments to implement contextual help on your page.

Variables: form_name, page_name

## Prompt

Design contextual help for the {{form_name}} on {{page_name}}. Identify fields where users might struggle and propose helpful tooltips or help icons. Include necessary HTML and CSS adjustments for implementing these contextual help features.

## Tips

Contextual help can reduce user frustration and enhance form completion rates.
