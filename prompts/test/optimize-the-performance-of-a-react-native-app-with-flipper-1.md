# Optimize the Performance of a React Native App with Flipper

Get a Flipper setup and profiling guide for debugging React Native bottlenecks, including Android, iOS, and custom plugins.

## Prompt

I want to use Flipper to debug and optimize the performance of our React Native application. I need a guide on how to set up Flipper and how to use it to identify performance bottlenecks.

Your task is to provide a comprehensive guide to using Flipper with a React Native application.

Your response should include:
1. **What is Flipper?:** A clear explanation of what Flipper is and how it can be used to debug and optimize a React Native application.
2. **Setup:** A step-by-step guide to setting up Flipper for both Android and iOS.
3. **Performance Profiling:** A guide to using the performance profiling tools in Flipper to identify performance bottlenecks in your application.
4. **React Native specific plugins:** A discussion of the React Native specific plugins available in Flipper, such as the React Native Inspector and the Hermes Debugger.
5. **Custom Plugins:** How to create your own custom Flipper plugins to debug and optimize your application.
