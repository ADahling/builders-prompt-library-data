# Technical Debt Evaluation

Get a repository technical debt evaluation with impact ratings, refactoring opportunities, and actionable prioritization strategies.

Variables: repository_url

## Prompt

Evaluate the technical debt in the project at {{repository_url}}. Identify key areas contributing to technical debt and categorize them by impact level (high, medium, low). Suggest actionable steps to address this debt, including refactoring opportunities and prioritization strategies.

## Tips

Use tools like SonarQube to quantify technical debt.
