# SEO Audit for Web Application

Audit your website's meta tags, alt attributes, URLs, and sitemap, with findings and actionable recommendations for search visibility.

Variables: website_url

## Prompt

Conduct an SEO audit for the website at {{website_url}}. Check for critical SEO factors such as meta tags, alt attributes, URL structure, and sitemap availability. Provide a summary of findings along with actionable recommendations to improve search engine visibility.

## Tips

Tools like Google Search Console or Screaming Frog can aid in this audit.
