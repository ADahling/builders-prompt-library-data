# Write a Unit Test for a Recursive Function

Generate comprehensive unit tests for recursive factorial functions, covering base cases and positive integers to ensure algorithm accuracy.

Variables: programming_language

## Prompt

You are a computer science student. Your task is to write a unit test for a recursive function that calculates the factorial of a number. The function is written in {{programming_language}}.

Context:
- The function should handle the base case (factorial of 0 is 1) and the recursive step.
- You need to test the function with a few different input values to ensure that it works correctly.

Provide:
1. A unit test that calls the recursive function with a positive integer.
2. A test case for the base case (input 0).
3. Assertions to verify that the function returns the correct factorial value.
