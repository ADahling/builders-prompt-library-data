# Improve Accessibility for Color Blind Users

Audit a page for color-only communication and get text label or pattern alternatives to make information clearer for color-blind users.

Variables: page_name, color_communicating_elements

## Prompt

Audit the color choices on the {{page_name}} for accessibility regarding color blindness. Identify areas where color alone communicates information. Suggest alternative methods, such as text labels or patterns, for {{color_communicating_elements}} to ensure clarity for all users.

## Tips

Accessibility improvements benefit all users, including those with color blindness.
