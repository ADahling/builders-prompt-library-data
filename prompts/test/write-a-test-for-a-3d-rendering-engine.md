# Write a Test for a 3D Rendering Engine

Implement automated visual regression tests and performance benchmarks to validate the accuracy and efficiency of a 3D rendering engine.

Variables: programming_language, graphics_api

## Prompt

You are a graphics engineer. Your task is to write a test for a 3D rendering engine to verify that it renders 3D scenes correctly. The rendering engine is written in {{programming_language}} and it uses a graphics API like {{graphics_api}}.

Context:
- You need to test the rendering engine with different 3D models, materials, and lighting conditions.
- You will compare the rendered image with a reference image to ensure that the rendering is correct.

Provide:
1. A test that loads a 3D scene and renders it with the rendering engine.
2. A script to compare the rendered image with a reference image pixel by pixel.
3. A benchmark to measure the performance of the rendering engine.

## Tips

An advanced prompt for graphics engineers who are working on 3D rendering engines and need to test their correctness and performance.
