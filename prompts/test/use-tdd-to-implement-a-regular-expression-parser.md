# Use TDD to Implement a Regular Expression Parser

Build a regex parser that generates abstract syntax trees using a test-driven development approach to support basic operators and logic.

## Prompt

You are a compiler engineer. Your task is to use Test-Driven Development (TDD) to implement a regular expression parser. The parser should take a regular expression as input and produce an abstract syntax tree (AST).

Context:
- The regular expression syntax should support basic operators like concatenation, union, and Kleene star.
- You will write a set of tests that define the expected AST for different regular expressions.

Provide:
1. A set of failing tests that define the behavior of the regular expression parser.
2. The implementation of the parser that makes the tests pass.
3. A visualization of the AST for a sample regular expression.

## Tips

An advanced prompt for engineers who want to practice TDD to implement a complex algorithm like a regular expression parser.
