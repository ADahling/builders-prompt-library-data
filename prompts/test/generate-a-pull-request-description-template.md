# Generate a Pull Request description template

Get a reusable Markdown pull request template for your project with issue links, change summaries, affected files, and testing instructions.

Variables: project_name

## Prompt

To streamline the process of submitting pull requests, generate a reusable template for {{project_name}}. The template should include placeholders for the issue link, a summary of changes, a list of areas affected or files changed, any instructions for testing or special considerations, and references to any related pull requests or issues. The output should be a markdown document, formatted and ready for immediate use.
