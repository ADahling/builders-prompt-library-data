# Write a Unit Test for a Complex Calculation Function

Generate robust unit tests in your preferred language to validate complex logic and ensure reliability across specific edge cases.

Variables: calculation_logic, programming_language, module_name, input_parameters, edge_case_1, edge_case_2

## Prompt

You are a junior software engineer. Your task is to write a comprehensive unit test for a function that calculates {{calculation_logic}}. The function is written in {{programming_language}} and is part of a larger module for {{module_name}}.

Context:
- The function takes {{input_parameters}} as input.
- It needs to handle edge cases such as {{edge_case_1}} and {{edge_case_2}}.

Provide:
1. A clear and concise unit test that covers the main functionality.
2. Test cases for all relevant edge cases.
3. Assertions to verify the correctness of the output.

## Tips

This prompt is ideal for beginners learning to write unit tests for functions with complex logic.
