# Improve Keyboard Navigation

Audit a page's keyboard navigation and get HTML and CSS changes for focusable interactive elements and visible focus feedback.

Variables: page_name, interactive_elements

## Prompt

Conduct an audit on the {{page_name}} to identify areas where keyboard navigation is lacking. Suggest modifications to {{interactive_elements}} to ensure they are focusable and provide clear visual feedback upon focusing. Include necessary changes for HTML and CSS to enhance keyboard accessibility.

## Tips

Improving keyboard navigation greatly enhances accessibility for users.
