# Automate regression testing

Plan regression coverage across test layers, mapping system risks to tests with run schedules, ownership, and quarantine rules.

## Prompt

Create a regression strategy for {{system}}. Map critical risks to unit, integration, contract, visual, accessibility, and end-to-end tests. Define what runs on pull request, merge, nightly, and release, plus ownership and quarantine rules.
