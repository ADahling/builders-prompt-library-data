# Design Clear Error Icons

Review form error icons for clarity and meaning, with design improvements and CSS adjustments for consistent style and size.

Variables: form_name, page_name

## Prompt

Evaluate the error icons used in {{form_name}} on {{page_name}}. Determine if they are easily identifiable and convey the right message. Suggest design improvements for the icons, ensuring they are consistent in style and size, along with CSS adjustments.

## Tips

Clear error icons help users notice and fix issues swiftly.
