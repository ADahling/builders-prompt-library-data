# Design Effective Loading States

Design an animated loading state for a UI component based on expected wait time, with CSS styles and relevant JavaScript logic.

Variables: component_name, page_name, loading_animation_type

## Prompt

Create a loading state for the {{component_name}} on {{page_name}}. Identify the expected loading duration and design an animated loading component that suits the overall UI style. Consider using {{loading_animation_type}} and ensure it communicates loading clearly without frustrating the user. Include CSS styles and any relevant JavaScript logic.

## Tips

Loading states should keep users informed and engaged.
