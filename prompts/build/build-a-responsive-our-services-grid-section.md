# Build a Responsive 'Our Services' Grid Section

Get HTML and CSS for a company website's responsive services grid, with an icon, title, and short description for each service.

## Prompt

I need to create a responsive 'our services' section for a company website. The section should display a grid of services, each with an icon, a title, and a short description. The grid should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our services' section.
