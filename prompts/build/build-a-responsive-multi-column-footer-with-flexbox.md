# Build a Responsive Multi-Column Footer with Flexbox

Get HTML and pure CSS for a Flexbox footer with link columns that stack on small screens and a section for social media icons.

## Prompt

I need to create a responsive footer for a website. The footer should have multiple columns with links. On large screens, the columns should be displayed in a row. On small screens, they should be stacked vertically. The footer should also have a section with social media icons. Provide the HTML structure and the CSS to create this responsive footer. The solution should be pure CSS and use Flexbox for the layout..
