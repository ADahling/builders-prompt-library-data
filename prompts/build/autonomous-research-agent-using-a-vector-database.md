# Autonomous Research Agent using a Vector Database

Build a Python research agent with web search, scraping, and vector database tools to gather new information and retain knowledge on a topic over time.

Variables: research_topic

## Prompt

Build an autonomous research agent that can browse the web, gather information, and store it in a vector database for long-term memory and retrieval. The agent should be able to build up a knowledge base on a topic over time.

**Agent Architecture:**

1.  **Core Task:** The agent is given a research topic, `{{research_topic}}`.
2.  **Tools:**
    *   `web_search`: A tool to search the web for relevant URLs.
    *   `web_scraper`: A tool to scrape the content of a URL.
    *   `vector_store_add`: A tool to add text content to a vector database (e.g., Chroma or FAISS).
    *   `vector_store_query`: A tool to query the vector database for information it has already learned.
3.  **Reasoning Loop:**
    *   The agent should first query its vector store to see what it already knows about the topic.
    *   Based on this, it should decide on a search query to find new information.
    *   It uses the `web_search` tool to get a list of URLs.
    *   It then iterates through the URLs, scraping the content of each.
    *   For each piece of content, it decides if it's relevant and new. If so, it uses the `vector_store_add` tool to save it.
    *   The agent can loop this process, refining its searches and building its knowledge base, until it determines it has sufficient information.

**Your Task:**

Design and implement this agent in Python. You will need to:

*   Set up a vector database.
*   Implement the four required tools.
*   Create a ReAct-style agent with a prompt that guides it through the research loop.
*   The prompt should encourage the agent to be curious and to try to build a comprehensive understanding of the topic.

**Output:**

A Python script for the agent. When run, it should perform a few cycles of searching, scraping, and saving information. The final output should be a summary of the information the agent has gathered, generated by querying its own vector store.
