# Build a Responsive 'Our Awards' Grid Section

Get HTML and CSS for a responsive company awards section featuring a grid of icons, titles, and short descriptions across screen sizes.

## Prompt

I need to create a responsive 'our awards' section for a company website. The section should display a grid of awards, each with an icon, a title, and a short description. The grid should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our awards' section.
