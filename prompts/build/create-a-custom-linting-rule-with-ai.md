# Create a Custom Linting Rule with AI

Write an AI coding request for an ESLint rule that flags async function declarations missing the required _async suffix in your team's code.

## Prompt

Your team has a coding convention that requires all asynchronous functions to have a `_async` suffix. You want to enforce this with a custom ESLint rule.

Ask an AI coding assistant to generate the code for a custom ESLint rule that flags any async function declaration that does not follow this naming convention. Specify that the rule should be written for ESLint's rule API.
