# System Design Interview: Design a Yelp-like Service

Architect a scalable geospatial search engine and microservices framework to handle location-based business discovery and user reviews.

## Prompt

You are in a system design interview. The interviewer asks you to "Design a service like Yelp."

**Your Task:**
Provide a high-level design for a service that allows users to find and review local businesses.

**Instructions & Constraints:**
1.  **Core Features:**
    *   Users can search for businesses.
    *   Users can add and review businesses.
    *   The service should be location-aware.

2.  **Geospatial Search:**
    *   This is a key component. Explain how you would implement the search for nearby businesses using a geospatial index.

3.  **Architecture:**
    *   Design the main services: Search Service, Business Service, Review Service.

**Output Format:**
Generate a design document in Markdown:
1.  **Designing a Yelp-like Service for Local Business Discovery**
2.  **The Core Challenge: Geospatial Search**
3.  **High-Level System Architecture**
