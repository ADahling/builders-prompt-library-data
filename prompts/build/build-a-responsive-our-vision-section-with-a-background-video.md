# Build a Responsive 'Our Vision' Section with a Background Video

Get HTML and CSS for a responsive company vision section with a background video, title, and description centered on both axes.

## Prompt

I need to create a responsive 'our vision' section for a company website. The section should have a title, a short description, and a background video. The content should be centered vertically and horizontally. The section should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our vision' section.
