# Creating a GraphQL API for a Social Network

Design a social network GraphQL API with user, post, and comment types, relationships, query and mutation outlines, and usage examples.

## Prompt

Design a GraphQL API for a social networking platform. Include types for {User}, {Post}, and {Comment}. Outline:
- Queries for retrieving a user's profile, their posts, and comments on a specific post.
- Mutations for creating and editing posts, adding comments, and following users.
- Input types for mutations and relationships between these types.
- Provide examples of queries and mutations reflecting typical use cases.

## Tips

This prompt will help you understand how to build a rich and interconnected GraphQL API.
