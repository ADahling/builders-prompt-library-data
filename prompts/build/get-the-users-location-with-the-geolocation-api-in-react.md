# Get the User's Location with the Geolocation API in React

Get a React component with a Get Location button that uses the Geolocation API and displays the user's current latitude and longitude.

## Prompt

I'm building a web application that needs to have a feature to detect the user's location. I want to create a 'Get Location' button that, when clicked, gets the user's current latitude and longitude using the Geolocation API. Provide a React component that has a 'Get Location' button and uses the Geolocation API to get the user's location. The component should display the latitude and longitude to the user.
