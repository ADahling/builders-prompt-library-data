# Design an API for a Pet Adoption Platform

Get a pet adoption RESTful API design for pet searches, profiles, and adoption applications, with HTTP methods, URIs, and request/response formats.

Variables: pet_adoption_platform_name

## Prompt

I am building a pet adoption platform called {{pet_adoption_platform_name}}. I need to design the API for it.

Your task is to design the core API for the platform.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the platform (e.g., pets, shelters, users, adoption applications).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Users can search for pets available for adoption.
    *   Users can view pet profiles with photos and information.
    *   Users can submit adoption applications.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoint, including the HTTP method, URI, and request/response format.
