# Design REST API for E-commerce Platform

Architect a comprehensive CRUD REST API for e-commerce user profiles with detailed schemas, security protocols, and standard conventions.

## Prompt

You are a senior API architect. Design a RESTful API endpoint for an e-commerce platform to manage user profiles. The endpoint should handle creating, reading, updating, and deleting user data, including personal information, shipping addresses, and order history. Specify the HTTP methods, URI structure, request/response payloads, and status codes for each operation. Ensure the design follows REST best practices, including resource naming conventions and statelessness. Address potential security concerns like data validation and authentication.

## Tips

Focus on a specific aspect of the user profile API for each prompt, e.g., creating a new user, retrieving user details, updating an address, etc.
