# Creating a Presentation Generation Agent

Get a Python script that turns a topic and slide count into a Markdown presentation through LLM calls, plus a sample deck.

Variables: topic, num_slides

## Prompt

Build an AI agent that can create a slide deck presentation from a given topic. The agent should generate the content for each slide.

**Agent's Task:**

Given a `{{topic}}` and a desired number of slides (`{{num_slides}}`), the agent should:
1.  Generate a title for the presentation.
2.  Create an outline for the presentation, with a title for each slide.
3.  For each slide in the outline, generate the content (e.g., bullet points, a short paragraph).

**Implementation:**

This can be implemented as a sequence of LLM calls.

1.  **Call 1 (Outline):** Prompt an LLM to generate a presentation outline in a structured format (like JSON). The prompt should specify the topic and the number of slides.
2.  **Call 2 (Content Generation):** Loop through the generated outline. For each slide title, make another LLM call, asking it to generate the content for that specific slide.
3.  **Formatting:** Combine all the generated content into a single Markdown file, with each slide separated by `---`.

**Your Task:**

Write a Python script that orchestrates these LLM calls and produces a complete presentation in a single Markdown file.

**Output:**

A Python script and a sample Markdown presentation file generated by the agent.
