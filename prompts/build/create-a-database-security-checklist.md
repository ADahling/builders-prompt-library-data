# Create a Database Security Checklist

Get a checklist for reviewing database security across authentication, least-privilege access, encryption, auditing, and security patching.

## Prompt

I want to improve the security of our database. I need to create a database security checklist to help us to identify and to fix any security vulnerabilities.

Your task is to create a database security checklist. The checklist should cover the following topics:

1.  **Authentication:** Are we using strong authentication for our database users?
2.  **Authorization:** Are we using the principle of least privilege to grant access to our database?
3.  **Encryption:** Are we encrypting our sensitive data both at rest and in transit?
4.  **Auditing:** Are we auditing all access to our database?
5.  **Patching:** Are we keeping our database up-to-date with the latest security patches?

## Tips

This prompt is a foundational document for any organization that wants to improve the security of its database.
