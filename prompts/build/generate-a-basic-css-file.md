# Generate a basic CSS file

Create a basic CSS file to customize the global background color and paragraph font size using dynamic variables.

Variables: color, font_size

## Prompt

You are an AI coding assistant. Generate a basic CSS file that sets the background color of the body to `{{color}}` and the font size of all paragraphs to `{{font_size}}`.
