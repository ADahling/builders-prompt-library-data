# Cloning a SaaS Application's User Profile Page

Build a functional, validated user profile page and mock backend API by cloning the design and features of an existing SaaS application.

Variables: saas_app_url

## Prompt

You are a full-stack developer working on a new SaaS product. Your task is to clone the user profile page from a well-designed SaaS application. The page should allow users to view and edit their personal information, change their password, and manage their notification settings.

Context:
- The SaaS application with the user profile page is {{saas_app_url}}.
- You will need to create both the front-end and a mock back-end to handle the user data.
- The form for editing user information should have proper validation and provide clear feedback to the user.

Provide:
1. The front-end code for the user profile page.
2. The back-end code for the mock API that handles user data updates.

If you cannot open {{saas_app_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

## Tips

A practical exercise for learning how to build common features in SaaS applications.
