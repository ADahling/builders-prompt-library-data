# Build a Cookie Consent Banner That Remembers the User's Choice

Get a React cookie consent banner for Next.js with an Accept button and cookie logic that hides the banner after consent is saved.

## Prompt

I'm building a Next.js application and I want to add a cookie consent banner that appears at the bottom of the page. The banner should have a message about cookies and an 'Accept' button. When the user clicks the 'Accept' button, the banner should be hidden, and a cookie should be set to remember the user's choice. The banner should not appear again if the cookie is set. Provide a React component for the cookie consent banner. The component should handle the cookie logic.
