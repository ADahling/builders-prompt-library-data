# Render 10,000 Rows with a Virtualized List Using react-window

Get a TypeScript component using react-window's FixedSizeList for over 10,000 items, with name and email rows, data passing, and styling.

## Prompt

I'm building a complex dashboard with a lot of data visualizations. I need to implement a performant virtualized list to display a large dataset of over 10,000 items without causing performance issues. I want to use the `react-window` library. Create a component that uses `react-window`'s `FixedSizeList` to render a long list of items. Each item in the list should display a name and an email address. The component should be written in TypeScript and demonstrate how to pass data to the list and style the rows..
