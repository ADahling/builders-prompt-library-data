# Optimize a GitHub Copilot prompt for generating a function with error handling

Write a detailed Copilot prompt for a Python API-fetching function with a URL parameter, exception handling, HTTP status checks, and return rules.

## Prompt

You are a prompt engineering expert. Your task is to refine the following GitHub Copilot prompt to generate a more robust Python function for fetching data from an API.

Original Prompt:
`# a function to fetch data from an API`

Provide a more detailed prompt that specifies the following:
1. The function signature, including the URL parameter.
2. The use of a `try...except` block for error handling.
3. Handling of different HTTP status codes (e.g., 200, 404, 500).
4. The return value in case of success (JSON data) and failure (None).

## Tips

Focuses on prompt engineering to improve the quality of AI-generated code with error handling.
