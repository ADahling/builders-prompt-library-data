# Design an API for a Sentiment Analysis Service

Get a sentiment analysis endpoint design with request and response formats for a service that returns sentiment and a confidence score from text.

Variables: sentiment_analysis_service_name

## Prompt

I am building a sentiment analysis service called {{sentiment_analysis_service_name}}. I need to design the API for it.

Your task is to design the core API for the service.

**Instructions:**
1.  **Sentiment Analysis Endpoint:** Design a simple API endpoint that takes a text as input and returns its sentiment (e.g., positive, negative, neutral) and a confidence score.

**Output Format:**
Provide the output as a Markdown document. Describe the design of the sentiment analysis endpoint, including the request and response formats.
