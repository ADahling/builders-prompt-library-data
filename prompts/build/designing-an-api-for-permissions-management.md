# Designing an API for Permissions Management

Plan an app permissions API with creation and role-based retrieval endpoints, required fields, error handling, and request and response examples.

## Prompt

Outline an API for managing user permissions within your application. Discuss:
- Endpoints for {POST /permissions} to create new permissions and {GET /permissions/{roleId}} to retrieve permissions associated with a role.
- Required fields and error handling strategies.
- Provide examples of requests and responses demonstrating typical permission operations.

## Tips

This prompt will help enforce security and access control in your API.
