# Build a Smooth Scroll-to-Top Floating Button in React

Get a React component for a bottom-right floating button that appears on scroll and smoothly returns the page to the top when clicked.

## Prompt

I want to create a 'scroll to top' button that appears when the user scrolls down the page. When the button is clicked, the page should smoothly scroll back to the top. The button should be a floating button in the bottom-right corner of the screen. Create a React component for this 'scroll to top' button. The component should handle the scroll event to show and hide the button and the click event to scroll to the top. The scrolling should be smooth. Provide the complete code for the component.
