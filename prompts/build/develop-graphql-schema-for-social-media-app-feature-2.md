# Develop GraphQL Schema for Social Media App - Feature 2

Design a scalable GraphQL schema for a social media platform featuring real-time notifications, user relationships, and optimized mutations.

## Prompt

As a backend developer, create a GraphQL schema for a new social media application. The schema should support core features like user authentication, creating and fetching posts, following other users, and real-time notifications. Define the necessary types, queries, mutations, and subscriptions. Pay special attention to schema organization, performance considerations for nested queries, and how to handle relationships between different data entities like users, posts, and comments. Provide a clear explanation of your design choices.

## Tips

Each prompt can focus on a different part of the schema, e.g., user authentication, post management, follower relationships, etc.
