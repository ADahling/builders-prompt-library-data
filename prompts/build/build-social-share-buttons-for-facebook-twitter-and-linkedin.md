# Build Social Share Buttons for Facebook, Twitter, and LinkedIn

Get a React component with Facebook, Twitter, and LinkedIn share buttons that use URL and title props to open pre-filled share dialogs.

## Prompt

I'm building a web application that needs to have a feature to share content on social media. I want to create a set of social media share buttons (Facebook, Twitter, LinkedIn) that, when clicked, open the corresponding share dialog with a pre-filled message. Provide a React component that displays a set of social media share buttons. The component should take the URL and the title of the content to be shared as props..
