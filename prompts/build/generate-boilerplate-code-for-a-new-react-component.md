# Generate Boilerplate Code for a New React Component

Generate a standardized React functional component template with hooks and default exports for rapid UI development.

Variables: component_name

## Prompt

You are an AI coding assistant. Your task is to generate the boilerplate code for a new React functional component named '{{component_name}}'.

Requirements:
- The component should be a functional component using hooks.
- It should import React at the top.
- It should export the component as a default export.

## Tips

A simple prompt to get started with a new React component, ideal for beginners.
