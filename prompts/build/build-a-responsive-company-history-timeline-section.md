# Build a Responsive Company History Timeline Section

Get HTML and CSS for a company history timeline with dates and descriptions, horizontal on large screens and vertical on small screens.

## Prompt

I need to create a responsive 'our history' section for a company website. The section should display a timeline of the company's history. The timeline should be horizontal on large screens and vertical on small screens. Each event on the timeline should have a date and a description. Provide the HTML structure and the CSS to create this responsive 'our history' section.
