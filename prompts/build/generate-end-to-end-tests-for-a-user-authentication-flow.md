# Generate end-to-end tests for a user authentication flow

Create comprehensive end-to-end test scripts for user registration, authentication, and session termination using a specific framework.

Variables: framework, language

## Prompt

You are an AI coding assistant. Generate an end-to-end test for a user authentication flow that includes signing up, logging in, and logging out.

Use the `{{framework}}` framework for `{{language}}`.

The test should cover:
1. Filling out the sign-up form and submitting it.
2. Filling out the login form and submitting it.
3. Clicking the logout button.
