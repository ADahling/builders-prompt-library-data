# Add a Copy-Code Button to Markdown Code Blocks in React

Get a react-markdown code block renderer and usage example that adds copy buttons using an existing clipboard hook for your documentation site.

## Prompt

I'm building a documentation website and I want to add a 'copy code' button to each code block. When the button is clicked, the code inside the block should be copied to the clipboard. I'm using `react-markdown` to render the markdown content, and `react-syntax-highlighter` to highlight the code blocks. Create a custom renderer for code blocks that adds a 'copy' button. The button should use the `useCopyToClipboard` hook from the previous prompt. Provide the complete code for the custom renderer and an example of how to use it with `react-markdown`..
