# Build an Image Carousel with Dot Navigation in React

Get complete React code for a responsive image carousel with next and previous buttons, plus dots for tracking and selecting images.

## Prompt

I want to create a simple image carousel in React from scratch. The carousel should display a list of images and have 'next' and 'previous' buttons to navigate through the images. The carousel should also have a set of dots at the bottom to indicate the current image and to allow direct navigation to a specific image. The carousel should be responsive and work on different screen sizes. Provide the complete code for the `Carousel` component.
