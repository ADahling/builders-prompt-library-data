# Build a Responsive Three-Column Features Section

Get HTML and CSS for landing page features with icons, titles, and descriptions in three columns on desktop and a vertical stack on mobile.

## Prompt

I need to create a responsive features section for a landing page. The section should display a grid of features, each with an icon, a title, and a description. On large screens, the grid should have 3 columns. On small screens, the features should be stacked vertically. Provide the HTML structure and the CSS to create this responsive features section. The solution should be pure CSS and use Flexbox or CSS Grid for the layout..
