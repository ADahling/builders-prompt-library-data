# Build a Reusable Star Rating Component in React

Get a reusable React star rating component with clickable stars, total-star and current-rating props, and a callback for rating changes.

## Prompt

I need to create a star rating component in React. The component should display a set of stars, and the user should be able to select a rating by clicking on a star. The component should be reusable and customizable. It should take the total number of stars and the current rating as props. It should also provide a callback function to be called when the rating changes. Provide the complete code for the `StarRating` component..
