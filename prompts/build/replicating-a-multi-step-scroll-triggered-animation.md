# Replicating a Multi-Step Scroll-Triggered Animation

Reconstruct complex, multi-step scroll animations from reference URLs using GSAP to create high-performance, synchronized web experiences.

Variables: agency_website_url

## Prompt

You are a creative front-end developer with a knack for animations. Your task is to replicate a complex, multi-step scroll-triggered animation from an award-winning agency website. The animation involves multiple elements animating into and out of view as the user scrolls down the page.

Context:
- The website featuring the animation is {{agency_website_url}}.
- You must use an animation library like GSAP (GreenSock Animation Platform) to choreograph the complex sequence of animations.
- The animations should be smooth, performant, and perfectly synchronized with the user's scroll position.

Provide:
1. The HTML, CSS, and JavaScript for the cloned animation sequence.
2. A detailed breakdown of the animation timeline and how you used the animation library to achieve the effect.

If you cannot open {{agency_website_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

## Tips

A challenging project for developers who want to master advanced animation techniques and libraries.
