# Build a Responsive 'How It Works' Numbered Steps Section

Get HTML and CSS for a landing page steps section with numbers, titles, and descriptions, shown in a desktop row and stacked on mobile.

## Prompt

I need to create a responsive 'how it works' section for a landing page. The section should display a set of steps, each with a number, a title, and a description. The steps should be displayed in a row on large screens and stacked vertically on small screens. Provide the HTML structure and the CSS to create this responsive 'how it works' section.
