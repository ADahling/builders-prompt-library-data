# Build a Portfolio Work Grid with Hover Descriptions

Get HTML and CSS for a responsive portfolio project grid with thumbnails, titles, and descriptions and links shown on hover.

## Prompt

I need to create a responsive 'our work' section for a portfolio website. The section should display a grid of projects. Each project should have a thumbnail image and a title. When a project is hovered, it should display a short description and a link to the project. The grid should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our work' section.
