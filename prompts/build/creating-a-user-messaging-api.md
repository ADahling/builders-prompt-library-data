# Creating a User Messaging API

Design a RESTful user messaging API with specific endpoints for sending and retrieving messages, including detailed error handling and response structures.

Variables: content

## Prompt

Outline an API for messaging users. Include endpoints for:
- {POST /messages}: Sending a message with fields {senderId}, {receiverId}, and {{content}}.
- {GET /messages/{userId}}: Retrieving messages for a user. Discuss response formats and error handling.
