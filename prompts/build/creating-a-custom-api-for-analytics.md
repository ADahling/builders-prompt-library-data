# Creating a Custom API for Analytics

Design an analytics API with event and report endpoints, required fields, storage options, query performance notes, and request examples.

Variables: timestamp

## Prompt

Design an API for collecting and retrieving analytics data. Include:
- Endpoints like {POST /analytics/events} for sending event data and {GET /analytics/report} for generating reports.
- Required fields for events, such as {eventName}, {userId}, and {{timestamp}}.
- Discuss data storage options and performance considerations for querying analytics data.
- Provide examples of requests and responses demonstrating typical analytics use cases.

## Tips

This prompt will help you understand how to track and analyze user interactions effectively.
