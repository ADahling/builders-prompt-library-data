# Load a Google Font Efficiently in Next.js with next/font

Get an example of using @next/font to load a Google Font and apply it across a Next.js application when adding custom typography.

## Prompt

I'm building a Next.js application and I want to add a custom font. I want to use a font from Google Fonts. I need to load the font efficiently without affecting the performance of the application. I want to use the `@next/font` package to optimize the font loading. Provide an example of how to use `@next/font` to load a custom font from Google Fonts and apply it to the application.
