# Write a simple bash script

Generate an executable bash script that outputs text to the console and creates a new directory.

## Prompt

You are an AI coding assistant. Write a bash script that prints ‘Hello, World!’ to the console and then creates a new directory named ‘test’ in the current folder. The script should be executable.

## Tips

A simple prompt to get started with bash scripting, ideal for beginners.
