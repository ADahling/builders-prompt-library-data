# Build a Countdown Timer Component with an On-Finish Callback

Get complete React code for a web app countdown timer that accepts seconds and a finish callback as props and displays time as MM:SS.

## Prompt

I'm building a web application that needs to display a countdown timer. The timer should count down from a specified time and display the remaining time in the format 'MM:SS'. When the countdown reaches zero, it should trigger a callback function. Create a React component for this countdown timer. The component should take the initial time in seconds and the on-finish callback as props. Provide the complete code for the component..
