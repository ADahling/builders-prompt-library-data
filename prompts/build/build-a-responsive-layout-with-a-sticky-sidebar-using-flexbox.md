# Build a Responsive Layout with a Sticky Sidebar Using Flexbox

Get HTML and pure CSS for a Flexbox layout with a sticky left sidebar on large screens and a top sidebar on small screens.

## Prompt

I need to create a responsive layout with a sticky sidebar using Flexbox. The layout should have a main content area and a sidebar. On large screens, the sidebar should be on the left and should be sticky, meaning it stays in place when the user scrolls the main content. On small screens, the sidebar should be at the top of the page. Provide the HTML structure and the CSS to create this layout. The solution should be pure CSS and use Flexbox for the layout.
