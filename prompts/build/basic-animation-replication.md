# Basic Animation Replication

Replicate specific button hover effects using CSS transitions to master element inspection and animation styling techniques.

Variables: portfolio_url

## Prompt

You are a junior web developer. Your task is to replicate a simple CSS hover animation from a portfolio website. The animation involves a button changing color and size when hovered over.

Context:
- The website with the animation is {{portfolio_url}}.
- You should use CSS transitions to achieve the effect.
- The goal is to understand how to inspect and replicate simple animations.

Provide:
1. The HTML for the button element.
2. The CSS code for the button's styling and hover transition.

If you cannot open {{portfolio_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

## Tips

An introductory task for learning about CSS transitions and animations.
