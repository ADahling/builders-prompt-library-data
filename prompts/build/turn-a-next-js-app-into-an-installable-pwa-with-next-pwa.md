# Turn a Next.js App into an Installable PWA with next-pwa

Get next-pwa configuration and service worker registration code to add mobile installation and offline functionality to a Next.js app.

## Prompt

I'm building a Next.js application and I want to add a PWA (Progressive Web App) functionality to it. I need to make the application installable on mobile devices and work offline. I want to use the `next-pwa` library to achieve this. Provide the necessary configuration for `next-pwa` and the code to register the service worker.
