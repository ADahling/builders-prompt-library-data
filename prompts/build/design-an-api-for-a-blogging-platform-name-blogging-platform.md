# Design an API for a Blogging Platform

Get a REST API design with methods, URIs, and request/response formats for managing blogs, posts, comments, and tag-based discovery.

Variables: blogging_platform_name

## Prompt

I am building a blogging platform called {{blogging_platform_name}}, similar to Medium or WordPress.com. I need to design the API for it.

Your task is to design the core API for the blogging platform.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the platform (e.g., users, blogs, posts, comments, tags).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Creating and managing blogs.
    *   Writing, publishing, and managing posts.
    *   Commenting on posts.
    *   Discovering posts by tags.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
