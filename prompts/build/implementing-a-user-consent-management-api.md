# Implementing a User Consent Management API

Get a data processing consent API outline covering recording, retrieval, revocation, updates, legal considerations, and request and response examples.

## Prompt

Outline an API for managing user consents for data processing. Include:
- Endpoints like {POST /consents} to record user consent and {GET /consents/{userId}} to retrieve consent details.
- Required fields such as {userId}, {dataType}, and {consentStatus}.
- Strategies for handling consent revocation and updates.
- Discuss legal compliance considerations (e.g., GDPR) and provide examples of requests and responses.

## Tips

This prompt will help ensure compliance and user trust in your application.
