# Designing a Resource Quota Management API

Design a multi-tenant resource quota API with retrieval and update endpoints, validation rules, error handling, and request examples.

## Prompt

Design an API that manages resource quotas for users in a multi-tenant environment. Include endpoints for:
- {GET /quotas/{userId}}: Retrieving quota information for a user.
- {POST /quotas}: Creating or updating resource quotas.
- Discuss validation rules and error handling when managing quotas.
- Provide examples of requests and responses demonstrating quota operations.

## Tips

This prompt will help you efficiently manage user resources.
