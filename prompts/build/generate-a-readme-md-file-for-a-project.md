# Generate a README.md file for a project

Generate a complete README.md for an open-source project: what it does, install and usage, configuration, and where to contribute.

Variables: project_type, language

## Prompt

You have a new open-source project. Your task is to use an AI coding assistant to generate a comprehensive README.md file for it.

The project is a `{{project_type}}` written in `{{language}}`.

Generate a README.md that includes:
1. A project title and description.
2. Installation instructions.
3. Usage examples.
4. A section on how to contribute.

## Tips

Automates the creation of a crucial piece of project documentation.
