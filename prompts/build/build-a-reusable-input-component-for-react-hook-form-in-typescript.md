# Build a Reusable Input Component for react-hook-form in TypeScript

Get a reusable TypeScript Input component with react-hook-form integration, validation, error messages, and a form usage example.

## Prompt

I'm building a web application with a lot of forms. I want to create a reusable `Input` component that is integrated with `react-hook-form`. The `Input` component should handle its own state, validation, and error messages. It should be able to be used for different types of inputs, such as text, email, and password. The component should be written in TypeScript and be highly customizable. Provide the complete code for the `Input` component and an example of how to use it within a form managed by `react-hook-form`.
