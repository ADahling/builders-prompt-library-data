# Build an Accessible Custom Radio Group Component in React

Get an accessible React RadioGroup with custom styling, option and value props, a change callback, and usage code without third-party libraries.

## Prompt

I want to create a custom radio button group component in React. The component should be accessible and should allow for custom styling of the radio buttons. The component should be built from scratch and should not rely on any third-party libraries. It should take a list of options and the current selected value as props. It should also provide a callback function to be called when the selected value changes. Provide the complete code for the `RadioGroup` component and an example of its usage..
