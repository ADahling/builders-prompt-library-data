# Build a Responsive 'Our Mission' Section with a Background Image

Get HTML and CSS for a responsive company mission section with a background image, title, and description centered on both axes.

## Prompt

I need to create a responsive 'our mission' section for a company website. The section should have a title, a short description, and a background image. The content should be centered vertically and horizontally. The section should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our mission' section.
