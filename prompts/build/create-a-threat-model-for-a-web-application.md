# Create a Threat Model for a Web Application

Get a web application threat model with component breakdowns, threat identification, risk prioritization, mitigations, and a regular review plan.

Variables: application_name

## Prompt

I want to improve the security of our web application by creating a threat model. A threat model is a structured process for identifying and prioritizing potential threats to an application. This will help us to focus our security efforts on the most important risks.

Your task is to create a threat model for our {{application_name}} web application. The threat model should include:

1.  **Application Decomposition:** A decomposition of the application into its key components, such as the web server, the application server, and the database.
2.  **Threat Identification:** An identification of the potential threats to each component. This should be based on a standard threat modeling methodology, such as STRIDE (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege).
3.  **Threat Analysis:** An analysis of each threat to determine its likelihood and its impact. This will help us to prioritize the threats.
4.  **Mitigation Plan:** A plan for how to mitigate the highest-priority threats. This could involve making changes to the application code, the infrastructure, or the development process.
5.  **Threat Model Review:** A plan for how to review and update the threat model on a regular basis.

## Tips

This prompt is a powerful security practice for any organization that wants to build secure applications.
