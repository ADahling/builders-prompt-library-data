# Build a Responsive Three-Plan Pricing Table with CSS Grid

Get HTML and CSS Grid code for three pricing plans with features and buttons, arranged in a row on large screens and stacked on small screens.

## Prompt

I need to create a responsive pricing table using CSS Grid. The table should display three pricing plans. On large screens, the plans should be displayed in a row. On small screens, they should be stacked vertically. Each plan should have a title, a price, a list of features, and a call-to-action button. Provide the HTML structure and the CSS to create this responsive pricing table. The solution should be pure CSS and use CSS Grid for the layout.
