# Design an API for a Video Conferencing App

Get a video conferencing API design with a real-time technology choice, RESTful meeting endpoints, and signaling for peer-to-peer connections.

Variables: video_conferencing_app_name

## Prompt

I am building a video conferencing app called {{video_conferencing_app_name}}, similar to Zoom or Google Meet. I need to design the API for it.

Your task is to design the core API for the app.

**Instructions:**
1.  **Real-time Communication:** Choose a technology for real-time video and audio communication (e.g., WebRTC) and explain why it is a good fit for this use case.
2.  **API Design:** Design the API for the app. This should include:
    *   RESTful endpoints for scheduling and managing meetings.
    *   The signaling mechanism for setting up peer-to-peer connections between participants.

**Output Format:**
Provide the output as a Markdown document. First, explain your choice of real-time communication technology. Then, describe the design of your API, including the RESTful endpoints and the signaling mechanism.
