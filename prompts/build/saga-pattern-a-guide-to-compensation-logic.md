# Saga Pattern: A Guide to Compensation Logic

Design reliable compensating transactions and error-handling strategies for distributed sagas using a trip booking case study.

## Prompt

You are a software architect implementing a saga. You need to design the compensation logic for each step of the saga.

**Your Task:**
Create a guide for designing robust compensation logic in a saga.

**Instructions & Constraints:**
*   For a given saga (e.g., a trip booking saga), design the compensating transaction for each step.
*   Discuss the challenges of writing compensation logic (e.g., what if the compensation fails?).

**Output Format:**
Generate a guide in Markdown:
1.  **A Guide to Writing Robust Compensation Logic for Sagas**
2.  **Our Trip Booking Saga: A Case Study**
3.  **Designing the Compensating Transactions**
4.  **When Compensations Fail: The Hardest Problem**
