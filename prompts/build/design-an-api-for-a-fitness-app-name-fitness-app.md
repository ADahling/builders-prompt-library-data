# Design an API for a Fitness App

Get a REST API design for a fitness app, with methods, URIs, and data formats for registration, profiles, workout logs, nutrition, and progress.

Variables: fitness_app_name

## Prompt

I am building a fitness app called {{fitness_app_name}} that will track users' workouts, nutrition, and progress. I need to design the API for it.

Your task is to design the core API for the fitness app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., users, workouts, exercises, food items, nutrition logs).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   User registration and profile management.
    *   Logging workouts and exercises.
    *   Tracking nutrition by logging food items.
    *   Viewing progress and statistics.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
