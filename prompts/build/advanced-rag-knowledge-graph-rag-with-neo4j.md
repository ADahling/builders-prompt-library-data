# Advanced RAG: Knowledge Graph RAG with Neo4j

Design a multi-hop RAG pipeline that transforms natural language into Cypher queries to extract precise relational data from Neo4j.

## Prompt

Act as a senior AI engineer building a next-generation RAG system. Instead of a simple vector store, your knowledge base is a Knowledge Graph stored in Neo4j. This allows for more precise, multi-hop queries.

**Your Task:** Design the logic for a RAG pipeline that queries a Neo4j graph to retrieve context.

**Scenario:**
- **Neo4j Graph:** Contains nodes for Movies, Actors, and Directors. Relationships are `(Actor)-[:ACTED_IN]->(Movie)` and `(Director)-[:DIRECTED]->(Movie)`.
- **User Query:** "Who directed the movie that Tom Hanks acted in?"

**Your Task: Design the Pseudocode/Logic**

**Logic Requirements:**

1.  **Step 1: Natural Language to Cypher Query:**
    -   This is the core of the system. You need to use an LLM to convert the user's query into a Cypher query (Neo4j's query language).
    -   **LLM Prompt:**
        -   **Role:** "You are an expert Neo4j developer."
        -   **Schema:** Provide the graph schema: "The graph contains (:Movie {title}), (:Actor {name}), and (:Director {name}) nodes. Relationships are (:Actor)-[:ACTED_IN]->(:Movie) and (:Director)-[:DIRECTED]->(:Movie)."
        -   **Task:** "Convert the following user question into a Cypher query: [User Query]"
        -   **Expected LLM Output:** `MATCH (p:Actor {name: 'Tom Hanks'})-[:ACTED_IN]->(m:Movie)<-[:DIRECTED]-(d:Director) RETURN d.name`

2.  **Step 2: Execute Cypher Query:**
    -   Use the Neo4j Python driver (`neo4j` library).
    -   Connect to your Neo4j database.
    -   Execute the Cypher query generated by the LLM.
    -   The result will be a list of director names (e.g., ['Robert Zemeckis', 'Steven Spielberg']).

3.  **Step 3: Format the Retrieved Data as Context:**
    -   Convert the query result into a natural language sentence. For example: "The directors of movies that Tom Hanks acted in include Robert Zemeckis and Steven Spielberg."

4.  **Step 4: Generate Final Answer:**
    -   Make a final LLM call.
    -   **Prompt:** "Based on the following context, answer the user's original question. Context: [Formatted context from Step 3]. Original Question: [User Query]."
    -   Return the final, natural language answer.

**Output Format:**
Provide a detailed, step-by-step description of this Knowledge Graph RAG pipeline.
