# Export an Array of Objects to a Downloadable CSV File in React

Get a TypeScript React component with a download button that uses csv-export to turn an array of objects into a CSV file for a web app.

## Prompt

I'm building a web application that needs to have a feature to export data to a CSV file. I want to create a 'Download CSV' button that, when clicked, generates a CSV file from an array of objects and downloads it. I want to use the `csv-export` library to achieve this. Provide a React component that has a 'Download CSV' button and uses `csv-export` to generate and download the CSV file. The component should be written in TypeScript..
