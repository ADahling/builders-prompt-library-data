# Design a Serverless API using AWS Lambda and API Gateway

Get Lambda function code and a step-by-step AWS API Gateway configuration and deployment guide for a simple serverless REST API.

## Prompt

I want to build a serverless API using AWS Lambda and API Gateway. The API will have a few simple endpoints.

Your task is to provide a step-by-step guide on how to create a serverless API on AWS.

**Instructions:**
1.  **Lambda Function:** Write a simple Lambda function in a language of your choice (e.g., Python, Node.js) that will handle the API requests.
2.  **API Gateway:** Explain how to configure API Gateway to create a RESTful API that triggers the Lambda function. This should include creating a new API, a resource, a method, and linking it to the Lambda function.
3.  **Deployment:** Describe how to deploy the API and make it accessible over the internet.

**Output Format:**
Provide the output as a Markdown document. Provide the code for the Lambda function. Then, provide a step-by-step guide with screenshots or AWS CLI commands on how to configure API Gateway and deploy the API.
