# Print a Single React Component with react-to-print

Get a TypeScript React component with a button that uses react-to-print to open a print dialog for only a specific section of a web page.

## Prompt

I'm building a web application that needs to have a feature to print a specific section of a page. I want to create a 'Print' button that, when clicked, opens the print dialog with only the content of a specific component. I want to use the `react-to-print` library to achieve this. Provide a React component that has a 'Print' button and uses `react-to-print` to print its content. The component should be written in TypeScript.
