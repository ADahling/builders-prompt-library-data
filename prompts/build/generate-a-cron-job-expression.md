# Generate a CRON job expression

Create a CRON job expression for a daily 3:00 AM schedule with a breakdown of its syntax and time field components.

## Prompt

You are an AI coding assistant. Generate a CRON job expression that runs a script every day at 3:00 AM.

Provide the CRON expression and an explanation of what each part means.

## Tips

A great use case for AI, as CRON expressions can be tricky to write.
