# System Design Interview: Back-of-the-Envelope Estimation Practice

Calculate storage, memory, and bandwidth requirements for common distributed systems using back-of-the-envelope estimation techniques.

## Prompt

You are a software engineer preparing for system design interviews. You need to practice your back-of-the-envelope estimation skills.

**Your Task:**
For each of the following systems, perform a quick back-of-the-envelope estimation of the storage, memory, and bandwidth requirements:
*   A URL shortener
*   A social media feed
*   A video streaming service

**Output Format:**
Generate a document in Markdown with your estimations and the assumptions you made.
