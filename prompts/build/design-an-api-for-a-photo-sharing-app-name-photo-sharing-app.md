# Design an API for a Photo Sharing App

Get a photo sharing RESTful API design for uploads, albums, comments, likes, and a photo feed, with methods, URIs, and request/response formats.

Variables: photo_sharing_app_name

## Prompt

I am building a photo sharing app called {{photo_sharing_app_name}}, similar to Instagram or Flickr. I need to design the API for it.

Your task is to design the core API for the photo sharing app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., users, photos, albums, comments, likes).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Uploading and managing photos.
    *   Creating and managing albums.
    *   Commenting on and liking photos.
    *   A photo feed.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
