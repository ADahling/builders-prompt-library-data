# Design a System for Tracking Data Lineage

Get a data lineage design for governance and root cause analysis, with a metamodel, collection strategy, storage, visualization, and use cases.

## Prompt

In our organization, we have a complex data ecosystem with data flowing through many different systems and processes. To improve data governance and to be able to track the root cause of data quality issues, we need to design a system for tracking data lineage.

Your task is to design a system for tracking data lineage. The design should include:

1.  **Lineage Metamodel:** A metamodel for representing data lineage. This should define the key concepts, such as data sources, datasets, transformations, and the relationships between them.
2.  **Lineage Collection:** A strategy for collecting lineage information from our various data systems. This could involve a combination of automated parsing of code and configuration files, and manual documentation.
3.  **Lineage Storage:** A recommendation for a storage solution for the lineage information. This could be a graph database like Neo4j or a specialized data lineage tool.
4.  **Lineage Visualization:** A plan for how to visualize the data lineage to make it easy for users to understand the flow of data. This could involve creating interactive diagrams that allow users to explore the lineage graph.
5.  **Use Cases:** A description of how the data lineage system will be used to support various use cases, such as impact analysis, root cause analysis, and compliance reporting.

## Tips

This prompt is for organizations that are serious about data governance and want to have a deep understanding of their data assets.
