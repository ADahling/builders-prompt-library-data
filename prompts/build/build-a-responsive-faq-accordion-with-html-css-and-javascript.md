# Build a Responsive FAQ Accordion with HTML, CSS, and JavaScript

Get HTML, CSS, and JavaScript for a responsive FAQ accordion that reveals answers on click and keeps only one answer visible at a time.

## Prompt

I need to create a responsive FAQ section with an accordion. The section should display a list of questions and answers. When a question is clicked, the corresponding answer should be revealed. Only one answer should be visible at a time. The solution should be implemented with HTML, CSS, and a small amount of JavaScript to handle the accordion logic.
