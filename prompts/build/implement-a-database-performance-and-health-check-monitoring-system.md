# Implement a Database Performance and Health Check Monitoring System

Get a database monitoring plan with key metrics, tool recommendations, alerts, health checks, and a real-time dashboard design.

Variables: database_type

## Prompt

We need to monitor the performance and the health of our database to ensure that it is running smoothly. I need to implement a database performance and health check monitoring system for our {{database_type}} database.

Your task is to create a plan for implementing a database performance and health check monitoring system. The plan should include:

1.  **Monitoring Metrics:** A list of the key metrics that we should monitor, such as CPU utilization, memory usage, disk space, I/O throughput, and slow queries.
2.  **Monitoring Tool:** A recommendation for a monitoring tool to collect and to visualize the metrics. This could be a self-hosted tool like Prometheus and Grafana or a cloud-based service like Datadog or New Relic.
3.  **Alerting:** A plan for how to set up alerts to notify us of any potential problems. The alerts should be based on thresholds for the key metrics, and they should be designed to avoid false positives.
4.  **Health Checks:** A plan for how to perform regular health checks on our database to ensure that it is running correctly.
5.  **Dashboard:** A design for a dashboard that provides a real-time view of the performance and the health of our database.

## Tips

This prompt is for organizations that want to be proactive about managing the performance and the health of their database.
