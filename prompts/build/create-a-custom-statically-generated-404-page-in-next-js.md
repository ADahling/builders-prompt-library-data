# Create a Custom Statically Generated 404 Page in Next.js

Get code for a custom Next.js 404 page in the pages directory, with a homepage link and static generation at build time.

## Prompt

I'm building a Next.js application and I need to create a custom 404 error page. The page should have a custom design and a link to the homepage. Create a `404.js` file in the `pages` directory to create the custom error page. The page should be statically generated at build time. Provide the code for the custom 404 page..
