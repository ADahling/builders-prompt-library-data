# Build a Photo Portfolio Grid with a Lightbox in React

Get a responsive React photo portfolio grid for a photographer's website, with clicked images opened using yet-another-react-lightbox.

## Prompt

I need to create a responsive portfolio grid for a photographer's website. The grid should display a set of photos. When a photo is clicked, it should open in a lightbox. The grid should be responsive and work on different screen sizes. I want to use the `yet-another-react-lightbox` library for the lightbox. Provide a React component that displays a portfolio grid and uses `yet-another-react-lightbox` to open the photos in a lightbox.
