# Creating API Documentation with Swagger

Write Swagger documentation for a REST API with paths, parameters, bodies, responses, endpoint examples, and authentication definitions if needed.

Variables: title, version, description

## Prompt

Generate API documentation using Swagger for your RESTful API. Include the following:
- Basic API information including {{title}}, {{version}}, and {{description}}.
- Define all API paths with their methods, parameters, request bodies, and responses.
- Include examples for each endpoint using Swagger annotations.
- Add security definitions if your API requires authentication. Explain how this documentation can be used by developers.

## Tips

This prompt will help you improve the accessibility and usability of your API through clear documentation.
