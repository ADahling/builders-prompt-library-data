# Generate a Table of Contents from Blog Post Headings in React

Get a React component that parses blog post HTML into a table of contents from h2 and h3 headings, with links that smoothly scroll to each heading.

## Prompt

I'm building a blog and I want to add a table of contents (TOC) to each blog post. The TOC should be generated automatically from the headings (h2, h3) in the post. The TOC should be a list of links that, when clicked, smoothly scroll the page to the corresponding heading. Create a React component that takes the post content as a string of HTML and generates a TOC. The component should parse the HTML to find the headings and create the TOC. Provide the complete code for the component.
