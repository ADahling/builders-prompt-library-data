# Design an API for a Gaming Platform

Get a RESTful API design for a gaming platform's store, social features, achievements, and leaderboards, with request and response formats.

Variables: gaming_platform_name

## Prompt

I am building a gaming platform called {{gaming_platform_name}}, similar to Steam or Epic Games Store. I need to design the API for it.

Your task is to design the core API for the platform.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the platform (e.g., games, users, friends, achievements, leaderboards).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   A game store where users can browse and purchase games.
    *   A social system for managing friends and communities.
    *   A system for tracking achievements and leaderboards.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoint, including the HTTP method, URI, and request/response format.
