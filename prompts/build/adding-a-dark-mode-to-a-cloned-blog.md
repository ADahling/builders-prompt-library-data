# Adding a Dark Mode to a Cloned Blog

Implement a toggleable dark mode for a cloned blog using CSS variables and local storage to persist user theme preferences.

Variables: project_directory

## Prompt

You are a junior front-end developer. Your task is to add a dark mode to a cloned blog. You will need to create a new stylesheet for the dark theme and a button to toggle between the light and dark modes.

Context:
- The cloned blog is in the directory {{project_directory}}.
- You should use CSS variables to make it easy to switch between the color schemes.
- The user"s preference for dark mode should be saved in local storage.

Provide:
1. The CSS for the dark theme.
2. The JavaScript for the theme switcher.

## Tips

A beginner-friendly introduction to creating a dark mode for a website.
