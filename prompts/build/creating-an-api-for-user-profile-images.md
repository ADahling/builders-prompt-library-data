# Creating an API for User Profile Images

Design an API for uploading, retrieving, and deleting user profile images, including endpoint definitions, response formats, and error handling.

## Prompt

Design an API for handling user profile images. Include endpoints for:
- {POST /profile-images}: Uploading a new profile image with fields {userId} and {imageData}.
- {GET /profile-images/{userId}}: Retrieving a user's profile image.
- {DELETE /profile-images/{userId}}: Deleting a user's profile image. Discuss response formats and error handling.

## Tips

This prompt will help you manage user images within your application.
