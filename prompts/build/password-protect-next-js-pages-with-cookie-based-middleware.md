# Password-Protect Next.js Pages with Cookie-Based Middleware

Get Next.js middleware and a password page to gate selected pages by checking a cookie and redirecting when the password is missing or incorrect.

## Prompt

I'm building a Next.js application and I want to add a feature to protect some pages with a password. I need to create a middleware that checks for a password in a cookie. If the password is not present or incorrect, the user should be redirected to a password protection page. Provide the code for the middleware and the password protection page.
