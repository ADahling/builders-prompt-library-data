# Generate Breadcrumb Navigation from React Router Routes

Get a React Breadcrumbs component and usage example that generate navigation links from the current React Router route, including nested routes.

## Prompt

I'm building a web application that needs to have a breadcrumb navigation. The breadcrumbs should be generated automatically based on the current route. I'm using React Router. Create a `Breadcrumbs` component that reads the current route and generates the breadcrumb links. The component should be able to handle nested routes. Provide the complete code for the `Breadcrumbs` component and an example of how to use it in a React application with React Router..
