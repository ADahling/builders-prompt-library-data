# Build a Responsive Team Grid with CSS Grid Breakpoints

Get HTML and CSS Grid code for a responsive website team section with photos, names, and job titles across four, three, and two columns.

## Prompt

I need to create a responsive team section for a website. The section should display a grid of team members. Each team member should have a photo, a name, and a job title. On large screens, the grid should have 4 columns. On medium screens, 3 columns, and on small screens, 2 columns. Provide the HTML structure and the CSS to create this responsive team section. The solution should be pure CSS and use CSS Grid for the layout.
