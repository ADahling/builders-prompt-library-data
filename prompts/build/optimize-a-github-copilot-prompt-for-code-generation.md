# Optimize a GitHub Copilot Prompt for Code Generation

Refine vague GitHub Copilot instructions into detailed technical prompts to ensure accurate Node.js REST API endpoint generation.

## Prompt

You are a prompt engineering expert. Your task is to refine the following GitHub Copilot prompt to generate more accurate and efficient code for creating a REST API endpoint in Node.js with Express.

Original Prompt:
'// a POST endpoint to create a new user'

Provide a more detailed prompt that specifies the following:
1. The route path.
2. Request body structure (e.g., JSON with username, email, password).
3. Success and error response formats.
4. Status codes to be used.

Focuses on prompt engineering to improve the quality of AI-generated code.
