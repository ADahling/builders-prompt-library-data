# Optimize a GitHub Copilot prompt for generating a class with a constructor

Refine a Python class prompt to include specific attributes, type hints, and methods for more precise GitHub Copilot code generation.

## Prompt

You are a prompt engineering expert. Your task is to refine the following GitHub Copilot prompt to generate a more complete Python class.

Original Prompt:
`# a class for a user`

Provide a more detailed prompt that specifies the following:
1. The class name.
2. The constructor with parameters for username, email, and password.
3. Type hints for the constructor parameters.
4. A method to get the user's information.

## Tips

Focuses on prompt engineering to improve the quality of AI-generated code for classes.
