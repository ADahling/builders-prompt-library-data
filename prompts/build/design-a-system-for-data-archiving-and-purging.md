# Design a System for Data Archiving and Purging

Get a plan for managing old database data with retention policies, archival access, purge procedures, automation, and auditing.

## Prompt

Our database is accumulating a lot of old data that is no longer needed for our day-to-day operations. This is increasing our storage costs and is impacting the performance of our database. I need to design a system for data archiving and purging to manage our old data.

Your task is to design a system for data archiving and purging. The design should include:

1.  **Data Retention Policy:** A data retention policy that will define how long we need to keep our data. The policy should be based on our business and legal requirements.
2.  **Data Archiving:** A plan for how to archive our old data. This should include where to store the archived data and how to access it when it is needed.
3.  **Data Purging:** A plan for how to purge our old data. This should include how to identify the data that can be purged and how to delete it from our database.
4.  **Automation:** A plan for how to automate the data archiving and purging process. This will help to ensure that the process is run on a regular basis.
5.  **Auditing:** A plan for how to audit the data archiving and purging process to ensure that it is working as expected.

## Tips

This prompt is for organizations that want to manage their data lifecycle in a more efficient and cost-effective way.
