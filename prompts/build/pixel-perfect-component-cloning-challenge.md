# Pixel-Perfect Component Cloning Challenge

Replicate a specific web component with pixel-perfect accuracy using HTML and CSS to master front-end styling and browser inspection skills.

Variables: target_website_url

## Prompt

You are a front-end developer in training. Your task is to select a single, simple component from a live website (e.g., a button, a card, an input field) and replicate it with pixel-perfect accuracy. Focus on matching every visual detail.

Context:
- Choose a component from {{target_website_url}}.
- You must use only HTML and CSS. Do not use any JavaScript or frameworks.
- Use browser developer tools to inspect the original component's dimensions, colors, fonts, and spacing.

Provide:
1. The HTML and CSS for your cloned component.
2. A side-by-side screenshot comparing your clone to the original.

If you cannot open {{target_website_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

## Tips

A great exercise for beginners to hone their CSS and attention to detail.
