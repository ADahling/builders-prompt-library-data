# Set Up Environment Variables for Development and Production in Next.js

Get a Next.js environment variable setup example using a local development file and hosting variables, with server-side and client-side access.

## Prompt

I'm building a Next.js application and I want to add support for environment variables. I need to have different environment variables for development and production. I need to create a `.env.local` file for development and use the hosting provider's environment variables for production. I need to access the environment variables on both the server-side and the client-side. Provide an example of how to set up and use environment variables in a Next.js application.
