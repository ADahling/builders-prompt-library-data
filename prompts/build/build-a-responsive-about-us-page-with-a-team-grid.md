# Build a Responsive About Us Page with a Team Grid

Get HTML and CSS for a responsive About Us page with a hero section and a team grid featuring photos, names, job titles, and bios.

## Prompt

I need to create a responsive 'about us' page with a team section. The page should have a hero section with a title and a short description. The team section should display a grid of team members, each with a photo, a name, a job title, and a short bio. The page should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'about us' page.
