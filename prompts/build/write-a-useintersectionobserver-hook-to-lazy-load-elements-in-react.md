# Write a useIntersectionObserver Hook to Lazy-Load Elements in React

Implement a custom React hook for viewport detection using the Intersection Observer API to enable efficient component lazy-loading.

## Prompt

You are an expert in frontend performance optimization. I need to create a custom hook in React that detects when an element is visible in the viewport, so I can lazy-load components or trigger animations. The hook should be named `useIntersectionObserver`. It should take a ref to the element and some options for the Intersection Observer API as arguments. The hook should return a boolean value indicating whether the element is currently intersecting the viewport. Provide a complete implementation of the `useIntersectionObserver` hook and an example of how to use it to lazy-load an image..
