# Generate a QR Code in React with qrcode.react

Get a React component that takes a string prop and uses qrcode.react to generate and display a QR code in your web app.

## Prompt

I'm building a web application that needs to have a feature to generate a QR code from a string. I want to create a component that takes a string as a prop and displays a QR code. I want to use the `qrcode.react` library to achieve this. Provide a React component that uses `qrcode.react` to generate and display a QR code.
