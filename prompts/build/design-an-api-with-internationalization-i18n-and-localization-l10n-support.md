# Design an API with Internationalization (i18n) and Localization (l10n) Support

Architect a localized RESTful API strategy that handles language negotiation, content translation, and region-specific data formatting.

## Prompt

I am building an application that will be used by people from different countries, and I need to design an API that supports multiple languages and cultural formats.

Your task is to design a strategy for internationalization (i18n) and localization (l10n) in a RESTful API.

**Instructions:**
1.  **Language Negotiation:** Describe how to determine the user's preferred language, for example, by using the `Accept-Language` header.
2.  **Localized Content:** Explain how to return localized content from the API. This could involve storing localized strings in a database or using a translation service.
3.  **Localization of Numbers, Dates, and Currencies:** Describe how to handle the formatting of numbers, dates, and currencies according to the user's locale.

**Output Format:**
Provide the output as a Markdown document. Address each of the instructions above in a clear and detailed manner. Provide examples where appropriate.
