# Implementing API Gateway Patterns

Design a microservices API gateway with routing, authentication, authorization, load balancing, rate limiting, and configuration and code examples.

Variables: path, method

## Prompt

Design an API gateway for managing multiple microservices. Discuss:
- How to route requests to the appropriate service based on {{path}} or {{method}}.
- Authentication and authorization strategies at the gateway level.
- Load balancing and rate limiting techniques.
- Provide examples of API gateway configurations and code snippets for common frameworks.

## Tips

This prompt will help you coordinate multiple services seamlessly through a single access point.
