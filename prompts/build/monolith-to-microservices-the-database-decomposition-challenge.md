# Monolith to Microservices: The Database Decomposition Challenge

Plan and execute the transition from a monolithic database to distributed microservices using proven decomposition patterns and migration strategies.

## Prompt

You are a database architect leading the decomposition of a monolithic database as part of a microservices migration.

**Your Task:**
Create a guide for decomposing a monolithic database.

**Instructions & Constraints:**
*   Discuss different decomposition patterns.
*   Outline a strategy for migrating the data with minimal downtime.

**Output Format:**
Generate a guide in Markdown:
1.  **The Hardest Part of Microservices: Decomposing the Database**
2.  **Database Decomposition Patterns**
3.  **A Zero-Downtime Data Migration Strategy**
