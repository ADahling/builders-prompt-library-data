# Generate a Basic HTML5 Template

Create a structured HTML5 boilerplate with essential metadata and customizable page titles to kickstart web development projects.

Variables: page_title

## Prompt

You are an AI coding assistant. Generate a basic HTML5 template with a title of '{{page_title}}'.

Include the following:
- A doctype declaration.
- The html, head, and body tags.
- A meta tag for character encoding.
