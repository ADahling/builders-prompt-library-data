# Ensure GDPR Compliance for Handling User Data in a SaaS Application

Implement a robust GDPR compliance framework for a SaaS application including data mapping, user rights management, and breach response plans.

Variables: tech_stack

## Prompt

I am the lead developer of a SaaS application that serves customers in the European Union. I need to ensure that our application is fully compliant with the General Data Protection Regulation (GDPR) when it comes to handling user data. The application is built with {{tech_stack}}.

Your task is to create a comprehensive checklist and a set of action items to achieve GDPR compliance. This should cover:

1.  **Data Mapping and Inventory:** Create a plan to identify and document all personal data that the application collects, processes, and stores. For each data point, specify the purpose of processing and the legal basis for it.
2.  **User Rights:** For each of the GDPR user rights (e.g., right to access, right to be forgotten, data portability), describe how to implement the necessary functionality in the application. Provide a high-level plan for building a user-facing privacy dashboard.
3.  **Consent Management:** Design a system for obtaining and managing user consent for data processing activities. The system should allow users to easily give and withdraw consent.
4.  **Data Protection by Design:** Recommend a set of best practices for data protection by design and by default. This should include techniques like data minimization, pseudonymization, and encryption.
5.  **Data Breach Response Plan:** Outline a data breach response plan that specifies the steps to be taken in the event of a data breach, including how to notify the supervisory authorities and the affected users.

## Tips

This prompt is essential for any developer whose application handles the data of EU citizens, as GDPR compliance is a legal requirement.
