# Build a Responsive Latest Blog Posts Grid Section

Get HTML and CSS for a responsive company blog section showing latest posts in a grid with featured images, titles, excerpts, and links.

## Prompt

I need to create a responsive 'our blog' section for a company website. The section should display a grid of the latest blog posts. Each blog post should have a featured image, a title, a short excerpt, and a link to the full post. The grid should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our blog' section.
