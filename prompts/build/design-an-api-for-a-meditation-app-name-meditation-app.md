# Design an API for a Meditation App

Get a meditation app RESTful API design for browsing and playing sessions, organizing categories, and tracking progress and streaks.

Variables: meditation_app_name

## Prompt

I am building a meditation app called {{meditation_app_name}}, similar to Calm or Headspace. I need to design the API for it.

Your task is to design the core API for the meditation app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., users, meditation sessions, categories, progress).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Users can browse and play meditation sessions.
    *   Sessions are organized into categories (e.g., stress, sleep, focus).
    *   The app tracks user progress and streaks.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
