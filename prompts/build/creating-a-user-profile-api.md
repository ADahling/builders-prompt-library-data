# Creating a User Profile API

Design a user profile API for retrieving and saving names, emails, and bios, with endpoint definitions, response formats, and error handling.

Variables: name, email, bio

## Prompt

Design an API for managing user profiles. Include endpoints for:
- {GET /profiles/{userId}}: Retrieving a user's profile.
- {POST /profiles}: Creating or updating a user's profile with fields {{name}}, {{email}}, and {{bio}}.
- Discuss response formats and error handling.

## Tips

This prompt will help you manage user profiles effectively.
