# Create a custom static analysis rule with AI

Draft an AI coding request for a rule that flags deprecated function use, specifying your static analysis tool and programming language.

Variables: deprecated_function

## Prompt

Your team has a coding convention that disallows the use of a specific deprecated function, `{{deprecated_function}}`. You want to enforce this with a custom static analysis rule for your preferred static analysis tool (e.g., SonarQube, Checkstyle).

Ask an AI coding assistant to generate the code for a custom rule that flags any use of the deprecated function. The prompt should specify the static analysis tool and the programming language.
