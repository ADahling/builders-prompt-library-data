# Cloning a SaaS Dashboard with Live Data Integration

Replicate a specific SaaS dashboard layout and functionality by developing a frontend UI integrated with a matching mock API for live data simulation.

Variables: saas_app_url

## Prompt

You are a full-stack developer. Your task is to clone the dashboard of a SaaS application and integrate it with a mock API to display live data.

Context:
- The SaaS dashboard to clone is from {{saas_app_url}}.
- The dashboard includes charts, tables, and real-time notifications.
- You will need to create a mock API that provides data in the same format as the original application.

Provide:
1. The front-end code for the dashboard clone.
2. The back-end code for the mock API.
3. Instructions on how to run the application locally.

If you cannot open {{saas_app_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

## Tips

A challenging project that involves both front-end and back-end development skills.
