# Write a Tailwind CSS Plugin for Custom Gradient Utilities

Get a Tailwind CSS plugin and configuration example to generate custom gradient utility classes from your design system's configured gradients.

## Prompt

I'm working on a project that uses Tailwind CSS, and I want to create a custom plugin to add some utility classes for a specific design system. The plugin should add utility classes for custom gradients. The gradients should be defined in the `tailwind.config.js` file. The plugin should generate classes like `bg-gradient-primary` and `bg-gradient-secondary`. Provide the code for the Tailwind CSS plugin and an example of how to configure it in the `tailwind.config.js` file..
