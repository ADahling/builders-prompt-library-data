# Add Client-Side Blog Search to Next.js with Fuse.js

Get a Next.js blog search page using Fuse.js for client-side results, plus a script to generate the search index at build time.

## Prompt

I'm building a Next.js application and I want to add a search feature that searches through the content of my blog posts. I want to use a client-side search solution. I need to create a search page that has a search input and displays the search results. The search should be performed on the client-side using a pre-built search index. I want to use the `fuse.js` library for the search. Provide the code for the search page and the script to generate the search index at build time.
