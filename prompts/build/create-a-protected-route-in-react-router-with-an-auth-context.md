# Create a Protected Route in React Router with an Auth Context

Get a React ProtectedRoute component, auth context, and router example that redirects unauthenticated users to a login page.

## Prompt

I need to create a protected route in a React application that uses React Router. The protected route should only be accessible to authenticated users. If an unauthenticated user tries to access the protected route, they should be redirected to the login page. I'm using a simple context to manage the authentication state. Create a `ProtectedRoute` component that wraps the routes that need protection. Provide the complete code for the `ProtectedRoute` component, the authentication context, and an example of how to use it in the main router setup.
