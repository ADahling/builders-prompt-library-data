# Cloning an E-commerce Product Showcase Carousel

Build a responsive, touch-enabled product image carousel with thumbnail navigation by replicating a specific e-commerce site's design.

Variables: ecommerce_site_url

## Prompt

You are a front-end developer working for an online retailer. Your task is to clone the product showcase carousel from a competitor's website. The carousel should be responsive, touch-friendly, and allow users to cycle through multiple product images.

Context:
- The e-commerce website with the carousel is {{ecommerce_site_url}}.
- You can use a library like Swiper.js or build the carousel from scratch.
- The carousel should display product thumbnails and allow users to click on them to view the full-size image.

Provide:
1. The HTML, CSS, and JavaScript for the product showcase carousel.
2. A brief explanation of how you made the carousel responsive and touch-friendly.

If you cannot open {{ecommerce_site_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

## Tips

A common component in e-commerce websites, this task helps practice building interactive carousels.
