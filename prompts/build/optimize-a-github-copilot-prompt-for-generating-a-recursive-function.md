# Optimize a GitHub Copilot prompt for generating a recursive function

Refine GitHub Copilot prompts to generate robust recursive factorial functions with error handling and optimized logic.

## Prompt

You are a prompt engineering expert. Your task is to refine the following GitHub Copilot prompt to generate a more correct and efficient recursive function for calculating the factorial of a number.

Original Prompt:
`# a recursive function to calculate the factorial of a number`

Provide a more detailed prompt that specifies the following:
1. The function signature.
2. The base case for the recursion (i.e., when the input is 0 or 1).
3. The recursive step.
4. Handling of negative inputs (e.g., by raising an error).

## Tips

Focuses on prompt engineering to improve the quality of AI-generated code for recursive functions.
