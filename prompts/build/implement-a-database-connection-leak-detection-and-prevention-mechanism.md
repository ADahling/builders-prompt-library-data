# Implement a Database Connection Leak Detection and Prevention Mechanism

Get a guide for apps running out of database connections, with leak detection steps, prevention practices, a code review checklist, and tools.

## Prompt

Our application is leaking database connections, which is causing our application to run out of connections and to fail. I need to implement a database connection leak detection and prevention mechanism.

Your task is to create a guide on how to implement a database connection leak detection and prevention mechanism. The guide should include:

1.  **Connection Leak Explained:** A clear explanation of what a database connection leak is and why it is a problem.
2.  **Detection:** A plan for how to detect database connection leaks. This could involve using a monitoring tool or a profiler to track the number of open connections.
3.  **Prevention:** A set of best practices for how to prevent database connection leaks. This should include how to properly close database connections and how to use a connection pool.
4.  **Code Review:** A checklist of what to look for when reviewing code to prevent database connection leaks.
5.  **Tooling:** A recommendation for a set of tools to help with database connection leak detection and prevention.

## Tips

This prompt is for organizations that are having problems with database connection leaks.
