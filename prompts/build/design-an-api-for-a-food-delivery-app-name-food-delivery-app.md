# Design an API for a Food Delivery App

Get a food delivery REST API design for restaurant browsing, orders, and driver assignment, plus a high-level architecture for real-time tracking.

Variables: food_delivery_app_name

## Prompt

I am building a food delivery app called {{food_delivery_app_name}}, similar to DoorDash or Uber Eats. I need to design the API for it.

Your task is to design the core API for the food delivery app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., restaurants, menus, customers, orders, delivery drivers).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Browsing restaurants and menus.
    *   Placing an order.
    *   Tracking the status of an order in real-time.
    *   Assigning orders to delivery drivers.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints. For real-time order tracking, explain the high-level architecture.
