# Design an API for a Language Learning App

Get a language learning app API design for language selection, lessons, exercises, and progress tracking, with methods, URIs, and data formats.

Variables: language_learning_app_name

## Prompt

I am building a language learning app called {{language_learning_app_name}}, similar to Duolingo or Babbel. I need to design the API for it.

Your task is to design the core API for the language learning app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., users, languages, lessons, exercises, progress).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Users can choose a language to learn.
    *   Users can complete lessons and exercises.
    *   The app tracks user progress.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
