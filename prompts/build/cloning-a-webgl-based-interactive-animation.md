# Cloning a WebGL-Based Interactive Animation

Replicate high-fidelity interactive WebGL animations from a source URL using Three.js or Babylon.js to achieve identical visual effects.

Variables: webgl_animation_site_url

## Prompt

You are a highly skilled front-end developer with expertise in WebGL. Your task is to clone a website that features a stunning, interactive 3D animation created with WebGL. The animation should be interactive, allowing the user to manipulate it with their mouse.

Context:
- The website with the WebGL animation is {{webgl_animation_site_url}}.
- You must use a WebGL library like Three.js or Babylon.js to create the 3D animation.
- The goal is to replicate the visual fidelity and interactivity of the original animation as closely as possible.

Provide:
1. The complete code for the cloned WebGL animation.
2. A guide on how to set up the development environment and run the project.

If you cannot open {{webgl_animation_site_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.
