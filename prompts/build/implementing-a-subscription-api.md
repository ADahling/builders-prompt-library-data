# Implementing a Subscription API

Design an API for creating and retrieving user subscriptions, including required submission fields, response formats, and error handling.

## Prompt

Design an API for managing subscriptions. Include endpoints for:
- {POST /subscriptions}: Creating a new subscription with fields {userId}, {planId}, and {paymentInfo}.
- {GET /subscriptions/{userId}}: Retrieving all subscriptions for a user. Discuss response formats and error handling.

## Tips

This prompt will help you implement subscription management in your application.
