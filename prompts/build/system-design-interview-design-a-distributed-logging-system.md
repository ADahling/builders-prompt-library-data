# System Design Interview: Design a Distributed Logging System

Architect a scalable distributed logging system using the ELK stack to handle high-throughput data ingestion and real-time log analysis.

## Prompt

You are in a system design interview. The interviewer asks you to "Design a distributed logging system."

**Your Task:**
Provide a design for a system that can collect, store, and analyze logs from a large number of servers.

**Instructions & Constraints:**
1.  **Requirements:**
    *   High throughput data ingestion.
    *   Near real-time search and analysis.

2.  **Architecture (The ELK Stack):**
    *   Propose an architecture based on the ELK stack (Elasticsearch, Logstash, Kibana) or a similar set of tools.
    *   Explain the role of each component.

3.  **Scaling the System:**
    *   Discuss how to scale the ingestion and storage layers.

**Output Format:**
Generate a design document in Markdown:
1.  **Designing a Distributed Logging and Analysis System**
2.  **Our Architecture: Leveraging the ELK Stack**
3.  **Scaling the Ingestion and Storage Layers**
