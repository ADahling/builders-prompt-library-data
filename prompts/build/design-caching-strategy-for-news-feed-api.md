# Design Caching Strategy for News Feed API

Architect a multi-layer caching system to optimize news feed latency and scalability using CDN, in-memory, and database-level strategies.

## Prompt

As a system architect, design a multi-layer caching strategy for a high-traffic news feed API. The goal is to minimize latency and reduce the load on the origin server. Describe the caching layers you would use (e.g., client-side, CDN, in-memory cache, and database cache) and the data that would be stored in each layer. Explain the cache invalidation strategy and how you would handle personalized content. Provide a diagram illustrating the caching architecture.

## Tips

Each prompt can focus on a different caching layer and its specific challenges.
