# Anthropic Claude API: Simple Text Completion for Content Creation

Develop a Python script using the Anthropic SDK to automate the generation of engaging blog introductions via the Claude Sonnet 5 API.

## Prompt

Imagine you are a content marketer using the Anthropic Claude API to generate a blog post introduction.

Your goal is to write a Python script that uses the 'anthropic' library to call the Claude API. The script should take a blog post title and generate a compelling, 200-word introduction.

**Constraints & Requirements:**
- The blog post title is: "The Future of Remote Work: Trends and Technologies".
- Use the Claude Sonnet 5 model ('claude-5-sonnet-20260124').
- The prompt sent to Claude must instruct it to write an engaging introduction that hooks the reader, introduces the topic, and briefly outlines what the article will cover.
- The script must use the 'anthropic' Python SDK.
- Ensure your API key is handled securely using environment variables ('ANTHROPIC_API_KEY').
- The script should print the generated blog post introduction to the standard output.
- Include basic error handling for the API call.

**Output Format:**
Provide a single, runnable Python script that performs the task described.
