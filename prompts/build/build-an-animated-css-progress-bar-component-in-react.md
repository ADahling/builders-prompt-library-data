# Build an Animated CSS Progress Bar Component in React

Get complete code for a React progress bar that accepts a percentage prop and uses CSS animation to display a task's current progress.

## Prompt

I'm building a web application that needs to display a progress bar. The progress bar should be animated and should show the current progress of a task. The component should take the current progress percentage as a prop. Create a `ProgressBar` component in React that displays an animated progress bar. The animation should be done with CSS. Provide the complete code for the component.
