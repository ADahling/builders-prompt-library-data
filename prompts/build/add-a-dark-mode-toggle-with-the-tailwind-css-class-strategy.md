# Add a Dark Mode Toggle with the Tailwind CSS Class Strategy

Get Tailwind CSS configuration for class-based dark mode and button code that toggles the dark mode class on a web app's html element.

## Prompt

I'm building a web application that needs to have a dark mode toggle. I want to implement this using Tailwind CSS's dark mode feature. I need to configure Tailwind CSS to use the 'class' strategy for dark mode. I also need to create a button that toggles the dark mode class on the `html` element. Provide the necessary configuration for Tailwind CSS and the code for the dark mode toggle button..
