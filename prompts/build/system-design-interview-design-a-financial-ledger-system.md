# System Design Interview: Design a Financial Ledger System

Architect a reliable, immutable double-entry bookkeeping system with physical schemas and audit strategies for fintech applications.

## Prompt

You are in a system design interview for a fintech company. The interviewer asks you to "Design a double-entry financial ledger system."

**Your Task:**
Provide a design for a reliable and auditable financial ledger system.

**Instructions & Constraints:**
1.  **Core Principles of Double-Entry Bookkeeping:**
    *   Explain the core principles: every transaction has a debit and a credit, and the total debits must equal the total credits.

2.  **Database Schema:**
    *   Design the database schema for accounts, journal entries, and ledger entries.

3.  **Reliability and Auditability:**
    *   Discuss how to ensure the reliability and auditability of the system. The data should be immutable.

**Output Format:**
Generate a design document in Markdown:
1.  **Designing a Double-Entry Financial Ledger**
2.  **Database Schema for a Double-Entry System**
3.  **Ensuring Immutability, Reliability, and Auditability**
