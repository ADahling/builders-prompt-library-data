# Animate a List with Staggered Fade-In Using Framer Motion

Get a React list component with Framer Motion variants and staggerChildren to fade and slide items upward in sequence when the list appears.

## Prompt

I want to create a staggered animation for a list of items using Framer Motion. When the list appears, each item should animate in with a short delay after the previous one. The animation should be a fade-in and a slide-up effect. Create a React component that renders a list of items and uses Framer Motion's `staggerChildren` and `variants` to achieve this staggered animation. Provide the complete code for the component and the necessary variants for the animation.
