# Design a System for Data Quality Monitoring

Get a monitoring design for missing, inaccurate, or inconsistent data, with quality rules, profiling, a dashboard, and remediation steps.

## Prompt

We are having problems with data quality in our application. We have a lot of missing, inaccurate, and inconsistent data. I need to design a system for data quality monitoring to help us to identify and to fix these problems.

Your task is to design a system for data quality monitoring. The design should include:

1.  **Data Quality Dimensions:** A definition of the key data quality dimensions that we should monitor, such as completeness, accuracy, consistency, and timeliness.
2.  **Data Quality Rules:** A set of rules for each data quality dimension to check the quality of our data. For example, a completeness rule might check that a certain field is not null.
3.  **Data Profiling:** A plan for how to use data profiling to get a better understanding of our data and to identify potential data quality issues.
4.  **Data Quality Dashboard:** A design for a dashboard that provides a real-time view of our data quality. The dashboard should show the data quality score for each data quality dimension and should highlight any data quality issues.
5.  **Data Quality Remediation:** A process for how to remediate data quality issues when they are identified.

## Tips

This prompt is for organizations that want to improve the quality of their data.
