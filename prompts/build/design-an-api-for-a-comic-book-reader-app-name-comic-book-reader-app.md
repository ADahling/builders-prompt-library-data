# Design an API for a Comic Book Reader App

Get a REST API design for a comic reader, with methods, URIs, and data formats for browsing, purchases, paginated reading, and progress tracking.

Variables: comic_book_reader_app_name

## Prompt

I am building a comic book reader app called {{comic_book_reader_app_name}}. I need to design the API for it.

Your task is to design the core API for the comic book reader app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., users, comic books, series, publishers, reading progress).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Users can browse and purchase comic books.
    *   Users can read comic books in a paginated format.
    *   The app tracks the user's reading progress.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
