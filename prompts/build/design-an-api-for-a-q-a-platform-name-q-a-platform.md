# Design an API for a Q&A Platform

Get a RESTful API design for a Q&A platform, with methods, URIs, and request/response formats for questions, answers, comments, votes, and search.

Variables: q&a_platform_name

## Prompt

I am building a Q&A platform called {{q&a_platform_name}}, similar to Stack Overflow or Quora. I need to design the API for it.

Your task is to design the core API for the Q&A platform.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the platform (e.g., users, questions, answers, comments, votes).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Asking questions.
    *   Answering questions.
    *   Commenting on questions and answers.
    *   Upvoting and downvoting questions and answers.
    *   Searching for questions.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
