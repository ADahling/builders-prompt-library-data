# Build a Responsive Blog Card Component with Image and Excerpt

Get HTML and CSS for blog cards with images, excerpts, and author details, arranged in a desktop grid and stacked on small screens.

## Prompt

I need to create a responsive card component for a blog. The card should display a featured image, a title, a short excerpt, and the author's name and avatar. On large screens, the cards should be displayed in a grid. On small screens, they should be stacked vertically. Provide the HTML structure and the CSS to create this responsive card component. The solution should be pure CSS and use Flexbox or CSS Grid for the layout..
