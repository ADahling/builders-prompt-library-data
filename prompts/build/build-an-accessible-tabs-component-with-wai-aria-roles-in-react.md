# Build an Accessible Tabs Component with WAI-ARIA Roles in React

Build responsive React tabs from scratch with clickable headers and WAI-ARIA tab roles, without third-party libraries.

## Prompt

I need to create a responsive and accessible tabs component in React. The component should be built from scratch and should not rely on any third-party libraries. The tabs should be switchable by clicking on the tab headers. The component should follow WAI-ARIA best practices for tabs, including the use of `role='tablist'
