# Design an API for a Note-Taking App

Get a note-taking app RESTful API design for notebooks, note creation and editing, tags, and search, with methods, URIs, and data formats.

Variables: note-taking_app_name

## Prompt

I am building a note-taking app called {{note-taking_app_name}}, similar to Evernote or Google Keep. I need to design the API for it.

Your task is to design the core API for the note-taking app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., users, notebooks, notes, tags).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Creating and managing notebooks.
    *   Creating, updating, and deleting notes.
    *   Adding tags to notes.
    *   Searching for notes.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
