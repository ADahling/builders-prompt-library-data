# Build a Pricing Page with an Animated Monthly/Yearly Toggle

Get HTML, CSS, and JavaScript for a responsive three-plan pricing page with a monthly/yearly toggle and animated price updates.

## Prompt

I need to create a responsive pricing page with a toggle to switch between monthly and yearly pricing. The page should display three pricing plans. When the toggle is switched, the prices should update with an animation. Provide the HTML structure, the CSS, and the JavaScript to create this responsive pricing page with a pricing toggle.
