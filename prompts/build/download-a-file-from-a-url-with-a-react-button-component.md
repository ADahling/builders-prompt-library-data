# Download a File from a URL with a React Button Component

Get a React download button component that creates a temporary link and triggers a click to download a file from a given URL.

## Prompt

I'm building a web application that needs to have a feature to download a file from a URL. I want to create a 'Download' button that, when clicked, downloads a file from a given URL. The file could be an image, a PDF, or any other type of file. Provide a React component that has a 'Download' button and a function to handle the file download. The function should create a temporary link and trigger a click on it to start the download.
