# Animate a Toast Notification with Framer Motion AnimatePresence

Get a React toast with configurable slide and fade animations using Framer Motion, message and type props, and a trigger example.

## Prompt

I want to create a custom animation for a toast notification component using Framer Motion. The toast should slide in from the right side of the screen and fade in. When it's dismissed, it should slide out to the right and fade out. The animation should be smooth and configurable. Create a `Toast` component in React that uses Framer Motion's `AnimatePresence` and `motion` components to achieve this effect. The component should accept a message and a type (e.g., 'success', 'error') as props. Provide the complete code for the `Toast` component and an example of how to trigger it..
