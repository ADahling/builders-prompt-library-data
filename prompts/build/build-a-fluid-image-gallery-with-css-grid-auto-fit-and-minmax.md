# Build a Fluid Image Gallery with CSS Grid auto-fit and minmax()

Get HTML and CSS for a fluid image gallery using CSS Grid, auto-fit or auto-fill, and minmax() to adapt columns without media queries.

## Prompt

I need to create a responsive image gallery using CSS Grid. The gallery should have a variable number of columns depending on the screen size. On large screens, it should display 4 columns, on medium screens 3 columns, and on small screens 2 columns. The images should have a small gap between them. The gallery should be fluid and adapt to the container's width. Provide the HTML structure and the CSS to create this responsive image gallery. The solution should be pure CSS and not use any media queries for the column changes, but instead use the `auto-fit` or `auto-fill` keywords with `minmax()`.
