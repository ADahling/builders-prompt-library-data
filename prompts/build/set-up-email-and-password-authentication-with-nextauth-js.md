# Set Up Email and Password Authentication with NextAuth.js

Get NextAuth.js credentials provider configuration, a login page, and a protected page for email and password authentication in Next.js.

## Prompt

I'm building a Next.js application and I want to add authentication using NextAuth.js. I need to set up authentication with a credentials provider (email and password). I also need to create a login page and a protected page that is only accessible to authenticated users. Provide the necessary configuration for NextAuth.js and the code for the login page and the protected page.
