# Creating a User Profile Management API

Design a profile management API for retrieving and saving names, bios, and avatars, with response formats and error handling.

Variables: name, bio, avatar

## Prompt

Design an API for managing user profiles with endpoints for:
- {GET /profiles/{userId}}: Retrieving a user's profile.
- {POST /profiles}: Creating or updating a profile with fields {{name}}, {{bio}}, and {{avatar}}.
- Discuss response formats and error handling.

## Tips

This prompt will help you maintain user profiles effectively.
