# Format and Validate a Credit Card Input with the Luhn Algorithm

Get a TypeScript React credit card input that adds spaces every four digits as users type and validates the number with the Luhn algorithm.

## Prompt

I'm building a form where the user needs to enter their credit card number. I want to format the input as the user types, adding spaces after every four digits. I also want to validate the credit card number using the Luhn algorithm. Create a React component for a credit card input field that provides this formatting and validation. The component should be written in TypeScript.
