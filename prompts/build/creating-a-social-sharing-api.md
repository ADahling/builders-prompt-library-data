# Creating a Social Sharing API

Design a social sharing API with sharing and user history endpoints, security measures, error handling, and request and response examples.

Variables: platform

## Prompt

Outline an API for sharing content on social media platforms. Include endpoints for:
- {POST /share}: Sharing content with fields {userId}, {contentId}, and {{platform}}.
- {GET /shares/{userId}}: Retrieving sharing history for a user.
- Discuss security measures and error handling when sharing content.
- Provide examples of requests and responses demonstrating sharing functionality.

## Tips

This prompt will help you facilitate social interactions through your API.
