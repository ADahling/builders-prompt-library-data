# Add a Route-Change Progress Bar to Next.js with nprogress

Get Next.js code that connects nprogress to router start and complete events to show a top-of-page loading bar during page changes.

## Prompt

I'm building a Next.js application and I want to add a loading progress bar that appears at the top of the page when navigating between pages. I want to use the `nprogress` library to create the progress bar. I need to configure `nprogress` to work with Next.js's router events. Provide the code to set up `nprogress` in a Next.js application. The code should listen to the `routeChangeStart` and `routeChangeComplete` events of the Next.js router to start and stop the progress bar.
