# Build a Next.js Contact Form That Sends Email via Nodemailer

Get code for a Next.js contact form with name, email, and message fields, plus a serverless function that sends email using Nodemailer.

## Prompt

I'm building a Next.js application and I want to add a contact form that sends an email when submitted. I want to use a serverless function to handle the email sending. I need to create a contact form with fields for name, email, and message. When the form is submitted, the data should be sent to a serverless function that sends an email using Nodemailer. Provide the code for the contact form and the serverless function.
