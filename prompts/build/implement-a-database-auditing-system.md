# Implement a Database Auditing System

Plan database auditing for compliance with auditing requirements, method selection, policies, log storage and protection, and review procedures.

Variables: database_type

## Prompt

We need to be able to track all the changes that are made to our database to meet our compliance requirements. I need to implement a database auditing system for our {{database_type}} database.

Your task is to create a plan for implementing a database auditing system. The plan should include:

1.  **Auditing Requirements:** A clear definition of our auditing requirements. This should include what we need to audit, why we need to audit it, and how long we need to keep the audit logs.
2.  **Auditing Method:** A recommendation for an auditing method. This could be using the built-in auditing features of our database or using a third-party auditing tool.
3.  **Audit Policy:** A set of audit policies that will define what we audit. The policies should be designed to meet our auditing requirements without creating too much overhead.
4.  **Audit Log Management:** A plan for how to manage the audit logs. This should include where to store the audit logs, how to protect them from tampering, and how to archive them.
5.  **Audit Log Review:** A process for how to review the audit logs to detect and to investigate any suspicious activity.

## Tips

This prompt is a critical practice for any organization that needs to meet compliance requirements.
