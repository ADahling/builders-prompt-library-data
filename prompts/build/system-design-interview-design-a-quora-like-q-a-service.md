# System Design Interview: Design a Quora-like Q&A Service

Architect a scalable Q&A platform by designing high-level schemas and personalized feed generation logic for system design interview prep.

## Prompt

You are in a system design interview. The interviewer asks you to "Design a Q&A service like Quora."

**Your Task:**
Provide a high-level design for a Q&A service.

**Instructions & Constraints:**
1.  **Core Features:**
    *   Users can post questions.
    *   Users can answer questions.
    *   Users can follow topics.
    *   A feed of relevant questions and answers.

2.  **Database Schema:**
    *   Design the database schema for questions, answers, users, and topics.

3.  **Feed Generation:**
    *   Discuss how you would generate a personalized feed for each user.

**Output Format:**
Generate a design document in Markdown:
1.  **Designing a Quora-like Q&A Platform**
2.  **Database Schema Design**
3.  **Generating the User Feed**
