# Build a Shimmering Skeleton Loading Screen for a Profile Page

Get a TypeScript React profile skeleton and shimmer CSS for loading states covering an avatar, username, bio, and posts.

## Prompt

I want to implement a skeleton loading screen for a user profile page in my React application. The profile page displays an avatar, a username, a short bio, and a list of posts. The skeleton screen should mimic this layout with placeholder elements that have a shimmering animation. The animation should be created with CSS. Create a `ProfileSkeleton` component that renders this skeleton layout. The component should be written in TypeScript. Provide the complete code for the component and the CSS for the shimmering animation.
