# Generate a Simple CSS Flexbox Layout

Generate a CSS flexbox container that centers a specific number of child elements both horizontally and vertically.

Variables: item_count

## Prompt

You are an AI coding assistant. Generate the CSS code for a simple flexbox layout with a container and {{item_count}} items.

Requirements:
- The container should be a flex container.
- The items should be centered horizontally and vertically within the container.

A basic prompt for creating a common CSS layout.
