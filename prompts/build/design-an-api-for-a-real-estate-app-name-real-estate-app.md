# Design an API for a Real Estate App

Get a RESTful API design for a real estate app, covering filtered property search, listing details, saved properties, and saved searches.

Variables: real_estate_app_name

## Prompt

I am building a real estate app called {{real_estate_app_name}} that will help users find properties to buy or rent.

Your task is to design the API for the real estate app.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the app (e.g., properties, agents, users, saved searches).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Searching for properties with various filters (e.g., location, price, number of bedrooms).
    *   Viewing property details, including photos and agent information.
    *   Saving properties and searches.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoint, including the HTTP method, URI, and request/response format.
