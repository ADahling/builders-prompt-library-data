# Build a Responsive Careers Section Listing Open Positions

Get HTML and CSS for a responsive company careers section listing open positions with job titles, locations, and description links.

## Prompt

I need to create a responsive 'our careers' section for a company website. The section should display a list of open positions. Each position should have a title, a location, and a link to the job description. The section should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our careers' section.
