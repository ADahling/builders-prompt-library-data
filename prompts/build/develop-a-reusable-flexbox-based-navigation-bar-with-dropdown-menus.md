# Develop a Reusable Flexbox-based Navigation Bar with Dropdown Menus

Build a responsive Flexbox navigation bar for a company website with commented HTML, CSS, multi-level dropdowns, and mobile toggle code.

Variables: website_name

## Prompt

For our company website, {{website_name}}, we need a responsive navigation bar that is both functional and easy to maintain. The navigation bar should be built using modern CSS, primarily Flexbox, and should include support for multi-level dropdown menus.

Create the HTML and CSS for a navigation bar component with the following features:
1.  The main navigation links should be horizontally aligned on larger screens and stack vertically on mobile screens.
2.  Use Flexbox to manage the layout of the navigation items, ensuring they are evenly spaced and aligned.
3.  Implement dropdown menus that appear on hover (on desktop) and on click/tap (on mobile) for parent navigation items.
4.  The dropdown menus should be styled to match a modern, clean aesthetic.
5.  The entire navigation bar must be fully responsive. Use a media query to switch to a mobile-friendly layout (e.g., a hamburger menu) at a breakpoint of 768px.
6.  The solution should be implemented with HTML and CSS only. A small amount of JavaScript is acceptable for toggling the mobile menu and dropdowns, but the layout itself must be CSS-driven.

Provide the complete HTML, CSS, and any necessary JavaScript for this component. The code should be well-structured and commented to explain the Flexbox properties and responsive logic.
