# Designing a File Upload API

Plan a file upload API with authentication, size and type validation, error handling, and example requests and responses.

## Prompt

Outline an API for handling file uploads. Include details on:
- Endpoint design for {POST /upload} that accepts file data.
- Required headers and authentication mechanisms.
- File size and type restrictions, and how to validate these before accepting uploads.
- Response structures for successful uploads and error handling. Provide examples of requests and responses.

## Tips

This prompt will help you structure a robust file handling system in your API.
