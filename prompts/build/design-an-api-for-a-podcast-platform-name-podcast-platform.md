# Design an API for a Podcast Platform

Get a podcast platform RESTful API design for uploads, episode management, discovery, subscriptions, and listening, with endpoint data formats.

Variables: podcast_platform_name

## Prompt

I am building a podcast platform called {{podcast_platform_name}}. I need to design the API for it.

Your task is to design the core API for the podcast platform.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the platform (e.g., users, podcasts, episodes, subscriptions).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Podcasters can upload and manage their podcasts and episodes.
    *   Users can browse, search for, and subscribe to podcasts.
    *   Users can listen to episodes.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
