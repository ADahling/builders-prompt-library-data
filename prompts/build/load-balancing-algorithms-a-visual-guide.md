# Load Balancing Algorithms: A Visual Guide

Generate a visual Markdown guide explaining Round Robin, Least Connections, and IP Hash algorithms with illustrative diagrams.

## Prompt

You are a computer science student creating a visual guide to different load balancing algorithms.

**Your Task:**
For each of the following algorithms, create a simple explanation and a diagram that illustrates how it works:
*   Round Robin
*   Least Connections
*   IP Hash

**Output Format:**
Generate a guide in Markdown with explanations and diagrams.
