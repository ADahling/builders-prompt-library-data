# Debug a React Application with Windsurf

Diagnose and resolve React re-rendering failures in Windsurf by isolating components to trace state inconsistencies and root causes.

Variables: component_name

## Prompt

You are debugging a React application using Windsurf. The application has a bug where a component is not re-rendering after its state changes. The component is named '{{component_name}}'.

Describe the prompts and workflow you would use in Windsurf to:
1. Isolate the problematic component.
2. Inspect its state and props.
3. Identify the root cause of the rendering issue.
