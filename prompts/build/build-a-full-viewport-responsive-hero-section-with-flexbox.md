# Build a Full-Viewport Responsive Hero Section with Flexbox

Get HTML and pure CSS for a full-height landing page hero with a background image, centered text, and a call-to-action button using Flexbox.

## Prompt

I need to create a responsive hero section for a landing page. The hero section should have a background image, a title, a subtitle, and a call-to-action button. The content should be centered vertically and horizontally. The hero section should take the full height of the viewport. Provide the HTML structure and the CSS to create this responsive hero section. The solution should be pure CSS and use Flexbox for the layout.
