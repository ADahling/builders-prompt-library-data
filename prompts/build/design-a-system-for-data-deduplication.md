# Design a System for Data Deduplication

Get a deduplication design for duplicate database records, covering fuzzy matching, master selection, merging, tools, and execution steps.

## Prompt

We have a lot of duplicate data in our database. This is increasing our storage costs and is making it difficult to get a single view of our customers. I need to design a system for data deduplication.

Your task is to design a system for data deduplication. The design should include:

1.  **Matching Strategy:** A plan for how to identify duplicate records. This should include a matching strategy that can handle fuzzy matches.
2.  **Master Record Selection:** A plan for how to select the master record from a set of duplicate records.
3.  **Data Merging:** A plan for how to merge the data from the duplicate records into the master record.
4.  **Deduplication Tool:** A recommendation for a data deduplication tool to automate the deduplication process.
5.  **Deduplication Process:** A step-by-step process for how to use the data deduplication tool to deduplicate our data.

## Tips

This prompt is for organizations that want to improve the quality of their data.
