# Write a useBrowser Hook to Detect Browser Name and Version

Get a complete useBrowser hook and usage example for detecting a web app user's browser name and version from the user-agent string.

## Prompt

I'm building a web application that needs to have a feature to detect the user's browser. I want to create a `useBrowser` hook that returns the name and version of the user's browser. The hook should parse the `user-agent` string to get the browser information. Provide a complete implementation of the `useBrowser` hook and an example of how to use it.
