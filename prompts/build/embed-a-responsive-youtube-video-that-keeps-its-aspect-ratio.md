# Embed a Responsive YouTube Video That Keeps Its Aspect Ratio

Get HTML and pure CSS for a responsive YouTube embed that preserves its aspect ratio as screen sizes change, without JavaScript.

## Prompt

I need to create a responsive video player that embeds a YouTube video. The video player should maintain its aspect ratio as the screen size changes. The solution should be pure CSS and not use any JavaScript. Provide the HTML structure and the CSS to create a responsive YouTube video embed..
