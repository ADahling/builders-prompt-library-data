# Creating a Content Management API

Design a content management API outline with endpoints for listing, creating, and retrieving content, plus response formats and error handling.

Variables: title, body

## Prompt

Outline an API for content management with endpoints for:
- {GET /content}: Retrieving a list of content items with optional filtering.
- {POST /content}: Creating new content with fields {{title}}, {{body}}, and {authorId}.
- {GET /content/{contentId}}: Retrieving details for a specific content item. Discuss response formats and error handling.

## Tips

This prompt will help you manage content effectively.
