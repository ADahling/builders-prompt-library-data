# Explain a Code Snippet in Plain English

Translate complex code snippets into simple, step-by-step explanations to help beginner developers understand logic and syntax.

Variables: language, code_snippet

## Prompt

You are an AI coding assistant. Please explain the following code snippet in plain English, assuming I am a beginner developer.

Code:
```{{language}}
{{code_snippet}}
```

Focus on explaining the purpose of the code and what each line does.

## Tips

Useful for understanding unfamiliar code. The user should replace {{language}} and {{code_snippet}}.
