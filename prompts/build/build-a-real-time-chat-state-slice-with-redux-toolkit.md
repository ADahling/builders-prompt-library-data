# Build a Real-Time Chat State Slice with Redux Toolkit

Get a Redux Toolkit chat slice with message, user, and typing reducers, a mock history fetch thunk, and a React usage example.

## Prompt

I'm building a real-time chat application and I need to manage the chat state, including messages, users, and typing indicators. I want to use Redux Toolkit for state management. Create a Redux Toolkit slice for the chat feature. The slice should have reducers for adding a new message, setting the list of users, and updating the typing indicator. Also, create an async thunk to fetch the initial chat history from a mock API. Provide the complete code for the chat slice and an example of how to use it in a React component..
