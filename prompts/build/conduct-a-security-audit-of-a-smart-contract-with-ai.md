# Conduct a Security Audit of a Smart Contract with AI

Review Solidity contract code before deployment for reentrancy, integer overflow or underflow, unchecked external calls, and gas limit issues.

Variables: contract_code

## Prompt

You have a Solidity smart contract for a decentralized application. Before deploying it to the blockchain, you need to perform a security audit to check for common vulnerabilities.

Provide the smart contract code (`{{contract_code}}`) to an AI assistant and ask it to audit the code for issues like:
- Reentrancy attacks.
- Integer overflow/underflow.
- Unchecked external calls.
- Gas limit issues.

## Tips

A high-stakes use case for AI in the specialized domain of blockchain development.
