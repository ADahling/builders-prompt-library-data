# Generate a Jenkinsfile for a CI/CD pipeline

Generate a declarative Jenkinsfile to automate the build, test, and staging deployment phases for a specified project type.

Variables: project_type

## Prompt

You are an AI coding assistant. Generate a Jenkinsfile for a CI/CD pipeline for a `{{project_type}}` project. The pipeline should have the following stages:
1. Build: build the project.
2. Test: run the unit tests.
3. Deploy: deploy the project to a staging environment.

## Tips

A great use case for AI, as it can be tedious to write a Jenkinsfile from scratch.
