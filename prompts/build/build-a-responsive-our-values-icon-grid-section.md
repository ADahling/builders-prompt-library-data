# Build a Responsive 'Our Values' Icon Grid Section

Get HTML and CSS for a responsive company values section with a grid of icons, titles, and short descriptions for different screen sizes.

## Prompt

I need to create a responsive 'our values' section for a company website. The section should display a grid of the company's values, each with an icon, a title, and a short description. The grid should be responsive and work on different screen sizes. Provide the HTML structure and the CSS to create this responsive 'our values' section.
