# Choose Between Monolithic and Microservices Architecture for a New Project

Evaluate architectural trade-offs between monolithic and microservices patterns to select the optimal backend structure for your project.

Variables: project_description

## Prompt

I am starting a new project, a {{project_description}}. I am trying to decide between a monolithic and a microservices architecture for the backend.

Your task is to help me make this decision by comparing the two architectural styles and recommending the best one for my project.

**Instructions:**
1.  **Architecture Comparison:** Create a table that compares monolithic and microservices architectures based on the following criteria:
    *   Development complexity
    *   Scalability
    *   Deployment
    *   Technology stack flexibility
    *   Fault isolation
    *   Team organization
2.  **Recommendation:** Based on the comparison and the description of my project, recommend the most suitable architecture. Justify your recommendation.

**Output Format:**
Provide the output as a Markdown document. Start with the comparison table. Then, state your recommendation and provide a detailed justification for it.
