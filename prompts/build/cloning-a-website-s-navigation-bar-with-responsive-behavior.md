# Cloning a Website's Navigation Bar with Responsive Behavior

Replicate a website's navigation bar using HTML, CSS, and JS with a functional, mobile-responsive hamburger menu transition.

Variables: website_url

## Prompt

You are a junior web developer. Your task is to clone the main navigation bar from a website, ensuring it is fully responsive. The navigation should transform from a horizontal bar on desktop to a hamburger menu on mobile.

Context:
- The website to clone the navigation from is {{website_url}}.
- You will need to use HTML, CSS, and a small amount of JavaScript to handle the hamburger menu toggle.
- Pay attention to the breakpoints at which the navigation changes its layout.

Provide:
1. The complete code (HTML, CSS, JS) for the responsive navigation bar.
2. A short screen recording showing the navigation's responsive behavior.

If you cannot open {{website_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.
