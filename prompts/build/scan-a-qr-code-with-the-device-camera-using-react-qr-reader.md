# Scan a QR Code with the Device Camera Using react-qr-reader

Get a React component with a Scan QR Code button that opens the user's camera and uses react-qr-reader to scan codes in a web app.

## Prompt

I'm building a web application that needs to have a feature to scan a QR code from the user's camera. I want to create a 'Scan QR Code' button that, when clicked, opens the camera and scans a QR code. I want to use the `react-qr-reader` library to achieve this. Provide a React component that has a 'Scan QR Code' button and uses `react-qr-reader` to scan a QR code.
