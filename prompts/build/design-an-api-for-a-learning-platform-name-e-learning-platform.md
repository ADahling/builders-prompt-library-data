# Design an API for an E-Learning Platform

Get an e-learning RESTful API design for course browsing, enrollment, content access, progress tracking, and instructor course management.

Variables: learning_platform_name

## Prompt

I am building an e-learning platform called {{learning_platform_name}}, similar to Coursera or Udemy. I need to design the API for it.

Your task is to design the core API for the e-learning platform.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the platform (e.g., courses, lessons, students, instructors, enrollments, progress).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Browsing and enrolling in courses.
    *   Viewing course content (lessons, videos, quizzes).
    *   Tracking student progress.
    *   Instructors can create and manage courses.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
