# Create an API Design Review Checklist

Get a Markdown checklist for formal API design reviews, covering resources, HTTP usage, security, documentation, and performance.

## Prompt

To ensure the quality and consistency of our APIs, we want to implement a formal API design review process. 

Your task is to create a comprehensive checklist for reviewing API designs.

**Instructions:**
Create a checklist that covers the following aspects of API design:
*   Resource modeling and naming
*   URI structure
*   HTTP method usage
*   Request and response formats
*   Status codes and error handling
*   Pagination, filtering, and sorting
*   Authentication and authorization
*   Documentation
*   Performance and scalability

**Output Format:**
Provide the output as a Markdown document with a checklist. For each item in the checklist, provide a brief explanation of what to look for during the review.
