# Mobile-First Cloning of a Social Media Feed

Build a responsive, infinitely scrollable social media feed clone using a mobile-first architectural approach with clean HTML, CSS, and JS.

Variables: social_media_app

## Prompt

You are a mobile-first front-end developer. Your task is to clone the main feed of a social media app, starting with the mobile design and then scaling it up to desktop.

Context:
- The social media app to clone is {{social_media_app}}.
- You must use a mobile-first approach in your CSS.
- The feed should be infinitely scrollable.

Provide:
1. The HTML and CSS for the responsive social media feed.
2. The JavaScript for the infinite scroll functionality.

## Tips

This task teaches the mobile-first responsive design workflow.
