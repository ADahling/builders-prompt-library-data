# Dark Mode Cloning of a Documentation Site

Clone a specific documentation site with a persistent, locally-stored dark mode toggle using HTML, CSS, and JavaScript.

Variables: docs_site_url

## Prompt

You are a front-end developer who loves dark mode. Your task is to clone a documentation website and add a dark mode theme switcher.

Context:
- The documentation site to clone is {{docs_site_url}}.
- You need to create a separate color scheme for dark mode and allow users to toggle between light and dark themes.
- The user's preference should be saved in local storage.

Provide:
1. The HTML and CSS for the documentation site with both light and dark themes.
2. The JavaScript for the theme switcher functionality.

If you cannot open {{docs_site_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

An advanced task that covers theme switching and local storage.
