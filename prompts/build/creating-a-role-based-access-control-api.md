# Creating a Role-Based Access Control API

Design an API for managing application roles and permissions, with creation, listing, updates, deletion, response formats, and error handling.

## Prompt

Outline an API for managing roles and permissions in your application. Include endpoints for:
- {POST /roles}: Creating a new role with permissions.
- {GET /roles}: Retrieving all roles and their permissions.
- {PATCH /roles/{roleId}}: Updating a specific role.
- {DELETE /roles/{roleId}}: Deleting a role. Discuss the response formats and error handling strategies.

## Tips

This prompt will help you ensure robust access control in your API.
