# Cloning with Accessibility Preservation

Replicate a news site's homepage using semantic HTML and ARIA standards to ensure full keyboard navigation and WCAG compliance.

Variables: news_website_url

## Prompt

You are a front-end developer with a focus on accessibility. Your task is to clone a news website's homepage while ensuring all accessibility features are preserved or improved.

Context:
- The news website to clone is {{news_website_url}}.
- Pay attention to semantic HTML, ARIA roles, keyboard navigation, and color contrast.
- Use accessibility audit tools to check your work.

Provide:
1. The HTML and CSS for the cloned homepage.
2. A report on the accessibility improvements you made.

If you cannot open {{news_website_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.

## Tips

This task emphasizes the importance of accessibility in web development.
