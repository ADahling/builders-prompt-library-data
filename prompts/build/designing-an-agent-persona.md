# Designing an Agent Persona

Get a Markdown guide to AI agent personas, covering tone, knowledge boundaries, behavioral rules, and a system prompt template and example.

## Prompt

Write a guide on how to design and implement a strong persona for an AI agent. A well-defined persona improves user experience and helps guide the agent's behavior.

**Guide Content:**

1.  **What is an Agent Persona?**
    *   Define it as the character, tone, and set of behavioral guidelines the agent adopts.
2.  **Key Elements of a Persona:**
    *   **Role/Identity:** Who is the agent? (e.g., a helpful tutor, a grumpy pirate, a precise legal assistant).
    *   **Tone of Voice:** How does it speak? (e.g., formal, casual, enthusiastic, sarcastic).
    *   **Knowledge Boundaries:** What does it know, and more importantly, what does it *not* know?
    *   **Behavioral Rules:** Specific instructions on how to handle certain situations (e.g., "Always ask for clarification if the user's request is under 5 words").
3.  **Implementing the Persona (The System Prompt):**
    *   Explain that the persona is primarily defined in the system prompt.
    *   Provide a template for a good system prompt structure:
        *   [Role Definition]
        *   [Tone Instructions]
        *   [Task Description]
        *   [Constraints/Rules]
4.  **Example:**
    *   Provide a complete example of a system prompt for a specific persona, such as a "Tech Support Agent for Elderly Users." The prompt should emphasize patience, simple language, and avoiding jargon.

**Output Format:**

A Markdown document that serves as a best-practices guide for prompt engineering an agent's persona.
