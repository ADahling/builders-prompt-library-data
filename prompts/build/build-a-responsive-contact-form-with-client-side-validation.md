# Build a Responsive Contact Form with Client-Side Validation

Get HTML, CSS, and JavaScript for a responsive contact form with name, email, and message fields, client validation, and mock API submission.

## Prompt

I need to create a responsive contact form with validation. The form should have fields for name, email, and message. The form should be validated on the client-side. When the form is submitted, the data should be sent to a mock API. Provide the HTML structure, the CSS, and the JavaScript to create this responsive contact form with validation.
