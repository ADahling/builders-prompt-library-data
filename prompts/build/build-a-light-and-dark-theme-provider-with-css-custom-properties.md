# Build a Light and Dark Theme Provider with CSS Custom Properties

Get a React ThemeProvider, CSS color variables, and a usage example for switching an app between light and dark themes with body classes.

## Prompt

Our application needs a robust theming solution that allows users to switch between light and dark modes. I want to implement this using CSS Custom Properties (Variables) and a simple React Context to manage the theme state. Create a `ThemeProvider` component that provides the current theme ('light' or 'dark') and a function to toggle the theme. The component should apply the appropriate theme class to the `body` element. Also, provide the CSS for the two themes using custom properties for colors. Finally, show an example of a component that consumes the theme context and styles itself accordingly..
