# Record Audio from the User's Microphone with the MediaRecorder API

Get a React component with Record and Stop buttons that uses MediaRecorder to capture microphone audio and make it available as a blob.

## Prompt

I'm building a web application that needs to have a feature to record audio from the user's microphone. I want to create a 'Record' button that, when clicked, starts recording audio. When the user clicks the 'Stop' button, the recording should stop, and the recorded audio should be available as a blob. I want to use the `MediaRecorder` API to achieve this. Provide a React component that has 'Record' and 'Stop' buttons and uses the `MediaRecorder` API to record audio.
