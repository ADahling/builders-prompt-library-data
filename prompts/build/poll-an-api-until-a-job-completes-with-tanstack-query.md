# Poll an API Until a Job Completes with TanStack Query

Get a TanStack Query example using useQuery and refetchInterval to poll a background job's status in React and stop when it completes.

## Prompt

I want to create a simple polling mechanism in a React application to fetch data from an API every few seconds. I want to use TanStack Query (formerly React Query) to handle the polling. I need to fetch the status of a background job from an API. The polling should continue until the job is completed. Provide an example of how to use the `refetchInterval` option in `useQuery` to implement polling. The example should also show how to stop the polling when the job is done..
