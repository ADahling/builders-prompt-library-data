# Design a RESTful API for a Blog Platform

Architect a structured RESTful API for a blog platform by defining resource models, HTTP endpoints, and relational data paths.

## Prompt

I am building a blog platform and I need to design a RESTful API for it. The platform will have users, posts, comments, and tags.

Your task is to design the API endpoints for the following resources:
*   Users
*   Posts
*   Comments
*   Tags

**Instructions:**
1.  **Resource Modeling:** Identify the attributes for each resource. For example, a 'Post' resource might have attributes like 'title', 'content', 'author_id', and 'publication_date'.
2.  **Endpoint Design:** Define the HTTP methods (GET, POST, PUT, DELETE) and URI patterns for each resource. For example, what would be the endpoint to get all posts by a specific user?
3.  **Relationships:** Show how to represent relationships between resources. For example, how would you fetch all comments for a specific post?

**Output Format:**
Provide the output as a Markdown document. For each resource, list the attributes and the corresponding API endpoints with their HTTP methods and URI patterns.
