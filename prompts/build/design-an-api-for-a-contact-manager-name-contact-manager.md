# Design an API for a Contact Manager

Get a REST API design with methods, URIs, and request/response formats for creating, managing, grouping, and searching contacts in a contact manager.

Variables: contact_manager_name

## Prompt

I am building a contact manager application called {{contact_manager_name}}. I need to design the API for it.

Your task is to design the core API for the contact manager.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the application (e.g., users, contacts, groups).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Creating, retrieving, updating, and deleting contacts.
    *   Organizing contacts into groups.
    *   Searching for contacts.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
