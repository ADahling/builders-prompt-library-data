# Make a Data Table Collapse into Cards on Small Screens

Get HTML and CSS for a responsive data table that shows standard rows on large screens and turns each row into a card on small screens.

## Prompt

I need to create a responsive table for displaying data. The table should have a header and a set of rows. On large screens, the table should be displayed as a standard table. On small screens, the table should be displayed as a list of cards, where each card represents a row. Provide the HTML structure and the CSS to create this responsive table.
