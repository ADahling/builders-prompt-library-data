# Cloning a Website with a Complex Responsive Layout

Clone a complex, media-rich website using advanced HTML and CSS techniques to achieve seamless responsiveness across all device breakpoints.

Variables: media_rich_website_url

## Prompt

You are a seasoned front-end developer specializing in responsive design. Your task is to clone a media-rich website that has a highly complex and adaptive responsive layout. The layout changes significantly across multiple breakpoints, with elements rearranging, resizing, and even disappearing to optimize the user experience on different devices.

Context:
- The target website to clone is {{media_rich_website_url}}.
- You must use advanced CSS techniques, such as container queries and clamp(), to create a fluid and truly responsive layout.
- The goal is to create a clone that not only looks identical to the original on all devices but also performs just as well.

Provide:
1. The HTML and CSS for the fully responsive website clone.
2. A detailed explanation of your responsive design strategy and the CSS techniques you employed.

If you cannot open {{media_rich_website_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.
