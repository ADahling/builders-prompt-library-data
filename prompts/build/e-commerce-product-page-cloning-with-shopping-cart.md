# E-commerce Product Page Cloning with Shopping Cart

Build a functional product page clone featuring a persistent local storage shopping cart for adding, updating, and removing items.

Variables: ecommerce_site_url

## Prompt

You are an e-commerce developer. Your task is to clone a product page from an e-commerce website and implement a functional shopping cart.

Context:
- The e-commerce site to clone from is {{ecommerce_site_url}}.
- The shopping cart should allow users to add products, update quantities, and remove items.
- You can use local storage to persist the cart data.

Provide:
1. The front-end code for the product page and shopping cart.
2. The JavaScript for managing the shopping cart functionality.

If you cannot open {{ecommerce_site_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.
