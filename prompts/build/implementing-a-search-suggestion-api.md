# Implementing a Search Suggestion API

Design a search suggestion API for user queries with a retrieval endpoint, caching guidance, and example requests and responses.

Variables: query

## Prompt

Design an API for providing search suggestions based on user input. Include endpoints for:
- {GET /suggestions}: Retrieving suggestions based on a {{query}} parameter.
- Discuss how to handle caching of suggestions for performance.
- Provide examples of requests and responses showcasing the search suggestion functionality.

## Tips

This prompt will help enhance search usability in your application.
