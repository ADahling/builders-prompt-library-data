# Build an Accessible Modal with Focus Trapping in React

Get a React TypeScript modal and usage example with focus trapping, WAI-ARIA guidance, and dismissal via overlay click or Escape.

## Prompt

I need to create a reusable and accessible modal component in React. The modal should be able to be closed by clicking on the overlay or pressing the 'Escape' key. It should also trap focus inside the modal when it's open. I want to build this from scratch without any third-party libraries for the modal logic itself, but you can use a library for focus trapping like `focus-trap-react`. The component should be written in TypeScript and follow WAI-ARIA guidelines. Provide the complete code for the `Modal` component and an example of its usage.
