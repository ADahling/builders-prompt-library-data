# Design an API for a Music Streaming Service

Get a music service API design for search, playlists, and personalized recommendations, plus a high-level audio streaming architecture.

Variables: music_streaming_service_name

## Prompt

I am building a music streaming service called {{music_streaming_service_name}}. I need to design the API for it.

Your task is to design the core API for the music streaming service.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the service (e.g., tracks, albums, artists, playlists).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Browsing and searching for music.
    *   Streaming audio content.
    *   Creating and managing playlists.
    *   Getting personalized recommendations.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints. For audio streaming, explain the high-level architecture.
