# Export a React Component to PDF with jsPDF and html2canvas

Get a React component with a download button that uses jsPDF and html2canvas to turn a specific component into a downloadable PDF.

## Prompt

I'm building a web application that needs to have a feature to generate a PDF from a component. I want to create a 'Download PDF' button that, when clicked, generates a PDF from a specific component and downloads it. I want to use the `jspdf` and `html2canvas` libraries to achieve this. Provide a React component that has a 'Download PDF' button and uses `jspdf` and `html2canvas` to generate and download the PDF.
