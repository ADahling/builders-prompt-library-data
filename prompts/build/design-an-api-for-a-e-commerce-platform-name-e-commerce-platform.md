# Design an API for an E-Commerce Platform

Get a REST API design for an e-commerce platform, with endpoint methods and data formats for product discovery, carts, orders, payments, and history.

Variables: e-commerce_platform_name

## Prompt

I am building an e-commerce platform called {{e-commerce_platform_name}}. I need to design the API for it.

Your task is to design the core API for the e-commerce platform.

**Instructions:**
1.  **Core Resources:** Identify the core resources of the e-commerce platform (e.g., products, categories, customers, orders, payments).
2.  **API Design:** Design the RESTful API endpoints for the following features:
    *   Browsing and searching for products.
    *   Managing the shopping cart.
    *   Placing an order.
    *   Processing payments.
    *   Viewing order history.

**Output Format:**
Provide the output as a Markdown document. For each feature, describe the design of the corresponding API endpoints, including the HTTP methods, URIs, and request/response formats.
