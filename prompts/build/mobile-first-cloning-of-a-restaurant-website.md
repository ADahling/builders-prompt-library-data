# Mobile-First Cloning of a Restaurant Website

Build a responsive restaurant site clone by applying mobile-first CSS strategies to ensure optimal performance and layout scaling.

Variables: restaurant_website_url

## Prompt

You are a front-end developer learning mobile-first design. Your task is to clone a restaurant website using a mobile-first approach. The mobile version should be clean and simple, with easy access to the menu, contact information, and reservations.

Context:
- The restaurant website to clone is {{restaurant_website_url}}.
- You must start by writing the CSS for the mobile layout first, and then use media queries to add styles for larger screens.
- The navigation should be a hamburger menu on mobile and a full navigation bar on desktop.

Provide:
1. The HTML and CSS for the responsive restaurant website.
2. A short explanation of the benefits of using a mobile-first approach.

If you cannot open {{restaurant_website_url}} yourself, say so before anything else and ask me for screenshots at each breakpoint or the page's HTML and CSS. Do not invent the design or describe it as verified.
If the full result does not fit in one reply, deliver it in parts in the order above, finish each part completely, and stop after each part so I can say continue.
