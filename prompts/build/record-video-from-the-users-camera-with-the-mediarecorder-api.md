# Record Video from the User's Camera with the MediaRecorder API

Get a React camera recording component with Record and Stop buttons that uses MediaRecorder and makes the recorded video available as a blob.

## Prompt

I'm building a web application that needs to have a feature to record a video from the user's camera. I want to create a 'Record' button that, when clicked, starts recording a video. When the user clicks the 'Stop' button, the recording should stop, and the recorded video should be available as a blob. I want to use the `MediaRecorder` API to achieve this. Provide a React component that has 'Record' and 'Stop' buttons and uses the `MediaRecorder` API to record a video.
