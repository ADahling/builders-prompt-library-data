# Write a Build-Time Sitemap Generator Script for Next.js

Get a script that generates an XML sitemap at build time for a Next.js application, including all its static and dynamic pages.

## Prompt

I'm building a Next.js application and I want to add a sitemap. The sitemap should be generated at build time and should include all the static and dynamic pages of the application. I need to create a script that generates the sitemap as an XML file. Provide the script to generate the sitemap.
