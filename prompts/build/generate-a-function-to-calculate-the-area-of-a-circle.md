# Generate a function to calculate the area of a circle

Generate a reusable function in a specified programming language to compute the area of a circle using the radius and the PI constant.

Variables: language

## Prompt

You are an AI coding assistant. Write a function in {{language}} that takes the radius of a circle as input and returns its area. Use the formula: area = PI * radius^2.
