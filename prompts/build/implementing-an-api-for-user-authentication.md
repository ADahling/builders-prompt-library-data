# Implementing an API for User Authentication

Design a user authentication API with login, logout, and token refresh endpoints, plus the session and error handling around them.

Variables: email, password

## Prompt

Outline an API for user authentication. Include endpoints for:
- {POST /login}: Authenticating a user with fields {{email}} and {{password}}.
- {POST /logout}: Logging the user out.
- Discuss response formats and error handling for authentication errors.

This prompt will help create secure access to your application.
