# Build a Responsive Alternating Vertical Timeline Component

Get HTML and CSS for a company history timeline with alternating dated events on desktop and events on one side on small screens.

## Prompt

I need to create a responsive timeline component for a company's history page. The timeline should display a series of events, each with a date and a description. The timeline should be vertical, with events alternating on the left and right sides of the timeline. On small screens, the events should be displayed on one side only. Provide the HTML structure and the CSS to create this responsive timeline component.
