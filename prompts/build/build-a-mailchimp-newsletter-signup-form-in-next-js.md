# Build a Mailchimp Newsletter Signup Form in Next.js

Get a React newsletter signup component for Next.js with an email field and submit button that sends emails to Mailchimp via react-mailchimp-subscribe.

## Prompt

I'm building a Next.js application and I want to add a newsletter signup form that integrates with Mailchimp. I need to create a form with an email input and a submit button. When the form is submitted, the email should be sent to a Mailchimp list. I want to use the `react-mailchimp-subscribe` library to handle the integration. Provide a React component for the newsletter signup form that uses `react-mailchimp-subscribe`.
