# Generate a .gitignore file

Generate a language-specific .gitignore file to exclude build artifacts, dependencies, and environment files from your version control.

Variables: project_type

## Prompt

You are an AI coding assistant. Generate a .gitignore file for a `{{project_type}}` project. The .gitignore file should include common files and directories to ignore for this type of project, such as build artifacts, dependencies, and environment files.

## Tips

A great use case for AI, as it can be tedious to create a comprehensive .gitignore file from scratch.
