# Implementing a 'Plan-and-Solve' Agent

Build a Python Plan-and-Solve agent with separate planning and tool execution phases to look up two city populations and calculate the difference.

Variables: city1, city2

## Prompt

Build an agent using the "Plan-and-Solve" architecture. This approach separates the reasoning process into two distinct phases: creating a step-by-step plan, and then executing that plan. This is often more effective for complex tasks than the standard ReAct loop.

**Architecture:**

1.  **Planner Agent:**
    *   Takes the user's objective.
    *   Generates a list of sequential steps to achieve the objective.
    *   Does *not* execute any tools.
2.  **Executor Agent:**
    *   Takes the plan generated by the Planner.
    *   Executes the steps one by one using available tools.
    *   Reports the final result.

**Scenario:**

The objective is: "Find the population of {{city1}} and {{city2}}, then calculate the difference."

**Implementation Steps:**

1.  **Tools:** Define a simple `search` tool or a mock population lookup tool.
2.  **Planner:** Create an LLM chain with a prompt that asks it to output a numbered list of steps.
3.  **Executor:** Create a ReAct agent that has access to the tools.
4.  **Orchestration:** Write a Python function that first calls the Planner, parses the steps, and then loops through the steps, passing each one to the Executor agent.

**Output:**

A Python script that clearly shows the two phases. When run, it should print the generated plan first, followed by the execution steps and the final answer.
