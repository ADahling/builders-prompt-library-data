# Capture a React Component as a Downloadable PNG with html2canvas

Get a React component with a screenshot button that uses html2canvas to capture its content and download a PNG file in a web app.

## Prompt

I'm building a web application that needs to have a feature to take a screenshot of a specific component. I want to create a 'Screenshot' button that, when clicked, takes a screenshot of a specific component and downloads it as a PNG file. I want to use the `html2canvas` library to achieve this. Provide a React component that has a 'Screenshot' button and uses `html2canvas` to take a screenshot of its content.
