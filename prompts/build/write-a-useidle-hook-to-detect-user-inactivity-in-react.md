# Write a useIdle Hook to Detect User Inactivity in React

Get a React useIdle hook that tracks activity with a configurable timeout and returns idle status, plus an example showing an idle modal.

## Prompt

I'm building a web application that needs to have a feature to detect when a user is idle. I want to create a 'useIdle' hook that takes a timeout as an argument and returns a boolean value indicating whether the user is currently idle. The hook should listen to user activity events, such as mouse move, key press, and scroll. Provide a complete implementation of the `useIdle` hook and an example of how to use it to show a modal when the user is idle.
