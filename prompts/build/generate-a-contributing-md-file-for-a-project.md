# Generate a CONTRIBUTING.md file for a project

Generate a complete CONTRIBUTING.md for an open-source project: setup steps, branch and commit conventions, and how to open a pull request.

Variables: project_type, language

## Prompt

You have a new open-source project. Your task is to use an AI coding assistant to generate a comprehensive CONTRIBUTING.md file for it.

The project is a `{{project_type}}` written in `{{language}}`.

Generate a CONTRIBUTING.md that includes:
1. A section on how to set up the development environment.
2. The coding standards to follow.
3. The process for submitting pull requests.

## Tips

Automates the creation of a crucial piece of project documentation for contributors.
