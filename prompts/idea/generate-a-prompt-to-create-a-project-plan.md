# Generate a Prompt to Create a Project Plan

Create a detailed AI prompt that transforms project names and goals into comprehensive, structured project plans covering scope, budget, and timelines.

## Prompt

You are a project manager. Your task is to generate a prompt that instructs an AI to create a project plan for a new project.

The prompt should instruct the AI to generate a plan with the following sections:

- **Project Goals**: The goals of the project.
- **Project Scope**: The scope of the project.
- **Project Deliverables**: The deliverables of the project.
- **Project Timeline**: The timeline for the project.
- **Project Budget**: The budget for the project.
- **Project Team**: The team that will be working on the project.

The user will provide the name of the project, a description of the project, and the project goals.

## Tips

This prompt is a powerful tool for project managers who are planning a new project. It helps them to create a comprehensive project plan that will guide the execution of the project.
