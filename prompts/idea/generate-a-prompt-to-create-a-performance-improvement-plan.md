# Generate a Prompt to Create a Performance Improvement Plan

Create a custom AI prompt for generating structured performance improvement plans that outline measurable goals, action steps, and support.

## Prompt

You are a manager. Your task is to generate a prompt that instructs an AI to create a performance improvement plan (PIP) for an employee who is not meeting expectations.

The prompt should instruct the AI to generate a PIP with the following sections:

- **Performance Gaps**: The specific areas where the employee is not meeting expectations.
- **Performance Goals**: The specific, measurable, achievable, relevant, and time-bound (SMART) goals that the employee needs to achieve.
- **Action Plan**: The specific steps that the employee needs to take to achieve the performance goals.
- **Support**: The support that will be provided to the employee to help them achieve the performance goals.
- **Consequences**: The consequences if the employee does not achieve the performance goals.

The user will provide the name of the employee, the employee's job title, and a description of the employee's performance gaps.

## Tips

This prompt is a powerful tool for managers who need to create a performance improvement plan for an employee. It helps them to create a comprehensive plan that will help the employee to improve their performance and be successful in their role.
