# Generate a Prompt to Create a Grant Proposal

Generate a highly structured AI prompt that produces comprehensive, professional grant proposals including executive summaries, budgets, and project needs.

## Prompt

You are a grant writer. Your task is to generate a prompt that instructs an AI to create a grant proposal for a non-profit organization.

The prompt should instruct the AI to generate a grant proposal with the following sections:

- **Executive Summary**: A brief overview of the grant proposal.
- **Statement of Need**: A statement of the need that the grant will address.
- **Project Description**: A description of the project that the grant will fund.
- **Budget**: A budget for the project.
- **Organization Information**: Information about the non-profit organization.

The user will provide the name of the non-profit organization, a description of the project, and the amount of funding requested.

## Tips

This prompt is a powerful tool for grant writers who need to create a grant proposal. It helps them to create a comprehensive and persuasive proposal that will increase their chances of getting funded.
