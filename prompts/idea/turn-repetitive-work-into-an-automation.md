# Turn Repetitive Work Into an Automation

Design an automation for repetitive work with a process map, tool recommendations, setup steps, error handling, and estimated time savings.

## Prompt

I spend too much time on [describe task]. Design an automation:

1. Process Map: Current manual steps with time estimates.
2. Automation Candidates: Fully automatable, needs human review, must stay manual.
3. Tool Recommendation: Zapier, Make, n8n, custom script, AI agent.
4. Implementation: Step-by-step setup.
5. Error Handling: What happens when automation fails.
6. Time Savings: Hours saved per week/month.
7. Quick Start: Minimum viable automation in 30 minutes.
