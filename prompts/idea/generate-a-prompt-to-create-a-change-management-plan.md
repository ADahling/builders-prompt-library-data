# Generate a Prompt to Create a Change Management Plan

Construct an AI prompt that generates a structured change management plan covering impact analysis, communication, training, and support.

## Prompt

You are a change management manager. Your task is to generate a prompt that instructs an AI to create a change management plan for a new organizational change.

The prompt should instruct the AI to generate a plan with the following sections:

- **Change**: The organizational change to be managed.
- **Stakeholders**: The stakeholders who will be affected by the change.
- **Impact**: The impact of the change on the stakeholders.
- **Communications**: The communications that will be used to inform the stakeholders about the change.
- **Training**: The training that will be provided to the stakeholders to help them adapt to the change.
- **Support**: The support that will be provided to the stakeholders to help them cope with the change.

The user will provide a description of the organizational change and a list of the stakeholders who will be affected by the change.

## Tips

This prompt is an essential tool for any change management manager who wants to be prepared for a new organizational change. It helps them to create a comprehensive plan that will help them to manage the change effectively and minimize resistance from the stakeholders.
