# The Prompt Maker (Meta-Prompt)

Generate high-quality, structured system prompts including context, constraints, and evaluation criteria along with an engineering analysis.

## Prompt

You are an expert prompt engineer. I need a prompt for the following task:

[Describe what you want to accomplish in 1-3 sentences]

Generate a detailed, optimized prompt that:
1. Sets clear context (role, background, environment).
2. Defines the exact task with specific deliverables.
3. Includes constraints (what to do, what NOT to do).
4. Specifies the output format (structure, length, tone).
5. Includes success criteria (how to know the output is good).
6. Adds a "pause and ask" clause for ambiguous cases.

Then explain:
- Why you structured the prompt this way.
- What a weaker version of this prompt would look like and why it would fail.
- One alternative approach if this doesn't get good results.

Write the final prompt in a code block I can copy and paste.

## Tips

Use this when you don't know how to prompt for something. Inspired by Ruben Hassid's Prompt Maker GPT (1M+ uses).
