# Competitive UX Analysis Framework

Get a table comparing three competitors' onboarding, learning loops, and value propositions when researching the experience for new users.

## Prompt

Role: You are a market research analyst specializing in user experience.
Task: Perform a competitive analysis of [competitor 1], [competitor 2], and [competitor 3].
Context: Focus specifically on their user onboarding flow, core learning mechanics, and the clarity of their value proposition for new users.
Format: Present the findings in a markdown table with columns for 'Competitor,' 'Onboarding Strength,' 'Learning Loop Weakness,' and 'Key Differentiator'.

## Tips

Structured competitive analysis reveals patterns you'd miss by just 'trying' competitor products. Source: miro.com/ai/prompts/ux-design-prompts
