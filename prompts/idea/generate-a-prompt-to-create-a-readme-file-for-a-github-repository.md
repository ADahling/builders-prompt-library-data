# Generate a Prompt to Create a README file for a GitHub Repository

Create a comprehensive, structured README file for open-source repositories including setup, usage, contribution, and licensing details.

Variables: project_name

## Prompt

You are a software developer who wants to create a high-quality README file for your new open-source project, `{{project_name}}`. Your task is to generate a prompt that instructs an AI to create a comprehensive README file that is easy to read and understand.

The prompt should instruct the AI to include the following sections in the README file:

- **Project Title and Description**: A clear and concise title and a short description of the project.
- **Installation**: Instructions on how to install and set up the project.
- **Usage**: Examples of how to use the project.
- **Contributing**: Guidelines for how other developers can contribute to the project.
- **License**: The license under which the project is released.

The user will provide the project name, a description of the project, and the license.

## Tips

This prompt helps developers create a high-quality README file, which is essential for any open-source project.
