# ELI5 — Test UX Simplicity

Review a feature for first-time users with a simple explanation, screen-by-screen flow, confusion fixes, and error recovery steps.

## Prompt

Explain this feature as if the user is a high-schooler who has never used a SaaS product:

Feature: [describe the feature]

1. What does this feature do in ONE sentence a 15-year-old would understand?
2. Walk through exactly what the user sees on screen at each step. Use simple language.
3. What's the most confusing part? How do we make it obvious?
4. What happens if they click the wrong thing? How do they recover?
5. Can you complete the core action in 3 clicks or fewer? If not, simplify.

If you can't explain it simply, the UX needs work. Rewrite the feature description and UI flow until a first-time user could figure it out without instructions.

## Tips

From Reddit r/lovable — if the AI can't explain it simply, users can't use it simply. Source: reddit.com/r/lovable/comments/1px6vpg
