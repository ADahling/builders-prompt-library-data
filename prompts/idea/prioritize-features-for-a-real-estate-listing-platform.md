# Prioritize Features for a Real Estate Listing Platform

Plan real estate platform feature priorities for buyers and agents using feedback, business needs, industry trends, and post-launch adoption.

Variables: home_buyers, real_estate_agents

## Prompt

Prioritize features for a real estate listing platform targeting {{home_buyers}} and {{real_estate_agents}}.

Context:
- Feature prioritization influences platform usability and market competitiveness.
- Balancing user needs and business goals is crucial for creating a valuable platform for buyers and agents.

Provide:
1. Simplified frameworks for prioritizing features based on user feedback and business requirements.
2. Criteria for evaluating feature importance in the context of real estate industry trends.
3. Strategies for incrementally enhancing platform features post-launch based on user adoption and feedback.

## Tips

Use this prompt to efficiently prioritize features and launch a user-centric real estate listing platform.
