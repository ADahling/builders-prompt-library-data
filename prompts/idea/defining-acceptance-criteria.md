# Defining Acceptance Criteria

Write measurable acceptance criteria for a user story, covering positive and negative scenarios, edge cases, and errors for QA.

Variables: user_story

## Prompt

Given the user story '{{user_story}}', define acceptance criteria to ensure the feature meets user expectations.

Context:
- Acceptance criteria should be specific and measurable
- Criteria should cover positive and negative scenarios

Provide:
1. List acceptance criteria for the user story
2. Include edge cases and error scenarios
3. Ensure criteria are easily testable by QA team

## Tips

Use this prompt to create clear guidelines for feature implementation and testing.
