# Generate a Prompt to Create a Customer Journey Map

Create a comprehensive UX prompt that generates detailed customer journey maps across five key stages to identify user pain points and growth opportunities.

## Prompt

You are a UX designer. Your task is to generate a prompt that instructs an AI to create a customer journey map for a new website.

The prompt should instruct the AI to generate a map with the following sections:

- **Phases**: The different phases of the customer journey (e.g., awareness, consideration, purchase, retention, advocacy).
- **Actions**: The actions that customers take in each phase.
- **Thoughts and Feelings**: The thoughts and feelings that customers have in each phase.
- **Pain Points**: The pain points that customers experience in each phase.
- **Opportunities**: The opportunities to improve the customer experience in each phase.

The user will provide the name of the website, a description of the website, and the target audience.

## Tips

This prompt is a powerful tool for UX designers who are working on a new website. It helps them to create a comprehensive customer journey map that will help them to improve the user experience.
