# Write a Grant Proposal for an Open-Source AI Project

Generate a professional, structured grant proposal in Markdown to secure funding for open-source AI software by showcasing impact and goals.

Variables: project_name, project_goal, project_achievements, grant_program_name, funding_amount

## Prompt

I am seeking funding to support the development of my open-source AI project, `{{project_name}}`. The project aims to `{{project_goal}}` and has already achieved `{{project_achievements}}` (e.g., 1000 GitHub stars, adoption by two major universities).

I am applying for a grant from `{{grant_program_name}}` (e.g., "Chan Zuckerberg Initiative's Essential Open Source Software for Science", "Mozilla Open Source Support").

Generate a comprehensive and persuasive grant proposal in Markdown format. The proposal should be tailored to the likely interests of a foundation supporting open-source software.

The proposal must include the following sections:

1.  **Project Title**: `{{project_name}}`
2.  **Principal Investigator(s)**: Your name and affiliation.
3.  **Abstract/Executive Summary**: A compelling, concise summary of the project, the problem it solves, its impact, and the amount of funding requested (`{{funding_amount}}`).

4.  **Introduction: The Problem and the Opportunity**:
    *   Describe the scientific or societal problem that `{{project_name}}` addresses.
    *   Explain why existing solutions are inadequate.
    *   Position your project as a critical piece of infrastructure for the open-source AI ecosystem.

5.  **Project Description and Current Status**:
    *   Describe the project's technology and architecture.
    *   Detail its current achievements, user base, and community engagement. Use metrics to demonstrate traction.
    *   Highlight any key integrations or adoptions by other projects or institutions.

6.  **Proposed Work and Objectives (for the grant period, e.g., 12 months)**:
    *   Clearly list 3-4 key objectives for the funding period.
    *   For each objective, describe the work to be done and the expected outcomes.
    *   Example Objective: "Objective 1: Improve Scalability and Performance. We will refactor the data processing pipeline to handle datasets 10x larger than currently possible."

7.  **Impact and Dissemination**:
    *   Describe the expected impact of the proposed work on the target community (e.g., researchers, developers).
    *   Explain your plan for disseminating the results and growing the user base (e.g., publications, conference presentations, tutorials).

8.  **Budget and Justification**:
    *   Provide a high-level breakdown of how the requested funding will be used. 
    *   Categories: Personnel (e.g., funding for a part-time developer), Infrastructure (e.g., server costs), and Community Engagement (e.g., travel to conferences).
    *   Justify each budget item.

9.  **Team**: Briefly introduce the core team members and highlight their relevant expertise.
