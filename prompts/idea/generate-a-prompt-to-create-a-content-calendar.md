# Generate a Prompt to Create a Content Calendar

Generate a developer prompt that directs an AI to build a detailed, multi-column blog content calendar based on specific goals and topics.

## Prompt

You are a content marketing manager. Your task is to generate a prompt that instructs an AI to create a content calendar for a blog.

The prompt should instruct the AI to generate a calendar with the following columns:

- **Date**: The date the blog post will be published.
- **Topic**: The topic of the blog post.
- **Keywords**: The target keywords for the blog post.
- **Author**: The author of the blog post.
- **Status**: The status of the blog post (e.g., idea, in progress, published).

The user will provide the name of the blog, the target audience, and a list of potential topics.

## Tips

This prompt is a great tool for content marketing managers who need to plan and organize their content. It helps them to create a comprehensive calendar that will keep their content on track.
