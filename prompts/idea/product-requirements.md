# Write clear product requirements

Write a feature PRD covering scope, user flows, edge cases, permissions, analytics, accessibility, and testable acceptance criteria.

## Prompt

Act as a senior product manager. Write a production-ready PRD for {{feature}}. Include user problem, scope, non-goals, primary flow, edge cases, states, permissions, data requirements, analytics events, accessibility requirements, and testable acceptance criteria.
