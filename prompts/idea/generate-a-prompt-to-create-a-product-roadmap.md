# Generate a Prompt to Create a Product Roadmap

Generate AI-driven product roadmaps featuring vision statements, SMART goals, initiatives, and feature timelines based on basic project data.

## Prompt

You are a product manager. Your task is to generate a prompt that instructs an AI to create a product roadmap for a new product.

The prompt should instruct the AI to generate a roadmap with the following sections:

- **Product Vision**: A brief statement of the product's long-term vision.
- **Product Goals**: A set of specific, measurable, achievable, relevant, and time-bound (SMART) goals for the product.
- **Product Initiatives**: A list of high-level initiatives that will be undertaken to achieve the product goals.
- **Product Features**: A list of specific features that will be developed for each initiative.
- **Timeline**: A timeline for the development and release of each feature.

The user will provide the name of the product, a description of the product, and the target audience.

## Tips

This prompt is a powerful tool for product managers who are planning a new product. It helps them to create a comprehensive roadmap that will guide the development of the product.
