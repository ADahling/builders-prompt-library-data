# Stakeholder Alignment Questions

Draft stakeholder interview questions for a project kickoff, grouped by business goals, technical constraints, and user and market context.

## Prompt

Role: You are a design lead preparing for a project kickoff.
Task: Create a list of key questions for the stakeholder interview.
Context: The project is a [project type, e.g., redesign of an e-commerce checkout process]. We need to define business goals, success metrics (e.g., conversion rate, cart abandonment), known technical constraints, and market positioning.
Format: Organize the questions into three sections: 'Business Goals,' 'Technical Constraints,' and 'User & Market'.

## Tips

Misaligned stakeholders are the #1 cause of project failure. Source: miro.com/ai/prompts/ux-design-prompts
