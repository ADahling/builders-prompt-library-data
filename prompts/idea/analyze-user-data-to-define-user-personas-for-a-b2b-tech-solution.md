# Analyze User Data to Define User Personas for a B2B Tech Solution

Get data analysis methods, persona templates, and feature prioritization guidance for a B2B solution serving enterprise clients.

Variables: enterprise_clients, industry_sector

## Prompt

Analyze user data to define detailed user personas for a B2B tech solution catering to {{enterprise_clients}} in the {{industry_sector}} sector.

Context:
- Understanding the unique needs and pain points of enterprise clients is essential for solution design.
- Data analysis allows for the creation of personas that align product features with specific business requirements.

Provide:
1. Methods for extracting meaningful insights from enterprise client data.
2. Templates for organizing persona attributes based on data analysis findings.
3. Recommendations on applying persona insights to feature prioritization and customization for targeted B2B clients.

## Tips

This prompt is valuable for ensuring the B2B tech solution resonates with the diverse needs of enterprise clients.
