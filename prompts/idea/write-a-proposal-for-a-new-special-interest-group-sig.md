# Write a Proposal for a New Special Interest Group (SIG)

Draft a Markdown proposal for an open-source project's steering committee to create a SIG, covering motivation, scope, goals, and leadership.

Variables: project_name, area_of_focus, sig_name, proposed_chair_1

## Prompt

Our open-source project, `{{project_name}}`, is growing, and I see a need for a dedicated group to focus on a specific area: `{{area_of_focus}}` (e.g., Documentation, Testing, AI Ethics).

I need to write a formal proposal to the project's Technical Steering Committee (TSC) to create a new Special Interest Group (SIG).

Generate a proposal document in Markdown format that makes a compelling case for the new SIG.

The proposal should follow this structure:

1.  **Proposal Title**: "Proposal to create SIG {{sig_name}}" (e.g., "SIG-Docs").

2.  **Abstract**: A brief, one-paragraph summary of the proposal.

3.  **Motivation**: 
    *   Explain why this new SIG is needed.
    *   What problems or gaps in the project will it address?
    *   What is the current state of `{{area_of_focus}}` in the project, and why is it insufficient?

4.  **Goals and Scope (Charter)**:
    *   **Mission Statement**: A clear, one-sentence mission for the SIG.
    *   **In Scope**: A bulleted list of the specific responsibilities and areas that the SIG will own.
        *   Example for SIG-Docs: "- Maintaining the official project documentation.", "- Managing the documentation website.", "- Creating tutorials and user guides."
    *   **Out of Scope**: A bulleted list of things the SIG will *not* be responsible for, to avoid overlap with other teams.

5.  **Initial Leadership and Membership**:
    *   Propose one or two initial chairs for the SIG (e.g., `{{proposed_chair_1}}\
    *   List a few community members who have already expressed interest in joining and contributing.

6.  **Communication and Operations**:
    *   Propose the primary communication channels for the SIG (e.g., a dedicated Slack/Discord channel, a mailing list).
    *   Suggest a meeting schedule (e.g., "Bi-weekly on Tuesdays").

7.  **Call to Action**: Formally request the TSC to approve the creation of the SIG and its charter.
