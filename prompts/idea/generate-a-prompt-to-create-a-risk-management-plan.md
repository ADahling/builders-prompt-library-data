# Generate a Prompt to Create a Risk Management Plan

Generate a detailed prompt that directs an AI to build structured risk management plans covering assessment, mitigation, and contingency.

## Prompt

You are a risk manager. Your task is to generate a prompt that instructs an AI to create a risk management plan for a new project.

The prompt should instruct the AI to generate a plan with the following sections:

- **Risks**: A list of potential risks that could affect the project.
- **Likelihood**: The likelihood of each risk occurring.
- **Impact**: The impact of each risk if it occurs.
- **Mitigation**: The steps that will be taken to mitigate each risk.
- **Contingency**: The steps that will be taken if each risk occurs.

The user will provide the name of the project, a description of the project, and a list of potential risks.

## Tips

This prompt is an essential tool for any project manager who wants to be prepared for potential risks. It helps them to create a comprehensive plan that will help them to manage risks effectively and protect their project from failure.
