# Prioritize Features for a Food Delivery Service App

Plan food delivery app feature priorities with frameworks for user needs, delivery efficiency, and partnerships, plus feedback and phased releases.

Variables: urban_dwellers

## Prompt

Define feature priorities for a food delivery service app catering to {{urban_dwellers}} looking for convenient and diverse culinary experiences.

Context:
- Feature prioritization influences app usability, customer satisfaction, and business revenue.
- Balancing core delivery features with innovative offerings enhances app competitiveness and user retention.

Provide:
1. Frameworks for prioritizing features based on user preferences, delivery efficiency, and restaurant partnerships.
2. Strategies for leveraging customer feedback to identify feature gaps and enhancement opportunities.
3. Roadmap planning for phased feature releases to enhance user experience and app performance over time.

## Tips

Use this prompt to create a roadmap that aligns feature development with the evolving preferences of urban food enthusiasts.
