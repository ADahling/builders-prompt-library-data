# Create a Data Governance Framework

Develop a comprehensive, strategic data governance framework to standardize data quality, security, and stewardship across a large enterprise.

Variables: enterprise_name

## Prompt

I am the Chief Data Officer (CDO) of a large enterprise, {{enterprise_name}}. We have vast amounts of data spread across dozens of different systems. The data is often inconsistent, inaccurate, and insecure. I need to establish a formal data governance framework to manage our data as a strategic asset.

Act as a data governance expert. Your task is to create a comprehensive data governance framework for my enterprise.

The framework should include:

1.  **Data Governance Council:**
    *   Define the structure and charter of a data governance council, which will be the central body responsible for data governance.
    *   Who should be on the council? (e.g., representatives from business, IT, legal, and compliance).

2.  **Data Stewardship:**
    *   Define the role of data stewards - individuals within the business units who are responsible for the quality and definition of specific data domains (e.g., customer data, product data).

3.  **Data Policies & Standards:**
    *   Develop a set of data policies and standards, including:
        *   **Data Quality Standards:** (e.g., accuracy, completeness, timeliness).
        *   **Data Definitions:** (e.g., a business glossary or data dictionary).
        *   **Data Security & Privacy Policies:** (in partnership with the CISO).

4.  **Data Catalog & Lineage:**
    *   What is a data catalog, and why is it important? What tools can we use to create one?
    *   How do we document data lineage to understand where our data comes from and how it flows through our systems?

5.  **Master Data Management (MDM):**
    *   Explain the concept of MDM. How can we create a single, authoritative source of truth for our key data domains (like "customer")?

6.  **Implementation Roadmap:**
    *   A phased roadmap for rolling out the data governance framework across the enterprise.

**Output Format:**

Please generate the data governance framework as a detailed and formal Markdown document. The document should be a complete guide to establishing data governance in a large enterprise.

**Constraints:**

*   The framework must be comprehensive and cover all key aspects of data governance.
*   The model must be practical and implementable in a complex, federated organization.
*   The tone should be authoritative, structured, and strategic.

## Tips

Data governance is a complex but essential discipline for any data-driven organization. This prompt provides a comprehensive framework for getting it right.
