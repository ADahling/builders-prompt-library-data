# Sprint Planning from Notes

Transform raw project notes into structured, sprint-ready user stories complete with specific titles and measurable acceptance criteria.

## Prompt

I'm preparing for sprint planning. Based on these priorities [paste notes], generate user stories with acceptance criteria. The stories should be specific, measurable, and achievable within a two-week sprint. For each story, provide a title, description, and a list of acceptance criteria.

## Tips

AI-generated user stories are a great starting point — but always refine with the team. Source: agilemania.com/how-to-create-user-stories-using-ai
