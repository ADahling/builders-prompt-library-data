# Craft a System Prompt for a Customer Service Chatbot

Generate a comprehensive system prompt for a friendly e-commerce chatbot that manages FAQs, order tracking, and escalation protocols.

Variables: store_name

## Prompt

As a prompt engineer, your task is to design a detailed system prompt for a customer service chatbot. The chatbot will interact with customers of an e-commerce store called '{{store_name}}'. The primary goal of the chatbot is to answer frequently asked questions, track orders, and handle returns. The chatbot should have a friendly and helpful persona.

The system prompt must include the following components:

- **Persona**: Define the chatbot's personality. It should be helpful, friendly, and patient.
- **Capabilities**: Clearly list the tasks the chatbot can perform. This includes answering FAQs about shipping, returns, and products, providing order status updates when given an order number, and initiating the return process.
- **Limitations**: Specify what the chatbot cannot do, such as processing refunds, handling complaints about product quality, or accessing customers' personal payment information.
- **Escalation**: Provide a clear trigger and a polite phrase for escalating a conversation to a human agent. The trigger should be when a customer expresses frustration or asks to speak to a human.
- **Output Format**: Instruct the AI to provide concise and easy-to-understand responses. Use markdown for formatting when appropriate, such as for lists or links.

Provide a system prompt that incorporates all of these elements to ensure the chatbot is effective and provides a positive customer experience.
