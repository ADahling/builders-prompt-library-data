# Analyze an Industry's Value Chain Using Porter's Value Chain Analysis

Conduct a comprehensive Porter’s Value Chain Analysis to identify competitive advantages and strategic drivers within a specific industry.

Variables: industry_name

## Prompt

I am a business analyst studying the {{industry_name}} industry. I need to understand how value is created in this industry and identify opportunities for competitive advantage. I want to use Porter's Value Chain Analysis framework for this purpose.

Act as a seasoned industry analyst. Your task is to analyze the value chain for the {{industry_name}} industry.

The analysis should be broken down into two parts: Primary Activities and Support Activities.

**1. Primary Activities:**
For each of the five primary activities, describe the key processes and how companies in this industry create value.

*   **Inbound Logistics:** (e.g., how raw materials are sourced, stored, and distributed)
*   **Operations:** (e.g., how products are manufactured or services are delivered)
*   **Outbound Logistics:** (e.g., how finished products are distributed to customers)
*   **Marketing & Sales:** (e.g., how companies reach, attract, and convert customers)
*   **Service:** (e.g., how companies provide after-sales support and service)

**2. Support Activities:**
For each of the four support activities, describe how they enable the primary activities.

*   **Firm Infrastructure:** (e.g., general management, finance, legal)
*   **Human Resource Management:** (e.g., recruiting, training, compensation)
*   **Technology Development:** (e.g., R&D, product design, process automation)
*   **Procurement:** (e.g., purchasing of raw materials, supplies, and assets)

**3. Strategic Implications:**
After analyzing the entire value chain, provide a summary of the key strategic implications. Where are the main opportunities to create a competitive advantage in this industry? Is it through cost leadership (i.e., being the most efficient) or differentiation (i.e., offering unique value)?

**Output Format:**

Please generate a detailed analysis in Markdown. Use headings and bullet points to structure the information clearly. The final output should be a comprehensive report that could be used for strategic decision-making.

**Constraints:**

*   The analysis must be specific to the {{industry_name}} industry.
*   The insights should be strategic and go beyond a simple description of the activities.
*   The tone should be analytical, expert, and structured.

## Tips

This prompt applies a classic strategic framework to analyze an entire industry, helping users understand the dynamics of competition.
