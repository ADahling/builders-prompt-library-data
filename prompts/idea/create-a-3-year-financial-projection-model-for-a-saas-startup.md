# Create a 3-Year Financial Projection Model for a SaaS Startup

Build a 36-month SaaS financial projection for an investor pitch, with editable assumptions, income and cash flow statements, and key metrics.

Variables: startup_name, product_description, launch_date, pricing_tiers, team_size

## Prompt

As the founder of a pre-seed SaaS startup, {{startup_name}}, I need to create a detailed 3-year financial projection model to include in my investor pitch deck. Our product is a {{product_description}} with a target launch date of {{launch_date}}. We plan to have a tiered subscription model with the following prices: {{pricing_tiers}}.

Act as an experienced CFO or financial analyst. Your task is to build a comprehensive, month-by-month financial projection model for the next 36 months. The model should be built in a way that I can easily modify the key assumptions.

The model should include the following sections:

1.  **Assumptions Sheet:** A dedicated section where I can input all the key drivers for the model, including:
    *   **Customer Acquisition:** Monthly new customers, churn rate.
    *   **Revenue:** Average revenue per customer (ARPC), pricing tiers distribution.
    *   **Cost of Goods Sold (COGS):** Hosting costs, third-party API fees, customer support costs.
    *   **Operating Expenses (OpEx):** Salaries (for a team of {{team_size}}), marketing & sales budget, rent, and other overheads.
2.  **Income Statement (P&L):** A monthly and annual view of our revenues, COGS, gross margin, operating expenses, and net income/loss.
3.  **Cash Flow Statement:** A monthly and annual view of our cash from operations, investing, and financing activities.
4.  **Key Metrics Dashboard:** A summary dashboard that visualizes the most important SaaS metrics, such as:
    *   Monthly Recurring Revenue (MRR)
    *   Annual Recurring Revenue (ARR)
    *   Customer Lifetime Value (LTV)
    *   Customer Acquisition Cost (CAC)
    *   LTV:CAC Ratio
    *   Churn Rate

**Output Format:**

Please generate the financial model as a well-structured spreadsheet (you can represent this in a detailed Markdown table format, clearly explaining the formulas). The output should be easy to understand and modify. Provide clear explanations for all the formulas used in the model.

**Constraints:**

*   The model must be based on standard accounting principles.
*   The formulas should be clearly explained so I can understand the logic.
*   The final output should be a professional-grade financial model that is ready for investor scrutiny.

## Tips

This is a complex prompt that requires the AI to generate a full-fledged financial model. It's for founders who need a sophisticated financial plan.
