# Generate a Prompt to Create a Press Release

Generate a comprehensive AI prompt that structures a professional product launch press release with all essential journalistic sections.

## Prompt

You are a public relations manager. Your task is to generate a prompt that instructs an AI to create a press release about a new product launch.

The prompt should instruct the AI to generate a press release with the following sections:

- **For Immediate Release**: A statement that the press release is for immediate release.
- **Headline**: A catchy headline for the press release.
- **Dateline**: The date and location of the press release.
- **Introduction**: An introduction to the new product.
- **Body**: The body of the press release, which should include more details about the new product.
- **Boilerplate**: A brief description of your company.
- **Contact Information**: The contact information for your company.

The user will provide the name of the new product, a description of the new product, and the contact information for your company.

## Tips

This prompt is a powerful tool for public relations managers who need to create a press release. It helps them to create a comprehensive and persuasive press release that will generate media coverage and build buzz for their new product.
