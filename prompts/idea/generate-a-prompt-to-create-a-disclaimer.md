# Generate a Prompt to Create a Disclaimer

Generate a comprehensive meta-prompt that instructs an AI to draft professional, multi-sector legal disclaimers for any website or mobile app.

## Prompt

You are a lawyer. Your task is to generate a prompt that instructs an AI to create a disclaimer for a website or mobile app.

The prompt should instruct the AI to generate a disclaimer with the following sections:

- **No Legal Advice**: A disclaimer that the website or mobile app does not provide legal advice.
- **No Medical Advice**: A disclaimer that the website or mobile app does not provide medical advice.
- **No Financial Advice**: A disclaimer that the website or mobile app does not provide financial advice.
- **No Professional Advice**: A disclaimer that the website or mobile app does not provide professional advice.

The user will provide the name of the website or mobile app and a description of the website or mobile app.

## Tips

This prompt is a powerful tool for lawyers who need to create a disclaimer. It helps them to create a comprehensive and legally binding disclaimer that will protect the interests of their clients.
