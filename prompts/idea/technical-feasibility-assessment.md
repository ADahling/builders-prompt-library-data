# Technical Feasibility Assessment

Assess a PRD for technical feasibility: complexity and effort per feature, a recommended stack, and the risks that could sink it.

## Prompt

Here is my PRD: [paste PRD summary]. Assess the technical feasibility:

1. Complexity rating (Low / Medium / High) and estimated dev time per feature.
2. Recommended tech stack and why (frontend, backend, database, auth, payments, hosting).
3. Third-party services or APIs required.
4. Technical risks or dependencies that could block progress.
5. Recommended build order based on dependencies and complexity.

Assume I am building with [Lovable / React / Supabase / specify]. Be practical and specific.

## Tips

Use before building to avoid surprises.
