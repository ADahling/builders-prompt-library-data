# Generate a Prompt to Create a Privacy Policy

Create a customized AI prompt for generating legally structured privacy policies tailored to specific website or mobile app requirements.

## Prompt

You are a lawyer. Your task is to generate a prompt that instructs an AI to create a privacy policy for a website or mobile app.

The prompt should instruct the AI to generate a privacy policy with the following sections:

- **Introduction**: An introduction to the privacy policy.
- **Information We Collect**: The types of information that the website or mobile app collects from users.
- **How We Use Your Information**: How the website or mobile app uses the information it collects from users.
- **How We Share Your Information**: How the website or mobile app shares the information it collects from users.
- **Your Choices**: The choices that users have about their information.
- **Security**: The security measures that the website or mobile app takes to protect user information.
- **Changes to This Privacy Policy**: How the website or mobile app will notify users of changes to the privacy policy.

The user will provide the name of the website or mobile app and a description of the website or mobile app.

## Tips

This prompt is a powerful tool for lawyers who need to create a privacy policy. It helps them to create a comprehensive and legally compliant privacy policy that will protect the interests of their clients.
