# Refactor a Prompt for Better Clarity and Performance

Optimize and rewrite existing AI prompts to enhance clarity, conciseness, and output quality while maintaining the original intent.

Variables: original_prompt

## Prompt

You are a prompt engineering expert. Your task is to refactor the following prompt to improve its clarity, conciseness, and performance. The original prompt is provided below:

---

**Original Prompt:**

`{{original_prompt}}`

---

Your refactored prompt should:

1.  **Be More Specific**: Reduce ambiguity and provide clearer instructions.
2.  **Be More Concise**: Remove any unnecessary words or phrases.
3.  **Improve Performance**: Optimize the prompt to produce better and faster results from the AI model.
4.  **Maintain the Original Goal**: The refactored prompt should still achieve the same goal as the original prompt.

Please provide the refactored prompt and a brief explanation of the changes you made and why.

## Tips

This prompt is a valuable tool for improving the quality of your prompts. It uses a meta-prompting approach to leverage the AI's own knowledge of prompt engineering.
