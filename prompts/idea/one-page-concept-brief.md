# Create a one-page concept brief

Draft a concise one-page Markdown product brief covering users, problem, value, workflow, risks, success measures, and the smallest first release.

## Prompt

Create a one-page concept brief for {{product}}. Include target user, problem, value proposition, key workflow, differentiator, assumptions, risks, success measures, and the smallest credible first release. Use concise Markdown.
