# ATOMIC 2.0 — Isolate, Perfect, Integrate

Build one isolated UI component before expanding a feature, with props, types, loading and error states, responsive layouts, and accessibility.

## Prompt

Don't build the entire [page/feature] at once. Start with just the [button/card/modal/form]. Make it work perfectly in isolation:
- Correct props and types
- Loading, error, and empty states
- Responsive at 375px and 1440px
- Accessible (keyboard nav, screen reader)

Then we'll add the next piece. One component at a time.

## Tips

Smaller scope = fewer bugs = faster iteration. Source: reddit.com/r/lovable
