# Generate a Prompt to Create a Communications Plan

Generate a meta-prompt that instructs an AI to build a structured communications plan for a product launch based on specific user inputs.

## Prompt

You are a communications manager. Your task is to generate a prompt that instructs an AI to create a communications plan for a new product launch.

The prompt should instruct the AI to generate a plan with the following sections:

- **Target Audience**: The target audience for the communications plan.
- **Key Messages**: The key messages to be communicated in the communications plan.
- **Communications Channels**: The communications channels to be used in the communications plan.
- **Communications Materials**: The communications materials to be created for the communications plan.
- **Timeline**: The timeline for the communications plan.

The user will provide the name of the product, a description of the product, and the target audience.

## Tips

This prompt is a powerful tool for communications managers who are planning a new product launch. It helps them to create a comprehensive communications plan that will increase their chances of success.
