# Create a Go-to-Market Strategy for a New API Product

Generate a comprehensive, developer-centric go-to-market strategy covering positioning, phased launch tactics, and onboarding metrics.

Variables: api_name, api_functionality, launch_quarter

## Prompt

I am the Head of Product for a new API product, {{api_name}}, that provides {{api_functionality}}. Our target audience is developers and tech companies. We are planning to launch in {{launch_quarter}}.

I need you to act as a marketing and product strategist and create a detailed Go-to-Market (GTM) strategy for our API launch. The GTM strategy should be a comprehensive plan that covers all aspects of the launch.

The GTM plan should include the following sections:

1.  **Target Audience & Personas:** Define our ideal developer personas. What are their roles, goals, and pain points? Where do they hang out online?
2.  **Positioning & Messaging:** Craft a clear and compelling value proposition for our API. What is the key message we want to communicate to developers?
3.  **Launch Phases & Timeline:** Outline a phased launch plan (e.g., pre-launch, launch day, post-launch). What are the key activities and milestones for each phase?
4.  **Marketing & Promotion Channels:** Recommend a mix of marketing channels to reach our target audience. This should include:
    *   **Content Marketing:** (e.g., blog posts, tutorials, documentation)
    *   **Community Engagement:** (e.g., Hacker News, Reddit, Stack Overflow)
    *   **Developer Relations (DevRel):** (e.g., webinars, conference talks, partnerships)
    *   **Paid Advertising:** (e.g., targeted ads on developer platforms)
5.  **Sales & Onboarding:** Describe the process for developers to sign up, get an API key, and start using our product. How can we make the onboarding process as smooth as possible?
6.  **Success Metrics & KPIs:** Define the key metrics we will use to measure the success of our launch (e.g., API sign-ups, active users, API calls).

**Output Format:**

Please generate the GTM strategy as a well-structured Markdown document. Use headings, bullet points, and tables to present the information clearly.

**Constraints:**

*   The strategy must be tailored to an API product and a developer audience.
*   The recommended activities should be practical for a startup with a lean team.
*   The tone should be strategic, actionable, and data-driven.

## Tips

This prompt is for experienced product leaders who need a comprehensive GTM plan for a technical product.
