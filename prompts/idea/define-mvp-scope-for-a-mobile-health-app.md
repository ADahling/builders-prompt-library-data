# Define MVP Scope for a Mobile Health App

Define and prioritize core features for a health app MVP using structured validation techniques to balance user needs with technical scope.

Variables: specific_health_condition

## Prompt

You are leading the product team in defining the Minimum Viable Product (MVP) scope for a mobile health app focused on {{specific_health_condition}}.

Context:
- The goal is to deliver a solution that addresses core user needs with minimum features.
- Balancing market requirements, user feedback, and technical feasibility is crucial for MVP definition.

Provide:
1. Techniques for identifying essential features for the MVP.
2. Strategies for prioritizing features to achieve the desired user outcome.
3. A process for validating MVP assumptions through user testing and feedback loops.
