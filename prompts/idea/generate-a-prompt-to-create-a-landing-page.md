# Generate a Prompt to Create a Landing Page

Generate a structured marketing prompt that directs an AI to draft a complete, high-converting landing page for any specific product.

## Prompt

You are a marketing manager. Your task is to generate a prompt that instructs an AI to create a landing page for a specific product.

The prompt should instruct the AI to generate a landing page with the following sections:

- **Headline**: A catchy headline for the landing page.
- **Body**: The body of the landing page, which should describe the product and its benefits.
- **Call to Action**: A call to action for the reader.
- **Testimonials**: Testimonials from satisfied customers.
- **FAQ**: A list of frequently asked questions about the product.

The user will provide the name of the product, a description of the product, and the target audience for the landing page.

## Tips

This prompt is a powerful tool for marketing managers who need to create a landing page. It helps them to create a comprehensive and persuasive landing page that will generate leads and sales.
