# Create a Technology Stack for a New Web Application

Generate a comprehensive, justified technology stack report for a new web application covering frontend, backend, database, and infrastructure.

Variables: app_description

## Prompt

I am the technical co-founder of a new startup. We are building a {{app_description}}. I need to choose the right technology stack for our web application. I want a stack that is modern, scalable, and allows us to build and iterate quickly.

Act as a seasoned CTO and solutions architect. Your task is to recommend a complete technology stack for our web application.

Your recommendation should cover:

1.  **Frontend:**
    *   What JavaScript framework should we use? (e.g., React, Vue, Svelte). What are the pros and cons of your recommendation?
    *   What about a meta-framework like Next.js or Nuxt.js?
    *   What CSS framework or library should we use? (e.g., Tailwind CSS, Bootstrap).

2.  **Backend:**
    *   What programming language and framework should we use? (e.g., Node.js with Express, Python with Django/Flask, Ruby on Rails).
    *   Should we build a monolithic backend or a microservices architecture?

3.  **Database:**
    *   Should we use a SQL database (like PostgreSQL) or a NoSQL database (like MongoDB)? What are the trade-offs?

4.  **Infrastructure & Deployment:**
    *   Where should we host our application? (e.g., AWS, Google Cloud, Vercel, Heroku).
    *   Should we use containers (like Docker and Kubernetes)?
    *   What CI/CD pipeline setup would you recommend?

5.  **Justification:**
    *   For each recommendation, provide a clear justification. Why is this the right choice for our specific application and team?

**Output Format:**

Please generate the technology stack recommendation as a detailed report in Markdown. The report should be a well-reasoned and comprehensive guide that I can use to make these critical technology decisions.

**Constraints:**

*   The recommended stack should be a cohesive whole, not just a list of popular technologies.
*   The recommendations must be justified based on the needs of the application and the team.
*   The tone should be that of a trusted technical advisor.

## Tips

Choosing the right tech stack is a critical decision for any new project. This prompt provides a structured way to think through the options and make an informed choice.
