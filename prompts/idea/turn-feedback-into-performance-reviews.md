# Turn Feedback Into Performance Reviews

Turn raw feedback into a structured performance review with themes, examples, ratings, measurable quarterly goals, and development resources.

## Prompt

I have raw feedback from multiple sources about [team member / department / product]. Organize into a structured performance review:

1. Summarize feedback into themes (strengths, improvement areas, opportunities).
2. For each theme, pull 2-3 specific examples or quotes.
3. Rate each: Exceeds / Meets / Needs Improvement.
4. Write 3 measurable goals for next quarter based on improvement areas.
5. Draft a professional narrative summary (3-4 paragraphs).
6. Suggest 2-3 development resources for each improvement area.

Tone: constructive and growth-oriented. Be specific, not vague.
