# Construct a Meta-Prompt for Generating SQL Queries

Create a structured template that guides an AI to generate precise, complex SQL queries based on schema definitions and business goals.

## Prompt

You are a database administrator. Your task is to construct a meta-prompt that can be used to generate complex SQL queries. The meta-prompt should be a template that a user can fill in with their specific requirements.

The meta-prompt should include the following sections:

- **Database Schema**: A description of the database schema, including the tables, columns, and relationships. The user will provide this information.
- **Query Goal**: A clear statement of what the user wants to achieve with the query. The user will provide this information.
- **Constraints**: Any constraints on the query, such as performance requirements or limitations on the use of certain SQL features. The user will provide this information.
- **Output Format**: The desired format of the output, such as a list of rows or a single value. The user will provide this information.

The meta-prompt should then instruct the AI to generate a SQL query that meets all of the user's requirements.

## Tips

This meta-prompt is a powerful tool for generating complex SQL queries. It allows users to specify their requirements in a structured way, which helps the AI to generate accurate and efficient queries.
