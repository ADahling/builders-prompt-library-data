# Choose an Open Source License for a New Project

Select the ideal copyleft license for a library to ensure code modifications remain open while supporting commercial integration.

## Prompt

You are a software architect. Your task is to choose an appropriate open source license for a new software project.

Context:
- The project is a library that you want other developers to use in their own projects, both open source and commercial.
- You want to ensure that any modifications to your library are also open sourced.

Provide:
1. A comparison of different types of open source licenses (e.g., permissive vs. copyleft).
2. A recommendation for a specific license (e.g., GPL, LGPL, MPL) and a justification for your choice.
3. An explanation of how to apply the license to your project.

## Tips

A critical decision for any open source project.
