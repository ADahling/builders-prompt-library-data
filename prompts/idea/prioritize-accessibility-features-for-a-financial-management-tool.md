# Prioritize Accessibility Features for a Financial Management Tool

Plan accessibility priorities for a financial management tool with user needs assessment, impact-effort frameworks, and validation strategies.

Variables: specific_disabilities

## Prompt

Given the importance of accessibility, prioritize features for enhancing the accessibility of a financial management tool for users with {{specific_disabilities}}.

Context:
- Accessibility features broaden product reach and comply with legal requirements.
- Prioritizing features that cater to diverse user needs demonstrates commitment to inclusive design.

Provide:
1. Guidelines for assessing the accessibility needs of users with specific disabilities.
2. Frameworks to prioritize accessibility features based on impact and implementation effort.
3. Strategies for testing and validating the effectiveness of implemented accessibility features.

## Tips

Use this prompt to embed accessibility considerations into feature prioritization processes.
