# Refine MVP Features for an E-Learning Platform

Plan e-learning MVP refinements with interactive learning methods, student feedback strategies, and a roadmap for phased releases and user testing.

Variables: student_demographic, academic_subjects

## Prompt

Refine the features of the Minimum Viable Product (MVP) for an e-learning platform targeting {{student_demographic}} studying {{academic_subjects}}.

Context:
- The MVP aims to provide essential learning resources and interactive features for student engagement.
- Iteratively refining MVP features ensures educational content alignment with student needs and curriculum requirements.

Provide:
1. Methods for incorporating interactive learning elements into the MVP design.
2. Strategies for gathering student feedback to enhance content relevance and usability.
3. A roadmap for phased MVP feature releases and user testing to validate learning outcomes.

## Tips

This prompt is suitable for teams developing an e-learning platform focused on student success and engagement.
