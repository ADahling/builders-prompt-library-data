# Generate a Prompt to Create a Competitive Analysis Report

Generate detailed competitive analysis reports identifying market rivals, their strategic positioning, and potential growth opportunities for new products.

## Prompt

You are a market research analyst. Your task is to generate a prompt that instructs an AI to create a competitive analysis report for a new product.

The prompt should instruct the AI to generate a report with the following sections:

- **Competitors**: A list of the top competitors for the product.
- **Strengths**: The strengths of each competitor.
- **Weaknesses**: The weaknesses of each competitor.
- **Opportunities**: The opportunities to compete against each competitor.
- **Threats**: The threats that each competitor poses to the product.

The user will provide the name of the product, a description of the product, and the target market.

## Tips

This prompt is a powerful tool for market research analysts who are working on a new product. It helps them to create a comprehensive competitive analysis report that will help them to make better strategic decisions.
