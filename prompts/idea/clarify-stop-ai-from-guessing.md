# CLARIFY — Stop AI from Guessing

Get three questions about a feature's data structure, user flow, and edge cases, with code deferred until all three are answered.

## Prompt

Ask me 3 clarifying questions about [feature] before you write any code. Focus on:
1. Data structure — What fields, types, and relationships are needed?
2. User flow — What does the user see, click, and experience step by step?
3. Edge cases — What happens with empty data, errors, or unexpected input?

Do not write ANY code until I answer all three questions.

## Tips

The single most effective prompt for reducing AI-generated rework. Source: reddit.com/r/lovable
