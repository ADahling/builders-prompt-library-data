# COMPARE — The Clarity Test

Get two coded implementations with Tailwind rationale, bundle estimates, accessibility and performance comparisons, plus advice for your app.

## Prompt

Generate TWO versions of this [component / feature / implementation]:

Version A: [Approach 1 — e.g., simpler, fewer dependencies]
Version B: [Approach 2 — e.g., more feature-rich, uses a library]

For each version, show:
1. Complete code.
2. Tailwind classes used and why.
3. Bundle size impact (estimate).
4. Accessibility score (does it use semantic HTML, ARIA, keyboard nav?).
5. Performance implications.
6. Trade-offs: what you gain, what you lose.

Then recommend which one to use for my specific situation: [describe your app, user count, team size, timeline].

## Tips

From Reddit r/lovable — forces the AI to think in trade-offs instead of defaulting to one approach. Source: reddit.com/r/lovable/comments/1px6vpg
