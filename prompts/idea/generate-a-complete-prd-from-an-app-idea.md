# Generate a Complete PRD from an App Idea

Turn an app idea into a structured PRD with personas, MVP user stories, future features, metrics, constraints, competitors, and risks.

## Prompt

I want to build [describe your app idea in 2-3 sentences]. Generate a complete Product Requirements Document (PRD) that includes:

1. Executive Summary: What the product is, who it serves, and the core problem it solves.
2. Target Users: 2-3 user personas with their goals, pain points, and technical comfort level.
3. Core Features (MVP): A numbered list of the minimum features needed to launch. For each feature, include a one-line description and the user story in the format "As a [user], I want to [action] so that [benefit]."
4. Nice-to-Have Features (Post-MVP): Features to add after launch, prioritized.
5. Success Metrics: 3-5 measurable KPIs that define whether this product is working.
6. Constraints and Assumptions: Technical constraints, budget limits, timeline, and any assumptions.
7. Competitive Landscape: 2-3 existing solutions and how this product differentiates.
8. Risk Assessment: Top 3 risks and mitigation strategies.

Format as a professional document with clear headings. Be specific and actionable.
