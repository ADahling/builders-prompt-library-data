# Understand Real Drivers Before Reacting

Review a changed metric with possible causes, evidence, external context, response options, and a recommendation on when to act.

## Prompt

Something changed: [describe metric/result]. Before reacting:

1. Signal vs Noise: Real trend or one-time? What data confirms?
2. Root Cause: 3-5 possible causes with supporting/contradicting evidence.
3. Leading Indicators: What should I have been watching?
4. Context: External factors (market, seasonal, competitive)?
5. Second-Order Effects: If this continues, what else is affected?
6. Response Options: 3 options from "monitor" to "immediate action" with pros/cons.
7. Recommendation: Based on analysis, what to do and when to reassess.

Think clearly, not react emotionally.
