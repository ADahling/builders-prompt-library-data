# Crafting User Stories

Generate structured user stories with clear acceptance criteria and business justifications to bridge the gap between user needs and code.

Variables: user_role, feature_description, reason_for_feature

## Prompt

As a {{user_role}}, I want {{feature_description}} so that {{reason_for_feature}}.

Context:
- Define the user persona clearly
- Ensure the user story is concise and focused

Provide:
1. Write a user story following the 'As a, I want, so that' format
2. Include acceptance criteria for the user story
3. Validate the user story with the product owner for clarity

## Tips

Use this prompt to ensure user stories are well-defined and align with user needs.
