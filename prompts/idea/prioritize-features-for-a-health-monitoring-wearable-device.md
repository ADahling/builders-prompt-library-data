# Prioritize Features for a Health Monitoring Wearable Device

Get feature prioritization methods for a health wearable aimed at active users, with evaluation criteria and ways to balance core and extra features.

Variables: active_lifestyle

## Prompt

Prioritize features for a health monitoring wearable device based on the needs of {{active_lifestyle}} individuals.

Context:
- Feature prioritization influences the device's usability and value proposition.
- Meeting the specific needs of active individuals is critical for product success in the health tech market.

Provide:
1. Methodologies for categorizing and prioritizing features based on user personas and market trends.
2. Criteria for evaluating feature importance in the context of health monitoring and fitness tracking.
3. Strategies for balancing core health monitoring features with complementary functionalities for an exceptional user experience.

## Tips

This prompt is suited for teams aiming to develop a highly functional and user-centric health wearable device.
