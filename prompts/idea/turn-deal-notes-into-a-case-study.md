# Turn Deal Notes Into a Case Study

Turn scattered deal notes into a one-page, PDF-ready case study with the client challenge, solution, quantified results, timeline, and takeaway.

## Prompt

Scattered notes from recent deal: [paste]. Turn into polished case study:

1. Challenge: Client problem as compelling narrative.
2. Solution: What we did. Specific approach, not generic.
3. Results: Quantified impact with actual numbers.
4. Timeline: Start to results.
5. Client Quote: Realistic testimonial they'd approve.
6. Key Takeaway: One thing a prospect should remember.
7. Format: One-page PDF-ready with sections.

Professional but human. No jargon.
