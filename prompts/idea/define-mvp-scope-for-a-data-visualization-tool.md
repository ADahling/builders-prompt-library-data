# Define MVP Scope for a Data Visualization Tool

Plan a business intelligence visualization MVP with feature selection techniques, chart priorities, and a testing and feedback plan.

Variables: data_analysis

## Prompt

Define the Minimum Viable Product (MVP) scope for a data visualization tool focusing on {{data_analysis}} for business intelligence purposes.

Context:
- The MVP needs to encompass essential functionalities for effective data interpretation.
- Iterative MVP definition and validation are key to delivering a valuable tool to users.

Provide:
1. Techniques for identifying critical data visualization features for the MVP.
2. Strategies for prioritizing visualization types based on user scenarios and data complexity.
3. A plan for MVP testing and feedback incorporation to refine the tool's visualization capabilities.

## Tips

Utilize this prompt to streamline MVP development for data-driven decision-making tools.
