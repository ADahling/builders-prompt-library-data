# Create a Sales Forecast for a B2B SaaS Business

Generate a bottoms-up B2B SaaS sales forecast by modeling AE capacity, ramp schedules, and pipeline requirements to project quarterly bookings.

## Prompt

I am the VP of Sales at a B2B SaaS company. I need to create a sales forecast for the next four quarters. The forecast needs to be realistic and based on a clear set of assumptions.

Act as a sales operations expert. Your task is to help me create a bottoms-up sales forecast.

The process should be:

1.  **Define the Key Inputs:**
    *   **Number of AEs:** How many quota-carrying Account Executives will we have in each quarter?
    *   **AE Quota:** What is the annual quota for a fully ramped AE?
    *   **AE Ramp Time:** How many months does it take for a new AE to become fully productive?
    *   **Sales Cycle:** How long is our average sales cycle?
    *   **Win Rate:** What is our average win rate from qualified opportunities?

2.  **The Forecasting Model:**
    *   Create a spreadsheet model (you can represent this in a Markdown table) that uses these inputs to build a quarterly forecast of new bookings.
    *   The model should account for the ramp time of new AEs.

3.  **The Pipeline Coverage Model:**
    *   How much sales pipeline do we need to generate to hit our forecast? 
    *   Calculate the required pipeline coverage ratio (e.g., if our win rate is 25%, we need a 4x pipeline coverage).

4.  **Sensitivity Analysis:**
    *   How can we run a sensitivity analysis to see how the forecast changes if we change our key assumptions (e.g., what if our win rate improves by 10%?).

**Output Format:**

Please generate the sales forecasting model and process as a detailed guide in Markdown. The guide should include the templates for the forecasting model and a clear explanation of the methodology.

**Constraints:**

*   The forecast must be bottoms-up and based on the capacity of the sales team.
*   The model must be transparent and easy to understand.
*   The tone should be analytical, data-driven, and pragmatic.

## Tips

A bottoms-up sales forecast is a critical tool for any sales leader. This prompt provides a guide to building a robust forecasting model.
