# Define the user problem

Turn research notes into a user problem statement with facts, assumptions, context, friction, workarounds, and a measurable outcome.

## Prompt

Act as a product discovery lead. Convert the following notes into a precise user problem: {{research_notes}}. Separate observed facts from assumptions. Define the user, context, desired progress, friction, current workaround, and measurable outcome.
