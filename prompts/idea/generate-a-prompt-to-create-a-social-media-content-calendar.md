# Generate a Prompt to Create a Social Media Content Calendar

Generate a structured prompt that produces a multi-column content calendar including copy, post types, visuals, and hashtags for social media.

## Prompt

You are a social media manager. Your task is to generate a prompt that instructs an AI to create a social media content calendar for a company.

The prompt should instruct the AI to generate a calendar with the following columns:

- **Date**: The date the post will be published.
- **Platform**: The social media platform the post will be published on (e.g., Twitter, Facebook, Instagram).
- **Post Type**: The type of post (e.g., text, image, video, link).
- **Copy**: The copy for the post.
- **Image/Video**: A description of the image or video to be included with the post.
- **Hashtags**: A list of relevant hashtags to be included with the post.

The user will provide the name of the company, the target audience, and a list of potential topics.

## Tips

This prompt is a great tool for social media managers who need to plan and organize their content. It helps them to create a comprehensive calendar that will keep their content on track.
