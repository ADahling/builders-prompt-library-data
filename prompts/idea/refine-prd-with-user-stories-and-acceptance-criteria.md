# Refine PRD with User Stories and Acceptance Criteria

Turn PRD features into a table of detailed user stories, testable acceptance criteria, edge cases, and launch priorities.

## Prompt

Here is my PRD: [paste your PRD or summarize key features]. For each feature listed, generate:

1. A detailed user story: As a [role], I want to [capability] so that [benefit].
2. Acceptance criteria: 3-5 specific, testable conditions that must be true for this feature to be complete.
3. Edge cases: 2-3 edge cases or error scenarios that need handling.
4. Priority: P0 (must have for launch), P1 (important, can follow), P2 (nice to have).

Organize as a table: Feature | User Story | Acceptance Criteria | Edge Cases | Priority.

## Tips

Run after generating your PRD to make features build-ready.
