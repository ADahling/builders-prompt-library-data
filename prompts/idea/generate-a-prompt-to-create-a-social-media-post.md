# Generate a Prompt to Create a Social Media Post

Generate a meta-prompt that instructs an AI to draft platform-specific social media content including copy, visuals, and hashtags.

## Prompt

You are a social media manager. Your task is to generate a prompt that instructs an AI to create a social media post for a specific platform.

The prompt should instruct the AI to generate a social media post with the following components:

- **Platform**: The social media platform the post will be published on (e.g., Twitter, Facebook, Instagram).
- **Post Type**: The type of post (e.g., text, image, video, link).
- **Copy**: The copy for the post.
- **Image/Video**: A description of the image or video to be included with the post.
- **Hashtags**: A list of relevant hashtags to be included with the post.

The user will provide the topic of the post and the social media platform the post will be published on.

## Tips

This prompt is a great tool for social media managers who need to create a social media post. It helps them to create a comprehensive and engaging post that will attract followers and generate engagement.
