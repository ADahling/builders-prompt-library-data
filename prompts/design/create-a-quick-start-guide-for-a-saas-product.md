# Create a Quick Start Guide for a SaaS Product

Generate a concise, Markdown-formatted quick start guide including account setup, workflows, and key features to accelerate user onboarding.

Variables: product_name, core_workflow, key_feature

## Prompt

You are a product marketer for a new SaaS product, {{product_name}}. You need to create a quick start guide to help new users get up and running with the product as quickly as possible.

Your task is to generate a concise and easy-to-follow quick start guide that covers the essential steps to get started. The guide should be no more than two pages long and should include:

*   **Account Creation:** Instructions on how to sign up for an account.
*   **Core Workflow:** A step-by-step walkthrough of the product's core workflow.
*   **Key Features:** A brief overview of the key features that new users should know about.
*   **Next Steps:** Suggestions for what users can do next to get the most out of the product.

Here is some information about your product:

*   **Product Name:** {{product_name}}
*   **Core Workflow:** {{core_workflow}}
*   **Key Feature:** {{key_feature}}

Generate the complete quick start guide in Markdown format. The guide should be visually appealing and use plenty of screenshots and diagrams.
