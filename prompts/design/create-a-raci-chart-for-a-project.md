# Create a RACI Chart for a Project

Generate a structured Markdown RACI chart to define clear roles and responsibilities for specific project tasks and team members.

Variables: task_1, task_2, task_3, team_member_1, team_member_2, team_member_3

## Prompt

You are a project manager for a new project. You need to create a RACI chart to clarify the roles and responsibilities of each team member.

Your task is to generate a RACI chart in a Markdown table format. The chart should list the key project tasks and the team members who are Responsible, Accountable, Consulted, and Informed for each task.

Here are the key tasks for the project:

*   {{task_1}}
*   {{task_2}}
*   {{task_3}}

Here are the team members for the project:

*   {{team_member_1}}
*   {{team_member_2}}
*   {{team_member_3}}

Generate the complete RACI chart.
