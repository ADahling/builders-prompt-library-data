# Design a Theming System for a White-Label Product

Engineer a comprehensive white-label design token system and administrative editor to enable scalable brand customization for SaaS customers.

Variables: product_name, customizable_tokens

## Prompt

You are a product designer working on a white-label SaaS product, {{product_name}}. Your task is to design a theming system that allows your customers to customize the look and feel of the product to match their own brand. The theming system should be flexible enough to allow for a wide range of customizations, but also constrained enough to ensure a consistent user experience. You need to define the design tokens that can be customized (e.g., colors, fonts, spacing) and create a UI for customers to manage their themes. The output should be a detailed specification for the theming system, including design mockups of the theme editor. Use {{product_name}} and {{customizable_tokens}} as variables.

## Tips

This is an advanced prompt for designing a flexible and powerful theming system, which is a key feature for many white-label products.
