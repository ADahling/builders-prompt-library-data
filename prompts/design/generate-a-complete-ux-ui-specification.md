# Generate a Complete UX/UI Specification

Turn a PRD into a UX/UI specification with a sitemap, user flows, navigation, page wireframe descriptions, and responsive design rules.

## Prompt

Based on this PRD: [paste PRD or summary]. Generate a complete UX/UI specification:

1. Information Architecture: Sitemap showing all pages and connections. Each page with purpose and key elements.
2. User Flows: For the 3 most critical journeys (signup, core action, payment), describe each step including decision points and error states.
3. Navigation Structure: Primary nav, secondary nav, what changes based on auth state.
4. Page-by-Page Wireframe Descriptions: For each page, describe layout in detail: components, position, hierarchy, interactions. Specific enough to build from.
5. Design System Basics: Color palette (primary, secondary, accent, bg, text), typography (heading/body), spacing scale, border radius. Mood recommendation.
6. Responsive Behavior: How each page adapts mobile vs desktop.

Format with clear headings per page. Be detailed and specific.

## Tips

This becomes your build spec. Paste sections into Lovable as you build each page.
