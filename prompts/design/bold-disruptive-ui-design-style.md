# Bold & Disruptive UI Design Style

Design an app page with high-contrast colors, oversized type, angular shapes, unconventional layouts, and fast animations for a bold visual style.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a bold and disruptive visual style. Apply these design principles:

**Color Palette**: High contrast — black and white base with one electric accent color (hot pink, electric yellow, or neon orange). Use color blocks, not gradients.
**Typography**: Use oversized, heavy-weight typefaces. 72-120px headings. Mix case intentionally — ALL CAPS for impact, lowercase for contrast.
**Layout**: Break conventions. Use full-bleed sections, text that runs edge-to-edge, overlapping elements, and intentional visual tension.
**Shapes**: Use sharp geometric shapes — hard edges, no border-radius. Diagonal cuts and angular dividers.
**Animation**: Use fast, snappy transitions (150-200ms). Hard cuts, not fades. Scroll-triggered reveals with scale and rotation.
**Imagery**: Use high-contrast black and white photography with duotone color overlays.

Key vocabulary: bold, loud, disruptive, statement, contrast, impact, edgy, unconventional, raw.

The design should feel like a manifesto — confident, unapologetic, and impossible to ignore.
