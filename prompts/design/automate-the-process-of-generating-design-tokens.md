# Automate the Process of Generating Design Tokens

Extract Figma design properties into platform-agnostic JSON tokens using an automated script to streamline design-to-code workflows.

Variables: figma_file_url, output_format

## Prompt

You are a design technologist. Your task is to automate the process of generating design tokens from a design file in Figma, {{figma_file_url}}. You need to use a tool, such as Style Dictionary or a custom script, to extract the design properties from the Figma file and convert them into a set of design tokens in a JSON file. The output should be the complete code for the automation script, along with a document that explains how to use it. Use {{figma_file_url}} and {{output_format}} as variables.

## Tips

This is an advanced prompt for automating the process of generating design tokens, which can save a lot of time and effort for design and development teams.
