# Create a Service Blueprint to Visualize the Backstage Processes

Map the end-to-end user journey and internal backstage processes for a specific service to identify operational gaps and improve delivery.

Variables: service_name, user_persona

## Prompt

You are a service designer. Your task is to create a service blueprint for a service, {{service_name}}. A service blueprint is a diagram that visualizes the relationships between different service components, such as people, props (physical or digital artifacts), and processes. It shows the user journey, the frontstage actions that the user sees, and the backstage actions that are hidden from the user. The output should be a detailed service blueprint. Use {{service_name}} and {{user_persona}} as variables.

## Tips

This is an advanced prompt for using service blueprinting to design and improve complex services.
