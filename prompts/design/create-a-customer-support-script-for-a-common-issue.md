# Create a Customer Support Script for a Common Issue

Generate a comprehensive, step-by-step customer support script in Markdown to standardize troubleshooting and resolution for specific issues.

Variables: issue_description

## Prompt

You are a customer support manager for a software company. You need to create a support script to help your team handle a common customer issue: {{issue_description}}.

Your task is to generate a detailed support script that provides a step-by-step guide for support agents. The script should include:

*   **Opening:** A polite and professional opening to the conversation.
*   **Information Gathering:** A series of questions to gather information about the customer's issue.
*   **Troubleshooting Steps:** A set of step-by-step instructions to help the agent troubleshoot the issue.
*   **Resolution:** Instructions on how to resolve the issue and confirm that the customer is satisfied.
*   **Closing:** A polite and professional closing to the conversation.

Generate the complete support script in Markdown format.
