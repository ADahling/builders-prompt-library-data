# Create a Design Handoff Checklist

Produce a standardized design handoff document for developers that includes asset checklists and pre-release review requirements.

Variables: team_name, design_process

## Prompt

You are a design lead. Your task is to create a design handoff checklist for your team. The checklist should list all the items that should be included in a design handoff, such as mockups, prototypes, style guides, and assets. The checklist should also include a section for a pre-handoff review to ensure that the design is ready for development. The output should be a document that contains the design handoff checklist. Use {{team_name}} and {{design_process}} as variables.

## Tips

This is a beginner-friendly prompt for creating a design handoff checklist to ensure that all handoffs are complete and consistent.
