# Generate a Set of Low-Fidelity Wireframes for a Mobile App

Generate detailed textual architectural blueprints for mobile app screens to define core user flows and layouts before starting visual design.

Variables: project_name, feature_set

## Prompt

You are a UX/UI designer. Your task is to create a set of low-fidelity wireframes for a new mobile application called 'TaskMaster', a to-do list and project management app. The primary goal of these wireframes is to outline the core functionality and user flow, focusing on structure and layout rather than visual design. The app should include the following screens: Splash Screen, Onboarding (3 screens), Sign Up/Login, Main Dashboard (showing a list of tasks), Create New Task, Task Details, and User Profile. For each wireframe, provide a textual description of the layout, including the placement of key UI elements such as buttons, input fields, and navigation components. The output should be a list of wireframes, with each wireframe clearly labeled with its corresponding screen name. The descriptions should be detailed enough for a developer to understand the intended layout without any visual aids. Use {{project_name}} and {{feature_set}} as variables to make the prompt reusable.

## Tips

This prompt is ideal for quickly generating a basic set of wireframes to validate an app idea and define its core structure.
