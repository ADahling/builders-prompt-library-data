# Design a Responsive Navigation Menu

Generate responsive navigation wireframes for multi-page websites to ensure seamless user experiences across desktop and mobile devices.

Variables: website_name, navigation_items

## Prompt

You are a UX designer. Your task is to design a responsive navigation menu for a website with a large number of pages, {{website_name}}. You need to design a menu that is easy to use on both desktop and mobile devices. For desktop, you can use a traditional horizontal navigation bar. For mobile, you need to design a mobile-friendly menu, such as a hamburger menu or a bottom navigation bar. The output should be a set of wireframes that show the design of the navigation menu on different screen sizes. Use {{website_name}} and {{navigation_items}} as variables.

## Tips

This prompt is for designing a critical component of any website: the navigation menu.
