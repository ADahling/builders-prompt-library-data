# Create a Style Guide for a Design Handoff

Generate a comprehensive technical style guide and UI documentation to ensure design consistency and streamline the development handoff.

Variables: project_name, design_elements

## Prompt

You are a UI designer. Your task is to create a style guide for a design handoff. The style guide should document the visual design of a website or application, including the color palette, typography, spacing, and UI components. The style guide should be designed to be a single source of truth for the development team, so that they can build the UI with consistency and accuracy. The output should be a document that contains the style guide. Use {{project_name}} and {{design_elements}} as variables.

## Tips

This prompt is for creating a style guide, which is an essential part of any design handoff.
