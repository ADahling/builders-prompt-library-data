# Validate a User Persona with User Research

Validate and refine target user personas for a specific product by conducting research interviews to align profiles with actual user data.

Variables: product_name, personas_to_validate

## Prompt

You are a UX researcher. You have a set of user personas for a product, {{product_name}}, but you are not sure if they are accurate. Your task is to validate the personas with user research. You need to conduct user interviews with people who match the demographics and psychographics of your personas. During the interviews, you need to ask questions to see if the users' goals, frustrations, and motivations match those of your personas. The output should be a report that summarizes your findings and provides recommendations for how to update the personas. Use {{product_name}} and {{personas_to_validate}} as variables.

## Tips

This prompt is for learning how to validate user personas with user research to ensure that they are accurate and useful.
