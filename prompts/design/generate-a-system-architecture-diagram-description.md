# Generate a System Architecture Diagram Description

Transform technical components and interactions into a clear, structured system architecture overview accessible to all stakeholders.

Variables: component_1, component_2, component_3, interaction_1, interaction_2

## Prompt

You are a system architect who has created a detailed architecture diagram for a new software system. To make the diagram more accessible to a wider audience, you need to write a clear and concise description of the architecture it represents.

Your task is to generate a textual description of the system architecture, based on the following components and their interactions:

*   **Components:** {{component_1}}, {{component_2}}, {{component_3}}
*   **Interactions:** {{interaction_1}}, {{interaction_2}}

The description should explain the role of each component and how they work together to achieve the system's goals. It should be written in a way that is easy to understand for both technical and non-technical stakeholders.

Generate the complete description in Markdown format.
