# Create a Set of Best Practices for Pair Programming

Establish clear pair programming guidelines and tool recommendations to improve team collaboration, code quality, and knowledge sharing.

## Prompt

You are a team lead who wants to encourage the adoption of pair programming on your team. You need to create a set of best practices to help your team get the most out of pair programming.

Your task is to generate a set of best practices that covers the following topics:

*   **When to pair program:** Guidelines on when to use pair programming.
*   **How to pair program:** Guidelines on how to be an effective driver and navigator.
*   **Pair rotation:** Guidelines on how often to rotate pairs.
*   **Tools for pair programming:** A list of tools that can be used for remote pair programming.

Generate the complete set of best practices in Markdown format.
