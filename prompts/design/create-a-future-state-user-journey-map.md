# Create a Future-State User Journey Map

Design an idealized user experience by mapping current pain points and visualizing strategic solutions for a persona's future journey.

Variables: product_name, user_persona

## Prompt

You are a UX strategist. Your task is to create a future-state user journey map for a product, {{product_name}}. A future-state journey map visualizes the ideal user experience that you want to create in the future. You need to start by identifying the current pain points in the user journey. Then, you need to brainstorm solutions to these pain points and create a new journey map that shows how the user experience will be improved. The output should be a presentation that compares the current-state and future-state journey maps. Use {{product_name}} and {{user_persona}} as variables.

## Tips

This is an advanced prompt for using journey mapping as a strategic tool to drive product innovation.
