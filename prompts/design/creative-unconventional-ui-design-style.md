# Creative & Unconventional UI Design Style

Design an experimental app page with unexpected colors, mixed typography, layered layouts, textures, custom interactions, and unconventional navigation.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a creative and unconventional visual style. Apply these design principles:

**Color Palette**: Use unexpected color combinations — chartreuse with deep purple, coral with teal, mustard with navy. Break traditional color theory rules intentionally.
**Typography**: Mix multiple typefaces (3-4) with purpose. Combine serif, sans-serif, and display fonts. Use text as a graphic element — rotated, scaled, or masked.
**Layout**: Use non-traditional layouts — magazine-style grids, Bento box arrangements, or free-form positioning. Let content overlap and interact.
**Texture**: Add grain, noise, paper textures, or halftone patterns. Mix digital precision with analog imperfection.
**Cursor & Interaction**: Custom cursors, magnetic buttons, text that reacts to mouse position, and parallax depth effects.
**Navigation**: Use unconventional navigation — side-scrolling, circular menus, or gesture-based exploration.

Key vocabulary: experimental, artistic, eclectic, mixed-media, collage, avant-garde, gallery, curated chaos.

The design should feel like an art exhibition — every screen is a composition, every interaction a discovery.
