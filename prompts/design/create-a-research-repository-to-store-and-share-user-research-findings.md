# Create a Research Repository to Store and Share User Research Findings

Establish a structured research repository and governance framework to effectively organize, tag, and share user insights across the company.

Variables: organization_name, repository_tool

## Prompt

You are a research operations manager. Your task is to create a research repository to store and share user research findings across your organization. You need to choose a tool for the repository (e.g., Airtable, Notion, or a dedicated research repository tool), and then create a system for organizing and tagging the research findings. You also need to create a process for how to add new research findings to the repository and how to search for existing findings. The output should be a document that explains how to use the research repository. Use {{organization_name}} and {{repository_tool}} as variables.

## Tips

This is an advanced prompt for creating a centralized system for managing and sharing user research findings.
