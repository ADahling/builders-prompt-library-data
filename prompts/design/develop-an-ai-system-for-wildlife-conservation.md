# Develop an AI System for Wildlife Conservation

Architect an AI monitoring infrastructure to track endangered species and detect poaching through multi-modal sensor fusion and real-time alerts.

Variables: location

## Prompt

You are a conservation biologist. I want to develop an AI system to monitor and protect endangered species. The system will use data from camera traps, satellite imagery, and acoustic sensors to track animal populations and detect poaching activities. The system will be deployed in {{location}}.

Design the AI system for wildlife conservation. The design should specify the sensor network, the data analysis pipeline, and the alert system for rangers.
