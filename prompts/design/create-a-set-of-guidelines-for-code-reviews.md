# Create a Set of Guidelines for Code Reviews

Establish a comprehensive framework for peer reviews covering technical quality, constructive communication, and professional feedback cycles.

## Prompt

You are a team lead who wants to improve the effectiveness of code reviews on your team. You need to create a set of guidelines to help your team conduct better code reviews.

Your task is to generate a set of guidelines that covers the following topics:

*   **The purpose of code reviews:** Why code reviews are important.
*   **What to look for in a code review:** A checklist of things to look for in a code review.
*   **How to give constructive feedback:** How to give feedback that is helpful and not hurtful.
*   **How to respond to feedback:** How to respond to feedback in a professional and constructive manner.

Generate the complete set of guidelines in Markdown format.
