# Perform a Return on Investment (ROI) Analysis for an AI Tool

Generate a comprehensive financial report calculating ROI, payback period, and NPV to justify the cost of implementing a specific AI tool.

Variables: tool_name, cost, expected_benefits

## Prompt

You are a financial analyst. My company is considering investing in {{tool_name}} and I need to perform an ROI analysis to justify the investment. The tool costs {{cost}} and we expect it to deliver {{expected_benefits}}.

Create a detailed ROI analysis that includes a calculation of the expected financial return, a payback period, and a net present value (NPV). The analysis should be based on realistic assumptions and presented in a clear and concise report.

## Tips

A prompt for business leaders who need to make a financial case for investing in an AI tool.
