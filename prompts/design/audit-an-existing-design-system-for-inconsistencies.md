# Audit an Existing Design System for Inconsistencies

Generate a comprehensive audit report and evolution roadmap to resolve inconsistencies and redundancies within a specific design system.

Variables: client_name, design_system_url

## Prompt

You are a design systems consultant. Your task is to audit the existing design system of a large enterprise client, {{client_name}}. The design system has grown organically over time and suffers from inconsistencies and redundancies. You need to conduct a thorough audit of the design system's components, styles, and documentation. The output should be a detailed audit report that identifies all the inconsistencies, provides recommendations for improvement, and includes a roadmap for evolving the design system. Use {{client_name}} and {{design_system_url}} as variables.

## Tips

This prompt is for designers who have a keen eye for detail and a passion for creating coherent and scalable design systems.
