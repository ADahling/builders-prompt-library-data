# Write a YouTube Video SEO Strategy

Generate a comprehensive YouTube SEO plan including keyword-optimized titles, descriptions, tags, and thumbnail concepts for higher ranking.

Variables: video_title, video_topic, target_keyword

## Prompt

You are a YouTube SEO expert. Your task is to create an SEO strategy for our new YouTube video, titled "{{video_title}}". The video is about {{video_topic}} and the target keyword is "{{target_keyword}}".

**Instructions:**

1.  **Optimize the Video Title:** Write a compelling and keyword-rich title for the video.

2.  **Write the Video Description:** Write a detailed video description that includes the target keyword, related keywords, and a transcript of the video (or a summary).

3.  **Create a List of Tags:** Create a list of 20-30 relevant tags for the video, including the target keyword, long-tail keywords, and broader topic-related keywords.

4.  **Design a Custom Thumbnail:** Describe a custom thumbnail that would be eye-catching and entice users to click on the video.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **YouTube Video SEO Strategy**
    *   **Video Title:**
    *   **Video Description:**
    *   **Tags:**
    *   **Custom Thumbnail Description:**

This prompt provides a comprehensive guide to optimizing a YouTube video for search to increase its visibility and views.
