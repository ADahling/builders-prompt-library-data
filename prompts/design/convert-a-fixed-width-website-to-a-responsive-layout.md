# Convert a Fixed-Width Website to a Responsive Layout

Refactor fixed-width web code into a mobile-first, responsive layout using media queries and flexible grids for optimized cross-device use.

Variables: website_url, target_devices

## Prompt

You are a front-end developer. Your task is to take an existing fixed-width website, {{website_url}}, and convert it to a fully responsive layout. You need to analyze the existing HTML and CSS, and then refactor the code to use a mobile-first approach with media queries to adapt the layout for different screen sizes. You should create a responsive grid system, make images and other media flexible, and ensure that the navigation is usable on mobile devices. The output should be the complete HTML and CSS code for the responsive website. Use {{website_url}} and {{target_devices}} as variables.

## Tips

This is a practical prompt for developers who want to learn how to make existing websites responsive.
