# Create a Generative Art Installation with AI

Design a conceptual proposal for a dynamic AI-driven art installation including technical specs and artistic vision for a specific venue.

Variables: venue, theme

## Prompt

You are a new media artist. I want to create a generative art installation that uses AI to create a constantly evolving visual experience for the audience. The installation will be displayed at {{venue}} and the theme is {{theme}}.

Propose a concept for the generative art installation. The proposal should describe the artistic vision, the AI techniques to be used, and the technical setup.
