# Document Design Tokens for a Design System

Generate a comprehensive technical documentation website that explains usage, purpose, and code examples for a specific design token set.

Variables: design_system_name, design_tokens

## Prompt

You are a technical writer. Your task is to document the design tokens for a design system, {{design_system_name}}. The documentation should be clear, concise, and easy to understand for both designers and developers. You need to explain what each design token is for, how to use it, and provide examples of its use in code. The output should be a documentation website for the design tokens. Use {{design_system_name}} and {{design_tokens}} as variables.

## Tips

This prompt is for creating high-quality documentation for design tokens, which is essential for the adoption and success of a design system.
