# Create a Wireframe for a Voice User Interface (VUI)

Design a detailed conversational dialogue flow for a smart home assistant that handles multi-step routines and error recovery scenarios.

Variables: assistant_name, user_scenario

## Prompt

You are a VUI designer. Your task is to create a wireframe for a voice-controlled smart home assistant, {{assistant_name}}. Unlike traditional wireframes, this will be a conversational wireframe, outlining the dialogue flow between the user and the assistant. The wireframe should cover a specific user scenario: setting a morning routine that includes turning on the lights, playing a specific playlist, and reading the day's weather forecast. You need to map out the different conversational paths, including potential user queries, the assistant's responses, and error handling (e.g., what happens if the user's request is unclear). The output should be a script-like document that clearly shows the back-and-forth conversation. Use {{assistant_name}} and {{user_scenario}} as variables.

## Tips

This prompt explores the emerging field of VUI design, which requires a different approach to wireframing focused on conversation and dialogue.
