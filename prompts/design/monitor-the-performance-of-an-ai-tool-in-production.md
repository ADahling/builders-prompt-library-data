# Monitor the Performance of an AI Tool in Production

Establish service-level objectives and monitoring KPIs to ensure the reliability and performance of AI tools in production environments.

Variables: tool_name, feature_description

## Prompt

You are a site reliability engineer (SRE). We have deployed an AI tool, {{tool_name}}, in our production environment to power {{feature_description}}. We need to monitor its performance to ensure that it is meeting our service-level objectives (SLOs).

Define a set of key performance indicators (KPIs) to track the performance of the AI tool. For each KPI, specify the target threshold and the monitoring tool to use.

## Tips

A prompt for engineering teams that need to monitor the performance of AI tools in a production environment.
