# Write a Project README from Scratch

Generate a professional, high-quality README.md file with standard documentation sections to attract users and contributors to your project.

Variables: project_name, api_name, tech_stack, license

## Prompt

You are a software engineer responsible for creating a high-quality README file for a new open-source project called {{project_name}}. A good README is crucial for attracting contributors and users, so it needs to be comprehensive, well-structured, and easy to navigate.

Your task is to generate a complete README.md file that includes the following sections:

*   **Project Title and Logo:** A clear and attractive title with the project logo.
*   **Badges:** Include relevant badges for build status, code coverage, license, etc.
*   **Introduction:** A brief, one-paragraph summary of what the project does.
*   **Features:** A bulleted list of the key features and functionalities.
*   **Installation:** Step-by-step instructions on how to install and set up the project, including any prerequisites or dependencies.
*   **Usage:** Clear and concise examples of how to use the project, with code snippets where applicable.
*   **Configuration:** An explanation of any configuration options available to the user.
*   **Contributing:** Guidelines for other developers who want to contribute to the project, including instructions on how to set up a development environment, run tests, and submit pull requests.
*   **License:** The project's license information.
*   **Contact:** Information on how to get in touch with the project maintainers.

Here is some information about the project:

*   **Project Name:** {{project_name}}
*   **Description:** A Python library for interacting with the {{api_name}} API.
*   **Tech Stack:** {{tech_stack}}
*   **License:** {{license}}

Generate the full README.md content. The tone should be professional yet welcoming. Use Markdown for formatting.
