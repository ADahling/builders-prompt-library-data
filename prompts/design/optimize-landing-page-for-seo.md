# Optimize Landing Page for SEO

Generate a comprehensive on-page and technical SEO strategy to rank a specific product landing page for a target keyword.

Variables: target_keyword, product_name

## Prompt

You are an SEO expert specializing in on-page optimization. Your task is to create a comprehensive SEO optimization plan for our landing page for the keyword "{{target_keyword}}". The landing page is for our product, {{product_name}}.

**Instructions:**

1.  **Keyword Analysis:** Briefly analyze the provided target keyword. Is it a good keyword to target? Are there any related long-tail keywords we should also consider?

2.  **On-Page SEO Recommendations:** Provide a detailed list of on-page SEO recommendations for the landing page. This should include:
    *   **Title Tag:** A compelling and optimized title tag.
    *   **Meta Description:** A meta description that entices users to click.
    *   **Header Tags (H1, H2, H3):** A clear hierarchy of header tags that include the target keyword and related terms.
    *   **Body Content:** Recommendations for incorporating the keyword naturally into the body content, including suggestions for content length and keyword density.
    *   **Image SEO:** Recommendations for optimizing images, including file names, alt text, and image compression.
    *   **Internal Linking:** Suggestions for internal links to other relevant pages on our website.

3.  **Technical SEO Checklist:** Provide a checklist of technical SEO items to ensure the landing page is crawlable and indexable by search engines. This should include items like mobile-friendliness, page speed, structured data (Schema.org), and SSL.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:
