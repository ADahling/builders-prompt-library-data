# Prototype a New Feature for an Existing Social Media App

Design a collaborative story feature for a social media app including high-fidelity prototypes and supporting design documentation.

Variables: app_name, new_feature_name

## Prompt

You are a product designer at a major social media company. Your task is to design and prototype a new feature called 'Collaborative Stories' for the existing mobile app, {{app_name}}. This feature allows multiple users to contribute to the same story. The prototype should demonstrate how a user can create a new collaborative story, invite friends to contribute, and view the story with contributions from different users. You need to create a high-fidelity prototype that seamlessly integrates with the existing UI of the app. The output should be a link to the prototype and a document explaining the design decisions you made. Use {{app_name}} and {{new_feature_name}} as variables.

## Tips

This prompt is for prototyping new features within an existing product, which requires careful consideration of the existing design system and user experience.
