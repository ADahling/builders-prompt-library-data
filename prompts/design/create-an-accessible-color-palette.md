# Create an Accessible Color Palette

Generate a WCAG-compliant, accessible color palette and style guide for a website that ensures high contrast and color-blind visibility.

Variables: website_name, brand_colors

## Prompt

You are a UI designer. Your task is to create a color palette for a new website, {{website_name}}, that is accessible to people with color blindness. You need to choose a set of colors that have sufficient contrast with each other, and that can be easily distinguished by people with different types of color blindness. You should use a color contrast checker to ensure that your color palette meets the WCAG 2.1 AA contrast ratio requirements. The output should be a style guide that documents the accessible color palette. Use {{website_name}} and {{brand_colors}} as variables.

## Tips

This prompt is for creating a visually appealing and accessible color palette for a website.
