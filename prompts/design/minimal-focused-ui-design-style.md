# Minimal & Focused UI Design Style

Design a minimal app page with a monochrome palette, one accent color, a single typeface, grid alignment, and generous whitespace.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a minimal and focused visual style. Apply these design principles:

**Color Palette**: Monochrome with one accent. White/light gray backgrounds, dark text, and a single functional accent color for CTAs and active states.
**Typography**: Use one typeface family only. Medium weight for headings, regular for body. 16-18px base size. Line-height 1.5-1.6.
**Layout**: Use a strict single-column or two-column grid. Maximum content width 640-800px. Align everything to a 4px or 8px grid.
**Whitespace**: This is the primary design element. Use 2-3x more padding than feels necessary. Let content breathe.
**Components**: Use borderless cards (background color differentiation only), simple underline links, and ghost buttons.
**Icons**: Use thin-stroke line icons (1.5-2px). Minimal set — only where text labels aren't sufficient.

Key vocabulary: clean, focused, simple, stripped-back, essential, quiet, functional, zen.

The design should feel invisible — the content is the interface, the UI gets out of the way.
