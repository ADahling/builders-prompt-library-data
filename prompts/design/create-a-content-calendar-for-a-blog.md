# Create a Content Calendar for a Blog

Generate a quarterly blog content calendar in Markdown format to manage topics, authors, deadlines, and publishing status.

## Prompt

You are a content manager for a company blog. You need to create a content calendar to plan and organize your blog content for the next quarter.

Your task is to generate a content calendar that includes the following for each blog post:

*   **Topic:** The topic of the blog post.
*   **Author:** The author of the blog post.
*   **Due Date:** The due date for the blog post.
*   **Publish Date:** The publish date for the blog post.
*   **Status:** The status of the blog post (e.g., idea, in progress, published).

Generate the content calendar in a Markdown table format.
