# Build a Navigation Component for a Component Library

Create a responsive, production-ready navigation component for a library featuring a desktop navbar, mobile hamburger menu, and documentation.

Variables: framework, navigation_props

## Prompt

You are a front-end developer. Your task is to build a reusable navigation component for a component library using {{framework}}. The navigation component should be designed to be responsive, so that it can be used on both desktop and mobile devices. You should include support for different navigation patterns, such as a horizontal navigation bar for desktop and a hamburger menu for mobile. The output should be the complete code for the navigation component, along with documentation on how to use it. Use {{framework}} and {{navigation_props}} as variables.

## Tips

This prompt is for building a critical component of any website or application: the navigation.
