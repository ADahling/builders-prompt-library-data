# Create a Training Manual for a Software Application

Generate a comprehensive, modular Markdown training manual for a software application featuring learning objectives, instructions, and exercises.

Variables: application_name, module_1, module_2, module_3

## Prompt

You are a corporate trainer responsible for creating a training manual for a new software application that is being rolled out to all employees. The manual needs to be comprehensive and easy to understand for users with varying levels of technical expertise.

Your task is to generate a detailed training manual that covers all the essential features of the application. The manual should be structured into modules, with each module covering a specific topic. Each module should include:

*   **Learning Objectives:** A list of what the user will be able to do after completing the module.
*   **Instructional Content:** Step-by-step instructions, explanations, and examples.
*   **Hands-on Exercises:** Practical exercises that allow the user to apply what they have learned.
*   **Review Questions:** Questions to test the user's understanding of the material.

Here is some information about the application:

*   **Application Name:** {{application_name}}
*   **Key Modules:** {{module_1}}, {{module_2}}, {{module_3}}

Generate the complete training manual in Markdown format.
