# Create a Content Style Guide for a Blog

Generate a comprehensive Markdown style guide to standardize tone, formatting, visual standards, and SEO practices for consistent blog content.

## Prompt

You are a blog editor. Your task is to create a content style guide for our company blog. The style guide should provide clear guidelines for all writers to ensure that our content is consistent, high-quality, and on-brand.

**Instructions:**

Create a content style guide that includes the following sections:

1.  **Tone of Voice:** A description of our blog's tone of voice (e.g., informative, conversational, humorous).

2.  **Formatting Guidelines:** Rules for formatting blog posts, including headings, subheadings, lists, and bold/italic text.

3.  **Image Guidelines:** Guidelines for selecting and formatting images for blog posts, including image size, resolution, and alt text.

4.  **Grammar and Punctuation:** Rules for grammar and punctuation, including our preferred style for things like serial commas, capitalization, and abbreviations.

5.  **SEO Guidelines:** Basic SEO guidelines for writers, such as how to incorporate keywords naturally and write compelling meta descriptions.

**Output Format:**

Please provide the content style guide in a structured Markdown format, with a separate section for each element.

## Tips

This prompt helps users create a content style guide to maintain consistency and quality across their blog.
