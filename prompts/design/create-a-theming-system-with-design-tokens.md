# Create a Theming System with Design Tokens

Architect a comprehensive multi-theme styling system using design tokens and dynamic switching logic for a specific web application.

Variables: app_name, themes

## Prompt

You are a design systems engineer. Your task is to create a theming system for a web application, {{app_name}}, using design tokens. The theming system should allow users to switch between different themes, such as a light theme and a dark theme. You need to create a set of design tokens for each theme, and then use them to style the components in your application. The output should be the complete code for the theming system, including the design tokens for each theme and the logic for switching between themes. Use {{app_name}} and {{themes}} as variables.

## Tips

This is an advanced prompt for creating a theming system with design tokens, which is a powerful way to provide users with a personalized experience.
