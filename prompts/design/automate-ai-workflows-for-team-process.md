# Automate AI Workflows for Team Processes

Design an AI automation workflow for a team process, with steps, tool choices, data flow, and examples of reducing manual work.

Variables: team_process

## Prompt

Design an automation workflow that uses AI tools to enhance {{team_process}}. Outline the steps involved, the AI tools to be used at each stage, data flow between tools, and how the automation will improve efficiency. Provide examples of how AI can reduce manual intervention and optimize outcomes.

## Tips

Focus on practical applications to demonstrate the value of AI in workflow automation.
