# Write a Test Plan for a New Software Feature

Generate a comprehensive Markdown-formatted test plan for specific software features, covering strategy, objectives, and detailed test cases.

Variables: feature_name

## Prompt

You are a QA engineer responsible for testing a new software feature, "{{feature_name}}". You need to write a comprehensive test plan to ensure that the feature is thoroughly tested before it is released.

Your task is to generate a detailed test plan that includes the following sections:

*   **Introduction:** A brief overview of the feature being tested.
*   **Test Objectives:** The specific goals of the testing effort.
*   **Test Scope:** The areas of the feature that will be tested.
*   **Test Strategy:** The overall approach to testing, including the types of testing that will be performed (e.g., functional, performance, security).
*   **Test Cases:** A detailed list of the specific test cases that will be executed.
*   **Test Environment:** The hardware and software environment that will be used for testing.
*   **Test Schedule:** A schedule for the testing effort.

Generate the complete test plan in Markdown format.
