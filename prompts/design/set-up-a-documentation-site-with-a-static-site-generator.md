# Set Up a Documentation Site with a Static Site Generator

Generate a comprehensive Markdown roadmap for installing, structuring, and deploying a branded documentation site using a chosen static generator.

Variables: project_name, static_site_generator, hosting_provider

## Prompt

You are a developer advocate tasked with creating a new documentation site for your company's open-source project, {{project_name}}. You have decided to use {{static_site_generator}} to build the site.

Your task is to generate a plan that outlines the steps to set up the documentation site. The plan should include:

*   **Installation and Setup:** Instructions on how to install {{static_site_generator}} and initialize a new project.
*   **Content Organization:** A plan for how to structure the documentation content, including the main sections and pages.
*   **Customization:** A list of the customizations you plan to make to the default theme, such as adding your company's logo and brand colors.
*   **Deployment:** A plan for how to deploy the documentation site to {{hosting_provider}}.

Generate the complete plan in Markdown format. The plan should be detailed and actionable, providing a clear roadmap for building the documentation site.
