# Premium & Sleek UI Design Style

Design an app page with a restrained palette, precise grids, frosted glass cards, and subtle motion for a premium, sleek visual style.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a premium and sleek visual style. Apply these design principles:

**Color Palette**: Use a restrained palette — deep blacks, whites, and one accent color (gold, electric blue, or emerald). Maximum 3 colors.
**Typography**: Use a modern sans-serif with generous letter-spacing. Thin weights for headings, regular for body. All-caps for labels.
**Layout**: Use strict grid alignment with mathematical precision. Generous padding (32-48px). Negative space is a feature, not a bug.
**Surfaces**: Use glass morphism effects — frosted glass cards with subtle backdrop-blur and thin 1px borders.
**Motion**: Smooth, slow transitions (300-500ms). Fade-ins and subtle parallax. Nothing bouncy or playful.
**Data Display**: Use clean data tables, minimal charts with thin strokes, and monospaced numbers.

Key vocabulary: refined, minimal, glass, precision, luxury, sophisticated, editorial, curated.

The design should feel like a luxury product — every pixel intentional, nothing wasted.
