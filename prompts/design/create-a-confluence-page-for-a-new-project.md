# Create a Confluence Page for a New Project

Generate a structured Confluence project hub in Markdown featuring goals, team roles, document links, and an action item tracker.

Variables: project_name

## Prompt

You are a project manager starting a new project, "{{project_name}}". You need to create a central hub for all project-related information in Confluence. This page will serve as the single source of truth for your team and stakeholders.

Your task is to generate the content for a new Confluence page that includes the following sections:

*   **Project Overview:** A brief summary of the project's goals, scope, and timeline.
*   **Team Members:** A list of all team members and their roles.
*   **Key Documents:** Links to important project documents, such as the project plan, requirements document, and design mockups.
*   **Meeting Notes:** A space to record notes from all project-related meetings.
*   **Action Items:** A table to track all open action items, with columns for the task, owner, and due date.

Generate the complete content for the Confluence page in Markdown format. The content should be well-organized and easy to navigate.
