# Set Up Google Analytics for a New Website

Configure Google Analytics 4 tracking and goal conversions for a specific domain and CMS platform with step-by-step implementation guidance.

Variables: website_url, website_platform

## Prompt

You are a Google Analytics expert. Your task is to provide a step-by-step guide for setting up Google Analytics on a new website, {{website_url}}. The website is built on the {{website_platform}} platform (e.g., WordPress, Shopify, custom HTML/CSS).

**Instructions:**

1.  **Create a Google Analytics Account:** Provide clear, step-by-step instructions on how to create a new Google Analytics account and property for the website.

2.  **Install the Tracking Code:** Explain how to find the Google Analytics tracking code and where to install it on the website. Provide specific instructions for the specified website platform.

3.  **Set Up Goals:** Guide the user on how to set up at least two essential goals in Google Analytics. Examples could be a destination goal for a 'thank you' page after a form submission, or an event goal for a button click.

4.  **Verify the Setup:** Explain how to verify that Google Analytics is correctly installed and tracking data.

**Output Format:**

Please provide your response as a numbered list of instructions, with clear headings for each section.

## Tips

This prompt provides a clear and actionable guide for beginners to set up Google Analytics on their new website.
