# Develop Wireframes for a Responsive E-commerce Website

Generate structured responsive wireframe specifications for an e-commerce site across mobile, tablet, and desktop breakpoints.

Variables: website_name, product_categories

## Prompt

You are a lead UX/UI designer. Your task is to create a set of wireframes for a new e-commerce website, {{website_name}}, that sells handmade leather goods. The wireframes must be designed for a responsive layout, showing how the content and UI elements will adapt across three breakpoints: mobile (375px), tablet (768px), and desktop (1440px). You need to wireframe the following pages: Homepage, Product Listing Page, Product Detail Page, and Shopping Cart. For each page, provide a separate wireframe description for each breakpoint, highlighting the changes in layout and component placement. The output should be a structured document with clear headings for each page and breakpoint. Use {{website_name}} and {{product_categories}} as variables.

## Tips

This prompt is essential for designing e-commerce sites that provide a seamless experience across all devices.
