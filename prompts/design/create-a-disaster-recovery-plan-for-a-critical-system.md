# Create a Disaster Recovery Plan for a Critical System

Generate a comprehensive, markdown-formatted disaster recovery plan defining roles, scenarios, and step-by-step restoration procedures.

## Prompt

You are a system administrator for a critical system. You need to create a disaster recovery plan to ensure that the system can be recovered quickly in the event of a disaster.

Your task is to generate a comprehensive disaster recovery plan that includes the following sections:

*   **Introduction:** An overview of the disaster recovery plan.
*   **Roles and Responsibilities:** The roles and responsibilities of the disaster recovery team.
*   **Disaster Scenarios:** A list of potential disaster scenarios.
*   **Recovery Procedures:** The step-by-step procedures for recovering the system in each disaster scenario.
*   **Testing and Maintenance:** A plan for testing and maintaining the disaster recovery plan.

Generate the complete disaster recovery plan in Markdown format.
