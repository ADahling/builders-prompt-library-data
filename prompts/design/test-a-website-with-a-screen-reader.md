# Test a Website with a Screen Reader

Generate a comprehensive accessibility bug report by navigating a specific URL with a screen reader to identify and document UX barriers.

Variables: website_url, screen_reader

## Prompt

You are a QA tester. Your task is to test a website, {{website_url}}, with a screen reader to identify any accessibility issues. You need to use a screen reader, such as NVDA or VoiceOver, to navigate the website and interact with its content. You should check for issues such as missing alt text for images, unlabeled form fields, and illogical tab order. The output should be a detailed bug report that lists all the accessibility issues you found, with steps to reproduce them. Use {{website_url}} and {{screen_reader}} as variables.

## Tips

This prompt is for learning how to test a website with a screen reader to identify accessibility issues.
