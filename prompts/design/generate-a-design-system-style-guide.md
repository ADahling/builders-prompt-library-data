# Generate a Design System / Style Guide

Get an app design system with colors, typography, spacing, component states, icon guidance, and CSS variables to paste into your project.

## Prompt

Create a design system for my [describe app type] application:

1. Color Palette: Primary, secondary, accent, success, warning, error, neutral with hex codes. Dark mode variants.
2. Typography: Heading and body fonts (Google Fonts). Size scale H1-H6, body, small, captions.
3. Spacing: Scale (4, 8, 12, 16, 24, 32, 48, 64px).
4. Border Radius: For buttons, cards, inputs, modals.
5. Shadows: sm, md, lg with CSS values.
6. Button Styles: Primary, secondary, outline, ghost, destructive. Hover and disabled states.
7. Form Elements: Inputs, selects, checkboxes, radios, toggles. Focus, error, disabled states.
8. Cards: Default style with padding, border, shadow, hover.
9. Icons: Recommend library (Lucide, Heroicons) and usage guidelines.

Provide CSS custom properties (variables) I can paste into my project.

## Tips

Establish before building so everything stays consistent.
