# Design a Mobile-First Onboarding Experience

Generate mobile-first wireframes for a streamlined app onboarding flow that uses interactive elements to drive specific user goals.

Variables: app_name, onboarding_goals

## Prompt

You are a UX designer. Your task is to design a mobile-first onboarding experience for a new mobile app, {{app_name}}. The onboarding experience should be designed to be as quick and easy as possible, while still providing users with the information they need to get started with the app. You should use a combination of visuals, text, and interactive elements to create an engaging and effective onboarding experience. The output should be a set of wireframes that show the design of the onboarding experience. Use {{app_name}} and {{onboarding_goals}} as variables.

## Tips

This prompt is for designing a user-friendly and effective onboarding experience for a mobile app.
