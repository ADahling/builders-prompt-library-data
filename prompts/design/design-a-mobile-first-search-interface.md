# Design a Mobile-First Search Interface

Create mobile-optimized wireframes for a search interface featuring intuitive navigation, filtering, and sorting for content-heavy websites.

Variables: website_name, search_features

## Prompt

You are a UX designer. Your task is to design a mobile-first search interface for a website with a large amount of content, {{website_name}}. The search interface should be easy to use on a small screen, with a large, clear search bar and a simple, intuitive results page. You should also consider how to provide users with advanced search options, such as filtering and sorting, in a mobile-friendly way. The output should be a set of wireframes that show the design of the search interface. Use {{website_name}} and {{search_features}} as variables.

## Tips

This prompt is for designing a user-friendly and effective search interface for a website on mobile devices.
