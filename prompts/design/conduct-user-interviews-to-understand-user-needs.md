# Conduct User Interviews to Understand User Needs

Generate a structured interview guide and research report to uncover user needs, pain points, and motivations for a specific product.

Variables: product_name, target_users

## Prompt

You are a UX researcher. Your task is to conduct user interviews with 5-7 potential users of a new product, {{product_name}}. The goal of the interviews is to understand the users' needs, pain points, and motivations. You need to create an interview guide with a set of open-ended questions to ask the participants. After conducting the interviews, you need to analyze the data and create a report that summarizes your findings. The output should be the interview guide and the research report. Use {{product_name}} and {{target_users}} as variables.

## Tips

This prompt is for learning how to conduct and analyze user interviews to gain insights into user needs.
