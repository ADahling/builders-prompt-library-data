# Create a Knowledge Base for a Customer Support Team

Develop a comprehensive strategy for building, managing, and launching a customer support knowledge base to improve team efficiency.

## Prompt

You are a customer support manager for a software company. You need to create a knowledge base to help your team answer customer questions more efficiently.

Your task is to generate a plan for creating a knowledge base. The plan should include:

*   **Content Strategy:** A plan for what content to include in the knowledge base.
*   **Content Creation Process:** A process for creating and updating content.
*   **Knowledge Base Platform:** A recommendation for a knowledge base platform.
*   **Launch Plan:** A plan for launching the knowledge base to your team.

Generate the complete plan in Markdown format.
