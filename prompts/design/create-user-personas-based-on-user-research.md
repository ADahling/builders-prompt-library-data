# Create User Personas based on User Research

Synthesize raw research data into detailed fictional personas to define target user groups, goals, and pain points for a specific product.

Variables: product_name, user_research_data

## Prompt

You are a UX researcher. Your task is to create a set of user personas based on the findings of a user research study. The personas should be fictional characters that represent the different user groups of a product, {{product_name}}. For each persona, you need to create a name, a photo, a backstory, and a set of goals and frustrations. The output should be a document that presents the user personas. Use {{product_name}} and {{user_research_data}} as variables.

## Tips

This prompt is for learning how to create user personas to help designers and developers empathize with users.
