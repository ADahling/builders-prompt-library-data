# Write a Code of Conduct for an Open Source Project

Generate a professional, Contributor Covenant-based Markdown code of conduct to foster a safe and inclusive environment for project contributors.

## Prompt

You are the maintainer of an open source project. You need to create a code of conduct to ensure that your project is a welcoming and inclusive environment for all contributors.

Your task is to generate a comprehensive code of conduct that is based on the Contributor Covenant. The code of conduct should include:

*   A pledge to make the project a harassment-free experience for everyone.
*   A list of the types of behavior that are unacceptable.
*   The consequences of violating the code of conduct.
*   A process for reporting violations.

Generate the complete code of conduct in Markdown format.
