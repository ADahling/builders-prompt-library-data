# Retro & Nostalgic UI Design Style

Design an app page with vintage colors, retro typography, print-inspired layouts, analog textures, and era-specific UI elements.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a retro and nostalgic visual style. Apply these design principles:

**Color Palette**: Use vintage-inspired colors — burnt orange, avocado green, mustard yellow, dusty pink, and brown. Desaturate slightly for an aged feel.
**Typography**: Use retro typefaces — slab serifs, rounded gothics, or pixel fonts depending on the era. Add text shadows and outlines for a poster feel.
**Layout**: Use grid-based layouts inspired by print design — newspaper columns, magazine spreads, or poster compositions. Add visible borders and frames.
**Textures**: Add film grain, VHS scan lines, halftone dot patterns, or paper textures. Make it feel analog.
**Elements**: Use retro UI elements — chunky buttons with 3D bevels, pixel art icons, cassette tape progress bars, or CRT screen effects.
**Photography**: Apply vintage filters — sepia, cross-processed, Polaroid frames, or duotone with retro color pairs.

Key vocabulary: vintage, retro, throwback, analog, pixel, arcade, cassette, neon-sign, diner, groovy.

The design should feel like a time machine — evoking a specific era while remaining functional and modern under the hood.
