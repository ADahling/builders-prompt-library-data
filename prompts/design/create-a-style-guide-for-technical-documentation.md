# Create a Style Guide for Technical Documentation

Generate a comprehensive Markdown style guide for technical documentation to ensure consistent voice, formatting, and terminology across teams.

## Prompt

You are the lead technical writer at a large technology company. To ensure consistency and quality across all of your company's technical documentation, you need to create a comprehensive style guide.

Your task is to generate a style guide that provides clear and consistent guidelines for writing and formatting technical documentation. The style guide should cover the following topics:

*   **Voice and Tone:** Guidelines on the appropriate voice and tone to use in technical documentation.
*   **Grammar and Punctuation:** Rules for grammar, punctuation, and capitalization.
*   **Formatting:** Standards for formatting headings, lists, tables, and code examples.
*   **Terminology:** A list of preferred technical terms and their definitions.
*   **Graphics and Screenshots:** Guidelines for using images, diagrams, and screenshots in documentation.

Generate the complete style guide in Markdown format. The style guide should be a comprehensive and authoritative resource for all technical writers at your company.
