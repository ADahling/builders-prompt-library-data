# Create a Customer Service Knowledge Base

Generate a comprehensive customer support knowledge base including FAQs, a detailed sample article, and a logical category structure.

Variables: product_name

## Prompt

You are a customer support manager. Your task is to create a customer service knowledge base for our product, {{product_name}}. The knowledge base should provide customers with self-service support options and reduce the number of support tickets.

**Instructions:**

1.  **Identify a list of Frequently Asked Questions (FAQs):** What are the most common questions that customers ask your support team? Create a list of at least 10-15 FAQs.

2.  **Write a Knowledge Base Article:** For one of the FAQs, write a detailed knowledge base article that provides a clear and comprehensive answer. The article should be well-structured, easy to read, and include screenshots or a video if necessary.

3.  **Organize the Knowledge Base:** How will you organize the knowledge base to make it easy for customers to find the information they need? Suggest a set of categories for the knowledge base articles.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **Customer Service Knowledge Base Plan**
    *   **Frequently Asked Questions (FAQs):**
    *   **Sample Knowledge Base Article:**
    *   **Knowledge Base Organization:**

## Tips

This prompt helps users create a customer service knowledge base to improve customer satisfaction and reduce support costs.
