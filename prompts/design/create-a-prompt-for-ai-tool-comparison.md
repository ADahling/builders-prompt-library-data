# Create a Prompt for AI Tool Comparison

Generate a comprehensive, impartial evaluation and recommendation comparing two AI tools for a specific complex task across key performance metrics.

Variables: tool_1_name, tool_2_name, complex_task_description

## Prompt

You are a prompt engineering expert. I need to create a detailed prompt to compare two AI tools, {{tool_1_name}} and {{tool_2_name}}, for a complex task: {{complex_task_description}}. The prompt should be designed to elicit a comprehensive and unbiased comparison from an AI assistant.

Craft a prompt that instructs an AI to act as an impartial analyst and evaluate the two tools across multiple dimensions, including performance, accuracy, scalability, and cost-effectiveness. The prompt should also ask for a final recommendation with a clear justification.

## Tips

A prompt for users who want to create their own high-quality prompts for comparing AI tools.
