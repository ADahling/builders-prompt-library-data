# Create a Responsive Pricing Table

Generate clean, responsive HTML and CSS for a SaaS pricing table that adapts seamlessly between desktop and mobile layouts.

Variables: product_name, pricing_plans

## Prompt

You are a web designer. Your task is to create a responsive pricing table for a SaaS product, {{product_name}}. The pricing table should display the different pricing plans for the product in a clear and easy-to-compare way. You need to design a layout that works well on both desktop and mobile devices. For example, on desktop, you can use a horizontal layout with multiple columns. On mobile, you might need to switch to a vertical layout or use a tabbed interface. The output should be the HTML and CSS code for the responsive pricing table. Use {{product_name}} and {{pricing_plans}} as variables.

## Tips

This prompt is for designing a common and important UI component for any SaaS product.
