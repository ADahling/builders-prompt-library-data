# Generate Synthetic Data with an AI Tool

Generate privacy-compliant synthetic datasets based on a specific schema and topic using recommended AI tools and implementation guides.

Variables: data_topic, schema_description

## Prompt

You are a data scientist. I need to generate synthetic data for training a machine learning model. The data should be representative of real-world data on {{data_topic}} but without containing any personally identifiable information (PII). I have a small sample of real data with the following schema: {{schema_description}}.

Recommend an AI tool for generating synthetic data and provide a step-by-step guide on how to use it to create a high-quality synthetic dataset.
