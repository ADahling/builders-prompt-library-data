# Write Advanced SEO Copy for a Product Category Page

Generate optimized H1 tags, engaging category descriptions, detailed buying guides, and meta tags to boost e-commerce search rankings.

Variables: product_category, target_keyword

## Prompt

You are an e-commerce SEO expert. Your task is to write the SEO copy for a product category page on our e-commerce website. The category is {{product_category}} and the target keyword is "{{target_keyword}}"

**Instructions:**

1.  **Write the H1 Tag:** Write a compelling H1 tag that includes the target keyword and entices users to explore the products in the category.

2.  **Write the Introductory Copy:** Write a 2-3 paragraph introduction to the category page. This copy should be engaging, informative, and naturally incorporate the target keyword and related long-tail keywords.

3.  **Create a Buying Guide:** Write a short buying guide (300-500 words) to help users choose the right product within the category. This will provide value to the user and also give you an opportunity to include more relevant keywords.

4.  **Write Meta Title and Description:** Write an optimized meta title and meta description for the category page.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **SEO Copy for {{product_category}} Page**
    *   **H1 Tag:**
    *   **Introductory Copy:**
    *   **Buying Guide:**
    *   **Meta Title:**
    *   **Meta Description:**
