# Wireframe a Mobile App with a Focus on Accessibility (WCAG 2.1 AA)

Generate accessible mobile banking wireframes with detailed WCAG 2.1 AA annotations for screen readers, contrast, and ARIA implementation.

Variables: app_name, accessibility_guidelines

## Prompt

You are an accessibility specialist. Your task is to create a set of wireframes for a mobile banking app, {{app_name}}, with a strong focus on accessibility, adhering to the WCAG 2.1 AA guidelines. You need to wireframe the following screens: Login, Account Summary, and Transfer Funds. For each wireframe, you must provide detailed annotations on how the design supports accessibility. This includes specifying ARIA labels for all interactive elements, ensuring sufficient color contrast, providing clear focus indicators, and designing for screen reader compatibility. The output should be a set of wireframe descriptions with a dedicated 'Accessibility Considerations' section for each screen. Use {{app_name}} and {{accessibility_guidelines}} as variables.

## Tips

This is a crucial prompt for designing inclusive applications that are usable by people with disabilities. It requires a deep understanding of accessibility principles and guidelines.
