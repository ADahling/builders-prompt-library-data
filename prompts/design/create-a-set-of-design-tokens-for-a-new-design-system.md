# Create a Set of Design Tokens for a New Design System

Generate a structured JSON design token system with consistent naming conventions for colors, typography, and spacing to scale visual specs.

Variables: design_system_name, token_categories

## Prompt

You are a design systems architect. Your task is to create a set of design tokens for a new design system, {{design_system_name}}. The design tokens should define the visual properties of the design system, such as colors, typography, spacing, and border radii. You need to create a clear and consistent naming convention for the tokens, and you should also provide examples of how to use the tokens in your design and code. The output should be a JSON file that contains the design tokens. Use {{design_system_name}} and {{token_categories}} as variables.

## Tips

This prompt is for creating a foundational element of any design system: the design tokens.
