# Generate a README Template

Get a project README template with your installation commands and usage examples, plus sections for contributing, license, and contact details.

Variables: project_name, installation_commands, usage_examples

## Prompt

Create a README template for a {{project_name}} project that includes sections for installation, usage, contributing, license, and contact information. Use {{installation_commands}} for installation instructions and {{usage_examples}} for usage examples.

## Tips

Replace placeholders with actual project details and commands.
