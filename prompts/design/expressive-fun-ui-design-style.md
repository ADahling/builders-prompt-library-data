# Expressive & Fun UI Design Style

Design an app page with vibrant colors, rounded typography, asymmetric layouts, illustrated icons, and playful interaction feedback.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using an expressive and fun visual style. Apply these design principles:

**Color Palette**: Use vibrant, saturated colors with playful gradients. Mix warm and cool tones for energy.
**Typography**: Use rounded, friendly typefaces. Mix weights boldly — oversized headings with compact body text.
**Layout**: Use asymmetric grids, overlapping elements, and generous whitespace. Break the grid intentionally for visual interest.
**Micro-interactions**: Add bouncy hover effects, playful loading animations, and satisfying click feedback.
**Iconography**: Use illustrated, hand-drawn style icons rather than minimal line icons.
**Cards & Containers**: Use rounded corners (16-24px), subtle shadows, and occasional rotation for a casual feel.

Key vocabulary to incorporate: vibrant, playful, bouncy, rounded, gradient, illustrated, whimsical, energetic.

The design should feel approachable and delightful — like the user is having fun while being productive.
