# Develop a Proto-Persona for a New Product Idea

Generate a structured proto-persona document based on assumptions to define target user goals and frustrations for a new product concept.

Variables: product_type, target_user_assumptions

## Prompt

You are an entrepreneur. You have a new product idea for a {{product_type}}, but you don't have the time or resources to conduct extensive user research. Your task is to create a proto-persona for your target user. A proto-persona is a lightweight persona that is based on your assumptions and anecdotal evidence. You need to create a name, a photo, a backstory, and a set of goals and frustrations for your proto-persona. The output should be a document that presents the proto-persona. Use {{product_type}} and {{target_user_assumptions}} as variables.

## Tips

This prompt is for learning how to create a proto-persona when you don't have a lot of user research data.
