# Automate a Workflow with Multiple AI Tools

Design an efficient multi-step automation strategy that integrates specific AI tools into a seamless process with clear triggers and data flows.

Variables: process_description, tool_list

## Prompt

You are a workflow automation specialist. I want to automate a business process that involves multiple steps and requires the use of several AI tools. The process is {{process_description}} and the tools I have in mind are {{tool_list}}.

Design an automated workflow that orchestrates the use of these AI tools to complete the process. The workflow should be designed for efficiency and reliability. Provide a diagram or a detailed description of the workflow, including the triggers, actions, and data flows between the tools.

## Tips

A prompt for users who want to automate complex workflows by combining the capabilities of multiple AI tools.
