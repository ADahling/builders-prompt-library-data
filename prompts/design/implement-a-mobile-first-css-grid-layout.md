# Implement a Mobile-First CSS Grid Layout

Generate mobile-first HTML and CSS using grid-template-areas to ensure a responsive, semantic layout that scales across devices.

Variables: website_name, grid_areas

## Prompt

You are a front-end developer. Your task is to implement a mobile-first CSS grid layout for a website, {{website_name}}. You need to start by creating a single-column layout for mobile devices, and then use media queries to create more complex layouts for larger screens. You should use the `grid-template-areas` property to create a semantic and easy-to-understand grid. The output should be the HTML and CSS code for the mobile-first CSS grid layout. Use {{website_name}} and {{grid_areas}} as variables.

## Tips

This prompt is for developers who want to learn how to use CSS grid to create responsive layouts with a mobile-first approach.
