# Design a Dynamic Color Theming System for a Mobile App

Design a mobile app theme editor prototype and technical specification with color tokens, preset themes, and custom theme controls.

Variables: app_name, theme_options

## Prompt

You are a mobile app designer. Your task is to design a dynamic color theming system for a mobile app, {{app_name}}. The system should allow users to choose from a predefined set of themes (e.g., light, dark, high contrast) and also create their own custom themes. You need to define a set of design tokens for the colors in the app, and then create a UI for users to customize these tokens. The output should be a high-fidelity prototype of the theme editor and a technical specification for the theming system. Use {{app_name}} and {{theme_options}} as variables.

## Tips

This is an advanced prompt for creating a highly customizable and personalized user experience.
