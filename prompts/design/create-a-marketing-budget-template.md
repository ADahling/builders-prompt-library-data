# Create a Marketing Budget Template

Generate a structured marketing budget table categorized by team, content, advertising, software, and events to track planned versus actual spend.

## Prompt

You are a marketing manager. Your task is to create a marketing budget template that we can use to plan and track our marketing spend for the year.

**Instructions:**

Create a marketing budget template that includes the following categories and sub-categories:

1.  **Marketing Team:** (e.g., salaries, benefits, training)
2.  **Content Marketing:** (e.g., freelance writers, stock photos, video production)
3.  **Paid Advertising:** (e.g., Google Ads, Facebook Ads, LinkedIn Ads)
4.  **Software and Tools:** (e.g., marketing automation, SEO tools, social media management tools)
5.  **Events:** (e.g., trade shows, webinars, meetups)

**Output Format:**

Please provide the marketing budget template in a table format. For each category and sub-category, include columns for the budgeted amount and the actual amount spent.

## Tips

This prompt provides a ready-to-use marketing budget template to help users plan and manage their marketing spend.
