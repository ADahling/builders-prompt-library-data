# Build an AI-Powered System for Personalized Medicine

Architect a clinical decision support system that integrates genomic and lifestyle data to generate personalized treatment predictions.

Variables: disease

## Prompt

You are a medical doctor and bioinformatician. I want to build an AI-powered system to provide personalized treatment recommendations to patients with {{disease}}. The system will analyze a patient's genetic data, medical history, and lifestyle information to predict their response to different treatments.

Design the architecture for the personalized medicine system. The design should include the data integration platform, the predictive models, and the clinical decision support interface for doctors.
