# Create a Typographic Scale for a Responsive Website

Generate a responsive, modular CSS typographic scale using relative units to ensure consistent and harmonious text styling across all devices.

Variables: website_name, base_font_size

## Prompt

You are a web designer. Your task is to create a typographic scale for a responsive website, {{website_name}}. The typographic scale should define a set of font sizes, line heights, and font weights that can be used for different text elements, such as headings, paragraphs, and captions. The scale should be designed to be harmonious and readable on all screen sizes, from mobile to desktop. The output should be a CSS file that implements the typographic scale using a modular scale and responsive units like `rem` and `vw`. Use {{website_name}} and {{base_font_size}} as variables.

## Tips

This prompt is for creating a flexible and scalable typographic system for responsive websites.
