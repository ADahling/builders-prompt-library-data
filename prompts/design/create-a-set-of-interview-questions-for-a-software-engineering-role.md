# Create a Set of Interview Questions for a Software Engineering Role

Generate a comprehensive set of 10 technical interview questions and evaluation criteria to assess software engineering candidates across key domains.

## Prompt

You are a hiring manager for a software engineering role. You need to create a set of interview questions to assess the technical skills and problem-solving abilities of the candidates.

Your task is to generate a set of 10 interview questions that cover a range of topics, such as:

*   Data structures and algorithms.
*   Object-oriented design.
*   System design.
*   Databases.
*   Networking.

For each question, you should also provide a brief explanation of what you are looking for in a good answer.

Generate the complete set of interview questions in Markdown format.
