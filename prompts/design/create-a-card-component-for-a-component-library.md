# Create a Card Component for a Component Library

Generate a reusable, documented card component for a UI library using specified frameworks and props to handle diverse content types.

Variables: framework, card_props

## Prompt

You are a front-end developer. Your task is to create a reusable card component for a component library using {{framework}}. The card component should be designed to be flexible enough to be used in a variety of contexts, such as for displaying blog posts, products, or user profiles. You should include support for images, titles, subtitles, and actions. The output should be the complete code for the card component, along with documentation on how to use it. Use {{framework}} and {{card_props}} as variables.

## Tips

This is a beginner-friendly prompt for building a common and versatile UI component: the card.
