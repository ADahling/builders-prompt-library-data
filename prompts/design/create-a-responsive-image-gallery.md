# Create a Responsive Image Gallery

Build a responsive, lightbox-enabled image gallery with optimized performance and fluid grid layouts for a professional photography portfolio.

Variables: portfolio_website, image_optimization_techniques

## Prompt

You are a web designer. Your task is to create a responsive image gallery for a photography portfolio website, {{portfolio_website}}. The gallery should display a grid of thumbnails on large screens, and then transition to a single-column layout on smaller screens. When a user clicks on a thumbnail, a larger version of the image should be displayed in a lightbox. You need to ensure that the gallery is optimized for performance by using responsive images that are appropriately sized for different screen resolutions. The output should be the HTML, CSS, and JavaScript code for the responsive image gallery. Use {{portfolio_website}} and {{image_optimization_techniques}} as variables.

## Tips

This prompt is for creating a common and important feature for any portfolio or e-commerce website.
