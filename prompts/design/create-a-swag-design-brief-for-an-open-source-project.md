# Create a Swag Design Brief for an Open-Source Project

Draft a Markdown design brief for open-source project stickers and shirts, covering audience, design goals, brand assets, and deliverables.

Variables: project_name, deadline, budget

## Prompt

Our open-source project, `{{project_name}}`, has a growing community, and we want to create some official project swag (stickers, t-shirts) to give away at conferences and to top contributors.

We need to create a design brief for a freelance designer to create the artwork.

Generate a comprehensive design brief in Markdown format. The brief should provide the designer with all the information they need to create compelling and on-brand designs.

The brief should include:

1.  **Project Overview**:
    *   **Project Name**: `{{project_name}}`
    *   **What we do**: A one-sentence description of the project.
    *   **Target Audience**: Who is this swag for? (e.g., Developers, data scientists, AI researchers).

2.  **Design Goals**:
    *   What is the primary message we want the swag to convey? (e.g., "Innovative", "Reliable", "Community-driven", "Fun").
    *   What feeling or emotion should the design evoke?

3.  **Existing Brand Assets**:
    *   **Logo**: Provide a link to the project's logo files (SVG, PNG). Mention any rules for using the logo (e.g., "Do not distort or change the colors.").
    *   **Color Palette**: List the primary and secondary colors of the project with their hex codes.
    *   **Typography**: Mention the primary font used by the project, if any.

4.  **Design Requirements**:
    *   **Deliverables**: List the specific items you need designs for:
        *   Design 1: A square sticker (for laptops).
        *   Design 2: A t-shirt design (front print).
        *   (Optional) Design 3: A more creative, illustrative design that incorporates the project's theme or mascot.
    *   **Style**: Describe the desired aesthetic. Use keywords like "minimalist", "retro", "techy", "playful", "corporate".
    *   **Inspiration**: Provide links to 2-3 examples of open-source project swag that you like.
    *   **Things to Avoid**: List anything you don't want to see in the design (e.g., "No clichés like brains or robots.", "Avoid using too many colors.").

5.  **Logistics**:
    *   **File Formats**: Specify that final designs should be delivered in vector format (SVG or AI) and high-resolution PNG.
    *   **Deadline**: `{{deadline}}`
    *   **Budget**: `{{budget}}`

3.  Does it include links to existing brand assets and inspiration? Yes.

## Tips

Good swag can be a powerful tool for building brand identity and making your community members feel like they are part of something special. A clear design brief is the first step to getting great results.
