# Find AI Tools for Data Analysis

Identify and implement user-friendly AI tools tailored to specific dataset topics and formats for actionable data insights.

Variables: dataset_topic, file_format

## Prompt

You are a data analyst. I need an AI tool to help me analyze a dataset about {{dataset_topic}}. The dataset is in {{file_format}} format.

Recommend a user-friendly AI tool for data analysis that can handle this type of data. Explain how I can use the tool to gain insights from my data.

## Tips

A prompt for beginners in data analysis who want to leverage AI tools.
