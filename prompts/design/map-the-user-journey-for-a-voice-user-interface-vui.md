# Map the User Journey for a Voice User Interface (VUI)

Generate a detailed VUI user journey map that outlines verbal interactions and emotional states from invocation to task completion.

Variables: vui_name, user_scenario

## Prompt

You are a conversation designer. Your task is to map the user journey for a user who is interacting with a voice user interface (VUI), {{vui_name}}. The journey should cover all the stages from invocation to completion of the task. You need to identify the user's utterances, the VUI's responses, and the user's emotions at each stage of the journey. The output should be a detailed user journey map for the VUI. Use {{vui_name}} and {{user_scenario}} as variables.
