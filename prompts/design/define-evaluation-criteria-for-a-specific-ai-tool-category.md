# Define Evaluation Criteria for a Specific AI Tool Category

Establish category-specific benchmarks to help target audiences systematically assess and compare AI software for informed purchasing decisions.

Variables: tool_category, target_audience

## Prompt

You are an industry analyst. I need to define a set of evaluation criteria for assessing AI tools in the {{tool_category}} category. The criteria will be used to create a buyer's guide for our audience of {{target_audience}}.

Provide a detailed list of evaluation criteria that are specific to this tool category. For each criterion, explain why it is important and what users should look for when evaluating tools.
