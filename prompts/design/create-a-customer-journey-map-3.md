# Create a Customer Journey Map

Visualize the end-to-end user experience and emotional touchpoints for a specific persona to optimize conversion and long-term loyalty.

Variables: product_name, customer_persona

## Prompt

You are a UX strategist. Your task is to create a customer journey map for a customer who is using a product, {{product_name}}, for the first time. The journey map should visualize the customer's experience from the moment they become aware of the product to the moment they become a loyal customer. You need to identify the different touchpoints that the customer has with the product, and the emotions they experience at each touchpoint. The output should be a detailed customer journey map. Use {{product_name}} and {{customer_persona}} as variables.

## Tips

This is an advanced prompt for learning how to create a customer journey map to understand and improve the customer experience.
