# Build a Real-Time AI-Powered Decision Engine

Design a high-throughput, low-latency architecture for streaming data ingestion, real-time AI inference, and automated model retraining.

Variables: business_process, data_source

## Prompt

You are a principal software engineer. I need to build a real-time decision engine that uses an AI model to make automated decisions for {{business_process}}. The engine must process a high volume of streaming data from {{data_source}} with low latency.

Design the architecture for the real-time decision engine. The design should include the data ingestion pipeline, the model serving infrastructure, and a mechanism for monitoring the model's performance and retraining it as needed.
