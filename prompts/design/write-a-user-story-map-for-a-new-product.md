# Write a User Story Map for a New Product

Generate a structured Markdown user story map that breaks down user activities, tasks, and detailed stories for end-to-end product planning.

## Prompt

You are a product owner for a new product. You need to create a user story map to visualize the user's journey and plan the product's development.

Your task is to generate a user story map that includes the following levels:

*   **User Activities:** The high-level activities that the user performs.
*   **User Tasks:** The specific tasks that the user performs to complete each activity.
*   **User Stories:** The detailed user stories for each task.

Generate the user story map in a Markdown format that is easy to read and understand.
