# Create an Accessible Navigation Menu

Design an accessible site navigation system featuring keyboard support, screen reader compatibility, and skip links for improved usability.

Variables: website_name, navigation_links

## Prompt

You are a UX designer. Your task is to create a navigation menu for a website, {{website_name}}, that is accessible to people with disabilities. The navigation menu should be easy to use with a keyboard and a screen reader. You need to ensure that all the links in the menu have clear and descriptive text, and that the menu has a logical tab order. You should also provide a skip link that allows users to skip the navigation and go directly to the main content of the page. The output should be a set of wireframes that show the design of the accessible navigation menu. Use {{website_name}} and {{navigation_links}} as variables.

## Tips

This prompt is for designing a user-friendly and accessible navigation menu for a website.
