# Implement a Design Linting Process

Get a design linting process document with tool selection, checks for design system inconsistencies, workflow integration, and designer instructions.

Variables: design_system_name, design_tool

## Prompt

You are a design technologist. Your task is to implement a design linting process to ensure that all new designs adhere to the company's design system, {{design_system_name}}. You need to choose a design linting tool (e.g., a Figma plugin or a custom script) and configure it to check for common design inconsistencies, such as incorrect colors, fonts, or spacing. You also need to integrate the design linting process into the design workflow, for example, by running it automatically on every new design file. The output should be a document that explains the design linting process and provides instructions for designers on how to use it. Use {{design_system_name}} and {{design_tool}} as variables.

## Tips

This prompt is for improving the quality and consistency of designs by automating the process of checking for adherence to the design system.
