# Create a Storyboard to Visualize a User Scenario

Generate a detailed 6-8 frame storyboard sequence that visualizes a specific user journey and context for a given product scenario.

Variables: product_name, user_scenario

## Prompt

You are a UX designer. Your task is to create a storyboard to visualize a user scenario for a product, {{product_name}}. A storyboard is a sequence of drawings that tells a story about how a user interacts with a product. You need to create a storyboard that shows the user's context, their goal, and the steps they take to achieve their goal. The output should be a storyboard with 6-8 frames. Use {{product_name}} and {{user_scenario}} as variables.

## Tips

This is a beginner-friendly prompt for learning how to use storyboarding to communicate user scenarios.
