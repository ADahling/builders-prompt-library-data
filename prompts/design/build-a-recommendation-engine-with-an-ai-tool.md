# Build a Recommendation Engine with an AI Tool

Select an AI library and outline an implementation strategy to build a personalized product recommendation engine for an e-commerce site.

Variables: website_url, data_sources

## Prompt

You are a machine learning engineer specializing in recommendation systems. I want to build a recommendation engine for my e-commerce website, {{website_url}}, to suggest products to users based on their browsing history and purchase behavior. I have access to the following data: {{data_sources}}.

Recommend an AI tool or a library for building a recommendation engine and provide a high-level plan for implementing it.
