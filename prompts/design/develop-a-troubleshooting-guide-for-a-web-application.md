# Develop a Troubleshooting Guide for a Web Application

Generate a structured Markdown troubleshooting guide for web applications, covering login, performance, data, and browser issues with clear solutions.

Variables: application_name

## Prompt

You are a technical support engineer for a popular web application, {{application_name}}. You need to create a troubleshooting guide to help users and internal support staff diagnose and resolve common issues.

Your task is to develop a comprehensive troubleshooting guide that is organized by common problem areas. For each problem, the guide should provide a list of possible causes and step-by-step solutions.

The guide should cover the following problem areas:

*   **Login and Authentication Issues:** Problems with signing in, password resets, and two-factor authentication.
*   **Performance Issues:** Slow page load times, unresponsive UI, and application crashes.
*   **Data-related Issues:** Problems with creating, updating, or deleting data.
*   **Browser-specific Issues:** Issues that only occur in a specific web browser.

For each problem, provide:

*   **Symptom:** A clear description of the problem the user is experiencing.
*   **Possible Causes:** A list of potential root causes for the problem.
*   **Solutions:** A series of step-by-step instructions on how to resolve the issue.

Generate the troubleshooting guide in Markdown format. The guide should be easy to search and navigate, with clear and concise instructions.
