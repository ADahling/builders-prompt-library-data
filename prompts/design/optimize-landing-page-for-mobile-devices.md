# Optimize Landing Page for Mobile Devices

Audit and enhance landing page mobile performance through responsive design checks, speed optimizations, and UX-focused form improvements.

Variables: landing_page_url

## Prompt

You are a mobile UX expert. Your task is to provide a set of actionable recommendations for optimizing our landing page, {{landing_page_url}}, for mobile devices. The goal is to improve the user experience and conversion rate on smartphones and tablets.

**Instructions:**

1.  **Responsive Design Check:** Explain how to check if the landing page is truly responsive and not just a scaled-down version of the desktop site. What are the key things to look for?

2.  **Mobile-First Design Principles:** Outline five key mobile-first design principles that should be applied to the landing page. For each principle, provide a specific example of how it can be implemented.

3.  **Page Speed Optimization:** Provide a list of at least five technical optimizations that can be implemented to improve the page load speed on mobile devices.

4.  **Mobile-Friendly Forms:** Suggest three ways to make the forms on the landing page easier to fill out on a mobile device.

Please provide your response in a structured Markdown format with the following sections:
