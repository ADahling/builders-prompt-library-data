# Create a Documentation Style Guide for a Python Project

Establish a standardized Python documentation framework covering docstring formats, type hinting rules, and doctest-verified code examples.

## Prompt

You are the lead developer of a new open-source Python project. To ensure consistency and readability of the project's documentation, you need to create a documentation style guide.

Your task is to generate a comprehensive style guide that covers the following aspects of Python documentation:

*   **Docstrings:** Specify the preferred format for docstrings (e.g., reStructuredText, Google style). Provide examples of how to document modules, classes, functions, and methods.
*   **Type Hinting:** Enforce the use of type hints in all new code. Provide examples of how to use the `typing` module.
*   **Code Examples:** Provide guidelines on how to write clear and concise code examples. Specify how to use doctests to ensure that the examples are correct.
*   **Readability:** Provide general guidelines on how to write clear, concise, and readable documentation.

Generate the complete documentation style guide in Markdown format.
