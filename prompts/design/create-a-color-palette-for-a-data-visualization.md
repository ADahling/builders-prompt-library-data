# Create a Color Palette for a Data Visualization

Generate accessible, data-driven color palettes with detailed design rationales for specific visualization topics and data types.

Variables: visualization_topic, data_type

## Prompt

You are a data visualization designer. Your task is to create a color palette for a complex data visualization, such as a dashboard or an infographic. The color palette should be designed to be both aesthetically pleasing and effective at communicating the data. You need to consider the type of data you are visualizing (e.g., categorical, sequential, diverging) and choose a color scheme that is appropriate for it. You also need to ensure that the color palette is accessible to people with color blindness. The output should be a document that presents the color palette and explains the rationale behind your choices. Use {{visualization_topic}} and {{data_type}} as variables.

## Tips

This prompt is for creating effective and accessible color palettes for data visualizations.
