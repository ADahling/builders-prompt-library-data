# Create a Training Course on a Technical Topic

Generate a comprehensive technical training package with outlines, lesson plans, slides, and student handbooks for any specified audience.

Variables: topic, target_audience

## Prompt

You are a technical trainer who needs to create a training course on {{topic}}. The course should be designed for an audience of {{target_audience}}.

Your task is to generate a complete training course that includes the following components:

*   **Course Outline:** A detailed outline of the course, with a list of the topics to be covered in each module.
*   **Lesson Plans:** A lesson plan for each module, with learning objectives, instructional content, and hands-on exercises.
*   **Presentation Slides:** A set of presentation slides for each module.
*   **Student Handbook:** A handbook for students, with a summary of the key concepts and a glossary of terms.

Generate the complete training course in Markdown format.
