# Design a Specific Page Layout

Design an app page for developer handoff with an exact layout, component behavior, empty and error states, interactions, and mobile adaptations.

## Prompt

Design the [page name: Dashboard / Settings / Pricing / Onboarding] page for my [app description]:

1. Purpose: What this page helps the user accomplish.
2. Layout: Exact layout. Header, sidebar, main content, footer. Grid structure.
3. Components: Every component (buttons, cards, tables, charts, forms, modals) with content and behavior.
4. States: Empty state, loading state, error state, populated state.
5. Interactions: What happens on click, hover, submit.
6. Mobile: How this adapts under 768px.

Be specific enough to hand directly to Lovable or a developer.

## Tips

Use for each page. Replace [page name] with your actual page.
