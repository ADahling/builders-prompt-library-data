# A/B Test Hero Section Copy for Conversion Rate Optimization

Generate a comprehensive CRO A/B test plan for landing page hero sections, including hypotheses, copy variations, and sample size metrics.

Variables: project_name, current_headline, current_sub_headline, baseline_conversion_rate, minimum_detectable_effect

## Prompt

As a senior conversion rate optimization (CRO) specialist, your task is to design a comprehensive A/B test for the hero section of our landing page for the project "{{project_name}}". Our primary goal is to increase the sign-up rate for our newsletter. The current headline is "{{current_headline}}" and the sub-headline is "{{current_sub_headline}}".

**Instructions:**

1.  **Formulate a Hypothesis:** Create a clear, testable hypothesis for the A/B test. The hypothesis should state what you believe the outcome of the test will be and why.

2.  **Create Variations:** Propose two alternative hero section copy variations (a headline and sub-headline for each). Each variation should be distinct from the original and from each other. Explain the psychological or marketing principle behind each variation (e.g., social proof, urgency, benefit-oriented).

3.  **Define Success Metrics:** Specify the primary and secondary metrics you will use to determine the winner of the A/B test. The primary metric must be the newsletter sign-up conversion rate. Secondary metrics could include click-through rate on the primary call-to-action (CTA), bounce rate, or time on page.

4.  **Determine Sample Size:** Using a baseline conversion rate of {{baseline_conversion_rate}}% and a desired minimum detectable effect of {{minimum_detectable_effect}}%, calculate the required sample size per variation to achieve statistical significance (95% confidence level).

5.  **Outline Implementation Plan:** Briefly describe the steps to implement this A/B test using a tool like Google Optimize, Optimizely, or VWO. Mention how you will ensure the test runs correctly and that the data is collected accurately.
