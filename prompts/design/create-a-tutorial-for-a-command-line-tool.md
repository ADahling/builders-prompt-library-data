# Create a Tutorial for a Command-Line Tool

Write a Markdown tutorial for a command-line tool, with installation steps, basic and advanced usage examples, and troubleshooting guidance.

Variables: tool_name, core_functionality, advanced_feature

## Prompt

You have developed a new command-line tool, {{tool_name}}, that helps developers automate a common task. You need to create a tutorial to teach users how to use the tool effectively.

Your task is to generate a step-by-step tutorial that walks users through the process of installing and using your tool. The tutorial should include:

*   **Introduction:** A brief overview of what the tool does and why it is useful.
*   **Installation:** Clear instructions on how to install the tool on different operating systems.
*   **Basic Usage:** A simple example that demonstrates the tool's core functionality.
*   **Advanced Usage:** Examples of how to use the tool's more advanced features and options.
*   **Troubleshooting:** A section that addresses common problems that users may encounter.

Here is some information about your tool:

*   **Tool Name:** {{tool_name}}
*   **Core Functionality:** {{core_functionality}}
*   **Advanced Feature:** {{advanced_feature}}

Generate the complete tutorial in Markdown format. The tutorial should be hands-on and easy to follow, with plenty of code examples.
