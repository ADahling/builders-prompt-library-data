# Create a Decision Matrix for AI Tool Selection

Compare AI tools in a decision matrix with 1-5 ratings for your chosen criteria, a findings summary, and three recommended tools.

Variables: criteria_list

## Prompt

Develop a decision matrix to assist in selecting AI tools based on essential criteria such as {{criteria_list}}. Rate each potential tool on a scale of 1-5 for each criterion and provide a summary of the findings. Use this matrix to recommend the top three tools.

## Tips

This systematic approach aids in making objective decisions.
