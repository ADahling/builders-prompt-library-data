# Use Empathy Mapping to Understand User Needs

Generate a structured empathy map to synthesize research data and uncover the core needs, thoughts, and feelings of a specific user persona.

Variables: user_persona, user_research_data

## Prompt

You are a UX researcher. Your task is to create an empathy map for a user, {{user_persona}}. An empathy map is a tool that helps you to understand a user's needs, thoughts, and feelings. You need to fill out the four quadrants of the empathy map: says, thinks, does, and feels. The output should be a completed empathy map. Use {{user_persona}} and {{user_research_data}} as variables.

## Tips

This is a beginner-friendly prompt for learning how to use empathy mapping to gain a deeper understanding of users.
