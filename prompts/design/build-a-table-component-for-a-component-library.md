# Build a Table Component for a Component Library

Generate a high-performance, feature-rich reusable table component with sorting, filtering, and pagination for any framework.

Variables: framework, table_props

## Prompt

You are a front-end developer. Your task is to build a reusable table component for a component library using {{framework}}. The table component should be designed to be powerful and flexible, with features such as sorting, filtering, and pagination. You should also consider the performance of the table, especially when dealing with large datasets. The output should be the complete code for the table component, along with documentation on how to use it. Use {{framework}} and {{table_props}} as variables.

## Tips

This is an advanced prompt for building a complex and powerful UI component: the data table.
