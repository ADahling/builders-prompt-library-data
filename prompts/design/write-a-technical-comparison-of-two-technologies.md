# Write a Technical Comparison of Two Technologies

Generate a structured Markdown report comparing two technologies across features, performance, and scalability to inform architectural decisions.

Variables: technology_1, technology_2

## Prompt

You are a software architect who needs to choose between two technologies, {{technology_1}} and {{technology_2}}, for a new project. You need to write a technical comparison of the two technologies to help you make a decision.

Your task is to generate a comprehensive technical comparison that includes the following sections:

*   **Overview:** A brief overview of each technology.
*   **Features:** A comparison of the features of each technology.
*   **Performance:** A comparison of the performance of each technology.
*   **Scalability:** A comparison of the scalability of each technology.
*   **Community:** A comparison of the community support for each technology.
*   **Cost:** A comparison of the cost of each technology.

Generate the complete technical comparison in Markdown format.
