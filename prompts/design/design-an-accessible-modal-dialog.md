# Design an Accessible Modal Dialog

Create a high-fidelity, screen-reader-ready modal mockup featuring keyboard focus trapping and accessible ARIA labeling.

Variables: dialog_purpose, dialog_content

## Prompt

You are a UI designer. Your task is to design a modal dialog that is accessible to people with disabilities. The modal dialog should be designed to be easy to use with a keyboard and a screen reader. You need to ensure that the focus is trapped within the dialog when it is open, and that the dialog can be closed by pressing the escape key. You should also provide a clear and descriptive title for the dialog. The output should be a high-fidelity mockup of the accessible modal dialog. Use {{dialog_purpose}} and {{dialog_content}} as variables.

## Tips

This prompt is for designing a common and important UI component: the modal dialog.
