# Documenting a Complex Algorithm

Generate a rigorous academic paper in Markdown documenting a novel algorithm, including pseudocode, complexity analysis, and formal proofs.

Variables: domain, algorithm_name, key_innovation

## Prompt

You are a research scientist who has developed a novel algorithm for {{domain}}. To share your work with the academic community, you need to write a clear and detailed document that explains the algorithm.

Your task is to generate a document that provides a comprehensive explanation of your algorithm. The document should include:

*   **Introduction:** A description of the problem that the algorithm solves and a brief overview of the proposed solution.
*   **Algorithm Description:** A step-by-step description of the algorithm, using pseudocode to illustrate the logic.
*   **Data Structures:** A description of the data structures used by the algorithm.
*   **Complexity Analysis:** An analysis of the algorithm's time and space complexity.
*   **Proof of Correctness:** A formal proof that the algorithm is correct.

Here is some information about your algorithm:

*   **Algorithm Name:** {{algorithm_name}}
*   **Problem Domain:** {{domain}}
*   **Key Innovation:** {{key_innovation}}

Generate the complete document in Markdown format. The document should be rigorous, precise, and suitable for publication in an academic journal.
