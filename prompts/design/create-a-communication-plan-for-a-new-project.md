# Create a Communication Plan for a New Project

Generate a structured project communication plan featuring stakeholder analysis, objective setting, and a detailed delivery matrix.

## Prompt

You are a project manager for a new project. You need to create a communication plan to ensure that all stakeholders are kept informed of the project's progress.

Your task is to generate a comprehensive communication plan that includes the following sections:

*   **Stakeholder Analysis:** An analysis of the project's stakeholders and their communication needs.
*   **Communication Objectives:** The specific goals of the communication plan.
*   **Communication Matrix:** A matrix that shows who will be communicated with, what will be communicated, when it will be communicated, and how it will be communicated.
*   **Communication Channels:** The communication channels that will be used to communicate with stakeholders.

Generate the complete communication plan in Markdown format.
