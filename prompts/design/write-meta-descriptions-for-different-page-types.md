# Write Meta Descriptions for Different Page Types

Generate SEO-optimized, high-CTR meta descriptions for blog posts, product pages, and homepages within character limits for improved search visibility.

Variables: blog_post_title, blog_post_topic, product_name, product_benefit, company_name, value_proposition

## Prompt

You are an SEO copywriter. Your task is to write meta descriptions for three different types of pages on our website: a blog post, a product page, and a homepage.

**Instructions:**

For each page type, write a compelling meta description that is between 150 and 160 characters. The meta description should be unique for each page and optimized for click-through rate (CTR).

*   **Blog Post:** The blog post is titled "{{blog_post_title}}" and is about {{blog_post_topic}}.
*   **Product Page:** The product is {{product_name}} and its main benefit is {{product_benefit}}.
*   **Homepage:** The company is {{company_name}} and our main value proposition is {{value_proposition}}.

**Output Format:**

Please provide your response in a structured Markdown format, with a separate section for each page type.
