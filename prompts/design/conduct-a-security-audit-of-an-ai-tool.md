# Conduct a Security Audit of an AI Tool

Evaluate an AI tool’s security posture through a targeted audit checklist covering data privacy, access controls, and vulnerability testing.

Variables: tool_name, specific_security_concern

## Prompt

You are a cybersecurity expert specializing in AI. I need to conduct a security audit of {{tool_name}} before my company can approve its use. We are particularly concerned about {{specific_security_concern}}.

Provide a checklist of security aspects to investigate. The checklist should cover data privacy, access control, and vulnerability management. For each item, suggest specific questions to ask the vendor or tests to perform.

## Tips

A prompt for security professionals who need to assess the security posture of an AI tool.
