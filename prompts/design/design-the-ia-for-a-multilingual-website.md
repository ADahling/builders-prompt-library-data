# Design the IA for a multilingual website

Generate a multilingual sitemap and architectural report that optimizes navigation, cross-language UX, and cultural localization.

Variables: website_name, supported_languages

## Prompt

You are an information architect. Your task is to design the information architecture (IA) for a multilingual website, {{website_name}}. You need to consider how to organize the content for different languages and how to provide a seamless user experience for users who switch between languages. You should also consider the cultural differences between the different target audiences. The output should be a sitemap for the multilingual website, along with a report that explains the rationale behind your decisions. Use {{website_name}} and {{supported_languages}} as variables.

## Tips

This is an advanced prompt for designing the information architecture for a multilingual website, which has its own unique challenges and considerations.
