# Test the Responsiveness of a Website

Generate a detailed bug report identifying layout and functional issues across diverse screen sizes using specified testing tools.

Variables: website_url, testing_tools

## Prompt

You are a QA tester. Your task is to test the responsiveness of a website, {{website_url}}. You need to use a variety of tools, such as your browser's developer tools and online responsive design checkers, to test the website on a wide range of screen sizes and devices. You should check for layout issues, such as overlapping elements or horizontal scrolling, and also test the functionality of the website on different devices. The output should be a detailed bug report that lists all the responsive issues you found, with screenshots and steps to reproduce them. Use {{website_url}} and {{testing_tools}} as variables.

## Tips

This is a beginner-friendly prompt for learning how to test the responsiveness of a website.
