# Wireframe a User Onboarding Flow for a Complex Application

Generate a structured UX onboarding sequence for complex platforms to simplify data integration, reduce churn, and accelerate feature adoption.

Variables: platform_name, onboarding_steps

## Prompt

You are a UX strategist. Design a comprehensive user onboarding flow through a series of wireframes for a complex financial analytics platform, {{platform_name}}. The onboarding must be educational and interactive, guiding users through the initial setup of their account, connecting their financial data sources, and understanding the core features of the platform. The flow should consist of at least 5 screens, including a welcome screen, a multi-step setup process, and a final confirmation screen that launches the user into the main application. For each wireframe, describe the key interactions and the information that needs to be communicated to the user. The output should be a sequence of wireframe descriptions, detailing the purpose of each screen and its UI elements. The goal is to reduce cognitive load and prevent user drop-off during this critical phase. Use {{platform_name}} and {{onboarding_steps}} as variables.

## Tips

This prompt focuses on creating an effective onboarding experience, which is crucial for user retention in complex applications.
