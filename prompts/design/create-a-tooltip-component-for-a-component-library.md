# Create a Tooltip Component for a Component Library

Build a reusable, accessible tooltip component for a UI library with customizable positioning and dual-trigger support for hover and focus.

Variables: framework, tooltip_props

## Prompt

You are a front-end developer. Your task is to create a reusable tooltip component for a component library using {{framework}}. The tooltip component should be designed to be lightweight and easy to use. You should include support for different positions, such as top, bottom, left, and right. You should also consider the accessibility of the tooltip, such as making sure that it can be triggered by both hover and focus. The output should be the complete code for the tooltip component, along with documentation on how to use it. Use {{framework}} and {{tooltip_props}} as variables.

## Tips

This is a beginner-friendly prompt for building a common and useful UI component: the tooltip.
