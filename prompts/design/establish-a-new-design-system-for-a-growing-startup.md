# Establish a New Design System for a Growing Startup

Generate a comprehensive design system document including principles, brand assets, and reusable framework-specific UI component code.

Variables: startup_name, preferred_framework

## Prompt

You are the founding designer of a rapidly growing startup, {{startup_name}}. Your task is to establish a new design system from scratch. This design system will be the single source of truth for all UI/UX design and front-end development. You need to define the design principles, create a comprehensive color palette, choose a typographic scale, and design a set of foundational UI components (e.g., buttons, forms, cards). The output should be a detailed document outlining the initial version of the design system, including code snippets for the components in {{preferred_framework}}. Use {{startup_name}} and {{preferred_framework}} as variables.

## Tips

This is a challenging but rewarding prompt for experienced designers who want to build a design system from the ground up.
