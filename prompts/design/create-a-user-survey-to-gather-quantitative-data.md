# Create a User Survey to Gather Quantitative Data

Generate a concise, metric-driven user experience survey to collect actionable quantitative data for any specific website or product.

Variables: website_url, survey_goals

## Prompt

You are a UX researcher. Your task is to create a user survey to gather quantitative data about the user experience of an existing website, {{website_url}}. The survey should be designed to be short, easy to understand, and engaging. You need to write a set of questions that measure user satisfaction, ease of use, and other relevant metrics. The output should be the user survey, ready to be distributed to users. Use {{website_url}} and {{survey_goals}} as variables.

## Tips

This prompt is for learning how to create a user survey to gather quantitative data about the user experience.
