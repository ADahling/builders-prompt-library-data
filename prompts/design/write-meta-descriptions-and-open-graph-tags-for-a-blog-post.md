# Write Meta Descriptions and Open Graph Tags for a Blog Post

Generate SEO-optimized meta descriptions and Open Graph tags to improve search visibility and social media engagement for blog content.

Variables: blog_post_title, blog_post_topic, target_keyword

## Prompt

You are an SEO and social media expert. Your task is to write a compelling meta description and create Open Graph tags for our latest blog post, titled "{{blog_post_title}}". The blog post is about {{blog_post_topic}} and the target keyword is "{{target_keyword}}".

**Instructions:**

1.  **Write the Meta Description:** Write a meta description that is between 150 and 160 characters. It should be engaging, include the target keyword, and entice users to click on the search result.

2.  **Create Open Graph Tags:** Create the following Open Graph tags for the blog post:
    *   `og:title`: The title of the blog post as it should appear on social media.
    *   `og:description`: A description of the blog post for social media (can be the same as the meta description or a variation).
    *   `og:image`: A placeholder for the URL of the image that should be displayed when the blog post is shared on social media.
    *   `og:url`: The canonical URL of the blog post.
    *   `og:type`: The type of content (in this case, "article").

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **Meta Description:**
*   **Open Graph Tags:**
