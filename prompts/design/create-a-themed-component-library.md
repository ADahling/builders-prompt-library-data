# Create a Themed Component Library

Build a customizable, themed component library with design tokens and an override mechanism using a specific framework and CSS-in-JS tool.

Variables: framework, theming_library

## Prompt

You are a front-end developer. Your task is to create a themed component library using {{framework}} and a CSS-in-JS library, such as styled-components or Emotion. The component library should be designed to be easily themable, so that it can be used in a variety of different projects with different visual styles. You need to create a set of design tokens for the default theme, and then create a mechanism for overriding the tokens to create new themes. The output should be the complete code for the themed component library, along with documentation on how to create new themes. Use {{framework}} and {{theming_library}} as variables.

## Tips

This is an advanced prompt for creating a themed component library, which is a powerful way to build flexible and reusable UIs.
