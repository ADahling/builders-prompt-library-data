# Create a Set of Guidelines for Writing Secure Code

Generate comprehensive security guidelines covering input validation, authentication, and cryptography to ensure resilient software development.

## Prompt

You are a security champion for your team. You need to create a set of guidelines to help your team write more secure code.

Your task is to generate a set of guidelines that covers the following topics:

*   **Input validation:** How to validate user input to prevent injection attacks.
*   **Output encoding:** How to encode output to prevent cross-site scripting (XSS) attacks.
*   **Authentication and authorization:** How to implement secure authentication and authorization.
*   **Cryptography:** How to use cryptography to protect sensitive data.
*   **Error handling and logging:** How to handle errors and log security events.

Generate the complete set of guidelines in Markdown format.
