# Design the Interaction for a Search Autocomplete Feature

Design intuitive search autocomplete interactions and high-fidelity mockups to enhance e-commerce product discovery and navigation.

Variables: website_name, search_query_examples

## Prompt

You are an interaction designer. Your task is to design the interaction for a search autocomplete feature for an e-commerce website, {{website_name}}. The feature should provide users with a list of suggested search queries as they type in the search bar. You need to design the visual appearance of the suggestions, as well as the interaction for selecting a suggestion. You should also consider how to handle cases where there are no suggestions available. The output should be a set of high-fidelity mockups that show the design of the search autocomplete feature. Use {{website_name}} and {{search_query_examples}} as variables.

## Tips

This prompt is for designing a common and important feature for e-commerce websites.
