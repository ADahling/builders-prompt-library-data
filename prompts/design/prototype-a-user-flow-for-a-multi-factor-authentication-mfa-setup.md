# Prototype a User Flow for a Multi-Factor Authentication (MFA) Setup

Design a secure and user-friendly multi-factor authentication setup flow with a functional prototype and usability documentation.

Variables: app_name, mfa_methods

## Prompt

You are a security-conscious UX designer. Your task is to prototype the user flow for setting up multi-factor authentication (MFA) for a web application, {{app_name}}. The prototype should guide the user through the process of enabling MFA, choosing an authentication method (e.g., SMS, authenticator app), and verifying their identity. The design should be clear, concise, and reassuring, as security-related tasks can be intimidating for some users. The output should be a clickable prototype of the MFA setup flow and a document explaining how you have addressed potential usability issues. Use {{app_name}} and {{mfa_methods}} as variables.

## Tips

This prompt focuses on designing a secure and user-friendly authentication experience, which is a critical aspect of modern web applications.
