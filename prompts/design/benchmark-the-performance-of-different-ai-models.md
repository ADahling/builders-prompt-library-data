# Benchmark the Performance of Different AI Models

Design and execute a benchmarking experiment to compare the accuracy, latency, and cost of multiple AI models for a specific task and dataset.

Variables: model_list, task_description, dataset_description

## Prompt

You are a machine learning engineer. I need to benchmark the performance of different AI models, such as {{model_list}}, for a specific task: {{task_description}}. The dataset I will be using is {{dataset_description}}.

Design a benchmarking experiment that measures the accuracy, speed, and cost of each model. Provide the code or the steps to run the experiment and a template for presenting the results.

## Tips

A prompt for technical users who want to compare the performance of different AI models for a specific task.
