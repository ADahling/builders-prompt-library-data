# Write a Pillar Page and Topic Cluster Content Strategy

Generate a comprehensive pillar page, identify high-ranking sub-topic clusters, and produce detailed blog content to boost domain authority.

Variables: topic

## Prompt

You are an SEO strategist. Your task is to create a pillar page and topic cluster content strategy to improve our website's authority and search engine rankings for the topic of {{topic}}.

**Instructions:**

1.  **Create the Pillar Page:** Write a 3,000-word pillar page that provides a comprehensive overview of the main topic. The pillar page should be well-structured, easy to read, and link out to more specific cluster content.

2.  **Identify the Topic Clusters:** Identify 5-7 sub-topics (topic clusters) that are related to the main topic. For each topic cluster, brainstorm a blog post idea.

3.  **Create the Content for a Topic Cluster:** For one of the topic clusters, write a 1,500-word blog post that provides a deep dive into that specific sub-topic. The blog post should link back to the pillar page.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **Pillar Page and Topic Cluster Strategy**
    *   **Pillar Page Content:**
    *   **Topic Cluster Ideas:**
    *   **Sample Topic Cluster Blog Post:**
