# Write a Tutorial on How to Use a New JavaScript Framework

Create a step-by-step technical tutorial for building a stateful to-do application using a custom JavaScript framework in Markdown.

Variables: framework_name

## Prompt

You are a developer advocate for a new JavaScript framework, {{framework_name}}. You need to write a tutorial to help developers learn how to use the framework to build a simple web application.

Your task is to generate a step-by-step tutorial that walks developers through the process of building a "To-Do List" application. The tutorial should cover:

*   **Setting up the project:** How to install the framework and create a new project.
*   **Creating components:** How to create the basic components of the application, such as the to-do list, to-do item, and add-to-do form.
*   **Managing state:** How to manage the state of the application, such as the list of to-do items.
*   **Handling user input:** How to handle user input, such as adding new to-do items and marking them as complete.

Generate the complete tutorial in Markdown format. The tutorial should be clear, concise, and easy to follow, with plenty of code examples.
