# SaaS Landing Page Conversion Optimizer

Generate high-converting landing page copy and A/B test strategies to maximize SaaS signups and optimize user acquisition funnels.

Variables: product_name, product_type, target_audience, current_page_description

## Prompt

You are a conversion rate optimization expert. Analyze and optimize the landing page for {{product_name}}, a {{product_type}} targeting {{target_audience}}.

Current landing page elements:
{{current_page_description}}

Optimize:
1. **Hero Section**: Headline formula (Problem -> Solution -> Benefit), subheadline, CTA button text and color
2. **Social Proof**: Where to place testimonials, logos, stats for maximum impact
3. **Feature Presentation**: Benefits over features, use cases over specifications
4. **Objection Handling**: FAQ section addressing the top 5 buying objections
5. **CTA Strategy**: Primary and secondary CTAs, placement frequency, urgency elements
6. **Trust Signals**: Security badges, guarantees, team photos, press mentions
7. **Mobile Optimization**: Thumb-zone CTA placement, content prioritization
8. **A/B Test Plan**: 5 highest-impact tests to run first, with hypothesis and success metrics

Provide the actual copy for each section, not just recommendations.

## Tips

Most SaaS landing pages convert at 2-5%. This prompt targets 8-12% conversion rates.
