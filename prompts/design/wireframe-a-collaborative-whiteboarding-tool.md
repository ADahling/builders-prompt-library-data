# Wireframe a Collaborative Whiteboarding Tool

Generate a structured wireframe layout and information architecture for a multi-user real-time collaborative whiteboarding interface.

Variables: tool_name, collaboration_features

## Prompt

You are a product designer working on a new collaborative whiteboarding tool, {{tool_name}}. Your task is to create a detailed wireframe for the main whiteboarding interface. The wireframe needs to accommodate multiple users working in real-time and should include a variety of tools, such as a pen tool, a sticky note tool, a shape tool, and a text tool. The design must also consider the user interface for managing collaboration, such as showing who is currently active on the board, a chat feature, and version history. The output should be a comprehensive description of the wireframe, detailing the layout of the tools, the real-time collaboration features, and the overall information architecture of the interface. Use {{tool_name}} and {{collaboration_features}} as variables.

## Tips

This is an advanced prompt for designing complex, real-time collaborative applications that require careful consideration of user interactions and state management.
