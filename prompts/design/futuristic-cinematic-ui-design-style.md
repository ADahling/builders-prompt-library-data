# Futuristic & Cinematic UI Design Style

Design an app page with a cinematic sci-fi style using dark colors, neon accents, HUD layouts, glowing cards, and animated charts.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a futuristic and cinematic visual style. Apply these design principles:

**Color Palette**: Dark backgrounds (#0a0a0f to #1a1a2e) with neon accents — cyan (#00f0ff), magenta (#ff00ff), or electric green (#00ff88). Use color as light source.
**Typography**: Use geometric sans-serifs or monospaced fonts. Add subtle glow effects to headings. Use small-caps for labels.
**Layout**: Use HUD-style layouts with thin border frames, corner brackets, and scan-line overlays. Data should feel like a command center.
**Effects**: Add subtle particle backgrounds, grid overlays, gradient mesh blurs, and animated border gradients.
**Cards**: Use transparent cards with neon border-glow, backdrop-blur, and subtle noise texture.
**Data Visualization**: Use glowing line charts, radar charts, and circular progress indicators with animated fills.

Key vocabulary: neon, glow, HUD, cyberpunk, holographic, matrix, terminal, cinematic, dark-mode.

The design should feel like a sci-fi movie interface — immersive, data-rich, and visually stunning.
