# Build an AI-Powered Fact-Checking System

Architect a specialized AI system to detect and debunk misinformation by integrating automated claim extraction with credible evidence retrieval.

Variables: topic

## Prompt

You are a journalist and technologist. I want to build an AI-powered system to automatically fact-check news articles and social media posts. The system should be able to identify false or misleading information and provide links to credible sources. The system will focus on the topic of {{topic}}.

Design the architecture for the fact-checking system. The design should include the data sources for claims and evidence, the natural language processing models for claim detection and stance detection, and the user interface for presenting the fact-checking results.
