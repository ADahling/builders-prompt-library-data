# Build a Personalized Learning Platform with AI

Architect a personalized AI learning platform featuring adaptive content engines, tailored assessment systems, and progress tracking tools.

Variables: subject, grade_level

## Prompt

You are an educational technologist. I want to build a personalized learning platform that uses AI to create customized learning paths for students. The platform will cover the subject of {{subject}} for students in {{grade_level}}.

Design the core features of the personalized learning platform. The design should include the content recommendation engine, the adaptive assessment system, and the student progress tracking dashboard.
