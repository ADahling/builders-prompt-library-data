# Write a Chatbot Script for Customer Support

Draft a structured customer support chatbot script featuring automated FAQ responses, navigational menus, and seamless human agent handoffs.

## Prompt

You are a conversational designer and chatbot specialist. Your task is to write a script for a customer support chatbot for our website. The chatbot should be able to answer frequently asked questions (FAQs) and escalate more complex issues to a human agent.

**Instructions:**

1.  **Create a Welcome Message:** Write a friendly and helpful welcome message that the chatbot will display to users when they first interact with it.

2.  **Design a Main Menu:** Design a main menu with a few options to guide the user to the information they are looking for (e.g., "Track my order", "Returns and exchanges", "Contact support").

3.  **Write a Script for a Common FAQ:** Choose a common FAQ for our business (e.g., "What is your shipping policy?") and write the chatbot's response. The response should be clear, concise, and helpful.

4.  **Design the Escalation Path:** How will the chatbot hand over the conversation to a human agent when it is unable to answer a question? Write the script for the handover message.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **Chatbot Script**
    *   **Welcome Message:**
    *   **Main Menu:**
    *   **FAQ Script:**
    *   **Escalation Path:**
