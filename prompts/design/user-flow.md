# Design a user flow

Design a persona-specific workflow with entry points, decisions, feedback and recovery states, a screen inventory, and usability risks.

## Prompt

Design the user flow for {{workflow}} used by {{persona}}. Map entry points, decisions, system feedback, empty, loading, success, error, permission, and recovery states. Finish with screen inventory and usability risks.
