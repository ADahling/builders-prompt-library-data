# Build a Reusable Button Component for a Component Library

Generate a customizable, production-ready button component with support for sizes, variants, icons, and loading states in your chosen framework.

Variables: framework, button_props

## Prompt

You are a front-end developer. Your task is to build a reusable button component for a component library using {{framework}}. The button component should be highly customizable, with props for controlling its size, color, and variant (e.g., primary, secondary, tertiary). You should also include support for icons and loading states. The output should be the complete code for the button component, along with documentation on how to use it. Use {{framework}} and {{button_props}} as variables.

## Tips

This is a beginner-friendly prompt for learning how to build a reusable component for a component library.
