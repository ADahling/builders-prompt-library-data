# Write a Technical Due Diligence Report for an Acquisition

Generate a comprehensive technical due diligence report in Markdown to evaluate software architecture, code quality, and acquisition risks.

## Prompt

You are a consultant who has been hired to conduct a technical due diligence assessment of a company that is being acquired. You need to write a report to present your findings to the acquiring company.

Your task is to generate a comprehensive technical due diligence report that includes the following sections:

*   **Executive Summary:** A high-level overview of the key findings and recommendations.
*   **Technology Stack:** An analysis of the company's technology stack.
*   **Software Architecture:** An analysis of the company's software architecture.
*   **Code Quality:** An analysis of the quality of the company's code.
*   **Technical Team:** An assessment of the company's technical team.
*   **Technical Risks:** The technical risks associated with the acquisition.

Generate the complete technical due diligence report in Markdown format.
