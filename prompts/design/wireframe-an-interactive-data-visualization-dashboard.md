# Wireframe an Interactive Data Visualization Dashboard

Architect a detailed wireframe for a marketing dashboard focusing on interactive data behaviors, custom layouts, and cross-chart filtering.

Variables: tool_name, chart_types

## Prompt

You are a data visualization specialist. Your task is to design a wireframe for an interactive dashboard for a marketing analytics tool, {{tool_name}}. The dashboard will display real-time data on website traffic, user engagement, and conversion rates. The wireframe should include at least three different types of charts (e.g., line chart, bar chart, pie chart), a date range selector, and filter options for drilling down into the data. The key challenge is to design the interactions for the dashboard, such as how users can hover over data points to see more details, click on chart elements to filter the entire dashboard, and customize the layout of the dashboard. The output should be a detailed description of the wireframe, with a strong focus on the interactive elements and their behavior. Use {{tool_name}} and {{chart_types}} as variables.

## Tips

This advanced prompt is for designing complex, interactive dashboards that allow users to explore and understand data effectively.
