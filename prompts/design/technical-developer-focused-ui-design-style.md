# Technical & Developer-Focused UI Design Style

Design a developer-focused app page with dark colors, dense layouts, code blocks, tables, and terminal elements for an IDE-like interface.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a technical and developer-focused visual style. Apply these design principles:

**Color Palette**: Dark mode default. Use syntax-highlighting inspired colors — green for success, red for errors, yellow for warnings, blue for info. Background: #0d1117 to #1e1e2e.
**Typography**: Use a monospaced font (JetBrains Mono, Fira Code) for code and data. Pair with a clean sans-serif (Inter, SF Pro) for UI text.
**Layout**: Use dense, information-rich layouts. Split panes, resizable panels, and tabbed interfaces. Maximize data density without clutter.
**Code Blocks**: Use syntax-highlighted code blocks with line numbers, copy buttons, and language badges. Support light/dark themes.
**Tables**: Use striped rows, sortable columns, and fixed headers. Monospaced numbers for alignment.
**Terminal Elements**: Include terminal-style elements — command prompts, log outputs, and status indicators with blinking cursors.

Key vocabulary: terminal, monospace, syntax, dark-mode, dense, technical, IDE, dashboard, data-rich.

The design should feel like a professional IDE — powerful, efficient, and built for people who think in code.
