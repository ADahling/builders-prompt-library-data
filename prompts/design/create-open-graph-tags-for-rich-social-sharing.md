# Create Open Graph Tags for Rich Social Sharing

Generate a complete set of SEO-optimized HTML Open Graph tags to ensure consistent and high-quality link previews across social media platforms.

Variables: blog_post_title, blog_post_url, image_url, blog_post_description, site_name

## Prompt

You are a social media and SEO specialist. Your task is to create a complete set of Open Graph tags for a piece of content to ensure it is shared beautifully on social media platforms like Facebook, Twitter, and LinkedIn.

**Instructions:**

Create the Open Graph tags for a blog post with the following details:

*   **Title:** {{blog_post_title}}
*   **URL:** {{blog_post_url}}
*   **Image URL:** {{image_url}}
*   **Description:** {{blog_post_description}}
*   **Site Name:** {{site_name}}

**Output Format:**

Please provide the complete set of Open Graph tags in HTML format. You should include the following tags: `og:title`, `og:type`, `og:url`, `og:image`, `og:description`, and `og:site_name`.

## Tips

This prompt helps users create the necessary Open Graph tags to control how their content appears when shared on social media.
