# Documenting Third-Party Dependencies

Write third-party dependency documentation for a project, including versions, licenses, how dependencies are used, and update procedures.

Variables: project_name

## Prompt

Create a detailed documentation for all third-party dependencies in {{project_name}}. Include version numbers, licensing information, and how each dependency is used within the project. Explain the process for updating dependencies.

## Tips

Maintain transparency with your development stack.
