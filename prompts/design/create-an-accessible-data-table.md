# Create an Accessible Data Table

Generate accessible HTML data tables using semantic markup and descriptive captions to ensure screen reader compatibility and UX compliance.

Variables: table_data, table_caption

## Prompt

You are a UX/UI designer. Your task is to create a data table that is accessible to people with disabilities. The data table should be designed to be easy to read and understand with a screen reader. You need to use proper HTML markup to associate the table headers with the table cells. You should also provide a caption for the table that describes its content. The output should be the HTML code for the accessible data table. Use {{table_data}} and {{table_caption}} as variables.

## Tips

This is an advanced prompt for designing a common but challenging UI component: the data table.
