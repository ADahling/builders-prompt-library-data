# Test the Readability of a Website in Dark Mode

Audit a website's dark mode across multiple devices to identify and document contrast, blurriness, and legibility issues in a bug report.

Variables: website_url, testing_devices

## Prompt

You are a QA tester. Your task is to test the readability of a website, {{website_url}}, in dark mode. You need to check for issues such as low contrast text, blurry text, and eye strain. You should also test the website on a variety of different devices and screen resolutions. The output should be a detailed bug report that lists all the readability issues you found, with screenshots and steps to reproduce them. Use {{website_url}} and {{testing_devices}} as variables.

## Tips

This is a beginner-friendly prompt for learning how to test the readability of a website in dark mode.
