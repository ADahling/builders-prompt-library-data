# Write a Financial Report for a Company

Write a quarterly board report in Markdown with an executive summary, financial statements, key ratios, and budget variance analysis.

## Prompt

You are a financial analyst for a company. You need to write a quarterly financial report to present the company's financial performance to the board of directors.

Your task is to generate a comprehensive financial report that includes the following sections:

*   **Executive Summary:** A high-level overview of the company's financial performance.
*   **Income Statement:** The company's income statement for the quarter.
*   **Balance Sheet:** The company's balance sheet for the quarter.
*   **Cash Flow Statement:** The company's cash flow statement for the quarter.
*   **Financial Ratios:** An analysis of key financial ratios.
*   **Variance Analysis:** An analysis of the variance between the actual financial results and the budget.

Generate the complete financial report in Markdown format.
