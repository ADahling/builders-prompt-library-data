# Calm & Elegant UI Design Style

Design an app page with muted colors, serif headings, spacious single-column layouts, soft imagery, and gentle interactions for a calm feel.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a calm and elegant visual style. Apply these design principles:

**Color Palette**: Use soft, muted tones — sage green, dusty rose, warm beige, soft lavender. No pure black — use dark charcoal (#2d2d2d) instead.
**Typography**: Use a serif font for headings (editorial feel) paired with a clean sans-serif for body text. Generous line-height (1.6-1.8).
**Layout**: Use centered, single-column layouts with maximum content width of 720px. Generous vertical spacing between sections.
**Imagery**: Use soft, natural photography with rounded corners. Muted color overlays on images.
**Cards & Containers**: Use subtle borders (1px, light gray), large border-radius (12-16px), and soft shadows (0 4px 24px rgba(0,0,0,0.06)).
**Interactions**: Use gentle fade transitions, smooth scroll, and understated hover states (opacity change, not color change).

Key vocabulary: serene, gentle, organic, breathable, warm, soft, natural, mindful.

The design should feel like a deep breath — calming, spacious, and intentionally slow.
