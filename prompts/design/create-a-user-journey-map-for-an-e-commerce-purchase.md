# Create a User Journey Map for an E-commerce Purchase

Generate a detailed end-to-end user journey map identifying touchpoints, pain points, and emotional states for a specific e-commerce persona.

Variables: website_name, customer_persona

## Prompt

You are a UX designer. Your task is to create a user journey map for a customer purchasing a product from an e-commerce website, {{website_name}}. The journey should cover all the stages from initial awareness to post-purchase evaluation. You need to identify the user's goals, actions, thoughts, and feelings at each stage of the journey. You should also identify the touchpoints the user has with the website and any pain points they might experience. The output should be a detailed user journey map visualization. Use {{website_name}} and {{customer_persona}} as variables.

## Tips

This prompt is for creating a comprehensive user journey map for a common user scenario.
