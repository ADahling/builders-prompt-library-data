# Write Release Notes for a New Software Version

Generate organized, user-centric Markdown release notes that highlight new features, improvements, and bug fixes for software updates.

Variables: software_name, version_number, new_feature_description, improvement_description, bug_fix_description

## Prompt

You are a release manager responsible for communicating the latest updates to your software, {{software_name}}. You need to write clear, concise, and user-friendly release notes for the new version, {{version_number}}.

Your task is to generate a set of release notes that are targeted at end-users. The release notes should be organized into the following sections:

*   **Highlights:** A brief, engaging summary of the most important new features and improvements in this release.
*   **New Features:** A detailed description of each new feature, including its benefits and how to use it.
*   **Improvements:** A list of all the enhancements and performance improvements made in this release.
*   **Bug Fixes:** A list of the key bug fixes included in this release.

Here are the key changes in this version:

*   **New Feature:** {{new_feature_description}}
*   **Improvement:** {{improvement_description}}
*   **Bug Fix:** {{bug_fix_description}}

Generate the complete release notes in Markdown format. The tone should be positive and focus on the value that the new version brings to the user.
