# Create a Content Migration Plan for a Website Redesign

Generate a structured Markdown content migration plan covering inventory, auditing, mapping, and validation to ensure a seamless website transition.

## Prompt

You are a project manager for a website redesign project. You need to create a content migration plan to ensure that all of the content from the old website is migrated to the new website correctly.

Your task is to generate a comprehensive content migration plan that includes the following sections:

*   **Content Inventory:** A list of all of the content on the old website.
*   **Content Audit:** An analysis of the quality and relevance of the content.
*   **Content Mapping:** A mapping of the content from the old website to the new website.
*   **Content Migration Process:** The step-by-step process for migrating the content.
*   **Content Validation:** A plan for validating the migrated content.

Generate the complete content migration plan in Markdown format.
