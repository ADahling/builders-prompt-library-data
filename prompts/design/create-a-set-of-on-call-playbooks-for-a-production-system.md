# Create a Set of On-Call Playbooks for a Production System

Generate standardized Markdown playbooks for diagnosing and mitigating high CPU, memory, and disk latency incidents in production systems.

## Prompt

You are a site reliability engineer (SRE) for a production system. You need to create a set of on-call playbooks to help your team respond to common production incidents.

Your task is to generate a set of three on-call playbooks for the following incidents:

*   **High CPU utilization.**
*   **High memory utilization.**
*   **High disk latency.**

For each playbook, you should provide a step-by-step guide on how to diagnose and mitigate the incident.

Generate the complete set of on-call playbooks in Markdown format.
