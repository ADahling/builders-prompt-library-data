# Create a Set of Templates for Common Project Documents

Generate a standardized suite of Markdown templates for core project management documentation to ensure consistent reporting and planning.

## Prompt

You are a project manager who wants to improve the consistency and quality of your project documentation. You need to create a set of templates for common project documents.

Your task is to generate a set of templates for the following documents:

*   Project charter.
*   Project plan.
*   Status report.
*   Risk register.
*   Lessons learned.

For each template, you should provide a brief description of the document and a list of the sections that should be included.

Generate the complete set of templates in Markdown format.
