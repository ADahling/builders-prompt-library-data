# Create a Set of Coding Challenges for a Programming Competition

Generate a tiered set of competitive programming problems with clear statements, I/O formats, and sample test cases in Markdown.

## Prompt

You are organizing a programming competition for students. You need to create a set of coding challenges to test their problem-solving and programming skills.

Your task is to generate a set of three coding challenges of varying difficulty (easy, medium, and hard). For each challenge, you should provide:

*   **Problem Statement:** A clear and concise description of the problem.
*   **Input and Output Format:** A description of the input and output format.
*   **Sample Input and Output:** A sample input and output to help the students understand the problem.

Generate the complete set of coding challenges in Markdown format.
