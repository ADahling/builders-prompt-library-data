# Map the User Journey for a SaaS Onboarding Process

Visualize a comprehensive SaaS onboarding lifecycle to identify friction points and optimize the path to first-time value for specific personas.

Variables: product_name, user_persona

## Prompt

You are a product manager for a SaaS company. Your task is to map the user journey for a new user onboarding to your product, {{product_name}}. The journey should start from the moment the user signs up for a free trial and end when they have successfully set up their account and experienced the core value of the product. You need to identify the user's goals, actions, and emotions at each step of the onboarding process. The output should be a user journey map that highlights opportunities to improve the onboarding experience. Use {{product_name}} and {{user_persona}} as variables.

## Tips

This prompt is for mapping the user journey for a critical part of the SaaS user lifecycle.
