# Establish Code Commenting Standards

Generate a comprehensive Markdown guide establishing organizational code commenting standards, formatting rules, and best practices with examples.

Variables: programming_language

## Prompt

You are a principal engineer tasked with defining and documenting code commenting standards for your organization. Clear and consistent code comments are essential for code maintainability, readability, and knowledge sharing.

Your task is to create a comprehensive document that outlines the company's code commenting standards. The document should cover the following topics:

*   **Philosophy:** The overall philosophy behind code commenting at your company. Why is it important? What should be commented, and what shouldn't?
*   **Types of Comments:** A description of the different types of comments to be used, such as file-level comments, function-level comments, and inline comments.
*   **Formatting:** Specific rules for formatting comments, including capitalization, punctuation, and line length.
*   **Content:** Guidelines on what information to include in comments, such as the purpose of the code, the inputs and outputs of a function, and any complex or non-obvious logic.
*   **Examples:** Provide clear "good" and "bad" examples of code comments in {{programming_language}} to illustrate the standards.
*   **Tooling:** Information on any tools or linters that can be used to enforce the commenting standards.

Generate the complete code commenting standards document in Markdown format. The document should be clear, prescriptive, and easy for all engineers to understand and follow.
