# Create a Mobile-First Style Guide

Generate a comprehensive, mobile-first visual style guide including color palettes, typography, and responsive UI components for a new brand.

Variables: website_name, brand_guidelines

## Prompt

You are a UI designer. Your task is to create a mobile-first style guide for a new website, {{website_name}}. The style guide should define the visual design of the website, including the color palette, typography, and UI components. You need to start by designing the styles for the mobile version of the website, and then adapt them for larger screens. The output should be a comprehensive style guide document. Use {{website_name}} and {{brand_guidelines}} as variables.

## Tips

This prompt is for creating a consistent and scalable visual design for a website using a mobile-first approach.
