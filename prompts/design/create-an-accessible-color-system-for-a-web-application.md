# Create an Accessible Color System for a Web Application

Generate a WCAG-compliant color palette and accessibility style guide for web applications, ensuring optimal contrast and readability.

Variables: app_name, accessibility_standard

## Prompt

You are a UX/UI designer with a strong focus on accessibility. Your task is to create a comprehensive color system for a web application, {{app_name}}, that meets the WCAG 2.1 AA contrast ratio requirements. You need to define a primary color, a secondary color, and a set of neutral colors. For each color, you must provide a range of accessible shades and tints that can be used for text, backgrounds, and UI components. The output should be a style guide that documents the color system, including the hex codes for all the colors and examples of how to use them in an accessible way. Use {{app_name}} and {{accessibility_standard}} as variables.

## Tips

This is a crucial prompt for creating inclusive web applications that are usable by people with visual impairments.
