# Design a Mobile-First User Profile Page

Generate a high-fidelity, mobile-first social media profile mockup that scales personal data and activity feeds across different screens.

Variables: app_name, user_profile_elements

## Prompt

You are a UI designer. Your task is to design a mobile-first user profile page for a social networking app, {{app_name}}. The profile page should display the user's personal information, photos, and recent activity in a clear and concise way. You need to prioritize the most important information for the mobile view, and then progressively reveal more information on larger screens. The output should be a high-fidelity mockup of the mobile-first user profile page. Use {{app_name}} and {{user_profile_elements}} as variables.

## Tips

This prompt is for designing a common and important UI component for any social networking app.
