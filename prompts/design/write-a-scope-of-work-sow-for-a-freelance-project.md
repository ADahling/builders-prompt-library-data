# Write a Scope of Work (SOW) for a Freelance Project

Generate a comprehensive, structured Scope of Work in Markdown to define project deliverables, timelines, and payment terms for freelancers.

Variables: freelancer_role

## Prompt

You are hiring a freelance {{freelancer_role}} for a new project. You need to write a clear and detailed Scope of Work (SOW) to ensure that both you and the freelancer have a clear understanding of the project requirements and deliverables.

Your task is to generate a comprehensive SOW that includes the following sections:

*   **Project Overview:** A brief summary of the project.
*   **Deliverables:** A detailed list of the specific deliverables that the freelancer will be responsible for.
*   **Timeline:** A timeline for the project, with specific deadlines for each deliverable.
*   **Payment:** The payment terms for the project, including the total fee and the payment schedule.
*   **Assumptions:** A list of any assumptions that the SOW is based on.
*   **Acceptance Criteria:** The criteria that will be used to determine whether the deliverables are acceptable.

Generate the complete SOW in Markdown format.
