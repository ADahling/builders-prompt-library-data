# Design an Accessible Form

Generate high-fidelity, WCAG-compliant web form mockups optimized for screen readers, keyboard navigation, and logical field structures.

Variables: form_purpose, form_fields

## Prompt

You are a UI designer. Your task is to design a web form that is accessible to people with disabilities. The form should be designed to be easy to use with a keyboard, a screen reader, and other assistive technologies. You need to ensure that all form fields have clear labels, that error messages are displayed in an accessible way, and that the form has a logical tab order. The output should be a high-fidelity mockup of the accessible form. Use {{form_purpose}} and {{form_fields}} as variables.

## Tips

This prompt is for designing a common and important UI component: the web form.
