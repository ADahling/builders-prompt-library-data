# Create a Dark Mode Color Palette

Generate a WCAG-compliant dark mode style guide with accessible background, text, and accent colors tailored to specific brand identities.

Variables: website_name, brand_colors

## Prompt

You are a UI designer. Your task is to create a dark mode color palette for a new website, {{website_name}}. The color palette should be designed to be easy on the eyes in low-light environments, and it should also meet the WCAG 2.1 AA contrast ratio requirements. You need to choose a dark background color, a light text color, and a set of accent colors. The output should be a style guide that documents the dark mode color palette. Use {{website_name}} and {{brand_colors}} as variables.

## Tips

This prompt is for creating a visually appealing and accessible dark mode color palette for a website.
