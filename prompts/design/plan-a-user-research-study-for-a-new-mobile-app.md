# Plan a User Research Study for a New Mobile App

Generate a comprehensive UX research plan including methodology, participant criteria, and timelines to validate new skill-learning apps.

Variables: app_name, research_goals

## Prompt

You are a UX researcher. Your task is to plan a user research study for a new mobile app, {{app_name}}, that helps people learn a new skill. You need to define the research goals, choose the right research methods (e.g., user interviews, surveys, usability testing), and create a research plan that outlines the timeline, budget, and participants for the study. The output should be a detailed user research plan document. Use {{app_name}} and {{research_goals}} as variables.

## Tips

This prompt is for learning how to plan a comprehensive user research study for a new product.
