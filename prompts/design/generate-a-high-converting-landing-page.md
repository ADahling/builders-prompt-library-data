# Generate a High-Converting Landing Page

Get ready-to-paste landing page copy and layout guidance for your product, including CTAs, features, pricing, testimonials, and FAQs.

## Prompt

Build a complete landing page for [describe product in 1-2 sentences]:

1. Hero: Headline (max 10 words), subheadline (1-2 sentences), primary CTA, secondary CTA. Hero image concept.
2. Social Proof Bar: Credibility indicators.
3. Problem Section: 3 pain points in user language.
4. Solution: 3-column feature grid (icon, title, description).
5. How It Works: 3-step numbered process.
6. Features Deep Dive: 4-6 features with longer descriptions. Alternate image/text layout.
7. Testimonials: 3 realistic quotes with name, role, company.
8. Pricing: [describe tiers]. Feature comparison.
9. FAQ: 6-8 questions with answers.
10. Final CTA: Urgency headline + button.
11. Footer: Terms, Privacy, Contact, Social.

Write all copy ready to paste. Specify layout and components.
