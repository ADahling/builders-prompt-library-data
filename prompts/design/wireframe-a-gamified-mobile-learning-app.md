# Wireframe a Gamified Mobile Learning App

Design a language learning app's UI wireframes with integrated gamification features like leaderboards and badge systems to boost engagement.

Variables: app_name, language_taught

## Prompt

You are a UX designer specializing in gamification. Create a set of wireframes for a mobile learning app, {{app_name}}, that teaches users a new language. The wireframes should incorporate gamification elements to make the learning process more engaging and motivating. You need to design the following screens: a daily goal tracker, a leaderboard to compare progress with friends, a points and badges system, and a series of interactive quizzes. For each wireframe, describe how the gamification elements are integrated into the UI and how they contribute to the overall user experience. The output should be a set of wireframe descriptions with a focus on the motivational aspects of the design. Use {{app_name}} and {{language_taught}} as variables.

## Tips

This prompt is for designing apps that leverage gamification to improve user engagement and retention.
