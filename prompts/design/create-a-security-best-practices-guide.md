# Create a Security Best Practices Guide

Generate a comprehensive Markdown guide with language-specific code examples to implement secure coding standards across an organization.

Variables: programming_language

## Prompt

You are a security engineer responsible for promoting secure coding practices within your organization. You need to create a security best practices guide for developers to help them write more secure code.

Your task is to generate a comprehensive guide that covers the following topics:

*   **Input Validation:** Best practices for validating and sanitizing user input to prevent injection attacks.
*   **Authentication and Authorization:** Guidelines for implementing secure authentication and authorization mechanisms.
*   **Cryptography:** Recommendations for using cryptography to protect sensitive data.
*   **Error Handling and Logging:** Best practices for handling errors and logging security-related events.
*   **Dependency Management:** Advice on how to manage third-party dependencies securely.

For each topic, provide clear explanations and code examples in {{programming_language}} to illustrate the best practices.

Generate the complete security best practices guide in Markdown format.
