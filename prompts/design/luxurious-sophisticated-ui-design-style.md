# Luxurious & Sophisticated UI Design Style

Design an app page with a luxury visual style using deep colors, metallic accents, serif headings, generous spacing, and subtle animations.

Variables: page_type, app_name

## Prompt

Design a {{page_type}} for {{app_name}} using a luxurious and sophisticated visual style. Apply these design principles:

**Color Palette**: Use rich, deep tones — midnight blue, burgundy, forest green, or charcoal. Accent with gold (#c9a96e), rose gold, or champagne. Never use pure white — use off-white (#faf9f6).
**Typography**: Use an elegant serif font (Playfair Display, Cormorant) for headings. Generous letter-spacing (0.05-0.1em). Use small-caps for labels and navigation.
**Layout**: Use generous margins (80-120px). Asymmetric layouts with intentional negative space. Content should feel curated, not crammed.
**Imagery**: Use high-end photography with subtle color grading. Implement Ken Burns effect on hero images. Use image masks and blend modes.
**Borders & Dividers**: Use thin gold or metallic lines as dividers. Subtle border animations on hover.
**Micro-details**: Add subtle texture overlays (linen, marble), animated gradient borders, and smooth page transitions.

Key vocabulary: opulent, refined, exclusive, bespoke, heritage, artisan, timeless, couture.

The design should feel like walking into a five-star hotel — every detail considered, nothing accidental.
