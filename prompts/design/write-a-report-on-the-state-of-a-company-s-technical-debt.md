# Write a Report on the State of a Company's Technical Debt

Generate a structured architectural report assessing technical debt impacts and providing actionable remediation strategies for stakeholders.

## Prompt

You are a software architect who has been tasked with assessing the state of your company's technical debt. You need to write a report to present your findings to senior management.

Your task is to generate a comprehensive report that includes the following sections:

*   **Executive Summary:** A high-level overview of the key findings and recommendations.
*   **Methodology:** A description of the methodology you used to assess the technical debt.
*   **Findings:** A detailed presentation of your findings, with specific examples of technical debt in the codebase.
*   **Impact:** An analysis of the impact of the technical debt on the company, such as reduced productivity, increased costs, and lower quality.
*   **Recommendations:** A list of specific recommendations for addressing the technical debt.

Generate the complete report in Markdown format.
