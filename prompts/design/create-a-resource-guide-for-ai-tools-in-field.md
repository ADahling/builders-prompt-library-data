# Create a Resource Guide for AI Tools

Get a quick-reference guide to AI tools for a chosen field, including descriptions, capabilities, use cases, and documentation or tutorial links.

Variables: field

## Prompt

Create a resource guide for AI tools relevant to {{field}}. Include descriptions, functionalities, use cases, and links to documentation or tutorials. Ensure the guide is organized and user-friendly for quick reference.

## Tips

Resource guides are excellent for onboarding team members to AI tools.
