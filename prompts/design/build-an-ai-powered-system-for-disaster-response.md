# Build an AI-Powered System for Disaster Response

Architect an AI-driven disaster management system that integrates multi-source data to optimize damage assessment and rescue coordination.

Variables: disaster_type

## Prompt

You are a disaster management expert. I want to build an AI-powered system to improve the effectiveness of disaster response efforts. The system will use data from satellite imagery, social media, and on-the-ground reports to assess damage, identify needs, and coordinate rescue operations. The system will be used for responding to {{disaster_type}} disasters.

Design the AI system for disaster response. The design should include the data fusion platform, the damage assessment models, and the resource allocation optimization engine.
