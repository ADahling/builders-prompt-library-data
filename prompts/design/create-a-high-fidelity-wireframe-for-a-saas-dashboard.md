# Create a High-Fidelity Wireframe for a SaaS Dashboard

Generate a detailed textual specification for a high-fidelity SaaS CRM dashboard including grid layouts, typography, and visual components.

Variables: saas_product_name, dashboard_metrics

## Prompt

You are a senior product designer. Your task is to create a single, detailed, high-fidelity wireframe for the main dashboard of a SaaS application called 'SalesLeap', which is a CRM for small businesses. This wireframe should be much more detailed than a low-fidelity one and include specific UI components, typography choices, and spacing. The dashboard needs to display the following key information: Monthly Recurring Revenue (MRR), New Customers this month, a list of recent activities, a sales pipeline, and a chart showing sales performance over the last 6 months. You must specify the exact layout using a grid system (e.g., a 12-column grid), define the font sizes and weights for all text elements, and suggest a color palette (using hex codes) for the UI components. The output should be a detailed textual description of the wireframe, broken down into sections for each component on the dashboard. Use {{saas_product_name}} and {{dashboard_metrics}} as variables.

## Tips

This prompt is for generating a more polished wireframe that can be used for user testing or as a direct reference for front-end development.
