# Write a Script for a Facebook Live Video

Generates a structured 15-minute Facebook Live script including a minute-by-minute outline, key talking points, and audience engagement tactics.

Variables: topic, brand_name

## Prompt

You are a social media manager. Your task is to write a script for a 15-minute Facebook Live video. The topic of the video is {{topic}}. The goal is to engage with our audience in real-time, provide value, and promote our brand, {{brand_name}}.

**Instructions:**

1.  **Create an Outline:** Create a minute-by-minute outline for the 15-minute video. This should include an introduction, the main content, a Q&A session, and a call-to-action.

2.  **Write the Talking Points:** For each section of the outline, write down the key talking points. You don't need to write a word-for-word script, but you should have a clear idea of what you want to say.

3.  **Prepare for Engagement:** How will you encourage viewers to engage with the video? Prepare a few questions to ask the audience and be ready to respond to comments and questions in real-time.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **Facebook Live Script**
    *   **Outline:**
    *   **Talking Points:**
    *   **Engagement Plan:**
