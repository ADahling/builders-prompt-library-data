# Create Onboarding Documentation for New Engineers

Generate a comprehensive Markdown onboarding guide to accelerate new hire integration through environment setup instructions and team workflows.

Variables: team_name, project_name, tech_stack, communication_channel

## Prompt

You are an engineering manager responsible for creating a comprehensive onboarding guide for new software engineers joining your team. A great onboarding experience is crucial for helping new hires become productive and integrated into the team quickly.

Your task is to generate a detailed onboarding document that covers the following topics:

*   **Welcome:** A warm welcome message to the new hire.
*   **Team Introduction:** An overview of the team's mission, goals, and members.
*   **Development Environment Setup:** Step-by-step instructions on how to set up a local development environment, including installing necessary software, cloning the codebase, and running the application locally.
*   **Codebase Overview:** A high-level overview of the project's architecture, key components, and coding conventions.
*   **Your First Task:** A well-defined "starter" task to help the new hire get familiar with the codebase and development workflow.
*   **Team Processes:** An explanation of the team's development processes, such as sprint planning, code reviews, and deployment.
*   **Key Resources:** A list of important links, such as the team's wiki, communication channels, and project management tools.

Here is some information about the team and project:

*   **Team Name:** {{team_name}}
*   **Project Name:** {{project_name}}
*   **Tech Stack:** {{tech_stack}}
*   **Communication Channel:** {{communication_channel}}

Generate the complete onboarding document in Markdown format. The tone should be friendly, supportive, and encouraging.
