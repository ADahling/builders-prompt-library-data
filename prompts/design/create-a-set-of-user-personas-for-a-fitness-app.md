# Create a Set of User Personas for a Fitness App

Generate detailed UX personas with backstories, goals, and pain points to inform the design and community features of a new fitness app.

Variables: app_name, user_groups

## Prompt

You are a UX researcher. Your task is to create a set of 3-4 user personas for a new fitness app, {{app_name}}. The app is designed to help users track their workouts, set fitness goals, and connect with a community of other fitness enthusiasts. You need to create personas that represent the different user groups of the app, such as a beginner who is just starting their fitness journey, an experienced athlete who is training for a competition, and a busy professional who is trying to stay active. For each persona, you need to create a name, a photo, a backstory, and a set of goals and frustrations. The output should be a document that presents the user personas. Use {{app_name}} and {{user_groups}} as variables.

## Tips

This is a beginner-friendly prompt for learning how to create user personas for a new product.
