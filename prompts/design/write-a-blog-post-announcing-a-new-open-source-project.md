# Write a Blog Post Announcing a New Open-Source Project

Generate a structured, enthusiastic blog post to launch an open-source AI project, featuring code examples and contributor calls-to-action.

Variables: project_name, project_type, solve_problem

## Prompt

I am launching a new open-source AI project called `{{project_name}}` and need to write a compelling blog post to announce it to the world. The project is a `{{project_type}}` (e.g., library, tool) that helps developers `{{solve_problem}}`.

Your task is to generate a complete draft for this announcement blog post. The tone should be enthusiastic, informative, and professional. The goal is to get developers excited about the project, encourage them to try it out, and invite them to contribute.

The blog post should have the following structure:

1.  **Catchy Title**: A title that grabs attention and clearly communicates what the project is.
    *   Example: "Introducing {{project_name}}: A New Open-Source Library for [...]."

2.  **Introduction**: 
    *   Start with a relatable problem that developers in your target audience face.
    *   Introduce `{{project_name}}` as the solution to this problem.
    *   Briefly explain what the project does in one or two sentences.

3.  **The "Why": Motivation and Philosophy**:
    *   Explain the motivation behind creating the project. What gap did you see in the existing ecosystem?
    *   Share the project's core philosophy (e.g., simplicity, performance, extensibility).

4.  **Key Features and a Compelling Example**:
    *   Highlight 3-4 key features of the project in a bulleted list.
    *   Provide a simple, well-explained code snippet that shows the project in action. This is the most important part of the post.
    *   Keep the example clean and focused on the core value proposition.

5.  **Getting Started**: 
    *   Tell readers how to install and start using the project (e.g., `pip install {{project_name}}\
    *   Link to the GitHub repository and the full documentation.

6.  **The Future: Roadmap and How to Contribute**:
    *   Briefly mention what's next for the project. What features are you planning to add?
    *   Make a clear call to action for contributions. Explain that the project is community-driven and welcome all forms of help (code, docs, bug reports).
    *   Link to the `CONTRIBUTING.md` file and point out any `good first issues`.

7.  **Closing**: 
    *   End with a final, enthusiastic call to action. Encourage readers to check out the GitHub repo, give it a star, and join the community.

3.  Is the code example simple and effective? Yes.
4.  Is there a clear call to action for users and contributors? Yes.
5.  Is the tone appropriate for a launch announcement? Yes.
