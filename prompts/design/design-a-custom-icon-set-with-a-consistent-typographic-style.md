# Design a Custom Icon Set with a Consistent Typographic Style

Generate a custom SVG icon set and design guide tailored to a specific app's typography for visual brand consistency.

Variables: app_name, typeface_name

## Prompt

You are a graphic designer. Your task is to design a custom icon set of 20 icons for a mobile app, {{app_name}}. The icons should be designed to be consistent with the app's primary typeface, {{typeface_name}}. This means that the icons should have a similar weight, style, and personality as the typeface. The output should be a set of SVG files for the icons and a style guide that explains the design principles behind the icon set. Use {{app_name}} and {{typeface_name}} as variables.

## Tips

This is an advanced prompt for creating a cohesive and branded visual language by aligning the style of icons with the typography.
