# Develop Use Cases for AI Tools in Business Functions

Get AI tool use cases for a business function, describing process improvements, expected outcomes, implementation prerequisites, and available examples.

Variables: business_function

## Prompt

Develop specific use cases that demonstrate how AI tools can be utilized in {{business_function}}. Describe the processes improved by these tools, the expected outcomes, and any necessary prerequisites for implementation. This should include real-world examples if available.

## Tips

Use cases will help stakeholders visualize the impact of AI tools.
