# Redesign a Desktop-First Website with a Mobile-First Approach

Convert desktop sites into responsive wireframes using a mobile-first philosophy to prioritize core functionality across all screen sizes.

Variables: website_url, core_functionality

## Prompt

You are a UX/UI designer. Your task is to redesign an existing desktop-first website, {{website_url}}, using a mobile-first approach. You need to start by designing the mobile version of the website, focusing on the essential content and functionality. Then, you can progressively enhance the design for larger screens, adding more features and content as the screen real estate increases. The output should be a set of wireframes that show the design of the website on different screen sizes, from mobile to desktop. Use {{website_url}} and {{core_functionality}} as variables.

## Tips

This prompt is for designers who want to practice the mobile-first approach to responsive design.
