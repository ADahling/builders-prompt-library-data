# Creating Release Notes

Write a project release notes template with sections for new features, bug fixes, known issues, and upgrade instructions, plus a release example.

Variables: project_name

## Prompt

Write a template for release notes to be used for {{project_name}}. Include sections for new features, bug fixes, known issues, and upgrade instructions. Provide an example of a recent release.

## Tips

Make release notes concise but informative.
