# Write Accessible Alt Text for Images

Generate concise, accurate, and descriptive alt text for images to ensure web content accessibility for visually impaired users.

Variables: image_urls, image_context

## Prompt

You are a content creator. Your task is to write accessible alt text for a set of images, {{image_urls}}. The alt text should describe the content of the images for people who are blind or have low vision. You need to write alt text that is concise, accurate, and descriptive. The output should be a document that lists the alt text for each image. Use {{image_urls}} and {{image_context}} as variables.

## Tips

This is a beginner-friendly prompt for learning how to write accessible alt text for images.
