# Create a Set of Architectural Principles for a Company

Establish foundational guidelines for software development by defining enterprise-wide standards for simplicity, scale, security, and cost.

## Prompt

You are the chief architect of a large enterprise. You need to create a set of architectural principles to guide the design and development of all new software systems.

Your task is to generate a set of architectural principles that covers the following topics:

*   **Simplicity:** The importance of simplicity in software design.
*   **Scalability:** The importance of designing systems that can scale to meet future demand.
*   **Reliability:** The importance of designing systems that are reliable and resilient to failure.
*   **Security:** The importance of designing systems that are secure.
*   **Cost-effectiveness:** The importance of designing systems that are cost-effective.

Generate the complete set of architectural principles in Markdown format.
