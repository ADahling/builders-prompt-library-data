# Design a Responsive Blog Layout

Create responsive, typography-focused wireframes for a blog layout that ensures optimal readability and visual hierarchy across all devices.

Variables: blog_name, content_types

## Prompt

You are a web designer. Your task is to design a responsive layout for a blog, {{blog_name}}. The layout should be optimized for readability on all devices. You need to choose a readable typeface, set a comfortable line length, and use a clear visual hierarchy. You should also consider how to display images and other media in a way that enhances the reading experience. The output should be a set of wireframes that show the design of the blog layout on different screen sizes. Use {{blog_name}} and {{content_types}} as variables.

## Tips

This prompt is for designing a user-friendly and readable layout for a blog.
