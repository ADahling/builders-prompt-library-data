# Wireframe a Settings Page for a Customizable SaaS Product

Generate structured wireframe descriptions for a complex SaaS settings page with logical tabbed navigation and diverse UI controls.

Variables: product_name, settings_categories

## Prompt

You are a UX/UI designer. Your task is to create a wireframe for the settings page of a highly customizable SaaS product, {{product_name}}. The settings page needs to be well-organized and easy to navigate, as it will contain a large number of options. You should use a tabbed navigation to group the settings into logical categories, such as 'Account', 'Billing', 'Notifications', and 'Integrations'. For each tab, wireframe the layout of the settings, using appropriate UI controls like toggles, dropdowns, and input fields. The output should be a set of wireframe descriptions, one for each tab, that clearly illustrates the structure and organization of the settings page. Use {{product_name}} and {{settings_categories}} as variables.

## Tips

This prompt focuses on information architecture and designing user-friendly settings pages for complex applications.
