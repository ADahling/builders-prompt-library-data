# Write a Comparison of Two Open-Source Libraries

Generate a comprehensive Markdown blog post comparing two open-source libraries with code snippets, performance analysis, and use-case recommendations.

Variables: purpose, library_one_name, library_two_name

## Prompt

As a developer advocate for open-source AI, I need to write a blog post that provides a fair and detailed comparison of two popular libraries for `{{purpose}}`: `{{library_one_name}}` and `{{library_two_name}}`.

The goal is not to declare one as definitively "better" but to help developers choose the right tool for their specific needs.

Generate a complete blog post in Markdown format that compares the two libraries across several key criteria.

The post should have the following structure:

1.  **Title**: An engaging title, e.g., "{{library_one_name}} vs. {{library_two_name}}: Which is Right for Your Next Project?"

2.  **Introduction**: 
    *   Briefly introduce both libraries and the problem they solve.
    *   State the goal of the post: to provide a balanced comparison to aid in decision-making.

3.  **Comparison Criteria**: For each of the following criteria, provide a detailed analysis of how each library performs. Use code snippets where appropriate to illustrate your points.
    *   **Ease of Use / API Design**: How intuitive is the API? How steep is the learning curve? Show a simple "hello world" example for each.
    *   **Performance**: How do they compare in terms of speed or resource usage for a typical task? (You can cite existing benchmarks or describe the architectural differences that affect performance).
    *   **Features and Extensibility**: What are the unique features of each library? How easy is it to extend or customize their functionality?
    *   **Documentation and Community**: How good is the documentation? How active is the community (GitHub stars, contributors, forum activity)?

4.  **When to Choose Which**: Create a summary section with clear recommendations:
    *   **Choose `{{library_one_name}}` if...**: List 2-3 scenarios or priorities where this library excels (e.g., "...if you prioritize raw performance and have a complex use case.").
    *   **Choose `{{library_two_name}}` if...**: List 2-3 scenarios where this library is a better fit (e.g., "...if you are a beginner and need to get started quickly.").

5.  **Conclusion**: A brief summary that reiterates that both libraries are excellent tools and the best choice depends on the specific context of the project.

Constraint Checklist & Confidence Score:
1.  Is the comparison balanced and fair to both libraries? Yes.
2.  Does the analysis cover all the specified criteria (ease of use, performance, etc.)? Yes.
3.  Are the recommendations in the "When to Choose" section clear and practical? Yes.
4.  Is the post well-structured and easy to read? Yes.
5.  Is the output a complete Markdown document? Yes.
