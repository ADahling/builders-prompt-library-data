# Write a Performance Review for an Employee

Generate a structured, constructive performance evaluation featuring key accomplishments, growth areas, and measurable future goals in Markdown.

Variables: employee_name

## Prompt

You are a manager who needs to write a performance review for one of your direct reports, {{employee_name}}. The review should be fair, constructive, and motivating.

Your task is to generate a performance review that includes the following sections:

*   **Overall Performance Summary:** A summary of the employee's performance over the review period.
*   **Accomplishments:** A list of the employee's key accomplishments.
*   **Areas for Improvement:** A constructive discussion of the employee's areas for improvement.
*   **Goals for Next Review Period:** A set of specific and measurable goals for the next review period.

Generate the complete performance review in Markdown format.
