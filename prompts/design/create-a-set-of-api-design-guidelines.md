# Create a Set of API Design Guidelines

Establish comprehensive RESTful standards for resource naming, status codes, and security to ensure consistency across enterprise API development.

## Prompt

You are a lead API architect at a large enterprise. To ensure consistency and quality across all of your company's APIs, you need to create a set of API design guidelines.

Your task is to generate a comprehensive set of guidelines that covers the following topics:

*   **Resource Naming:** Guidelines for naming resources and their URLs.
*   **HTTP Methods:** Guidelines for using HTTP methods (GET, POST, PUT, DELETE) correctly.
*   **Request and Response Formats:** Guidelines for formatting request and response bodies.
*   **Status Codes:** Guidelines for using HTTP status codes correctly.
*   **Error Handling:** Guidelines for handling errors and returning meaningful error messages.
*   **Versioning:** Guidelines for versioning your APIs.
*   **Security:** Guidelines for securing your APIs.

Generate the complete API design guidelines in Markdown format.
