# Build a Modal Component for a Component Library

Create a fully accessible, customizable modal component for your component library, with focus trapping and complete documentation.

Variables: framework, modal_props

## Prompt

You are a front-end developer. Your task is to build a reusable modal component for a component library using {{framework}}. The modal component should be highly customizable, with props for controlling its size, position, and content. You should also include support for accessibility features, such as trapping focus within the modal and closing it with the escape key. The output should be the complete code for the modal component, along with documentation on how to use it. Use {{framework}} and {{modal_props}} as variables.

## Tips

This prompt is for building a common and important UI component: the modal.
