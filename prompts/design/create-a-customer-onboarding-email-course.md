# Create a Customer Onboarding Email Course

Generate a 5-day educational email sequence to fast-track software onboarding and drive early user engagement through actionable lessons.

Variables: software_name

## Prompt

You are an email marketing and customer education expert. Your task is to create a 5-day email course to onboard new users of our software, {{software_name}}. The goal of the course is to help users understand the key features of the software and achieve their first win as quickly as possible.

**Instructions:**

1.  **Outline the 5-Day Course:** For each day of the course, define a clear learning objective and the key topics that will be covered in the email.

2.  **Write the First Email of the Course:** Write the full copy for the first email in the course. The email should welcome the user, set expectations for the course, and provide the first lesson.

3.  **Include a Call-to-Action in Each Email:** Each email should have a clear call-to-action that encourages the user to take a specific action within the software.

**Output Format:**

Please provide your response in a structured Markdown format with the following sections:

*   **Email Onboarding Course Outline:**
*   **Day 1 Email Copy:**

This prompt helps users create an email onboarding course to improve user activation and retention for their software product.
