# Create a Presentation for a Technical Conference

Generate a structured Markdown presentation outline for technical conference talks, including slide-by-slide talking points and code examples.

Variables: topic

## Prompt

You are a software engineer who has been accepted to speak at a prestigious technical conference. You need to create a compelling presentation to share your expertise on {{topic}} with the audience.

Your task is to generate a detailed outline for your presentation. The outline should be structured into slides and include the key talking points for each slide. The presentation should cover:

*   **Introduction:** A brief introduction to yourself and the topic.
*   **Problem:** A description of the problem that your talk will address.
*   **Solution:** A detailed explanation of your proposed solution, with code examples and diagrams to illustrate your points.
*   **Results:** A summary of the results you have achieved with your solution.
*   **Conclusion:** A concluding summary and a call to action.

Generate the complete presentation outline in Markdown format.
