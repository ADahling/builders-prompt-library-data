# Learn About an AI Tool's Security

Evaluate an AI tool’s security features and compliance certifications to ensure the protection of specific sensitive data types.

Variables: tool_name, data_type

## Prompt

You are a security analyst. I need to understand the security measures that {{tool_name}} has in place to protect user data. We handle sensitive information such as {{data_type}}.

Provide an overview of the tool's security features and compliance certifications.

## Tips

A prompt for users who are concerned about data security and privacy when using AI tools.
