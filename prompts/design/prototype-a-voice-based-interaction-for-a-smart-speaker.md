# Prototype a Voice-Based Interaction for a Smart Speaker

Generate a detailed, multi-path conversational script for a voice-activated pizza ordering system including error handling and confirmation.

Variables: device_name, pizza_chain_name

## Prompt

You are a conversation designer. Your task is to prototype a voice-based interaction for a smart speaker, {{device_name}}, that allows users to order a pizza from a fictional pizza chain, {{pizza_chain_name}}. The prototype should be a script that outlines the complete conversation between the user and the smart speaker, from initiating the order to confirming the delivery address and payment. You need to consider different conversational paths, including handling errors, offering suggestions, and confirming the user's choices. The output should be a detailed conversational script, including both the user's and the speaker's dialogue. Use {{device_name}} and {{pizza_chain_name}} as variables.

## Tips

This advanced prompt focuses on prototyping for voice user interfaces, which requires a deep understanding of natural language processing and conversational design principles.
