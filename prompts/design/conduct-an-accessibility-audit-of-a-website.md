# Conduct an Accessibility Audit of a Website

Generate a comprehensive WCAG 2.1 AA compliance report with reproduction steps and remediation advice for a specific web URL.

Variables: website_url, accessibility_tools

## Prompt

You are an accessibility consultant. Your task is to conduct an accessibility audit of a website, {{website_url}}, to identify any issues that may prevent people with disabilities from using the website. You need to use a combination of automated tools and manual testing to check for compliance with the WCAG 2.1 AA guidelines. The output should be a detailed audit report that lists all the accessibility issues you found, with screenshots, steps to reproduce them, and recommendations for how to fix them. Use {{website_url}} and {{accessibility_tools}} as variables.

## Tips

This prompt is for learning how to conduct a comprehensive accessibility audit of a website.
