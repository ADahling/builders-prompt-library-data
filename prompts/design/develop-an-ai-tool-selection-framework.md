# Develop an AI Tool Selection Framework

Establish a standardized evaluation framework to select secure, scalable AI tools aligned with specific organizational goals and governance.

Variables: industry, employee_count

## Prompt

You are a senior AI strategist. My organization, a {{industry}} company with {{employee_count}} employees, needs to develop a standardized framework for selecting new AI tools. The framework should ensure that we choose tools that are secure, scalable, and aligned with our business goals.

Outline a comprehensive AI tool selection framework. The framework should include key evaluation criteria, a scoring methodology, and a process for involving stakeholders from different departments (e.g., IT, legal, finance).

## Tips

A prompt for organizations that want to establish a systematic process for procuring AI tools.
