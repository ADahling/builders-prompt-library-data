# Design a Responsive Contact Form

Create high-fidelity mockups of mobile-friendly, responsive contact forms with clear validation and touch-optimized inputs.

Variables: website_name, form_fields

## Prompt

You are a UI designer. Your task is to design a responsive contact form for a business website, {{website_name}}. The form should be easy to use on all devices, with large, touch-friendly input fields and a clear call-to-action button. You need to consider how the form will be displayed on different screen sizes, and how to handle validation errors in a mobile-friendly way. The output should be a high-fidelity mockup of the responsive contact form. Use {{website_name}} and {{form_fields}} as variables.

## Tips

This prompt is for designing a common and important UI component: the contact form.
