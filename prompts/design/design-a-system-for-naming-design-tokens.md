# Design a System for Naming Design Tokens

Get a design token naming document with a structured convention and category examples for designers and developers in a growing design system.

Variables: design_system_name, token_categories

## Prompt

You are a design systems architect. Your task is to design a clear, consistent, and scalable system for naming design tokens in your company's design system, {{design_system_name}}. The naming convention should be easy to understand for both designers and developers, and it should be able to accommodate future growth of the design system. You need to define a structure for the token names, for example, using a `category-property-variant` format. The output should be a document that explains the naming convention and provides examples of how to name different types of tokens. Use {{design_system_name}} and {{token_categories}} as variables.

## Tips

This prompt is for creating a robust and future-proof naming system for design tokens, which is a crucial foundation for any design system.
