# Develop an AI-Powered System for Financial Fraud Detection

Design a compliant, real-time fraud detection architecture featuring automated data pipelines, ML models, and investigator workflows.

Variables: data_source, regulations

## Prompt

You are a financial crime investigator. I need to develop an AI-powered system to detect and prevent financial fraud in real-time. The system will analyze transaction data from {{data_source}} to identify suspicious activities. The system must comply with {{regulations}}.

Design the architecture for the fraud detection system. The design should include the data pipeline, the machine learning models for anomaly detection, and the case management system for investigators.
