# Identify and Prioritize Pain Points in a User Journey

Prioritize user journey friction using a severity-frequency matrix to deliver a ranked roadmap of actionable product improvements.

Variables: product_name, user_journey_map

## Prompt

You are a product manager. You have a user journey map for a product, {{product_name}}, but you are not sure which pain points to address first. Your task is to identify and prioritize the pain points in the user journey. You need to use a framework, such as the severity-frequency matrix, to prioritize the pain points. The output should be a prioritized list of pain points, with a brief description of each pain point and a recommendation for how to address it. Use {{product_name}} and {{user_journey_map}} as variables.

## Tips

This prompt is for learning how to identify and prioritize pain points in a user journey to focus your design and development efforts.
