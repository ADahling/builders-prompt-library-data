# Create a Negative Persona to Identify Undesirable Users

Define and document problematic user segments by generating detailed profile archetypes to refine product positioning and fraud prevention.

Variables: product_name, undesirable_user_characteristics

## Prompt

You are a product manager. Your task is to create a negative persona for a product, {{product_name}}. A negative persona is a fictional character that represents a user that you do not want to use your product. This could be a user who is likely to abuse the product, a user who is not a good fit for the product, or a user who is likely to churn. You need to create a name, a photo, a backstory, and a set of goals and frustrations for your negative persona. The output should be a document that presents the negative persona. Use {{product_name}} and {{undesirable_user_characteristics}} as variables.

## Tips

This is an advanced prompt for learning how to create a negative persona to help you design a product that is more resilient to abuse and that is more likely to attract and retain the right users.
