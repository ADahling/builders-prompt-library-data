# Write a User Manual for a Desktop Application

Get a Markdown desktop app manual organized into chapters covering installation, the interface, feature instructions, and troubleshooting.

Variables: application_name, feature_1, feature_2, feature_3

## Prompt

You have developed a new desktop application, {{application_name}}, and you need to create a user manual to help users understand how to use it.

Your task is to generate a comprehensive user manual that covers all the features of your application. The manual should be organized into chapters and include:

*   **Introduction:** An overview of the application and its purpose.
*   **Getting Started:** Instructions on how to install and launch the application.
*   **User Interface:** A detailed description of the application's user interface, with screenshots to illustrate the different components.
*   **Features:** A chapter for each major feature, with step-by-step instructions on how to use it.
*   **Troubleshooting:** A section that provides solutions to common problems.

Here is some information about your application:

*   **Application Name:** {{application_name}}
*   **Key Features:** {{feature_1}}, {{feature_2}}, {{feature_3}}

Generate the complete user manual in Markdown format.
